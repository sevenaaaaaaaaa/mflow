# Lovart RULES — 10 报告类（Reports）

> 适用路线：SEO 报告、舆情报告、竞品报告、SERP 报告、OKR 完成度
> 加载 Profile：`lovart-reports`

---

## 一、硬条款（违反即重出）

1. **必须**每份报告、每个维度都有环比（**禁止**只出 snapshot）
2. **必须**环比格式 = 绝对变化 + 百分比（`↓-218,884 / -27.9%`）
3. **必须** GSC 关键词给全：点击 + 曝光 + CTR 三者环比
4. 天数不等时**必须**用日均值
5. **必须**按月报 V2 的 13 章节固定顺序输出（见 §三），不得缺章或改序
6. **必须**每章附 💡 洞察（问题/根源/缓解）+ 📊 年均对比
7. **必须**品牌词用 `lovart_brand_match.py` 的 regex（改词只改一处，**禁止**各处硬编码）
8. **必须**用『有曝光 URL / 语料库 20,000』作为收录主口径（**禁止**用 sitemap 提交量 ÷1000）
9. Sentinel 舆情**必须** 8 板块齐全；与 SEO 报告分界（**禁止**混入 OKR 看板/关键词分层）
10. Agent 跑报告前**必须**确认 OKR 版本（默认 2026-05；用户未确认不得沿用旧值）

## 二、参数表

### 环比基准

| 报告 | 环比基准 |
|------|----------|
| 日报 | 前日（D vs D-1） |
| 自然周报 | 上上周同期（周一～周日） |
| 复盘周报 | 上上周三～上周二 |
| 月报 / 季报 / 年报 | 上一自然月 / 季 / 年 |

### OKR 目标（默认 2026-05 版）

| OKR | 指标 | 月目标 |
|-----|------|:-----:|
| O1 | Organic UV | 960,000 |
| O1 | 注册（估） | 360,000 |
| O1 | 付费（估） | 22,800 |
| O3 | Referral UV | 360,000 |

转化率：O1 UV→注册 37.5%，注册→付费 6.3%；O3 UV→注册 11.7%，注册→付费 7.1%

### 报告结构（SEO 月报 V2，13 章节固定顺序）

一(核心洞察) → 二(OKR看板) → 三(Dashboard A-F + C-Bing/D-Bing/E-Bing) → 四(关键词分层 Google+Bing) →
五(GA4用户数据) → 六(DataWorks产品数据) → 七(品牌vs非品牌) → 八(竞品非品牌词) → 九(页面目录流量) →
十(页面查询明细) → 十一(分地区) → 十二(TODO) → 十三(Bing补充)

- 关键词表：点击+曝光+CTR + 三者环比 + 点击占比+曝光占比
- 地区每区 mini 月报 + Top15 品牌/非品牌词 + Top10 页面
- 代码 SSOT：`seo_monthly_v2.py` + `lovart_brand_match.py`

### 竞品词 / 舆情 / 数据量

- 竞品词库：265 全量 / 36 核心；子串匹配；输出命中数、覆盖率、分层表现、缺失分析
- Sentinel 8 板块：关键指标 + 摘要核心发现 + 搜索舆情 + 社媒数据 + 品牌形象 + 用户画像 + 风险机遇 + SWOT+监测阈值 + 行动清单
- GSC 数据量：月报 5000 词 / 周报 2000 词 / 日报 200 词；维度 query/country/page/country×query/device；有 2 天延迟
