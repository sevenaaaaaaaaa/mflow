# 季节性内容日历（12个月 × 行业）

> 设计行业的需求有强季节性，v2 完全没有规划日历驱动的内容
> 本文档规划每月的主题设计内容，覆盖核心行业

---

## 一、季节性内容策略

### 1.1 为什么需要季节性内容

| 理由 | 说明 |
|------|------|
| **SEO 时效性** | "Valentine's Day design" 每年1月开始有搜索量，2月初达到峰值 |
| **用户需求匹配** | 用户在特定时间有特定设计需求，提供及时内容 = 高转化 |
| **社媒传播** | 节日内容天然有社交分享属性 |
| **复用价值** | 每年更新同一主题内容，成本递减、排名递增 |
| **行业覆盖** | 不同行业有不同的季节性峰值 |

### 1.2 内容类型

每月发布**两类**季节性内容：

| 类型 | 说明 | 页面类型 |
|------|------|---------|
| **设计模板包** | 可直接使用的模板集合 + 使用教程 | Marketplace + Detail Page (How-To) |
| **行业营销指南** | 针对特定行业的季节性营销策略 | Detail Page (Segment / How-To) |

### 1.3 发布节奏

```
每月1日：发布当月主题设计模板包
每月15日：发布下月预告（制造期待）
节日前30天：SEO 内容上线（抢占搜索窗口）
节日前14天：社媒推广启动
节日前7天：Email 推送
节日当天：社媒互动 + 用户作品征集
```

## 三、季节性内容模板包结构

每个模板包的**标准产出**：

| 产出物 | 数量 | 格式 |
|--------|------|------|
| Instagram Post 模板 | 5-8 个 | 1080×1080 |
| Instagram Story 模板 | 3-5 个 | 1080×1920 |
| Facebook Cover 模板 | 1-2 个 | 820×312 |
| LinkedIn Banner 模板 | 1-2 个 | 1584×396 |
| Twitter/X Header 模板 | 1-2 个 | 1500×500 |
| 印刷物料（海报/传单） | 2-3 个 | A4/A5 |
| Email Header 模板 | 1-2 个 | 600×200 |
| 配套博客教程 | 1 篇 | 1500-2500字 |
| 配套 Prompt 模板 | 1 份 | 文本 |

**总计**：每个季节性模板包 = 15-25 个模板 + 1 篇教程 + 1 份 Prompt
