# Social Media Image Size Guide 2026: Complete Dimensions Reference

## Are Your Social Media Images the Right Size?

Nothing undermines a professional social media presence faster than poorly sized images — stretched logos, cropped-out text, pixelated graphics, and awkward letterboxing. Each platform has its own dimension specifications, and they change regularly. What was correct in 2025 may already be outdated in 2026.

This guide provides the definitive, up-to-date image dimensions for every major social media platform as of May 2026. Bookmark this page — we update it quarterly as platforms change their specifications.

## Instagram Image Sizes 2026

Instagram supports more image formats than any other platform. Getting dimensions right for each format is critical — incorrect sizing triggers automatic cropping that can cut off key visual elements.

| Format | Dimensions (px) | Aspect Ratio | Notes |
|---|---|---|---|
| Square post | 1080 x 1080 | 1:1 | Standard feed post. Minimum 320px width. |
| Portrait post | 1080 x 1350 | 4:5 | Maximum vertical ratio before cropping to square in grid view. |
| Landscape post | 1080 x 566 | 1.91:1 | Maximum horizontal ratio. |
| Story | 1080 x 1920 | 9:16 | Full-screen vertical. Keep key content within 1080 x 1420 safe zone to avoid UI overlap. |
| Reels cover | 1080 x 1920 | 9:16 | Displayed in grid at 1:1 crop from center. Place key visual in center square. |
| Profile picture | 320 x 320 | 1:1 | Displays at 110 x 110 px circular crop. |
| Carousel post | 1080 x 1080 | 1:1 | All slides must be same aspect ratio. First slide determines ratio for all. |
| IGTV cover (legacy) | 420 x 654 | 1:1.55 | Still used for older content display. |
| Threads post | 1080 x 1080 | 1:1 | Supports landscape (16:9) and portrait (4:5) as well. |

**Instagram Pro Tips**:
- Upload at maximum resolution (1080px wide minimum) — Instagram compresses but starting high preserves quality
- Use sRGB color profile for accurate color rendering
- Keep text and logos within the center 80% to avoid cropping in grid preview
- Export at 72 PPI — higher does not improve display quality on Instagram

## Universal Best Practices for All Social Media Images

Regardless of platform, these principles apply universally:

1. **Design at exact dimensions**: Don't rely on platform auto-cropping. Design precisely for each format.
2. **Safe zones are real**: Account for platform UI elements (like buttons, usernames, captions) that overlay your content.
3. **Export quality matters**: Use PNG for graphics with text/logos; JPG at 85%+ quality for photographs. Maximum file sizes vary by platform.
4. **Test across devices**: What looks perfect on desktop may crop awkwardly on mobile. Check both.
5. **Color profile consistency**: Use sRGB for all digital platforms. Adobe RGB or ProPhoto RGB will display incorrectly.
6. **Accessibility**: Maintain text contrast ratios above 4.5:1. Don't rely solely on color to convey information.
