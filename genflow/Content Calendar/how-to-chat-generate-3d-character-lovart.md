## The Chat-Generate 3D Character Workflow

### Step 1 — Define the Character's Identity

Before any visual description, decide who the character is. Identity drives design decisions:

- **Brand mascot**: Represents your entire brand. Friendly, memorable, simple enough to work at icon size. Often an animal, object, or abstract shape with a face.
- **Product persona**: Represents a specific product feature or user role. More specific than the brand mascot. Often human or humanoid.
- **Narrative character**: Part of a story — game character, comic protagonist, animated series personality. Needs backstory and personality cues.
- **Abstract mascot**: A geometric or shape-based character — a sphere with eyes, a cube with limbs. Minimalist, scalable, timeless.

Name the type in your prompt: "3D brand mascot character — a friendly robot..."

### Step 2 — Write a Comprehensive Character Prompt

A 3D character prompt that produces consistent results has seven components:

```
3D character design — brand mascot for a productivity SaaS app.

1. SPECIES/FORM: A small, round owl — stylized, not realistic. 
   Body is a perfect sphere. Head blends seamlessly into body (no neck).

2. MATERIAL/TEXTURE: Matte, soft-touch plastic — like a high-end designer toy (think Pop Mart or Kidrobot). 
   Slightly textured surface with subtle subsurface scattering for a warm, approachable feel. No glossy reflections.

3. COLOR PALETTE: Primary: warm cream (#FFF8E7). Accent: deep navy (#1B2A4A) for the eyes and feet. 
   A tiny pop of coral (#FF6B6B) on the beak.

4. PROPORTIONS: Oversized head/body (80% of total visual mass), tiny feet (10%), tiny wings (10%). 
   Eyes are massive — 40% of the face area. Beak is tiny. Proportions read: cute, harmless, approachable.

5. EXPRESSION: Default expression — wide-eyed, curious, slight smile. Eyes are large circles with navy irises 
   and a tiny white catchlight in each. The expression should read as "helpful and slightly eager."

6. POSE: Standing (on tiny round feet), wings slightly raised in a welcoming gesture. 
   Facing the camera, slight 10-degree head tilt for personality. Isometric-like angle — slightly from above.

7. STYLE REFERENCE: 3D illustration, Pixar-adjacent character design, soft lighting, 
   clean background (transparent or soft gradient), toy photography aesthetic.
```

The seven-component framework produces characters that look intentionally designed, not randomly generated. The agent has enough constraints to produce something coherent — but enough creative latitude to produce something surprising within those constraints.

### Step 3 — Generate the Character Sheet

A single character image is a nice visual. A character sheet is a production asset. Generate variations:

```
Character sheet for the same owl mascot. Generate four views:
1. FRONT VIEW: Default expression, welcoming pose (as previously described).
2. SIDE VIEW: Profile, same proportions, neutral expression.
3. ACTION POSE: Flying — wings spread, feet tucked, determined expression. Same style, same material.
4. EXPRESSION VARIATION: Frustrated — furrowed brow (as much as an owl can furrow), 
   tiny sweat drop icon floating beside the head, comic-style.

Arrange in a 2x2 grid, labeled, clean light background.
```

The character sheet serves multiple purposes: you can show it to stakeholders for approval, hand it to animators or illustrators as reference, and use it yourself to maintain consistency when generating the character in new contexts.

### Step 4 — Generate Context Scenes

With the character established, deploy it:

```
Same owl mascot, same exact character design and material. Now place the owl in a scene:
The owl is sitting at a miniature desk, looking at a tiny laptop. The desk has a tiny coffee mug 
and a small plant. Warm, cozy lighting — desk lamp from upper left. 
The scene communicates "your friendly productivity companion." 
Same Pixar-adjacent 3D illustration style. The desk and props are to scale — the owl is the hero 
and should occupy roughly 50% of the frame.
```

The prompt opens with "Same owl mascot, same exact character design and material" — this is the critical consistency anchor. Every scene prompt must reaffirm the character's visual identity before describing the new context.

### Step 5 — Build a Character Prompt Library

Codify the character's DNA so you never have to describe it from scratch again:

```
[Character Prompt Library: Owly the Productivity Owl]

BASE CHARACTER: "3D stylized owl — spherical body, matte soft-touch plastic material, 
cream body (#FFF8E7), navy eyes and feet (#1B2A4A), coral beak (#FF6B6B). 
Oversized eyes (40% face), tiny feet and wings. Pixar-adjacent toy aesthetic, 
soft lighting, subsurface scattering."

EXPRESSION LIBRARY:
- Default: Wide-eyed, curious, slight smile
- Happy: Eyes closed in arcs (^_^), bigger smile, wings raised higher
- Determined: Furrowed brows (angled navy lines), focused eyes, feet planted wide
- Surprised: Eyes extra large, beak slightly open, wings thrown back
- Sleepy: Half-closed eyes, drooping wings, tiny "Z" floating nearby

SCENE TEMPLATES:
- Desk Scene: "Owl at miniature desk, tiny laptop, coffee mug, small plant, warm desk lamp lighting"
- Celebration: "Owl holding a tiny confetti popper, colorful streamers, party hat, festive"
- Onboarding: "Owl pointing at a large floating tablet screen, tutorial arrows, welcoming gesture"
```

Next time you need the owl in a new context, paste the base character description and add the scene. The character stays consistent. The context changes. This is how professional character design pipelines work — and the AI agent makes it accessible without the pipeline.

## Frequently Asked Questions

**Can the agent maintain the same character across multiple generations?**

Yes — with careful description discipline. The key is creating a comprehensive base character description (with hex colors, proportion ratios, and material terms) and using it verbatim at the start of every prompt. Do not abbreviate. Do not assume the agent "remembers." Paste the full character DNA each time.

**Can I generate a character in different art styles (2D, pixel art, sketch)?**

Yes. Prompt: "Same owl mascot — exact same proportions, colors, and features — but rendered in a different style: 2D flat vector illustration." The character design carries over; the rendering style changes. This is useful for deploying the same character across platforms with different visual requirements.

**How do I give my 3D character a specific pose?**

Describe the pose in terms of major body parts: "Arms crossed, weight on left foot, head tilted 15 degrees right, looking up toward upper left." Avoid vague terms like "confident pose." Describe the physical configuration of the body that communicates confidence.

**Can I generate a character that looks like a specific person?**

The agent can generate stylized 3D characters inspired by a description. It cannot produce realistic 3D likenesses of real people without their consent. For brand personas, describe the character's traits — clothing style, hair, expression — rather than trying to reference a specific individual.

**What if my character's proportions keep drifting between generations?**

This is the most common consistency problem. The fix: use exact ratios in your base description ("head is 60% of total height, eyes are 35% of face width") and replicate those ratios verbatim in every prompt. The more numerical your description, the more consistent the output.

**Can I animate my 3D character through the agent?**

The Lovart agent generates static character images. For animation, export your character sheet and context scenes as reference material and use them in animation software or AI video tools. The character design is production-ready; animation is a separate pipeline step.
