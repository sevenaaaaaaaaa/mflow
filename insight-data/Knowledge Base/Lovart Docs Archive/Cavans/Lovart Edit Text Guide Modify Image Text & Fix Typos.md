Lovart Edit Text Guide: Modify Image Text & Fix Typos

### **What It Does**

Edit Text allows you to modify text content directly within images. You can change text strings, update wording, correct typos, or replace placeholder text with new content.

### **How To Use**

1. **Access the Tool**
	- Click **"Edit Text"** in the top toolbar
2. **Edit Your Text**
	- The Edit Text panel opens on the right side
	- Type or paste your new text content
3. **Apply Changes**
	- Click **"Apply edits"** to confirm and save
	- Or click **"Cancel"** to discard changes
	- Press **Esc** to exit the text editing mode

### **Quick Tips**

- Make sure text is clearly visible before and after editing
- Keep text consistent with your design style
- Review spelling and formatting before applying
- Use undo if the result doesn't look right
	- Edit Text feature does not yet support reliable editing of images that contain large amounts of text (e.g., essays, reports, etc), so results may be inaccurate or incomplete in these cases.

### Text Editing Best Practices

**Optimal Image Quality:**
- Higher resolution images produce better text editing results
- Clear, well-lit text is easier to modify accurately
- Avoid images with heavy compression or artifacts

**Text Characteristics:**
- Larger text edits more reliably
- High-contrast text (white on dark or vice versa) works best
- Simple fonts are easier to preserve than decorative scripts

**Content Length Considerations:**
- Single words and short phrases: Excellent results
- Medium sentences (5-15 words): Good results with proper context
- Long paragraphs: May require multiple edits or show inconsistencies

### Advanced Tips

**Maintaining Typography Consistency:**
- AI automatically matches font characteristics
- Preserve original styling including bold/italic
- Maintain alignment and spacing patterns
- Match perspective for 3D text effects

**Batch Text Updates:**
- Work through images sequentially
- Maintain consistent editing approach
- Document changes for version control
- Save originals for comparison

### Troubleshooting

**Text Not Editing Properly:**
- Ensure text is clearly visible and not obscured
- Try with smaller text selections
- Use higher quality source images
- Avoid editing text over complex backgrounds

**Style Not Preserved:**
- Original text may have complex effects
- Try selecting smaller text regions
- Check for overlapping elements
- Consider manual replacement for complex cases

### FAQ

**Q: Can I edit text in any language?**
A: Yes, Lovart supports multiple languages. English typically shows best results, but other languages are supported.

**Q: What if my image has multiple text areas?**
A: Edit one section at a time. Start with the most important text and work through systematically.

**Q: Does the tool preserve font matching exactly?**
A: AI approximates font matching based on visual characteristics. For perfect replication, manual editing may be needed.

**Q: Can I undo text edits?**
A: Yes, use Cmd/Ctrl+Z to undo. You can also reload the original image and start over.

**Q: Does text editing work on low-resolution images?**
A: Higher resolution images produce better results. If possible, use the highest quality source available.
