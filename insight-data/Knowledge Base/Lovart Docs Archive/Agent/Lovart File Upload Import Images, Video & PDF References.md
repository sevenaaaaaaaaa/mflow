## Upload Files

Easily import assets to Lovart AI. Supports JPG, PNG, MP4, and PDF for Nano Banana references, Flux Context, and ChatCanvas. Drag & drop up to 10 files.

![Lovart File Upload: Import Images, Video & PDF References](https://cdn.sanity.io/images/o11tm2qe/production/a770b42f5944235d30cc24f34ce7b92589dd3492-2160x1350.png)

Lovart File Upload: Import Images, Video & PDF References

The **Upload file** at the bottom right of Lovart's input area supports uploading **images, videos, and PDFs** in two ways:

### How to Use

**Method 1: Click the upload button**

- Click the **upload button** on the left side of the input box and select files from your device.

**Method 2: Drag and drop**

- Simply drag files into the "Drop files here to add to chat" area for instant upload.

### Supported Formats

- Images: JPG, PNG
- Videos: MP4, MOV
- PDF: Documents and design files

\*Each conversation input can include a maximum of 10 elements combined (files, images, mentions, etc.).

### File Upload Workflows

**Image Upload Applications:**

1. **Style Reference Upload**
   - Upload reference images to guide AI generation
   - Works with Nano Banana for style matching
   - Perfect for maintaining brand consistency across outputs

2. **Composition Reference**
   - Upload layout examples for composition guidance
   - AI analyzes spatial relationships and element placement
   - Great for recreating successful layouts with new content

3. **Color Palette Extraction**
   - Upload images for AI to extract dominant colors
   - Creates cohesive color schemes from reference photos
   - Useful for brand color development

4. **Before/After Comparison**
   - Upload original designs for AI to understand context
   - Request improvements or variations based on uploaded reference
   - Streamlines revision workflows

**Video Upload Applications:**

1. **Motion Reference**
   - Upload reference videos for motion style matching
   - AI analyzes movement patterns and camera techniques
   - Ideal for creating consistent video content

2. **Video Enhancement**
   - Upload existing footage for AI-powered improvement
   - Can extend, enhance, or stylize video content
   - Perfect for repurposing existing assets

3. **Frame Extraction Reference**
   - AI can extract key frames from uploaded videos
   - Use frames as reference images for generation
   - Enables sophisticated video-to-design workflows

**PDF Upload Applications:**

1. **Brand Guidelines Upload**
   - Upload PDF brand guides for AI to analyze
   - Extracts color codes, typography guidelines, logo usage rules
   - Ensures brand compliance across all outputs

2. **Design Briefs**
   - Upload client briefs in PDF format
   - AI extracts key requirements and design direction
   - Great for client onboarding workflows

3. **Product Documentation**
   - Upload spec sheets or catalogs
   - AI extracts product info for design generation
   - Streamlines product marketing workflows

### Upload Best Practices

**File Size Considerations:**
- Images: Optimal size 1-5MB for best quality-to-speed ratio
- Videos: Smaller files process faster; consider compression for long clips
- PDFs: First pages are processed for style extraction; specify relevant pages

**Organizing Multiple Uploads:**
1. Group related files by purpose (style references together, product photos together)
2. Upload in logical batches to maintain context
3. Use @ mentions to explicitly tie uploads to specific requests

**Quality Tips:**
- Use high-resolution images for best AI analysis
- Clear, well-lit photos produce more accurate results
- Consistent image quality across uploads ensures uniform output

### Troubleshooting Upload Issues

**Common Issues and Solutions:**

1. **Upload fails**: Check file format is supported (JPG, PNG, MP4, MOV, PDF)
2. **Slow processing**: Reduce file size or split large files into smaller batches
3. **AI doesn't reference uploaded files**: Use @ mention to explicitly attach uploads to requests

### FAQ

**Q: What's the maximum file size?**
A: Check platform limits, but generally images up to 20MB, videos up to 500MB are supported.

**Q: Can I upload files from cloud storage?**
A: Download cloud files locally first, then upload to Lovart.

**Q: How long are uploads retained?**
A: Files are available during your session. For persistent references, use @ to attach files to projects.
