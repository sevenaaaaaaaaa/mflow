# portrait-grid · 方形 / 竖版卡网格

> **section type**：`portrait-grid-3 / portrait-grid-4`  
> **图片来源字段**：`items[].media.src`  
> **尺寸 / 比例**：1000 × 1000 / 900 × 1200 · 1:1 (grid-3) / 3:4 (grid-4)  
> **每实例图片数**：3  
> **站内覆盖页面**：约 41 个文档

## 模块形态

grid-3：3 张 1:1 卡，上图下文；grid-4：4 张 3:4 竖版卡（`aspect` 可改 1:1 / 9:16）。

**用途**：用于「角色/场景系列」或「人物案例」。

## 本模块专属纪律

1. **必须是同一系列**：同材质、同光向、同景别；只换角色或场景
2. 每卡下方有 title + subtitle + CTA，主体避开下方 20%
3. 竖版 3:4 构图需给竖直方向留呼吸，主体不要顶天立地

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
