## How to Produce the Best Designs

While there is no hard and fast rule on what is correct and what is wrong, it all depends on the creativity you want. However, there are some basic things which you should keep in mind to get the best design results.

- **Keep prompts simple but specific:** Add brand name, style, and audience every time you want to create a design.
- **Use color psychology:** Green = eco-friendly, gold = luxury, blue = trust. This is the universally accepted color combination.
- **Always test designs:** Check how they look on mobile and desktop. This will help you avoid last minute confusions on how it will look on each device.
- **Save a brand folder:** Keep all logos, fonts, and colors in one place for future designs. This is going to help you find them easily once you need them.
