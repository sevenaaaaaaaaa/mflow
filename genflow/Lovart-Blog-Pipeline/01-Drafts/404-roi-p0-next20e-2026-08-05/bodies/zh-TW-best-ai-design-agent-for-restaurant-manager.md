# 餐廳經理最佳 AI 設計助手：2026 從菜單到限動

这篇补 `/zh-TW/blog/best-ai-design-agent-for-restaurant-manager` 404。搜索意图围绕「餐厅经理 AI 设计助手」，读者要可执行步骤，不是灵感图库。

## 我的立场

餐厅视觉 **3 米外读懂菜名和价格**，改价 **Touch Edit 数字区**，过敏 **icon 不靠 AI 瞎编**。

## Brief 合约（我实际在用的）

```
尺寸：A4 菜单 + 1080 外卖主图 + 台卡 A5
任务：1 主推菜 + 价格 + 1 CTA（订位/外送）
禁止：假米其林星、假食安认证
过敏：icon 库手动，不 AI 生成
光线：食物 warm，禁止 oversaturate
```

## 踩坑

**坑 1：改价整图重跑。** 解法：Touch Edit 价格区。
**坑 2：假米其林 badge。** 解法：法务 BLOCK。
**坑 3：外卖图 appetite 假。** 解法：真实 plating 参考。
**坑 4：菜单字太小。** 解法：3m 测试 + 字号下限。
**坑 5：过敏 icon AI 瞎编。** 解法：手动 icon 库。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export

## 公式

\[ \text{翻台} = \frac{\text{菜价可读} \times \text{Touch Edit}}{\text{改价重跑}} \]

## FAQ

### 能直接交付客户吗？

Export 前跑一遍 checklist：假徽标、双 CTA、联系信息可读。

### 改期/改价怎么办？

Touch Edit 改对应区域，不全图重跑。

### 需要会 PS 吗？

不必；极端修图仍可用 PS 补。

### 多语言 brief？

品牌术语 Lovart、MCoT、ChatCanvas、Touch Edit 不翻译。

### 多少 direction 够？

3–4 个，选一个进 Brand Kit 流程。
