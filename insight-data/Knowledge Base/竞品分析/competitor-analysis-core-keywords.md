## 竞品内容方向

基于内容库（17.5k 篇）与 GSC 数据，竞品在以下方向有内容优势：

- **设计流程自动化**：Canva 的模板流程、Adobe 的 Firefly 集成
- **批量生成**：Midjourney 的 batch 模式、Canva 的 bulk create
- **品牌一致性**：Brand Kit / Design System 相关词
- **多格式导出**：print/social/web 一键导出

## Lovart 差异化角度

1. **生成即可编辑**（Touch Edit）—— 竞品"生成后不可编辑"是最大痛点
2. **ChatCanvas 协作**（多人在同一画布上协作改稿）
3. **跨格式导出**（一张 brief → 多格式，竞品需手动适配）
4. **中文排版优势**（竞品多为位图输出，中文不可编辑）

## 写竞品对比内容时

- **禁止**贬低竞品（合规红线）
- **必须**用数据说话（用户量/价格/速度对比，标 [待考证]）
- **必须**给出适用场景（"如果你是 X，选 A；如果你是 Y，选 B"）
