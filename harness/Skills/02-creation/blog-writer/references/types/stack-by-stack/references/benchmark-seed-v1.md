# Lovart Stack by Stack Benchmark Seed V1

Purpose: build a benchmark base for articles comparing workflows made of multiple tools rather than single-tool reviews.

## Category definition

Stack × Stack compares one workflow stack against another by stage, friction, handoff cost, and final output quality.

## Five core topics

1. Solo creator stack vs all-in-one AI stack
2. Marketing content stack vs Lovart-centered stack
3. Brand design stack vs prompt-native design stack
4. Video ad production stack vs Lovart hybrid stack
5. Agency delivery stack vs lean in-house stack

## Benchmark traits to absorb

- compare by workflow stage, not just features
- include integration cost and context-switch overhead
- recommend different stacks for different team types
- include anti-recommendations
- distinguish orchestration from asset creation from review

## What to avoid

- single-tool review masquerading as a stack article
- feature-table-only comparisons
- no handoff or operational cost discussion
- winner claims with no audience segmentation
