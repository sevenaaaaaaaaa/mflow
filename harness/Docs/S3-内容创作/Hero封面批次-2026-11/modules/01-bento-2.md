# bento-2 · 两栏特性卡

> **section type**：`bento-2`  
> **图片来源字段**：`features[].media.src`  
> **尺寸 / 比例**：1600 × 1000 · 16:10  
> **每实例图片数**：2  
> **站内覆盖页面**：约 6383 个文档

## 模块形态

2 等宽大卡，每卡 title + description + 大图；桌面端左右并排，移动端上下堆叠。

**用途**：用于「两个最重要能力 / 两个转化任务」的平行对比。

## 本模块专属纪律

1. 两卡必须视觉同构（同布光、同背景色系、同机位高度），否则并排会歪
2. 每卡只表达 1 个能力，不要塞多个元素
3. 卡片下方有 title + description 文字区，图片下半 20% 保持简洁

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
