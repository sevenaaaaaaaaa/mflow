# MFlow 产品介绍

> 面向：管理层 / 商业分析 / 研发 / 风控法务 / 增长团队。
> 一句话：MFlow 是 Lovart 从"人工写内容"升级为"治理化内容工厂"的基础设施，也是面向 GEO（生成式引擎优化）时代的战略投资。

---

## 一、为什么不是"再加两个写手"

人工内容产出的物理极限是一个人一天 1-2 篇。要覆盖非品牌词、在 AI 搜索引擎中获得引用、在多语言市场建立存在感，这个数量级的差距不是加人能解决的。

| 维度 | 加 2 个写手 | MFlow |
|------|-----------|-------|
| 月均产出 | 12-24 篇 | 20-50 篇起，边际成本递减 |
| 多语言 | 需额外雇人 | LLM 原生，10 语重写（非直译） |
| 时效性 | 人需要消化热点再写 | 舆情触发，分钟级启动 |
| 数据反馈 | 凭经验判断 | GSC/GA4/Bing 自动闭环 |
| 系统月成本 | 恒定人力 | ¥800-2800（API 成本为主） |

关键不是"替代写手"：写手从生产者升级为策略师——不再从零写 How-to，而是把关质量、定策略、产出真正需要人类判断力的 Case Study。

## 二、为什么是现在：SEO 正在被 GEO 取代

传统 SEO 的前提是"用户在搜索结果页看到链接并点进来"。这个前提正在瓦解：

- Google AI Overview 覆盖 100+ 国家；Perplexity 月活 1500 万+；ChatGPT Search 全面开放
- Gartner 预测：到 2028 年，品牌传统搜索自然流量下降 25%，被 AI 引擎分流

GEO 的新规则是**在 AI 回答中被引用**。AI 引用谁？引用覆盖广泛关键词、结构清晰、信息准确的站点。公式很简单：

```
内容数量 × 内容质量 = AI 引用概率
```

人工方式数量是瓶颈；无治理的 AI 批量生产质量是灾难。MFlow 同时锁死两端。

## 三、和"内容农场"的本质区别

| 特征 | 内容农场 | MFlow |
|------|---------|-------|
| 触发逻辑 | 穷举关键词 | 舆情事件 + 缺口分析（信号驱动） |
| 质量控制 | 无 | 状态机 + 4 道钩子 + Anti-Slop + 三层门禁 |
| 写作方式 | 堆关键词 | 每段必须回答"谁读/为何读/读完改变什么" |
| SEO 策略 | 密度游戏 | E-E-A-T + 结构化数据 + 内链 + 环比复盘 |
| 多语言 | 机器直译 | Per-language 信号驱动重写 |

## 四、给风控/法务的五层防线

1. Quality Gate：10 项自动质检，不达标不发布
2. 写作规范硬编码：7 类 AI 模板化表达禁止，不可验证数据强制标 `[待考证]`
3. 人工抽查：每日 1-2 篇
4. GSC 排名监控：连续下滑自动暂停
5. 回滚方案：24 小时内可批量下线

## 五、给研发的维护边界

这不是一套需要持续开发的新后端。核心是**文件 + 状态机 + 定时脚本**：

- 无数据库依赖（状态 = 原子写的 JSON；可上云时换 PG，PRD 已备）
- 无常驻服务（cron/systemd 定时触发，崩了就下次修）
- 铁律全在 git 管理的 Markdown/脚本里，改动可审计、可回滚
- 通用内核（状态机/路由器/钩子/治理）与 Lovart 业务配置天然分层，未来可抽为开源内核 + 私有品牌包

## 六、当前战果（真实数字）

- Sanity production **8,247 文档**，10 语，从 961 起步
- 404 修复战役：compositePage 393 清零（实际修复 639 页），Blog/Landing 累计 169+ 页修复并全量 HTTP 200 验证
- 信号驱动重写：Phase D 49 篇全部发布；Top878 重写工程 2 天完成分片执行
- 舆情：Sentinel 每日 22 源全自动（X/Reddit/TikTok/YouTube/百度/搜狗/必应 SERP…）
- 报告：周报/月报/季报全自动生成，强制环比与日均值口径

## 七、路线

- **近期**：分发线恢复产能（530 篇 ready 稿过 UTM 加工后按轨道发射）；服务器私有实例部署（独立目录/URL）
- **中期**：内核抽取 —— pipeline-state / router / hooks / governance / 知识固化循环 打包为通用"内容工厂内核"，Lovart 业务层退化为"品牌包"
- **长期**：内核开源（带 dummy 品牌包做 demo），Lovart 的竞争力收敛为"内核 + 我们的内容方法论 + 8,200 文档的真实数据飞轮"
