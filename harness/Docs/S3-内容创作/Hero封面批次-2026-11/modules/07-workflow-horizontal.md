# workflow-horizontal · 横向 N 步流程

> **section type**：`workflow-horizontal`  
> **图片来源字段**：`steps[].media.src`  
> **尺寸 / 比例**：1200 × 900 · 4:3  
> **每实例图片数**：3  
> **站内覆盖页面**：约 6557 个文档

## 模块形态

横向一排 step 卡（编号 + 标题 + 描述），每卡一张图。

**用途**：用于「3 步搞定」类流程叙事，覆盖页数极高。

## 本模块专属纪律

1. **必须是同一主体的 3 个连续状态**（时间轴），不是 3 个不同对象
2. 3 张同背景、同光向、同机位高度；只让「状态」递进
3. 每卡下方 30% 留编号与描述位，保持低细节

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
