## Crop

![](https://cdn.sanity.io/images/o11tm2qe/production/af811310fed54ad6b245eca84ea07a708e0851a9-2160x1350.png)

### What It Does

The Crop tool lets you trim and reframe your image by selecting the area you want to keep. You can drag to define the crop area, adjust dimensions, or choose preset aspect ratios.

### How To Use

1. **Access the Tool**
	- Select your image layer
	- Click **"Crop"** in the toolbar
2. **Select Crop Area**
	- Drag on the image to define the crop region
	- A grid overlay shows the area being kept
3. **Adjust Dimensions**
	- Use preset aspect ratios (Custom dropdown)
	- Manually enter width (W) and height (H) values
	- Or drag the corners to resize the crop box
4. **Apply Crop**
	- Click the **"Crop"** button to confirm
	- Or press Esc to cancel

### Quick Tips

- Use the grid lines to align subjects perfectly
- Try different aspect ratios to find the best composition
- Crop tightly to focus on your main subject
- Undo (Cmd+Z/Ctrl+Z) if you crop too aggressively
### Aspect Ratio Quick Reference

| Ratio | Use Case | Common Applications |
|-------|----------|---------------------|
| 1:1 | Balanced square | Instagram posts, profile images, logos |
| 4:3 | Standard display | PowerPoint slides, blog images |
| 16:9 | Cinematic/wide | YouTube videos, presentations, web banners |
| 3:2 | Photography | Photo prints, editorial content |
| 9:16 | Vertical/mobile | Instagram Stories, TikTok, Reels |

### Crop Workflow Examples

**Social Media Optimization:**
1. Select landscape photo
2. Apply Crop tool
3. Choose 1:1 for Instagram post
4. Adjust frame to highlight key subject
5. Confirm and export

**Presentation Slide Image:**
1. Select wide panoramic image
2. Apply Crop tool
3. Choose 16:9 aspect ratio
4. Reposition to focus on main content
5. Use grid lines to ensure alignment

**YouTube Thumbnail:**
1. Select striking image
2. Apply Crop tool
3. Choose 16:9 but frame tightly
4. Ensure face/text is prominent
5. Export at recommended 1280×720

### Advanced Crop Techniques

**Rule of Thirds Integration:**
- Enable grid overlay in Crop tool
- Position key subjects at grid intersections
- Creates balanced, professional composition
- Works especially well for portraits and landscapes

**Face-Aware Cropping:**
- When cropping portrait photos, position eyes at upper third
- Ensures natural viewing direction
- Creates engaging visual hierarchy

**Text Safety Zone:**
- When preparing images with overlay text
- Keep main text in center 60% of frame
- Prevents accidental cropping in different platforms

### Crop vs. Expand Tool

**Use Crop When:**
- Image has excess space you want to remove
- You need a specific format/size
- Composition allows tighter framing

**Use Expand When:**
- You want to preserve original image
- Need larger canvas for text/elements
- Prefer to add content rather than remove

Both tools offer complementary approaches to image composition.

### FAQ

**Q: Does cropping affect image quality?**
A: Cropping reduces dimensions but maintains quality of the visible area. Use Upscale to enlarge cropped images if needed.

**Q: Can I undo a crop?**
A: Yes, Cmd/Ctrl+Z undoes the last crop. Original image data is not destroyed until you save/export.

**Q: How do I crop to exact pixel dimensions?**
A: Enter specific width (W) and height (H) values in the Crop tool for precise control.

**Q: What's the difference between crop and mask?**
A: Crop permanently removes image data outside the frame. Masking hides areas without deleting them, allowing non-destructive editing.
