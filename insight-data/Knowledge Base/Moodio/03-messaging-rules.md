# Moodio 表达口径与内容红线（官方 v1.0 — 质检按此逐条对照）

## 必须传递（Key Messages）

1. 全球首款真正覆盖 AI 影视创作**全流程**的产品。
2. 对 AI 初学者友好：带着灵感来，用专业级工作流完成短片，展现个人风格。
3. 更懂专业 AI 团队的协作：人与人 / 人与 Agent / 甲方乙方。
4. 帮你发现并发挥自己的审美：**协助你创作，不代替你**。
5. CTA：已开放少量内测名额 → app.moodio.art 申请内测码（request an access code）。

## 五条表达红线（Don'ts — 违反即质检 BLOCK）

| # | 禁止 | 应改为 |
|---|---|---|
| 1 | 不强调成片效果"直接优于其他平台" | 强调帮助创作者发挥自身审美：把自己的故事和审美讲出来的基础上，Moodio 帮你做得更好 |
| 2 | 不强调素材库数量、不与竞品比库量 | 强调**审美好**：能搜到你脑中的画面，并把画面变成最终视频 |
| 3 | 不把协同简化为"多人同时操作画布" | 写不同角色在不同画布、不同制作阶段并行推进：编剧改剧本、美术做资产、导演生成视频、甲方留言反馈 |
| 4 | 不把专业工作流绑定"只服务专业影视团队" | 强调初学者也能理解使用；源自好莱坞创作方法 + 优秀 AI 影视创作者实践经验 |
| 5 | 不宣称专业团队的最终成片完全在 Moodio 完成 | 强调各阶段专业格式导出（Word/PDF/FDX 剧本；XML 剪辑 → Final Draft、达芬奇） |

## 风格禁例（出现即整改）

- 以"一键成片 / one-click filmmaking""做 AI 就能赚钱"为卖点。
- 营销风格强烈、hard-sell 口吻。
- 空泛形容词堆叠（颠覆级、革命性、最强）。

## 内容三要素（官方要求每篇内容追求）

1. **情感共鸣**（emotional resonance）
2. **个性化的审美表达**（a distinctive, personal visual style）
3. **画质精美的意象**（beautiful, high-quality imagery）

## 写作语气（从官方文案提炼）

- 像懂技术的导演/制片人说话：尊重 craft、讲工作流与可控性，不贩卖焦虑。
- 用创作者视角动词：发现、打磨、推敲、对齐、沉淀——少用"生成XX内容"的流水线语感。
- 专业术语可用并顺手解释（previz、shot list、FDX）——符合"非专业用户学得会"的品牌主张。
