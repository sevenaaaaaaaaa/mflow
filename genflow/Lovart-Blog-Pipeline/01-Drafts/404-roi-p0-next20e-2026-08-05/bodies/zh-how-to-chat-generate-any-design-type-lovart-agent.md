# 用 Lovart Agent 聊天生成任意设计类型：2026 完整路径

这篇补 `/zh/blog/how-to-chat-generate-any-design-type-lovart-agent` 404。搜索意图围绕「Lovart Agent 聊天生成设计」，读者要可执行步骤，不是灵感图库。

## 我的立场

Lovart Agent 不是「万能咒语」，而是 **同一 ChatCanvas 会话里锁 Brand Kit，换类型只改任务句 + MCoT 换 artboard**。

## Brief 合约（我实际在用的）

```
会话：1 ChatCanvas 锁 Brand Kit 不断链
类型：poster / logo / social / slide 用任务句切换
每步：尺寸 + 1 CTA + 禁止项
收尾：Touch Edit 改字 export
禁止：每类型重开对话丢 Kit
```

## 踩坑

**坑 1：每类型重开对话。** 解法：同会话换任务句。
**坑 2：Brand Kit 丢失 drift。** 解法：会话内锁 Kit 不断。
**坑 3：logo 和 poster 混 brief。** 解法：一次一种类型。
**坑 4：改字全图重跑。** 解法：Touch Edit 文案区。
**坑 5：export 漏尺寸。** 解法：MCoT artboard 清单 export。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export

## 公式

\[ \text{类型切换} = \frac{\text{同会话} \times \text{MCoT artboard}}{\text{重开对话}} \]

## FAQ

### 能直接交付客户吗？

Export 前跑一遍 checklist：假徽标、双 CTA、联系信息可读。

### 改期/改价怎么办？

Touch Edit 改对应区域，不全图重跑。

### 需要会 PS 吗？

不必；极端修图仍可用 PS 补。

### 多语言 brief？

品牌术语 Lovart、MCoT、ChatCanvas、Touch Edit 不翻译。

### 多少 direction 够？

3–4 个，选一个进 Brand Kit 流程。
