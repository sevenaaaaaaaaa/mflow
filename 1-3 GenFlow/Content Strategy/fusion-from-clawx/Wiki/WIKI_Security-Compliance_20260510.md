Security & Compliance

**Data encryption:** All data in transit is encrypted via TLS 1.3. Data at rest is encrypted using AES-256. Customer content is isolated at the account level.

**GDPR compliance:** Lovart maintains GDPR compliance for European users. Data processing agreements available on request. Users can request data deletion and export at any time.

**Training data policy:** Lovart does not use customer content for model training without explicit consent. Enterprise customers can opt into a strict no-training policy.

**Enterprise agreements:** Custom data processing agreements, business associate agreements (for healthcare), and SOC 2 reports available for enterprise customers.

Contact [enterprise sales](https://www.lovart.ai/pricing) for compliance documentation and security review calls.
