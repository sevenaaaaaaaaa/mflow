# Workflow Auto-Resize multiplataforma

Uma social media manager em fintech gastava toda segunda redimensionando: feed quadrado → Story, LinkedIn → X, Facebook → thumbnail YouTube. Cinco plataformas, três horas, toda semana.

Com o Auto-Resize da Lovart, a mesma tarefa leva **6 minutos**. Ela desenha uma vez; a IA adapta o resto.

## 1. A realidade multiplataforma

Em 2026, marcas usam em média **4,7 plataformas**. Cada uma tem dimensões ideais:

| Plataforma | Formato | Dimensões | Proporção |
|------------|---------|-----------|-----------|
| Instagram Feed | Quadrado | 1080×1080 | 1:1 |
| Story / Reel | Vertical | 1080×1920 | 9:16 |
| Facebook Feed | Horizontal | 1200×630 | 1.91:1 |
| LinkedIn | Horizontal | 1200×627 | 1.91:1 |
| X | Horizontal | 1200×675 | 16:9 |
| YouTube thumb | Horizontal | 1280×720 | 16:9 |
| TikTok / Shorts | Vertical | 1080×1920 | 9:16 |
| Pinterest | Vertical | 1000×1500 | 2:3 |
| E-mail header | Horizontal | 600×200 | 3:1 |

Campanha em 5 plataformas = 5+ variantes. Redimensionar manualmente: **2–4 h** por campanha.

## 2. Como o Auto-Resize funciona

Não é só escalar imagem — é **adaptação de composição**:

1. Aceita o design do ChatCanvas  
2. Analisa texto, imagens, fundo, CTAs  
3. Recalcula posição por plataforma  
4. Escala tipografia mantendo legibilidade  
5. Recorta/estende fundo com inteligência (não só center-crop)  
6. Exporta todas as variantes de uma vez  

## 3. Três estratégias

**Reframe inteligente** — fotos hero, pouco texto.  
**Reflow de layout** — infográficos, muito texto.  
**Elemento-adaptativo** — header/corpo/rodapé independentes.

## 4. Otimização por plataforma

| Plataforma | Ajuste |
|------------|--------|
| Instagram Feed | Texto legível em mobile |
| Story | Evita zonas de UI superior/inferior |
| LinkedIn | Tom profissional, desktop-first |
| YouTube | Alto contraste, texto grande, evita canto do timestamp |
| TikTok | Evita botões de interação |
| E-mail | Conteúdo crítico no preview pane |

## 6. Checklist de 30 segundos

1. Texto legível no menor formato  
2. CTA visível  
3. Recorte não mata a mensagem  
4. Logo proporcional  
5. Safe zones (UI da plataforma)  
6. Parece nativo, não “esticado”  

Ajuste fino com Edit Elements só na variante afetada.

## 7. Agências multi-marca

5 clientes × 5 plataformas = 25 redimensionamentos. Manual: ~3,3 h/campanha. Com Auto-Resize: ~8 min.

## 8. Começar

1. Master no ChatCanvas (plataforma principal)  
2. Selecionar destinos no painel Auto-Resize  
3. Escolher estratégia  
4. Gerar → checklist → exportar
