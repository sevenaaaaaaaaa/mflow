用户反馈（33 模块复刻普遍问题）：交互未完全复刻、排版/字体/位置非 1:1、无响应式。

**系统性审计实锤**：33 片段 583 唯一 class，旧嵌入 CSS 缺失 **217 个**——全部是变体类（md:/2xl:/hover:/group-hover:/data-[state]）+ 40 个 @font-face 的 `../media/` 相对路径未绝对化（字体全 404）。

**根因**：主站浏览器实际生效的 CSS ≠ 页面 <link> 的 4 个文件——Next.js 按 chunk 拆分，变体规则在浏览器实际加载的其他样式层。

**修复（换方法论）**：从主站浏览器 document.styleSheets 直接序列化全部顶层规则（2.5MB）→ 分段取回（修 evaluate 参数传递）→ 字体路径绝对化（../media → _next/static/media）。
