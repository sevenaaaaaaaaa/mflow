# 遊戲開發案例：AI 材質與貼圖流水線（2026 實測）

这篇补 `/zh-TW/blog/case-study-game-dev-ai-textures-materials` 404。搜索意图围绕「游戏开发 AI 材质贴图」，读者要可执行步骤，不是灵感图库。

## 我的立场

游戏材质 AI **先服务概念和 placeholder**，上线前要 **人工 tile 检查 + 引擎里看 lighting**——别直接把 seam 明显的贴图进 build。

## Brief 合约（我实际在用的）

```
格式：2048 tileable diffuse + 概念 non-tile
引擎：Unity URP 或 Unreal 5，写明
风格：stylized 或 realistic 二选一
检查：tile 9×9 预览 seam
禁止：抄袭现有 game IP texture
```

## 踩坑

**坑 1：tile seam 明显。** 解法：9×9 预览 + 重 gen。
**坑 2：PBR 通道不齐。** 解法：只 AI diffuse，normal 手做或工具。
**坑 3：风格与角色不搭。** 解法：Brand Kit 锁 palette。
**坑 4：改脏度重跑整张。** 解法：Touch Edit 污迹区。
**坑 5：IP 纹理撞车。** 解法：reference 禁知名 game。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export

## 公式

\[ \text{进引擎} = \frac{\text{tile合格} \times \text{风格一致}}{\text{seam修复小时}} \]

## FAQ

### 能直接交付客户吗？

Export 前跑一遍 checklist：假徽标、双 CTA、联系信息可读。

### 改期/改价怎么办？

Touch Edit 改对应区域，不全图重跑。

### 需要会 PS 吗？

不必；极端修图仍可用 PS 补。

### 多语言 brief？

### 多少 direction 够？

3–4 个，选一个进 Brand Kit 流程。
