# Moodio 可引用事实清单（Fact Sheet — 数据点唯一出处）

> 规则：文章里的每个数字/硬事实必须出自本表；同数据不重复使用（一篇内引用同一事实 ≤1 次）。

## 性能与规模（可引用）

| 事实 | 数值/表述 |
|---|---|
| 实时协作容量 | 最高 **15 人同画布** |
| 同步延迟 | **毫秒级**同步，支持跨时区 |
| 产品验证规模 | **200+ 位专业创作者**参与、累计 **3000 分钟**高强度测试 |
| 检索响应 | 文本/图片/视频均**毫秒级**出结果 |
| 灵感检索价格 | **免费**（Free to use） |

## 技术背书（可引用）

- 灵感检索模型由 **CMU 顶尖计算机视觉科研团队自研**（proprietary search model）。
- 素材库由**数百位专业影视创作者共建**，覆盖主体、场景、动作、空间关系、运镜。
- **World Labs / Atlas 集成——国内第一批**接入的平台（Among the first platforms in China）。
- 剧本方法融合**好莱坞与国内专业编剧经验**。

## 互操作与导出（可引用）

- 剧本导出：**Word / PDF / FDX**（Final Draft 格式）。
- 剪辑导出：**XML**，衔接 **Final Draft、DaVinci Resolve（达芬奇）**；支持导出 **Final Cut 工程**。
- 审片：免登录分享链接、精确到**秒**的时间线评论、评论回流工程文件。
