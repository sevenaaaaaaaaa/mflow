# Sentinel Credentials Example

This directory documents the credential files Sentinel expects. Do not place real secrets in Git.

Recommended real credential location:

```text
~/Library/Application Support/Lovart/credentials/sentinel/
```

Expected files:

| File | Purpose |
|------|---------|
| `bing_credentials/api_key` | Bing Webmaster API key |
| `gsc_credentials/oauth-client.json` | Google OAuth desktop client |
| `gsc_credentials/gsc-token.json` | GSC OAuth token generated by `gsc_auth.py` |
| `ga4_credentials/ga4-token.json` | GA4 OAuth token generated by `ga4_auth.py` |
| `ga4_credentials/service-account.json` | Optional GA4 service account credential |

Loading policy:

1. Environment variables should be preferred when scripts support them.
2. Local private credential paths should be second.
3. In-repo real credentials are legacy only and should be removed after migration.
