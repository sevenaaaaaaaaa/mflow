## 一、Step ① 素材预处理层：Rembg + Real-ESRGAN

### 1.1 Rembg：基于 U²-Net 的背景去除

**技术原理**：Rembg 底层使用 U²-Net（U-squared Net），一种嵌套 U 结构的深度学习显著性检测模型。核心架构是 RSU（Residual U-block），在多个尺度上捕获上下文信息，对电商硬边缘产品（电子产品、箱包、家居）的抠图精度达到 90%+。

**安装与调用**：

```bash
# 安装
pip install rembg[gpu]  # GPU 加速版本
pip install rembg        # CPU 版本

# CLI 单张处理
rembg i product_raw.jpg product_nobg.png

# CLI 批量处理（遍历目录）
rembg p ./raw_photos ./white_bg_photos

# Python API 调用
from rembg import remove, new_session

session = new_session("u2net")  # 可选: u2net, isnet-general-use, silueta
with open("input.jpg", "rb") as i:
    input_data = i.read()
    output_data = remove(input_data, session=session)
with open("output.png", "wb") as o:
    o.write(output_data)
```

**模型选择策略**：

| 模型 | 适用场景 | 精度 | 速度 |
|------|---------|------|------|
| `u2net` (默认) | 通用产品，硬边缘 | 高 | 中 |
| `isnet-general-use` | 软边缘（服装、毛发） | 更高 | 较慢 |
| `silueta` | 人像为主 | 中 | 快 |
| `u2net_human_seg` | 人物+产品混合 | 高 | 中 |

**性能基准**（RTX 3060 12GB）：单张 2000×2000 图片约 0.3 秒，批量处理 200 张约 60 秒。

### 1.2 Real-ESRGAN：基于 RRDBNet 的超分辨率重建

**技术原理**：Real-ESRGAN 是腾讯 ARC 实验室提出的盲超分模型，核心创新在于 high-order degradation modeling——模拟真实世界中多次压缩、缩放、噪声叠加的退化过程来训练模型。相比传统 ESRGAN，对 JPEG 压缩伪影有更好的修复能力，这对电商场景（供应商 WhatsApp 压缩图）至关重要。

**安装与调用**：

```bash
# 克隆仓库
git clone https://github.com/xinntao/Real-ESRGAN.git
cd Real-ESRGAN
pip install -r requirements.txt

# 基础用法：4x 超分
python inference_realesrgan.py \
    -n RealESRGAN_x4plus \
    -i input.png \
    -o output.png

# 大图分块处理（避免显存溢出）
python inference_realesrgan.py \
    -n RealESRGAN_x4plus \
    -i large_input.png \
    -o output.png \
    --tile 400 \
    --tile_pad 10 \
    --pre_pad 0

# 针对人脸/动漫的专用模型
python inference_realesrgan.py \
    -n RealESRGAN_x4plus_anime \
    -i anime_input.png \
    -o output.png
```

**模型选型**：

| 模型 | 参数量 | 适用场景 | 放大倍数 | 显存需求 |
|------|--------|---------|---------|---------|
| RealESRGAN_x4plus | ~16M | 通用照片 | 4x | ~4GB |
| RealESRGAN_x2plus | ~16M | 通用照片 | 2x | ~2GB |
| RealESRNet_x4plus | ~16M | 平滑输出（少伪影） | 4x | ~4GB |
| RealESRGAN_x4plus_anime | ~16M | 插画/动漫 | 4x | ~4GB |

**批处理 Shell 脚本**（串联 Rembg + Real-ESRGAN）：

```bash
#!/bin/bash
# batch_process.sh — 批量预处理产品图

RAW_DIR="./raw_photos"
WHITE_DIR="./white_bg_photos"
OUTPUT_DIR="./hd_output"

mkdir -p "$WHITE_DIR" "$OUTPUT_DIR"

# Step 1: 批量抠白底
echo "🔍 Rembg: 批量去除背景..."
rembg p "$RAW_DIR" "$WHITE_DIR"

# Step 2: 批量 4x 超分
echo "🔬 Real-ESRGAN: 超分辨率放大..."
for img in "$WHITE_DIR"/*.png; do
    filename=$(basename "$img")
    python inference_realesrgan.py \
        -n RealESRGAN_x4plus \
        -i "$img" \
        -o "$OUTPUT_DIR/${filename%.png}_4x.png" \
        --tile 400
done

echo "✅ 预处理完成！输出目录: $OUTPUT_DIR"
```

**性能基准**（RTX 3060 12GB）：800×800 → 3200×3200 约 0.8 秒/张。

## 三、Step ③ 品牌化出图：Lovart Brand Kit 技术架构

### 3.1 MCoT（Multi-step Chain of Thought）推理引擎

Lovart 的核心是其 MCoT 推理引擎，将品牌视觉规范编码为多步推理链：

```
输入: 产品白底图 + Brand Kit 配置 + 风格 prompt
    ↓
Step 1: 场景理解 → 识别产品类别、形态、材质
    ↓
Step 2: 色彩映射 → 基于 Brand Kit 色板重新映射色调
    ↓
Step 3: 构图推理 → 根据目标尺寸智能布局
    ↓
Step 4: 风格迁移 → 应用风格 prompt + 品牌约束
    ↓
输出: 品牌化的多尺寸产品图
```

### 3.3 多尺寸智能适配

Lovart 的尺寸适配不是简单的中心裁剪，而是基于显著区域的**内容感知重构图**：

```
原始图像 (2000x2000) 
    │
    ├── 显著性检测 → 产品区域 mask
    ├── 目标比例计算 (e.g., 9:16 = 1080x1920)
    ├── 智能扩展背景（outpainting）或
    └── 智能裁剪（保留完整产品 + 合理留白）
```

## 四、Step ④ 视频生成：LibTV 节点工作流

### 4.1 技术架构

LibTV 采用节点可视化工作流引擎，底层基于 FFmpeg + WebGL 渲染管线：

```
┌─────────────────────────────────────────────────┐
│                  LibTV 节点架构                    │
├─────────────────────────────────────────────────┤
│                                                  │
│  [Image Input] → [Transform] → [Transition] →    │
│       │              │              │             │
│       ▼              ▼              ▼             │
│  Ken Burns     Scale/Rotate   Dissolve/Wipe      │
│                                                  │
│  [Audio Input] → [TTS] → [Subtitle Gen] →        │
│                                  │               │
│                                  ▼               │
│  [Overlay: Logo/CTA/Subtitle] → [Render: MP4]    │
│                                                  │
└─────────────────────────────────────────────────┘
```

### 4.2 关键参数调优

```python
# LibTV 节点配置伪代码
```

### 5.2 Postiz：多平台分发 API

**Postiz REST API 集成**：

```python
# postiz_publish.py — 多平台批量发布脚本
import requests

POSTIZ_API = "https://your-postiz-instance/api"
API_KEY = "your-api-key"

platforms = ["tiktok", "instagram", "pinterest", "youtube"]

def publish_product_video(video_path: str, sku: str, title: str, tags: list):
    for platform in platforms:
        # 各平台内容微调
        payload = {
            "platform": platform,
            "media": video_path,
            "title": f"{title} | {sku}",
            "description": get_platform_description(platform, sku),
            "hashtags": get_platform_tags(platform, tags),
            "schedule": get_optimal_time(platform)
        }
        
        resp = requests.post(
            f"{POSTIZ_API}/publish",
            json=payload,
            headers={"Authorization": f"Bearer {API_KEY}"}
        )
        print(f"[{platform}] {resp.status_code}: {resp.json()}")

def get_optimal_time(platform: str) -> str:
    # 各平台最优发布时间（UTC）
    optimal_times = {
        "tiktok": "12:00",
        "instagram": "17:00", 
        "pinterest": "20:00",
        "youtube": "14:00"
    }
    return optimal_times.get(platform, "12:00")
```

## 七、排障指南 & 常见问题

### 7.1 Rembg 边缘锯齿

**问题**：产品边缘出现锯齿状半透明像素，植入场景图时白边明显。

**原因**：U²-Net 对软边缘和透明材质的 alpha matting 精度不足。

**解决方案**：
```bash
# 方案 1: 切换模型
rembg i input.jpg output.png -m isnet-general-use

# 方案 2: 后处理 — alpha 通道腐蚀
from PIL import Image, ImageFilter
import numpy as np

img = Image.open("output.png")
alpha = img.split()[-1]
# 腐蚀 alpha 通道 2px
alpha = alpha.filter(ImageFilter.MinFilter(3))
img.putalpha(alpha)
img.save("output_eroded.png")
```

### 7.2 Real-ESRGAN 显存溢出

**问题**：处理 4K+ 大图时 CUDA out of memory。

**解决方案**：
```bash
# 启用分块处理
python inference_realesrgan.py \
    -n RealESRGAN_x4plus \
    -i 4k_input.png \
    -o output.png \
    --tile 400 \      # 分块大小（像素）
    --tile_pad 10 \   # 块间重叠（防接缝）
    --pre_pad 0 \     # 预处理填充
    --fp32            # 降级到 FP32（省显存）
```

### 7.3 Lovart 风格不一致

**问题**：不同批次出图风格差异大。

**根因**：未使用 Brand Kit 统一视觉参数。

**解决方案**：
1. 确保 Brand Kit 中 `visual_style.keywords` 设置准确
2. 场景 prompt 添加品类限定词
3. 同品类图片使用相同的 prompt 模板 + 仅替换产品名
