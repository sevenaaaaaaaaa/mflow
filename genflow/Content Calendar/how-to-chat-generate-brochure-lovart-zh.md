# 如何通过聊天用Lovart生成宣传册——从空白页到可打印PDF

[图片1占位符——人物场景]

你的客户需要为下周的贸易展准备一本宣传册。你打开InDesign。你盯着一个空白版面。你想起宣传册设计不是一项任务——而是二十项任务：封面布局、内页流程、图片放置、文本格式化、出血边距、折线、打印规格。两小时后，你只完成了一半的封面，并且越来越怀疑这会占用你整个星期。

宣传册设计特别折磨人，因为它将编辑布局、品牌设计和打印制作整合到一个交付物中。每个面板必须既独立（作为单独的视觉元素）又连续（作为叙事流程）地工作。AI设计代理将这个多层次的设计问题转化为一次对话——你描述宣传册结构，代理进行构图，你逐面板进行优化。

## 为什么宣传册是设计系统的终极考验

[图片2占位符——概念图]

宣传册不是一张带文字的图片。它是一个面板系统，每个面板都有自己的内容层级，通过一致的视觉语言连接。当宣传册成功时，读者会将其体验为一次无缝的旅程——从封面到内页再到封底——而不会注意到使其连贯的数千个微观决策。

当宣传册失败时，它会明显失败：不一致的边距、不匹配的颜色面板、跨折页不对齐的文本、尴尬出血的图片、每个面板上渲染不同的字体。传统宣传册设计需要你手动在每个面板上强制执行每一条一致性规则。AI设计代理会自动强制执行它们——就像设计系统在网站上强制执行一致性一样。

## 聊天生成宣传册的工作流程

### 第一步——定义宣传册结构

宣传册有标准格式。在提示中命名你的宣传册可以设定画布：

- **双折页**：单张纸，折叠一次。四个面板（封面、内左、内右、封底）。常用于活动节目单、简单产品宣传册。
- **三折页**：单张纸，折叠两次（三折）。六个面板（每面三个）。是展示架卡片、服务宣传册、旅游材料的标准格式。
- **多页小册子**：多张纸，骑马订或胶装。每张纸四页。常用于目录、年度报告、品牌手册。
- **门式折页**：三个面板——两个侧面板向内折叠覆盖中心面板。高端房地产、奢侈品发布。

以格式和尺寸开始提示。例如："美国信纸三折页宣传册，8.5x11英寸，水平折叠，共六个面板。"

### 第二步——编写主布局提示

主布局提示建立了每个面板将遵循的视觉系统。它不是逐面板的描述——而是代理在所有面板上应用的设计规则。

```
美国信纸三折页宣传册，8.5x11英寸，水平折叠，六个面板。
应用品牌套件：[品牌套件名称]——使用品牌主蓝色（#1A3A5C）、
点缀金色（#C8A84E）、字体搭配 Montserrat（标题）和 Lora（正文）。

主布局规则：
- 所有边缘 0.25 英寸出血。
- 折线位于距左边缘 3.6875 英寸和 7.375 英寸处。
- 所��面板具有一致的 0.4 英寸内边距。
- 标题：Montserrat Bold，24pt，品牌蓝色，每个面板内左上对齐。
- 正文：Lora Regular，11pt，深炭灰色（#333333），14pt 行距。
- 图片区域约占每个面板视觉权重的 50%。
- 一条细金色规则线（1pt）分隔标题区域和正文区域。
- 每个面板右下角页码，8pt，Lora Italic，品牌蓝色 50% 透明度。

封面面板（在平面布局中最右侧，折叠后成为正面）：
- 全出血主图覆盖整个面板。
- 宣传册标题以大型白色 Montserrat Bold 叠加在底部三分之一处，标题后方有深色渐变叠加以确保可读性。
- 副标题以较小的金色文本位于标题下方。
- 公司徽标位于左上角，在安全边距内。

面板 1（内左）：公司故事/关于我们部分。
左半部分：图片。右半部分：标题 + 2 段正文 + 金色斜体引用语。

[继续描述每个面板的内容和布局...]
```

关键见解：主规则部分告诉代理如何设计。面板描述告诉代理在每个面板上放什么。在提示中分离这些关注点，比从头描述每个面板产生更一致的输出。

### 第三步——逐面板生成

如果你的宣传册有六个面板，不要试图在一个庞大的提示中描述所有六个面板。代理在顺序方法下表现更好：

1. **提示 1**：描述主布局规则和面板 1（封面）。
2. **提示 2**："面板 2，相同的主布局规则。内左——关于我们部分。[内容描述]。"
3. **提示 3**："面板 3，相同的主布局规则。内中——服务概览。[内容描述]。"

继续每个面板。通过引用"相同的主布局规则"，代理在所有面板上保持视觉一致性——相同的边距、相同的字体、相同的颜色规则——无需你重复说明。

### 第四步——导出打印

当所有面板都获得批准后，提示导出：

```
将完整的三折页宣传册导出为可打印 PDF。
包括：所有边缘 0.25 英寸出血、裁切标记、CMYK 色彩配置文件（US Web Coated SWOP v2）、
300 DPI、所有字体嵌入。
将折线指定为非打印参考线。
文件名：AcmeCorp_Trifold_Brochure_2026.pdf。
```

如果你通过在线服务打印，请检查他们的具体文件要求。大多数服务需要单个 PDF，包含平面布局（所有面板在一侧）、按阅读顺序的页面、带出血和裁切标记。在导出提示中指定这些。

### 第五步——为未来宣传册创建模板

第一本宣传册教你结构。第十本宣传册应该花费你十分钟，而不是十小时。将主布局提示保存为模板：

```
[三折页宣传册模板]
格式：美国信纸，三折页，水平折叠，六个面板。
品牌套件：[插入品牌套件名称]。
主布局规则：[上述标准规则]。
面板 1（封面）：[全出血图片 + 标题 + 副标题 + 徽标]。
面板 2：[图片左 + 正文右 + 引用语]。
面板 3：[内容类型]。
面板 4：[内容类型]。
面板 5：[内容类型]。
面板 6（封底）：[联系信息、行动号召、徽标]。
导出：可打印 PDF，CMYK，300 DPI，出血 + 裁切标记。
```

下一个项目：更换品牌套件，更换图片，更换内容。结构保持不变。

## 常见问题

**代理支持哪些宣传册尺寸？**

所有标准尺寸：美国信纸（8.5x11"）、美国法律用纸（8.5x14"）、A4（210x297mm）、A5（148x210mm）、DL（99x210mm）。在提示中指定尺寸和测量单位。

**代理能否处理专业打印的出血和裁切标记？**

可以。在导出提示中指定"包括 0.25 英寸出血、裁切标记和 CMYK 色彩配置文件"。代理将生成满足商业打印机规格的可打印输出。

**如何确保文本不会在折线处丢失？**

在主布局规则中指定"0.25 英寸折线安全区域"。代理将使文本和关键视觉元素远离折线。对于三折页宣传册，内页的右侧面板和封底的左侧面板对折线特别敏感——请特别提及它们。

**如果我需要将宣传册翻译成多种语言怎么办？**

先用主要语言生成一次主布局。然后提示："将所有正文替换为附带的西班牙语翻译，保留字体、大小、颜色和布局。调整文本流以适应更长的西班牙语副本。"代理在交换内容的同时保持视觉系统。

**我能否从现有 PDF 或文档生成宣传册？**

可以。将内容作为文本文件上传或粘贴到聊天中。提示："为此餐厅菜单内容生成三折页宣传册布局。品牌套件：[餐厅品牌套件]。应用主布局规则并将此内容分配到六个面板中。"

**定价计划如何影响宣传册生成？**

宣传册是图片密集型、多面板项目。免费计划支持基本的单图片生成。19 美元的入门计划支持单面板宣传册导出。对于完整的多面板三折页和小册子生成及可打印导出，49 美元的专业计划提供无限生成和 CMYK 导出。99 美元的团队计划和 149 美元的代理计划增加了品牌套件管理和协作审查功能。

**我能否为数字宣传册添加交互元素？**

可以。提示："数字宣传册版本——在图片上添加微妙的悬停效果、可点击的目录链接以及面板 2 中的嵌入式视频占位符。导出为交互式 PDF。"代理可以生成用于数字分发的交互式 PDF 功能，同时保持相同的视觉设计。
