## Thinking & Fast Mode

Master Lovart's workflow modes. Use Thinking Mode for strategic execution plans and brand systems, or Fast Mode for rapid visual brainstorming and iteration.

### Thinking Mode

![Lovart AI Modes: Thinking Mode Strategy vs. Fast Mode Speed](https://cdn.sanity.io/images/o11tm2qe/production/73a9870b5cfe563ebc35a69551fd9c014f07a2f3-2160x1350.png)

Lovart AI Modes: Thinking Mode Strategy vs. Fast Mode Speed

Delivers comprehensive, structured solutions with in-depth analysis and strategic reasoning. Use when you need:

- Complex brand systems and design guidelines with clear strategic direction.
- Multi-step campaigns requiring coordinated concept-to-execution planning.
- Strategic decisions that demand careful consideration and justified reasoning.
- Long-term content series with consistent brand voice and visual language.

**When to Use Thinking Mode:**

1. **Brand Development Projects**
   - Creating comprehensive brand guidelines (logo usage, color palettes, typography systems)
   - Developing brand voice documents and visual identity systems
   - Planning multi-channel brand rollouts

2. **Campaign Strategy**
   - Designing multi-phase marketing campaigns with consistent messaging
   - Creating content calendars with strategic visual directions
   - Planning cross-platform brand presence

3. **Complex Design Systems**
   - Building UI component libraries with consistent styling
   - Creating template systems for recurring marketing needs
   - Developing design token systems for scalable branding

**Thinking Mode Best Practices:**
- Provide detailed context in your initial prompt
- Break complex requests into logical phases
- Review AI outputs for strategic alignment before proceeding
- Iterate systematically with clear feedback

### Fast Mode

![](https://cdn.sanity.io/images/o11tm2qe/production/bc6e807affb256c5fc80047f7df8747ea4f0ebe4-2160x1350.png)

Generates multiple creative options quickly for rapid exploration and iteration. Use when you need:

- Initial brainstorming and exploratory concept generation.
- Quick side-by-side comparison of different design directions.
- Fine-tuning and incremental refinements to existing concepts.
- Visual references and inspiration gathering.

**When to Use Fast Mode:**

1. **Early-Stage Exploration**
   - Brainstorming visual concepts for a new project
   - Generating multiple style variations for client review
   - Exploring different mood boards and aesthetic directions

2. **Rapid Iteration**
   - Quick refinements to existing designs
   - A/B testing multiple headline styles or visual treatments
   - Generating alternatives when current options aren't working

3. **Inspiration Gathering**
   - Creating reference collections for research
   - Generating style exploration for creative briefs
   - Building mood boards with diverse visual options

**Fast Mode Best Practices:**
- Start broad and let AI generate diverse options
- Use generated results as springboards for direction
- Compare multiple outputs to identify what resonates
- Refine promising directions with additional prompts

### Choosing the Right Mode

**Decision Framework:**

| Scenario | Recommended Mode | Rationale |
|----------|------------------|-----------|
| Creating brand guidelines | Thinking | Strategic consistency matters |
| Generating 10 social post variations | Fast | Speed and variety are priorities |
| Planning a product launch campaign | Thinking | Coordinated strategy essential |
| Exploring logo design directions | Fast | Iteration and exploration needed |
| Building a design system | Thinking | Systematic thinking required |
| Creating quick mockups for review | Fast | Fast feedback loop needed |

**Hybrid Approach:**
Many workflows benefit from using both modes strategically:
1. **Start with Fast Mode**: Generate multiple directions quickly
2. **Select promising concepts**: Identify 2-3 strong directions
3. **Switch to Thinking Mode**: Develop selected concepts with depth and strategy

This approach maximizes both creativity exploration and strategic refinement.

### Mode Switching During Projects

**When to Switch:**
- When you need to pivot from exploration to execution
- When initial concepts need deeper strategic development
- When quick variations are needed mid-project
- When project scope changes from exploratory to comprehensive

**How to Switch:**
Simply indicate in your next prompt: "Now switch to Thinking mode to develop this concept comprehensively" or "Let's use Fast mode to explore variations of this."

### FAQ

**Q: Can I save mode preferences for future sessions?**
A: Yes, your mode selection is remembered. However, you can override it anytime with specific mode requests in prompts.

**Q: Does mode choice affect AI model selection?**
A: Thinking mode tends to use more comprehensive model combinations for strategic depth. Fast mode optimizes for speed while maintaining quality.

**Q: What if I need both speed and strategy?**
A: Use the hybrid approach: Fast mode for initial exploration, then Thinking mode for selected concepts.
