# Content Production Ledger Reference

SSOT: `1-1 GEO Readme/文档/04-质量治理/Content-Production-Ledger.md`

Blog writers must:

1. Create H2 Ledger after SERP brief, before body.
2. Update status after each H2 (`planned` → `drafted` → `verified`).
3. Re-read Ledger before any resume — never continue from chat memory.
4. Run 30/40/30 shrinkage check before final output.
5. Attach Ledger Completion Report in Final QA.

Quick H2 fields: `judgment`, `mechanism`, `example`, `counterexample`, `evidence`, `visual`, `cta_or_next`.

Each major H2 needs at least 3 of: judgment, example, mechanism, reader insight, next action.
