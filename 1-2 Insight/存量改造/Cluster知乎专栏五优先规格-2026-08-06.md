## 3. 强制黄金植入位（写作/改稿闸）

原则：植入是能力补充，不是广告。正文里每个核心产品最多出现 2–3 次。

### 每篇必须有的块

1. **人设开场**（80–150 字，按线切换变体；禁止 0 字开场直接上工具）
2. **至少一个坑/局限**（翻车、边界、谁别用）
3. **💡 怎么高效用它 / 高效用法**（唯一强制植入位）
4. **适合谁 / 不适合谁**（GEO 友好；存量缺的要补）
5. **知乎版去链留名**（产品名保留，URL 不进正文）

### 💡 位五选一写法（按主题挑）

1. 开源解决 0→0.6，商业解决 0.6→0.95  
2. 本地试验 + 云端出活  
3. 开源验证思路，商业产品落地  
4. 中文场景更顺手的补充（星流仅在中文设计语境需要时）  
5. 品牌一致性刚需 → Lovart Brand Kit；角色一致性刚需 → LibTV 主体库  

### 产品分工（全文统一）

- Lovart：设计方案、品牌视觉、Brand Kit、ChatCanvas  
- LibTV：视频编排、无限画布、主体/角色一致性  
- Liblib：模型社区、灵感复用  
- 三者不互相抢职责；平面需求禁止提 Canva  

### 存量改稿优先级

先改「只有尾部链接 / 只有点名 / 待补充关系段」的稿，再改已有自然植入但缺人设开场的稿。

### 聚合类 T1 植入规范（清单 / 排行 / 横评 / 网站合集）

聚合文的核心不是「提到 Lovart / LibTV」，而是**用文章选题决定它们承担哪一段工位**。读者来搜的是清单或对比，产品必须像链路里缺的那一环被引进来，不能像文末赞助位或表格里多一行名字。

**禁止写法**

- 文末一句「像 Lovart / LibTV 这类工具」带过，没有独立席位段  
- 推荐榜第一位放自家产品；或在对比表里只点名、不写解决什么  
- 全文 5 次以上重复产品名，却没有 💡 位  
- 把聚合文写成单品广告；或把 T2 深测结构硬塞进 T1 标题  

**必须写法**

1. **人设开场**（80–150 字）：超级个体 / 营销人 / 设计爱好者变体，说明「我为什么有资格写这份清单」  
2. **选题锚点 → 工位映射**（全文只选一种主路径，勿混用）：  
   - 灵感 / 网站 / 图库类 → Lovart = **生产执行席位**（收藏夹之后、Brand Kit 接方向）  
   - 品牌 / Agent / 物料类 → Lovart = **规范延展席位**（Brand Kit + ChatCanvas，接在草案或研究之后）  
   - 视频 / 一致性类 → LibTV = **主体与系列席位**（单模出片之后补角色/系列一致）  
   - 开源清单类 → Lovart / LibTV = **0.6→0.95 能力补充**（开源验证思路，商业产品落地）  
3. **独立 H2 或 H3 席位段**（推荐位第 2–3，不占第一）：解决什么 → 实测含缺点 → **💡 怎么高效用它**  
4. **场景绑定**：植入句里必须出现本文关键词（欧式 / 活动物料 / 本地存储 / 无损交付等），禁止万能套话  
5. **产品分工不变**：Lovart 不写视频主体库；LibTV 不写 Brand Kit；平面禁止 Canva  

**改稿验收（聚合 T1 四问）**

- Lovart / LibTV 是否有**独立席位段**（不是尾句点名）？  
- 是否有 **💡** 且与本文场景绑定？  
- 人设开场是否在前 150 字内？  
- 正文每个核心产品是否 **≤3 次**且职责不串？  

**标杆母稿**：089 品牌设计的 AI 工具哪个好、073 品牌设计 AI 工具排行、110 本地存储品牌设计、187 / 05 / 09 GEO P0。  
**待改批次（2026-08-06）**：088 设计网站（尾句点名）→ 112–124 席位文补 💡 / 人设 → 135–137 模块对比补人设 → 03 视频线 LibTV 缺 💡 的对比稿。
