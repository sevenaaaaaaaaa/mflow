# 如何使用 Lovart 通过聊天生成 AI 短视频 — 从脚本到视觉分镜

[图片 1 占位符 — 用户场景]

你的内容日历要求本周制作三个短视频。你打开视频编辑器。时间线是空的。你没有素材，没有 B-roll，不知道从何下手。你花了两个小时浏览素材库，找到一些勉强匹配脚本但又不完全匹配的片段，最终结果看起来就像互联网上其他所有素材混剪一样 — 千篇一律、支离破碎、毫无记忆点。

短视频是这十年主导的内容格式。Instagram Reels、TikTok、YouTube Shorts、LinkedIn 视频 — 每个平台都在将竖屏视频作为其主要内容类型。但制作并没有像分发那样实现民主化。大多数创作者拥有分发渠道，却缺乏制作能力。AI 设计代理弥补了这一差距：你描述场景序列，代理生成视觉资产，你将其组装成视频。

## 为什么 AI 生成的视觉效果正在改变短视频制作

[图片 2 占位符 — 概念图]

传统视频制作要求你要么 (a) 拍摄原始素材（昂贵、耗时、需要设备和技能），要么 (b) 授权使用素材库（选择有限、感觉千篇一律、授权复杂）。这两种途径都为你能够制作的视频内容量设定了上限。

AI 生成的视觉效果移除了这个上限。你不再受限于你能拍摄什么或素材库中存在什么。你描述你需要的场景，代理就会生成它。这不是理论 — 内容创作者已经在大规模制作 AI 生成的视频内容，使用 AI 视觉资产作为关键帧、背景板、B-roll 插入片段和动画场景元素。

## 聊天生成 AI 短视频工作流程

### 第一步 — 编写视觉脚本

不要从提示词开始。从将文字映射到视觉的脚本开始：

```
脚本："改变我工作流程的 3 个 AI 工具"（60 秒竖屏短视频）

场景 1（0-5 秒）：钩子 — 我，震惊的表情，看着我的手机。
屏幕文字："我测试了 47 个 AI 工具。只有 3 个真正有效。"
视觉风格：手机自拍美学，我的客厅，自然光。

场景 2（5-15 秒）：工具 1 — 工具界面的截图，
漂浮在干净的 3D 空间中，带有微弱的发光效果。
我的画外音解释它的功能。
屏幕文字："工具 #1：[名称]"

场景 3（15-25 秒）：工具 2 — 相同的视觉处理，不同的工具。

场景 4（25-35 秒）：工具 3 — 相同的视觉处理，不同的工具。

场景 5（35-50 秒）：演示 — 分屏。左侧：我用旧方式做任务
（挣扎，夸张）。右侧：我用 AI 工具做任务
（轻松，夸张的解脱）。喜剧节拍。

场景 6（50-60 秒）：结尾 — 我，放松，自信。
文字："你会先尝试哪一个？在下方评论。"
带有 CTA 的结束卡。
```

这种脚本格式为代理提供了所需的一切：场景时长、视觉描述、文字叠加、风格参考和情感基调 — 按场景、按顺序。

### 第三步 — 生成过渡和 B-roll 资产

关键帧之间的空间是视频感觉专业或业余的地方。生成过渡资产：

```

```

```

```


### 第四步 — 组装和计时

导出所有关键帧、过渡和 B-roll 资产。在你的视频编辑器中（CapCut、Premiere、DaVinci Resolve，甚至 Canva）：

1. 按脚本顺序将关键帧放置在时间线上。
2. 在场景之间添加过渡。
3. 调整每个关键帧的时长以匹配脚本时间。
4. 录制并嵌入你的画外音。
5. 添加运动 — 在静态关键帧上使用简单的 Ken Burns ��放和平移来营造视频的错觉。
6. 以 1080x1920、30fps 或 60fps 导出。

## 常见问题解答

**Lovart 是生成完整的视频还是只生成图像？**

Lovart 生成视觉资产 — 关键帧图像、过渡元素、结束卡、B-roll 帧。你使用任何视频编辑器将这些资产组装成视频。这个工作流程让你完全控制时间、节奏和音频，同时消除了最困难的部分 — 创建视觉效果。

**哪些视频编辑器最适合 Lovart 生成的资产？**

任何支持图像序列的编辑器都可以。CapCut（免费，移动优先）在短视频创作者中最受欢迎。DaVinci Resolve（免费，专业级）用于更高的制作价值。Canva（拖放式）适合初学者。Premiere Pro 适合已经使用 Adobe 生态系统的用户。

**代理能生成动画元素吗？**

代理生成带有运动建议的静态图像。对于简单的动画，导出你的关键帧并在编辑器中应用 Ken Burns 效果（缩放/平移）。对于更复杂的动画，将生成的图像作为参考，在动画软件或接受图像输入的 AI 视频工具中使用。

**一个 60 秒的视频需要多少个关键帧？**

最少 6-8 个关键帧（每 7-10 秒一个）。关键帧越多 = 视觉变化越多 = 越不无聊。对于快节奏内容，生成 10-15 个关键帧，每个停留 3-5 秒。视觉变化本身就能吸引注意力。

**我可以在多个短视频中使用相同的视觉风格吗？**

可以 — 这就是风格参考方法的目的。在你的提示词系列开始时定义一个"频道风格"："本系列所有场景：深色模式美学，品牌蓝色点缀，高对比度，电影感照明。"每个关键帧都将共享这个视觉 DNA。

**音频和画外音呢？**

音频是你的视频编辑器的领域。在 Lovart 中生成你的视觉效果，然后在编辑器中录制画外音、添加音乐并同步所有内容。视觉管线与音频管线解耦 — 各自做自己最擅长的事。

**这与 Sora 或 Runway 等完全 AI 生成的视频工具相比如何？**

Sora、Runway 和类似工具从文本提示词生成完整的视频片段 — 包括运动等。Lovart 生成你组装成视频的高质量静态视觉资产。Lovart 方法让你对构图和品牌有更多控制，但需要手动组装。完全 AI 方法给你完整的片段，但控制较少。它们是互补的 — 许多创作者两者都使用。
