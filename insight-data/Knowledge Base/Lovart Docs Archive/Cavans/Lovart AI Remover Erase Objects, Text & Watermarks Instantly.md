## Remover

Clean up images intelligently with Lovart's AI Remover tool. erase unwanted objects, people, or watermarks while automatically filling the background context.

### What It Does

The Remover tool uses AI to intelligently erase unwanted objects, people, text, or watermarks from your images while automatically filling in the removed area with contextually appropriate content.

### How To Use

1. **Access the Tool**
	- Select your image
	- Click **"Remover"** in the top toolbar
2. **Draw Your Selection**
	- Click and drag to outline the object you want to remove
	- Adjust brush size for precision (smaller for details, larger for big areas)
	- Use the reset icon if you need to start over
3. **Apply Removal**
	- Click the **"Remover"** button to process
	- AI will intelligently remove the area (takes 3-10 seconds)
### Removal Workflows

**Object Removal:**
1. Select image on canvas
2. Click "Remover" in toolbar
3. Adjust brush size for target object
4. Paint over object you want to remove
5. Click "Remover" button to process
6. AI fills area with appropriate content
7. Review and refine if needed

**Text/Watermark Removal:**
1. Zoom in to text area for precision
2. Select smaller brush size
3. Carefully trace around text
4. Include small margin around edges
5. Apply removal
6. Check for clean elimination
7. Use touch-up if needed

**People Removal:**
1. Select entire person area
2. Use larger brush for efficiency
3. Include shadows and reflections
4. Apply removal
5. AI generates background fill
6. Blend edges if visible

### Brush Size Guide

| Task | Recommended Brush Size |
|------|------------------------|
| Small objects/logos | Small (10-30px) |
| Medium objects | Medium (30-60px) |
| Large areas | Large (60-100px) |
| Background fills | Large or variable |

### Best Practices

**For Clean Results:**
- Leave small margin around objects
- Cover entire area you want removed
- Work from edge to center
- Check results at different zoom levels

**Quality Tips:**
- Higher resolution images process better
- Clear backgrounds make fills easier
- Complex scenes may need multiple passes
- Review edges for seamless blending

### Troubleshooting

**Fill Doesn't Match:**
- Try selecting slightly different area
- Use smaller brush for better precision
- May need manual editing for complex fills
- Try removing in smaller sections

**Edges Visible:**
- Use touch-up brush
- Apply smaller removal for edges
- Blend with surrounding content
- Adjust selection and retry

**Removal Incomplete:**
- Ensure selected area covers entire object
- Try with slightly larger selection
- Include shadows and reflections
- Apply removal again if needed

### FAQ

**Q: What's the difference between Remover and Remove BG?**
A: Remover selectively removes specific areas you paint. Remove BG removes entire background automatically.

**Q: Can I remove multiple objects?**
A: Yes, you can make multiple selections in one session. Process all at once or one at a time.

**Q: Does removal work on all image types?**
A: Best results with good contrast and clean backgrounds. Complex scenes may need multiple passes.

**Q: Can I undo removal?**
A: Yes, Cmd/Ctrl+Z undoes. You can also reload the original image.

**Q: How long does processing take?**
A: Typically 3-10 seconds depending on selection size and image complexity.
