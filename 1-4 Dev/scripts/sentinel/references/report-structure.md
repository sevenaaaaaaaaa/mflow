# Lovart Sentinel 报告结构说明 V3

## 企业级品牌声誉报告结构（7板块）

### 一、摘要与核心发现
- 总览品牌声誉变化历程
- 提炼本周期舆情关键指标与核心结论
- 为决策层提供战略概览
- 3-5个核心判断，每个2-3句
- 末尾附代表性用户引用

### 二、品牌声量与影响力分析
- 2.1 搜索声量趋势（引用现有SEO周报，不自制GSC数据）
- 2.2 渠道声量分布（各平台声量特征+情感倾向+角色定位）
- 2.3 区域影响力（地域流量占比+CTR+趋势评估）
- 诊断信息传播结构，量化品牌曝光与触达效果

### 三、关键事件回顾
- 梳理本周期重大营销活动与危机事件
- 按时间线还原舆情波动的关键触发点
- 标注"应对评估"列（✅ 已应对 / ❌ 未应对 / 🟡 观望）
- 事件关联分析（多个事件之间的因果链条）

### 四、品牌形象与用户认知
- 4.1 正面品牌联想（证据来源+强度+衰减趋势）
- 4.2 负面品牌信号（关键指标+严重度+公众可见度）
- 4.3 品牌叙事一致性分析
- 4.4 核心议题热度（讨论热度+情感倾向+主要平台）
- 深入情感态度、品牌联想与核心议题

### 五、用户画像分析
- 5.1 核心用户群体分层（典型画像+核心诉求+触达状态+流失风险）
- 5.2 兴趣标签（"AI工具尝鲜者""设计师/创意人""电商/小企业主"等）
- 5.3 触媒习惯（用户了解品牌的核心路径和行为模式）
- 洞察目标受众特征与行为模式

### 六、声誉风险与机遇洞察
- 6.1 主要负面议题（每个议题含：核心数据+本周变化+影响量化+恶化路径）
- 6.2 高危风险预警（阈值+当前状态+触发后果）
- 6.3 正面机遇（证据+战略价值+时间窗口）
- 追踪负面议题、预警潜在风险、挖掘正面机遇

### 七、结论与战略建议
- 7.1 SWOT分析（优势/劣势/机会/威胁 × 影响评估）
- 7.2 分部门战略建议（品牌安全P0 + 社媒运营P0 + 内容策略P1 + 中国市场P1 + 评价信任P1）
- 7.3 下一周期监测重点（指标+预警阈值+当前基线表）

## 关键原则

1. **GSC数据引用已有报告**：SEO搜索数据直接引用 `SEO周报_*.md` 和品牌词趋势分析，不在舆情报告中重复提取GSC CSV
2. **叙事优先于数据堆砌**：数据服务于故事线，而不是相反
3. **分部门可执行**：每个洞察都标注影响部门和优先级
4. **风险量化**：每个风险项都标注阈值、当前状态和恶化路径
5. **机遇带时间窗口**：每个机遇标注战略价值和时间紧迫度
