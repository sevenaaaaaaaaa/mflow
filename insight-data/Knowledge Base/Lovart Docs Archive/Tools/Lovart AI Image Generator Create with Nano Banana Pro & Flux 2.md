## Image Generator

Generate 4K design assets with Lovart. Access premium models like Nano Banana Pro, Flux 2 Max, and GPT Image. Features aspect ratio control and image referencing.

Lovart AI Image Generator: Create with Nano Banana Pro & Flux 2

### Overview

AI-powered image generation tool for creating design assets through text prompts

### How to Use

1. Click the Image Generator icon in the left toolbar
2. Enter your image description in the "What are we creating today" input field
3. Configure generation settings:
	- **Model**: Select from available AI models
		- Nano Banana Pro (default)
		- GPT Image 1.5
		- Flux 2 Pro
		- Flux 2 Max
		- Nano Banana
		- Seedream 4.5
		- Seedream 4
		- GPT Image
		- ...
	- **Resolution**: Choose output quality
		- 1K (default)
		- 2K
		- 4K
	- **Aspect Ratio (Format)**: Select canvas dimensions
		- 21:9 (1568×672)
		- 16:9 (1456×816)
		- 4:3 (1232×928)
		- 3:2 (1344×896)
		- 1:1 (1024×1024) - default
		- 9:16 (816×1456)
		- 3:4 (928×1232)
		- 2:3 (896×1344)
		- 5:4 (1280×1024)
		- 4:5 (1024×1280)
	- **Image Reference**: Optional
		- Upload Image
		- Select from Canvas
4. Click generate to create your image
5. Generated images automatically appear on canvas for editing

### Image Model Selection Guide

**Nano Banana Pro (Default)**
- Best for: Versatile, balanced outputs for most use cases
- Strengths: Fast generation, reliable quality, good for brand content
- Use when: Social media, marketing materials, general purpose

**GPT Image 1.5 / GPT Image**
- Best for: Artistic interpretations, creative exploration
- Strengths: Unique visual styles, creative edge cases
- Use when: Creative campaigns, artistic projects, unconventional briefs

**Flux 2 Pro / Flux 2 Max**
- Best for: Professional-quality photorealistic outputs
- Strengths: High detail, accurate rendering, commercial quality
- Use when: Product photography, brand imagery, client deliverables

**Seedream 4.5 / 4.0**
- Best for: Chinese aesthetic, Asian market content
- Strengths: Cultural understanding, regional style matching
- Use when: Chinese market campaigns, Asian-focused branding

### Resolution Selection Guide

**1K Resolution (Default)**
- Best for: Quick iterations, social media, drafts
- Faster generation time
- Suitable for: Testing concepts, exploration, rapid workflows

**2K Resolution**
- Best for: Standard marketing materials, web content
- Balanced quality and speed
- Suitable for: Blog images, website hero sections, presentations

**4K Resolution**
- Best for: Print materials, large format displays, professional deliverables
- Higher quality with longer generation time
- Suitable for: Posters, print ads, billboards, client presentations

### Image Reference Techniques

**Using References Effectively:**
- Upload reference images to guide style, composition, or subject
- AI analyzes reference and applies characteristics to new generation
- Works for: Style transfer, composition matching, subject consistency

**Reference Workflows:**
1. Upload brand style image → Generate consistent brand visuals
2. Upload composition reference → Apply layout to new content
3. Upload character reference → Generate same character in new scenes
4. Upload color palette image → Extract and apply color scheme

### Crafting Effective Image Prompts

**Prompt Structure:**
1. Subject: What you want to see (person, object, scene)
2. Style: Visual treatment (photorealistic, illustration, abstract)
3. Composition: How elements are arranged
4. Lighting: Type and mood (golden hour, studio, dramatic)
5. Quality: Professional polish (high detail, 8K, masterpiece)

**Example Prompts:**
- Product: "Professional product photography of wireless headphones on white marble, soft studio lighting, clean background, commercial quality, 4K"
- Branding: "Minimalist brand identity mockup, elegant coffee packaging on natural wood surface, morning light, warm tones, professional photography"
- Creative: "Abstract digital art, floating geometric shapes in gradient colors, ethereal lighting, wide composition, artistic masterpiece"
- Social: "Trendy social media post for fitness brand, dynamic pose with modern gym aesthetic, vibrant colors, Instagram-ready composition"

### FAQ

**Q: Which model is best for photorealistic images?**
A: Flux 2 Max offers the highest quality photorealistic outputs. For speed, Flux 2 Pro provides excellent results.

**Q: Should I always use 4K resolution?**
A: Not necessarily. Use 4K for final deliverables and large formats. Use 1K for exploration and 2K for standard marketing use.

**Q: How do image references work?**
A: The AI analyzes the reference image for style, composition, colors, and subject characteristics, then applies these to the new generation.

**Q: Can I generate images with specific text?**
A: Yes, include text in your prompt. For best results with text, use "clear typography" and describe the text content specifically.

**Q: What's the difference between aspect ratio and resolution?**
A: Aspect ratio defines the shape (horizontal vs vertical). Resolution defines the size/detail level (1K, 2K, 4K).
