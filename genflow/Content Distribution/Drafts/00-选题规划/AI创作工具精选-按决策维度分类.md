## 📊 决策矩阵：怎么选？

### 按预算选

| 预算 | 推荐组合 |
|------|---------|
| **零成本** | Ollama + ComfyUI + Fooocus + GPT-SoVITS + Rembg + social-auto-upload + Trae |
| **月花 <¥100** | 上述 + 云 API（DeepSeek/Qwen 极低价）+ Midjourney 基础版 |
| **月花 ¥100-500** | 上述 + Cursor + 部分付费 SaaS 补充 |
| **不限预算** | 直接用 SaaS（HeyGen/Runway/Midjourney），开源工具做定制化补充 |

### 按技术水平选

| 水平 | 推荐方案 |
|------|---------|
| **纯小白** | 秋叶整合包（SD）+ MoneyPrinterTurbo + Edge-TTS + Trae |
| **会基础命令行** | ComfyUI + Ollama + Rembg + FunASR + social-auto-upload |
| **开发者** | Dify + n8n + LangChain + 全套自部署 |
| **深度玩家** | ComfyUI + kohya_ss（训练 LoRA）+ Wan2.1 + 全链路自动化 |

### 按创作类型选

| 创作类型 | 核心工具链 |
|---------|-----------|
| **短视频博主** | TrendRadar → MoneyPrinterTurbo → social-auto-upload |
| **AI 短剧** | ChatTTS/GPT-SoVITS → AIDrama Studio → KrillinAI（翻译） |
| **AI 画师** | ComfyUI + Flux + ControlNet + IOPaint + Upscayl |
| **数字人直播** | FAY/OpenAvatarChat + CosyVoice + MuseTalk |
| **自媒体矩阵** | TrendPublish → Postiz → social-auto-upload → n8n（数据回收） |
| **设计团队** | Onlook + Excalidraw + Screenshot-to-Code + Penpot |
| **出海团队** | KrillinAI + Lingo.dev + Postiz + TikHub SDK |
