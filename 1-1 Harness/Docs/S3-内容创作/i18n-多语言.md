## npm 入口（Studio）

```bash
cd "1-4 Dev/lovart.sanity.studio"

npm run i18n:prepare    # 准备翻译清单
npm run i18n:apply      # 应用翻译
npm run i18n:verify     # 校验
npm run i18n:publish    # 发布阶段
npm run i18n:verify:crosslang   # composite v2 跨语言结构一致
```

---

## preflight i18n 检查

```bash
node scripts/preflight-content.js --type tools --lang en,ja,pt
node scripts/preflight-content.js --type blog-i18n
```

BLOCK 示例：`I18N_FILENAME`、`I18N_MARKER`（body 含 `(section_de)`）、`I18N_GAP`。

---

## 原则

- 多语言是**重写**不是逐句翻译；关键词本地化，痛点本地化
- SEO 报告必须含 locale 查询证据，不得只按英文优先级排产（`seo_report_standards.py`）
- 支持语言：Pages `en de fr it ja ko pt ru zh-TW`；Blog 常见 `en zh ja zh-TW` + `pt ru`

---

## 验收

- `_index.json` 无关键语言缺口（或已登记 backlog）
- 翻译后 `(section_xx)` marker 为 0
- GROQ 同 slug 各语言 `_id` 不同
