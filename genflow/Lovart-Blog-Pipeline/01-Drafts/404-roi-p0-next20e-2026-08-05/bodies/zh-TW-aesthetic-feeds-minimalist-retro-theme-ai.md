# 極簡與復古 aesthetic feed：2026 AI 維持九宮格一致性

这篇补 `/zh-TW/blog/aesthetic-feeds-minimalist-retro-theme-ai` 404。搜索意图围绕「極簡復古 aesthetic feed」，读者要可执行步骤，不是灵感图库。

## 我的立场

Aesthetic feed 不是每張都好看，而是 **九張放在一起像同一本雜誌：色溫、留白、字體三件套先鎖**。

## Brief 合约（我实际在用的）

```
格線：3×3 預覽 + 1080×1350 貼文 + 1080×1920 限動
調性：minimalist 或 retro 二選一，禁止混
色票：2 主色 + 1  accent，寫 hex
顆粒：retro 才加 film grain，minimalist 禁止
禁止：每張不同字體、假 VSCO preset 名
```

## 踩坑

**坑 1：九宮格色溫 drift。** 解法：Brand Kit 鎖 hex + 色溫關鍵字。
**坑 2：復古顆粒過重。** 解法：grain 15% 上限，Touch Edit 降。
**坑 3：極簡變空。** 解法：每張留 1 個 focal point。
**坑 4：限動與 feed 不同調。** 解法：MCoT 同 brief 多尺寸。
**坑 5：仿 IG 大 V 排版。** 解法：原創 grid 結構。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export
