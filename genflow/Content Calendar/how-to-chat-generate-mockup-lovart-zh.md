# 如何通过聊天用 Lovart 生成产品样机——无需摄影棚的产品展示

[图片 1 占位符——人物场景]

你的应用已经完成。UI 打磨好了，流程流畅了，发布日期也定好了。你需要将截图放入设备框架中，用于 App Store、你的网站和演示文稿。你打开一个样机模板网站。可选的要么是 (a) 每个竞争对手都在用的那六个相同的 iPhone 在木桌上的模板，要么是 (b) 每个 29 美元的高级模板，但仍然需要 Photoshop 来嵌入你的截图。

样机是产品展示的通用语言。它们回答了每个利益相关者都会问的问题：“这实际看起来会是什么样？”一个执行良好的样机能将一张平面截图转化为一个真实的产品瞬间。一个 AI 设计智能体通过描述你的产品所属的上下文来生成自定义的样机场景——而不是模板化的样机。

## 为什么样机比截图更重要

[图片 2 占位符——概念图]

一张白底平面截图传达的是“这是一个进行中的工作”。同一张截图放在设备里，由一只手握着，置于真实场景中，传达的则是“这是一个产品”。这种差异是心理上的，而非技术上的。样机创造了上下文。上下文创造了信任感。

对于数字产品——应用、网站、SaaS 平台——样机回答了那个未说出口的问题：“这感觉像是我会使用的真实东西吗？”对于实体产品——包装、服装、商品——样机回答的是：“这东西在我手里、在我架子上、在我生活中会是什么样子？”一个 AI 设计智能体可以通过同一个聊天界面生成这两种类型的样机。

## 聊天生成样机的工作流程

### 第一步——选择你的样机类型

样机可分为清晰的类别。在提示词开头说出你的类型：

- **设备样机**：手机、平板、笔记本电脑、台式显示器、智能手表——你的屏幕设计显示在设备上。
- **印刷品样机**：名片、宣传册、传单、海报、书籍封面、包装——握在手中、放在桌面上或置于场景中。
- **服装样机**：T 恤、连帽衫、帽子、手提袋——你的设计印在服装上，穿在模特身上或平铺展示。
- **包装样机**：盒子、瓶子、袋子、罐子、管子——你的标签设计应用其上，置于产品摄影场景中。
- **环境样机**：广告牌、店面招牌、车身贴膜、展会展位——你的设计置于真实世界环境中。

每种类型需要不同的场景线索。设备样机需要手的出现和环境上下文。包装样机需要材质纹理和能展现形态的照明。

### 第二步——撰写上下文优先的提示词

普通样机和引人注目的样机之间的区别在于上下文。不要描述设备。描述那个瞬间。

```
iPhone 15 Pro 健身应用样机。
一只手在户外清晨直射阳光下握着手机。
屏幕显示我们应用的运动追踪仪表盘——明亮、多彩、高对比度，
以便在阳光下清晰可见。手部自然、不做作——像是刚跑完步，
正在查看数据的人。模糊的背景中：一条公园小径，晨光透过树叶，
散景效果。手机是主角——它大约占据画面中央的 50%。
周围的上下文（手、公园、光线）支持产品而不与之竞争。
干净、有抱负、编辑风格的科技产品摄影。
暖色调——接近黄金时刻。
```

关键要素：
- 具体设备型号（iPhone 15 Pro）——智能体渲染出正确的设备形状和边框比例。
- 描述屏幕内容（运动仪表盘）——智能体在屏幕上显示正确类型的内容。
- 上下文（跑步后、公园、早晨）——讲述设备之外的产品故事。
- 手部出现且姿势自然——避免“机器手臂握手机”的恐怖谷效应。
- 景深（模糊背景、散景）——营造摄影真实感。
- 构图指令（占据画面 50%、居中）——防止设备太小。

### 第三步——替换屏幕内容

AI 生成设备样机的魔力在于：你描述屏幕内容，智能体将其合成到设备中。无需 Photoshop 智能对象替换。

```
同样的样机场景——同一只手、同一个公园、同样的光线。
现在替换屏幕内容：不要运动仪表盘，显示我们应用的饮食记录屏幕。
其他所有元素完全保持不变。
```

从一个场景生成一个屏幕样机库。一个公园场景；换入五个不同的应用屏幕。你的 App Store 截图、网站主图和社交媒体图片都共享一致的视觉上下文——品牌一致性，无需制作开销。

### 第四步——生成包装和印刷品样机

对于实体产品，描述物体的材质属性：

```
高端护肤品包装样机。
一个深蓝色矩形盒子，带有金色烫印文字（我们的品牌标志），
放在大理石浴室台面上。左侧窗户射入的晨光，投下柔和的斜影。
盒子微微打开，露出里面的玻璃滴管瓶。
柔焦背景中有一枝桉树和一条亚麻手巾。
干净、奢华的美丽摄影风格。
强调金色烫印的纹理——它应该捕捉光线。
盒子占据画面 60%，居中，从略微俯视的角度拍摄。
```

注意材质线索：“深蓝色盒子”、“金色烫印文字”、“玻璃滴管瓶”、“大理石台面”、“桉树”。这些不仅仅是物体——它们是材质规格，告诉智能体表面应如何反射光线、纹理应如何呈现，以及产品所处的品质等级。

### 第五步——构建可复用的样机库

一旦你有了一个出色的样机场景，将其保存为可复用的模板：

```
[样机场景模板：晨间公园 iPhone]
设备：iPhone 15 Pro。上下文：户外、早晨、公园小径、斑驳阳光、
手握手机（自然、活动后姿势）。背景：模糊的树木、散景。
光线：黄金时刻、暖色调。构图：设备占画面 50%、居中。
风格：编辑型科技产品摄影。
```

下一个产品，同一个场景——只需交换屏幕内容。你的整个产品线共享一种视觉语言。这就是品牌建立可识别视觉形象的方式——不是为每个产品发明新的摄影，而是建立一个场景语言并一致地应用它。

## 常见问题解答

**智能体能否在设备上显示我实际的应用截图？**

智能体根据你提供的描述生成屏幕内容的表示。要获得你实际 UI 的像素级精确度，最可靠的工作流程是：生成带有屏幕内容占位符的设备样机场景，导出它，然后在后期处理中合成你的真实截图。智能体处理困难的部分——逼真的设备、手、环境、光线。

**智能体可以为哪些设备生成样机？**

iPhone（最新型号）、Android 手机（通用旗舰设计）、iPad、MacBook、Windows 笔记本电脑、台式显示器、Apple Watch 和通用智能手表。为获得最佳效果，请按名称指定设备。对于不常见的设备，进行物理描述（“一款坚固耐用的 GPS 手持设备，4 英寸屏幕，厚边框，橙色点缀”）。

**如何让手看起来自然，而不是机械？**

提示词中使用“自然握持，放松的手，真实的人拿着——不是摆拍，不是模特，不是机械”。如果手看起来不对，迭代修改：“手看起来太僵硬了。让它更放松——手指自然弯曲，拇指放在侧面，就像有人随意查看手机一样。”手的真实感是设备样机中最大的质量变量。

**我可以生成印有我的设计的服装样机吗？**

可以。描述设计、服装和上下文。“一件黑色连帽衫，胸前印有我们的品牌标志（白色山形剪影）。穿在户外的人身上，自然姿势，轻微布料褶皱以增加真实感。标志应顺应布料褶皱——而不是贴在上面的平面贴纸。”智能体将设计渲染为印在布料上的效果。

**产品发布时我应该生成多少种样机变体？**

至少五种：手持设备（主图）、桌面设备（生活方式）、屏幕特写（功能细节）、产品带包装（开箱）、环境（场景/原位）。这套组合覆盖你的 App Store 截图、网站主图、功能部分、社交媒体和新闻资料包。

**样机的最佳导出分辨率是多少？**

对于应用商店列表：遵循平台指南（Apple 要求特定尺寸）。对于网页：2400 像素宽、72 DPI 是一个不错的通用尺寸。对于印刷：按实际印刷尺寸的 300 DPI。在导出提示词中指定分辨率和 DPI。
