Set Up Your Brand Kit
Configure your brand identity once so every output stays on-brand.
If you&#x27;re working with an existing brand, we recommend setting up a Brand Kit before generating to ensure on-brand output. A Brand Kit stores your logo, colors, fonts, and design guidance globally, and will be applied to every creative task based on your needs. You can create a separate Brand Kit for each brand you work on.
Open the Brand Kit manager.
From the Lovart homepage, click the Brand Kit icon in the left toolbar.
Add your brand assets.
Manual upload:
Add logos, fonts, color swatches, and design guidance one at a time.
Parse a brand book:
Upload an existing brand book PDF and let Lovart extract elements automatically.
