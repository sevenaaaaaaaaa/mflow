你拍了一张合照。每个人都看起来很棒，除了你。你的微笑介于“人质处境”和“税务审计通知”之间。你正在眨眼。或者没有眨眼。光线在你的脸上刻下阴影，就像一座哥特式大教堂。

二十年前，这张照片是废片。十年前，你可以在Photoshop中用克隆图章和液化工具花上45分钟，制作出看起来像自己蜡像的东西。如今，AI人脸编辑让你可以修复微笑、平滑皮肤、调整光线和重塑表情——同时让你看起来还是你自己。不是滤镜下的幽灵。不是Snapchat的面具。是你自己。

## 旅程：五种修复，一个工具

[图片2占位符 — 概念图]

### 修复1 — 微笑调整（“我看起来像便秘”问题）

这是最常被要求的人脸编辑，远超其他。强挤出的微笑看起来不自然，因为它只动用了嘴巴，而不是眼睛。真正的微笑——杜兴微笑——涉及眼轮匝肌。

**Lovart 工作流程：**

1. 将你的肖像上传到Lovart。
2. 使用ChatCanvas选择嘴巴和眼睛区域（两者都要——不要只调整嘴巴）。
3. 输入提示词：`自然的真诚微笑，杜兴微笑，眼睛在笑，放松快乐的表情，保留所有其他面部特征，保持皮肤纹理和光线`
4. 生成。检查。
5. 如果微笑太强烈（小丑风格），添加：`微妙的闭口微笑，嘴角轻微上扬，温暖但自然`

**需要避免的：** 永远不要在提示词中使用“大笑”或“大微笑”——AI会字面理解并产生令人不安的结果。“自然”、“真诚”和“微妙”是更安全的向量。

### 修复2 — 皮肤平滑，避免塑料感

AI可以平滑皮肤。AI也可以把你变成一个没有毛孔的瓷娃娃。区别在于提示词。

**两层方法：**

**对于自然肖像（推荐）：**
```
微妙的皮肤修饰，减少瑕疵和不均匀纹理，保留自然皮肤毛孔，保持逼真的皮肤细节，无塑料效果，无喷绘感，自然皮肤
```

**对于编辑/美容：**
```
专业美容修饰，平滑均匀的皮肤，微妙光泽，工作室灯光打在皮肤上，杂志编辑质量，去除瑕疵，保留自然皮肤纹理
```

关键词是“保留”——它告诉模型保留已有的东西，而不是从头生成全新的、完美平滑的皮肤。真实的脸有纹理。去掉纹理，你就得到了一个人体模型。

### 修复3 — 眼睛修正（眨眼、红眼、视线方向）

照片中眨眼是宇宙提醒你摄影是一门概率艺术的方式。AI可以修复这个问题。

**闭眼/眨眼：**
在ChatCanvas中选择眼睛区域。提示词：`眼睛睁开，看向相机，自然表情，匹配原始眼睛颜色和形状，逼真的巩膜，眼睛中的眼神光`

**视线��向修正（看向错误的相机）：**
提示词：`眼睛直接看向相机，自然的眼神接触，微弱的眼神光反射，保留眼睛颜色和形状`

**红眼去除：**
在大多数情况下，Lovart的AI会自动检测并修正红眼。对于顽固的红眼，选择瞳孔区域并提示：`自然的深色瞳孔，微妙的虹膜细节，去除红色反射，逼真的眼睛`

### 修复4 — 光线修正

糟糕的光线无法通过增加亮度来修复。增加亮度会冲淡高光并将阴影提升为灰色。AI可以完全重新照亮脸部——模拟不同的光源位置。

**ChatCanvas 光线修正提示词：**
```
用[描述所需光线]重新照亮脸部，保留皮肤纹理和颜色，自然光线衰减，逼真的阴影，[方向]主光，[强度]补光
```

**按问题分类的光线配方：**

| 问题 | 提示词 |
|--------|------------|
| 平淡，无立体感 | "添加伦勃朗光，脸颊上戏剧性的三角光，柔和的阴影" |
| 头顶强光阴影 | "填充眼睛下方和下巴的阴影，宽阔柔和的正面光，降低对比度" |
| 背光/剪影 | "均匀曝光，展现面部细节，平衡光线，自然肤色" |
| 温暖的黄色室内光 | "将白平衡校正为自然日光，去除黄色色偏，清洁肤色" |

### 修复5 — 面部特征调整（微妙，非手术式）

你可以调整个别特征���—下颌线、鼻子、眉毛——但“更好的你”和“不同的人”之间的界限很窄。

**安全调整（保持身份）：**
- 微妙的下颌线定义：`稍微定义下颌线，微妙的轮廓，自然阴影`
- 眉毛对称：`自然均匀的眉毛，微妙的修饰，匹配现有形状`
- 眼下提亮：`减少眼下阴影，提亮眼部区域，自然外观`

**避免：**
- “改变我的鼻子”——这会产生一个不同的鼻子，而不是你鼻子的更好版本
- “让我的脸更瘦”——这会重构骨骼几何结构并破坏身份
- “让我看起来像[名人]”——这会触发换脸行为，而非修饰

原则：修饰增强已有的东西。它不替换它。如果你想要一张不同的脸，请使用头像生成器或换脸功能——这些是不同的工具，用于不同的工作。

### 验证步骤

在导出之前，检查两件事：

1. **切换前后对比**（Lovart包含一个分屏切换开关）。编辑后的版本看起来是同一个人，只是光线更好、表情更佳吗？如果你无法认出是同一个人，你就越过了修饰的界限，进入了身份改变。撤销并调整。

2. **放大到100%。** 检查编辑区域周围的AI伪影——尤其是发际线、耳朵以及面部与背景之间的边界。这些边缘区域是混合错误出现的地方。Lovart的放大处理可以处理大多数伪影，但请验证。

## 常见问题解答

**问：AI真的能修复照片中糟糕的微笑吗？**
能，这是AI人脸编辑真正优于传统Photoshop的领域之一。Photoshop的微笑修复需要手动扭曲嘴部形状，这通常会产生不自然的结果。AI可以用自然的微笑表情重新生成下半部分脸部，同时保留周围的面部特征。关键在于将眼睛包含在再生区域中——真正的微笑涉及嘴巴和眼睛。

**问：AI修饰后，脸还会看起来像我吗？**
如果你遵循“修饰，不替换”的原则——会的。使用包含“保留”、“自然”和“保持”的提示词。避免改变结构特征的提示词（鼻子形状、脸宽、骨骼结构）。前后对比切换是你的诚实检查。如果你认不出自己，你就做得太过分了。

**问：AI人脸修饰比使用Facetune等应用更好吗？**
不同的工具，不同的理念。Facetune将调整叠加为滤镜层——它通过模糊来平滑皮肤，通过去饱和来美白牙齿，通过扭曲像素来重塑形状。Lovart的AI方法根据你的提示词重新生成选定区域，同时保留周围上下文。AI方法对于复杂编辑（微笑变化、重新照明）产生更自然的结果，但需要更有意图的提示词。滤镜应用对于简单平滑更快。AI更适合结构性编辑。

**问：我可以修复一张照片中某人没有看向相机的情况吗？**
可以。使用ChatCanvas选择眼睛区域并提示：“眼睛直接看向相机，自然的眼神接触，眼神光反射。”对于极端的视线角度（侧面视图试图看向相机），结果可能不完美，因为周围的面部几何结构不支持新的视线方向。先在小选区上测试。

**问：免费计划可以做多少次人脸编辑？**
Lovart的免费层包括每天有限数量的图像编辑。对于无限编辑、更高分辨率的导出以及全分辨率下的ChatCanvas区域选择等高级功能，$19/月的计划是标准入门点。

**问：AI可以从肖像背景中移除物体或人物吗？**
可以。Lovart的ChatCanvas允许你选择背景区域并独立重新生成它们。提示词：“干净整洁的背景，移除[物体]，自然景深，匹配现有光线。”脸部保持不动，而背景被重建。这与人脸编辑是分开的，但通常在同一个肖像修饰会话中使用。

**问：AI人脸修饰适用于集体照吗？**
可以，但要有选择性。使用ChatCanvas一次选择一张脸。应用你的修饰提示词。对每张需要调整的脸重复。尝试一次修饰整张集体照会产生不一致的结果，因为AI会对每张脸应用相同的编辑。单独编辑较慢，但会产生显著更好的结果。
