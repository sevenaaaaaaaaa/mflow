## 内容差异化方向

### Lovart 独有角度（竞品写不了的）

1. **生成与可编辑一体**：竞品是"生成器"或"编辑器"，Lovart 是 agent（生成后仍可改）
2. **ChatCanvas 协作**：多人在同一画布改稿，竞品是逐人导出
3. **中文排版**：竞品普遍位图渲染，中文排版失真；Lovart 保留可编辑文字
4. **品牌一致性**：Brand Kit 锁 logo/色彩/字体，竞品需要手动逐张调整

### 写竞品对比时的检查

- [ ] 是否给出了双方适用的场景？
- [ ] 是否有具体数据（价格/速度/数量）？
- [ ] 是否引用了竞品的公开定价页（link）？
- [ ] 是否避免了"Revolutionary" "Best" "Best-in-class" 等空话？
