# 用 Bing AI 做設計：2026 從搜尋到可交付素材

这篇补 `/zh-TW/blog/how-to-create-designs-with-ai-bing` 404。搜索意图围绕「Bing AI 設計製作」，读者要可执行步骤，不是灵感图库。

## 我的立场

Bing 適合 **快速試方向**，但交付前要過 **Lovart 的 ChatCanvas 合約 + Touch Edit 改字**——別把搜尋結果當 final。

## Brief 合约（我实际在用的）

```
Bing：explore 3-5 direction，不烤字
Lovart：锁尺寸、Brand Kit、Touch Edit 文案
任务：1 hero + 2 variant，写明渠道
禁止：Bing 直出带小字、假 logo
出口：PNG + 源 brief 存档
```

## 踩坑

**坑 1：Bing 直出当 final。** 解法：进 Lovart 重排+改字。
**坑 2：画面小字糊。** 解法：Touch Edit 文案区。
**坑 3：尺寸不对渠道。** 解法：MCoT 按 artboard 导出。
**坑 4：风格每次不同。** 解法：Brand Kit 锁关键词。
**坑 5：商用权未查。** 解法：license 段落写进 brief。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export

## 公式

\[ \text{交付} = \frac{\text{Bing探索} + \text{Lovart修整}}{\text{返工小时}} \]

## FAQ

### 能直接交付客户吗？

Export 前跑一遍 checklist：假徽标、双 CTA、联系信息可读。

### 改期/改价怎么办？

Touch Edit 改对应区域，不全图重跑。

### 需要会 PS 吗？

不必；极端修图仍可用 PS 补。

### 多语言 brief？

品牌术语 Lovart、MCoT、ChatCanvas、Touch Edit 不翻译。

### 多少 direction 够？

3–4 个，选一个进 Brand Kit 流程。

## 实战复盘 1：Bing 试色三个方向

我先故意用不清晰的需求去跑：两个 CTA、日期含糊、渠道不明确。围绕「Bing AI 設計製作」的第一轮输出往往很好看，也往往说不清要观众做什么。

然后我只改一句「任务句」，其他先保持粗糙。第二轮明显更可用。说明瓶颈经常在需求，不在模型神话。

本轮我聚焦「Bing 试色三个方向」：在 ChatCanvas 里把渠道尺寸写死，把禁止项列进 brief，MCoT 出三个方向时我只看信息层级是否清楚，不先看装饰。

### 我改了什么

只保留一个行动点；日期写成陌生人能读懂的格式；禁止假徽标；写明渠道尺寸；默认文案可 Touch Edit。
