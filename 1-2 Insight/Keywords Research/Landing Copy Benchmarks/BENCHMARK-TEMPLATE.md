## Six Fields

### 1. Page Promise

- 这页在第一屏到底承诺了什么？
- 是 job-to-be-done、团队结果、还是教育判断？

### 2. Hero Formula

- 主语是什么？
- 输入是否明确？
- 输出是否明确？
- 风险降低点是什么？
- 面向谁？

### 3. Proof Shape

- 它用什么建立可信度？
- deliverable / before-after / formats / rights / testimonial / benchmark / limitation / pricing

### 4. Workflow Shape

- 输入 → 生成 → 编辑 → 导出是否写清？
- 是 3-step、tab、compare、gallery 还是 dense explanation？

### 5. CTA Shape

- CTA 动词是什么？
- 对应哪个流量阶段？
- 是 start free / compare / talk to sales / see workflow / claim offer？

### 6. FAQ Objection Shape

- 它回答了哪几类真实异议？
- 商用、格式、团队、迁移、速度、可编辑性、适用边界？
