# FreeCut 深度测评：浏览器里开多轨剪辑——还要不要装剪映/Premiere？

> T2 深度测评 · 浏览器视频编辑 · 2026  
> 在线版：https://freecut.net · 文档：https://freecut.net/docs  
> GitHub：https://github.com/walterlow/freecut（笔记口径 ⭐ 1.4k+）· MIT · 纯 Chromium 本地剪辑，不上传素材

---

## 👤 测评人背景

分发侧剪视频，常常卡在「装哪个软件」：剪映快但工程偏平台；Premiere 重；LosslessCut 只适合无损切一刀。FreeCut 声称把多轨、关键帧、WebGPU 预览、Whisper 字幕、本地 TTS 塞进浏览器，素材不上云。我按夹内笔记拆：它能替掉哪些「临时精剪」，又绝对替不掉哪类专业流。

---

## 🎯 先说结论

FreeCut 是开源的 **浏览器端多轨视频编辑器**：WebGPU/WebCodecs/OPFS/File System Access，时间线含视频音频文字图片形状遮罩，支持混合模式、关键帧、色键、示波器，以及 Whisper 字幕、Kokoro TTS、MusicGen 等本地 AI 辅助。项目以纯文本保存在你选的文件夹，媒体引用原文件不复制。适合要免安装、免上传的创作者；**非 Chromium、要完整达芬奇协作调色、要移动端**的人，直接出局。

**我的决策句：你用 Chrome/Edge 做中短视频精剪、在意隐私与开源，优先打开 freecut.net 建工作区试一条；Firefox/Safari 用户或重度桌面 NLE 工作流，不建议迁移——LosslessCut 管快切，专业成片仍回桌面套件。**

## 📦 FreeCut 是什么？

核心主张：「桌面级剪辑体验搬进浏览器」。导出 MP4/WebM/MOV/MKV 等，编码选项含 H.264/H.265/VP9/AV1/ProRes 等口径，全部本地 WebCodecs。简单了解：常和 Clipchamp、Canva、剪映网页向工具比——差异在 **MIT 开源 + 不上云 + 更偏专业剪辑控件**（源监视器、三点编辑、滑移/滑动、速率伸缩等笔记口径）。

## 🧩 FreeCut 有哪些功能？

### 功能特色一览

| 功能模块 | 具体表现 | 实用价值 |
|----------|----------|----------|
| 多轨时间线 | 视音频文字图片形状遮罩；快捷键剪辑 | 真剪辑，不只是裁一刀 |
| GPU 特效与关键帧 | 混合模式、转场、贝塞尔关键帧、色键、示波器 | 预览与调色辅助更接近桌面 |
| AI 辅助 | Whisper 字幕；Kokoro TTS；MusicGen；语义场景搜索 | 少切出软件做旁白/字幕 |
| 本地工程 | 纯文本项目文件；媒体不拷贝 | 隐私友好；换机需重链素材 |

### 时间线才是本体

`V` 选择、`C` 剃刀、`R` 速率、`Ctrl+K` 拆分……这套快捷键说明它想服务「会剪的人」，不是纯模板用户。对我这种偶尔精剪口播的人，价值是开网页就能干，不用再装一套。

> 📷 **配图待补**：剃刀与多轨（`images/freecut-feature-timeline.png`）

### AI 辅助：加分项，不是主菜

Whisper 出字幕、本地 TTS 出旁白，适合教程快链。终稿字幕仍建议人审；复杂译制可交接 MioSub。

> 📷 **配图待补**：Whisper 字幕面板（`images/freecut-feature-ai.png`）

### 浏览器与 Brave 坑

仅 Chromium 113+。Brave 默认可能关 File System Access，要去 flags 打开——这是真实安装摩擦，写进团队说明可少挨骂。

## 🧠 核心逻辑：它为什么不一样？

云剪辑卖算力与素材库；FreeCut 卖 **浏览器里的本地工程权**。

三拍：工作区落盘 → GPU 预览编辑 → 本地导出。

**机制层怎么选**：隐私精剪、免安装 → FreeCut；只切无再封装 → LosslessCut；模板化社媒成片 → 剪映/Canva；电影级调色协作 → 桌面 NLE。

## ⚔️ FreeCut 和 Clipchamp/Canva、LosslessCut 有什么区别？

| 维度 | FreeCut | Clipchamp/Canva | LosslessCut |
|------|---------|-----------------|-------------|
| 定位 | 开源浏览器多轨 NLE | 商业在线成片 | 无损快切 |
| 隐私 | 不上云叙事 | 常需账号/云 | 本地 |
| 能力 | 多轨特效关键帧 | 模板与素材强 | 几乎不调色 |
| 平台 | Chromium 桌面 | 更广 | 桌面客户端 |
| 最强场景 | 隐私精剪免安装 | 快速模板出片 | 只切不要重编码 |

选型句：要 **开源本地多轨**，优先 FreeCut；要 **模板商用素材**，Canva/Clipchamp；要 **无损快切**，LosslessCut。

## 🧪 我实际跑下来的体验

说明：功能列表、限制、快捷键来自夹内笔记；Stars 为笔记口径。**未编造导出耗时与画质分数。**

### ✅ 好的方面

**1. 「免安装 + 不上云」对准真痛点**  
客户样片、未上线素材可以在浏览器里剪完再压。

**2. 控件像给会剪的人用的**  
三点编辑、示波器等口径，不是玩具时间线。

**3. MIT + 导出无水印**  
分发向很友好。

**4. AI 辅助收在同一工作区**  
字幕/TTS 少切软件，周更节奏更顺。

### ❌ 不好的方面

**1. 非 Chromium 直接不可用**  
团队有人用 Safari/Firefox，别强制统一到 FreeCut。

**2. 工程不可随便挪机器**  
换电脑要重链媒体——备份策略要写清。

**3. 高分辨率吃内存**  
大片请关杂标签；老 GPU 会降级 Canvas 2D，预览会挫。

**4. 开源但未开放 PR**  
只收 Issue/Discussion——别指望提 PR 改你的私有需求。功能缺口用 Issue 反馈，或用别的工具补一环，不要 fork 出无法合并的私服幻想。

内存与 GPU 是物理墙：4K 时间线开三个特效时，我会先关其它标签，再谈「浏览器能不能替代 Premiere」。能，是在素材体量与特效欲望都克制的前提下；不能，是你把电影调色预期塞进标签页。

## 💡 怎么高效用它

### 用法 1：工作区与素材盘分离

工作区放项目文本；大素材放固定盘符/文件夹，避免整盘乱搬。导出后需要压缩可走 tools.video。换电脑前导出成片与项目备份，并记录媒体绝对路径——重链素材比「我文件呢」省半小时。

> 📷 **配图待补**：选择工作区（`images/freecut-usage-1.png`）

### 用法 2：粗剪→精剪分工

无损快切可先 LosslessCut/FunClip；进 FreeCut 做多轨与字幕；封面多尺寸走 Lovart。Whisper 出的字幕先当草稿，专名与时间轴仍要人看——浏览器 NLE 省的是安装，不省审片。

> 📷 **配图待补**：工具链交接（`images/freecut-usage-2.png`）

### 用法 3：导出前关标签、存一次

浏览器崩是真实风险。关键节点手动确保项目写入工作区。Brave 用户把 File System Access flags 写进内部 Wiki，新人第一天少踩坑。快捷键 `Ctrl+Shift+E` 导出前，先把播放头走一遍听音轨——本地导出无水印，但静音段和爆音一样会跟着出去。

本地开发需 Node 22+；日常用 https://freecut.net 即可。移动端明确不支持，别拿平板 Safari 开会演示「我们全部迁浏览器剪辑」。

## ⚠️ 安装和使用需要注意什么？

### 数据会离开本机吗？

编辑与导出按叙事在本地。若使用在线托管版，仍信任该站点分发前端；极敏感可自建 `npm run dev`。

### 许可证

MIT。商用友好；以仓库 LICENSE 为准。

> 📷 **配图待补**：浏览器要求说明（`images/freecut-note-permission.png`）

---

语义场景搜索（笔记口径 `Ctrl+Shift+F`）适合长素材里找某一屏 UI；找到后再剃刀，比纯靠记忆拖时间线快。MusicGen/Kokoro 当草稿音，商用曲库与音色授权仍要另审——本地生成不等于免版权。处理 4K 前先用低分辨率代理试时间线，确认特效与字幕位置，再换回高分辨率导出，能少崩几次浏览器。

> **怎么选：** Chromium 用户要做隐私向多轨精剪，优先 FreeCut；只要无损切一刀用 LosslessCut，要模板社媒成片用剪映/Canva，要电影级调色协作请回桌面 NLE——不要为「浏览器很酷」硬迁全流程。
