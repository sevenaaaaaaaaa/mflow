## Quick Edit

Streamline design iterations with Lovart's Quick Edit. Press 'Tab' to access rapid AI adjustments, A/B testing, and non-destructive editing tools instantly.

![Lovart Quick Edit: Instant AI Adjustments via Tab Shortcut](https://cdn.sanity.io/images/o11tm2qe/production/a1bec3984ff83d96290cc94412c1d41cab2fae09-2160x1350.png)

Lovart Quick Edit: Instant AI Adjustments via Tab Shortcut

Quick Edit provides fast access to common editing tasks through a convenient tab interface. It streamlines workflow by grouping frequently used adjustments in one accessible panel for rapid modifications.

### How To Use

1. **Access Quick Edit**
	- Click the **"Quick Edit"** button/tab at the bottom of images
	- Or press **Tab** keyboard shortcut
2. **Make Adjustments**
3. **Apply & Exit**
	- Changes apply automatically as you adjust
	- Click elsewhere or press Esc to close panel

### Quick Tips

- Use Quick Edit for rapid iterations and A/B testing
- Combine multiple adjustments in one session
- Keyboard shortcuts speed up workflow
- Perfect for non-destructive editing
### Quick Edit Features

**Instant Adjustments Available:**
- Brightness/Contrast adjustments
- Color balance and saturation
- Shadow and highlight recovery
- Sharpening and blur effects
- Crop suggestions based on composition
- One-click enhancements

### Quick Edit Workflow

**Basic Adjustment Workflow:**
1. Select image on canvas
2. Press Tab or click Quick Edit tab
3. View available adjustments
4. Drag sliders for instant preview
5. Click elsewhere or Esc to apply and close

**A/B Testing Workflow:**
1. Open Quick Edit panel
2. Try different adjustment combinations
3. Note preferred settings
4. Reset and try variations
5. Apply final choice

### Adjustment Categories

**Light Adjustments:**
- Brightness: Overall light/dark control
- Contrast: Difference between light and dark
- Highlights: Brightest areas
- Shadows: Darkest areas
- Exposure: Global light level

**Color Adjustments:**
- Saturation: Color intensity
- Vibrance: Smart saturation boost
- Temperature: Warm/cool shift
- Tint: Green/magenta adjustment

**Quality Enhancements:**
- Sharpness: Edge definition
- Clarity: Midtone contrast
- Dehaze: Remove atmospheric haze
- Denoise: Reduce noise

### Keyboard Shortcuts Integration

**Efficient Workflow:**
- Tab: Open Quick Edit
- Esc: Close Quick Edit (applies changes)
- Arrow keys: Fine adjustment when slider focused
- Space: Toggle before/after view

**Customizing Your Workflow:**
- Set preferred starting point
- Create adjustment presets
- Save successful combinations
- Apply consistently across projects

### Common Use Cases

**Photo Enhancement:**
1. Upload photo to canvas
2. Open Quick Edit
3. Auto-enhance for better exposure
4. Adjust contrast for punch
5. Apply slight sharpening
6. Close and continue editing

**Social Media Optimization:**
1. Import image
2. Quick Edit → boost saturation slightly
3. Increase contrast for visual impact
4. Apply subtle sharpening
5. Export optimized for social

**Presentation Polish:**
1. Add images to presentation
2. Use Quick Edit for consistency
3. Apply same color treatment
4. Ensure sharp, professional look

### Tips for Best Results

**Start Conservative:**
- Small adjustments often best
- Build up from subtle changes
- Check at actual size before major changes
- Avoid over-processing

**Use as Starting Point:**
- Quick Edit gives quick baseline
- Refine further with full tools
- Combine with AI-powered features
- Achieve optimal results faster

### FAQ

**Q: Are changes destructive?**
A: Changes can be undone with Cmd/Ctrl+Z. You're not permanently committed until you save.

**Q: Can I see before/after?**
A: Many tools show preview as you adjust. Some systems offer toggle between original and edited.

**Q: Does Quick Edit affect all images?**
A: Only the selected image/element is affected. Other canvas elements remain unchanged.

**Q: Can I save adjustment presets?**
A: After finding good settings, document them for application to other images.

**Q: What's the difference between Quick Edit and full editing tools?**
A: Quick Edit provides fast access to common adjustments. Full tools offer more control and specialized features.
