## 👤 测评人背景

分发侧最烦的「字幕债」不是不会做，而是工具链太碎：Whisper 出稿、机翻糊一版、Aegisub 对齐、再找人压制——一条 20 分钟片子能把下午磨没。剪映字幕快，但专名、双语导出、ASS 样式一碰就憋。MioSub 喊的是「下载 → 转录 → 翻译 → 校对 → 时间轴 → 压制」一条龙，还带在线 Demo。我按夹内调研笔记与官方公开口径拆开看：哪些环节真能省工具切换，哪些仍得人审。

---

## 🎯 先说结论

MioSub 是开源的 **一站式 AI 字幕桌面端**（Electron + React 19），口号是「世界的内容，你的语言」。它不是又一个「只会吐 SRT 文本」的转录壳，而是把对齐、双语导出和一键压制放进同一编辑器；v3.0 还强调 CTC 毫秒级对齐与纯音频（播客/有声书）路径。官方宣传口径里，约 30 分钟视频可在约 8 分钟内跑完主流程——**我未在撰写当日复测该时长，不当成我的测速成绩**。适合每周都要出双语字幕、愿意配 AI/转录 API 的 UP 主与字幕组；只想零配置机翻、也不导出成片的人，会觉得它偏重。

**我的决策句：你每周至少认真做 1 次「外站视频/播客 → 双语字幕成片」，并且能接受配置 API 与人审专名，再装桌面版；只想偶尔糊一句字幕，用剪映或网页机翻就够，别为全流程付学习成本。**

## 📦 MioSub 是什么？

MioSub 面向「字幕工程」：粘贴视频/音频链接，自动走下载与转录翻译，回到可边看边改的编辑器，最后导出 SRT/ASS 或直接压成片。文档与 Demo（https://demo.miosub.app）降低试错成本；大批量与压制仍建议桌面端。简单了解：它常和「Aegisub + 机翻」土法、剪映/CapCut 字幕并列讨论——差异不在「有没有 AI」，而在 **全流程是否收口到一个可编辑工作台**。

## 🧩 MioSub 有哪些功能？

总起：技术栈是 Electron 39 + React 19 + TypeScript；能力依赖你配置的 AI/转录服务，软件本身是编排壳，不是「免费无限云算力」。

### 功能特色一览

| 功能模块 | 具体表现 | 实用价值 |
|----------|----------|----------|
| 全自动主链路 | 粘贴链接 → 下载/转录/翻译/对齐 → 回到可编辑成品 | 少在 4–5 个软件间来回倒文件 |
| 上下文向编辑器 | 实时预览、自动滚动、说话人标注、术语提取、搜索替换 | 专名与梗能集中改，不当黑盒机翻 |
| 导入导出与压制 | SRT/ASS 导入；双语导出；一键压制成片 | 交付物能直接发，不只是聊天框里的字幕草稿 |
| v3.0 对齐与音频 | CTC 毫秒级对齐；播客/电台/有声书纯音频路径 | 少依赖外部对齐工具；不只服务「有画面视频」 |

### 全自动主链路

对我这种要持续出片的人，价值在「半成品能进下一棒」：编辑器里改完就能导出或压制，而不是再找第三条命令行。笔记口径支持中/英/日界面与 100+ 语言互译——语言覆盖以官方文档为准，冷门语言仍要抽检。

> 📷 **配图待补**：粘贴链接后的自动流水线状态（`images/miosub-feature-pipeline.png`）

### 编辑器与人审

没有复核的自动化，只会自动化地出错译。说话人标注、术语提取，本质是承认：专名、梗、口语必须人过一眼。我自己的规矩是——机器出第一版，我只改「人名/品牌/梗」三层，比从零打轴快一个数量级。

> 📷 **配图待补**：边看边改的字幕编辑面板（`images/miosub-feature-editor.png`）

### v3.0：对齐与纯音频

CTC 对齐若按文档口径成立，能砍掉「外挂对齐工具」那一环；纯音频路径则让播客译制不必先硬找画面轨。Release 有时仍挂在旧名 `Gemini-Subtitle-Pro` 路径下——下载以 Releases 页实际资产为准，别被仓库改名搞懵。

## 🧠 核心逻辑：它为什么不一样？

很多字幕工具卖的是「转录准确率」；MioSub 卖的是 **工序收口**。

可以想成三拍：

1. **收口**：链接/文件进同一工作台，少搬运  
2. **加工**：对齐 + 上下文翻译 + 可编辑轨道  
3. **交出**：SRT/ASS/压制成品，能进平台或下一棒配音

**机制层怎么选**：先用 Demo 或短样本打通「转录 + 翻译 + 导出」；再谈批量长片与压制。一上来就丢两小时成片，等于主动找账单和翻车。

## ⚔️ MioSub 和 Aegisub+机翻、剪映字幕有什么区别？

| 维度 | MioSub | Aegisub + 机翻 | 剪映 / CapCut 字幕 |
|------|--------|----------------|-------------------|
| 定位 | 一站式 AI 字幕工程台 | 专业打轴 + 外挂翻译 | 成片剪辑里的字幕附带能力 |
| 门槛 | 要配 API/服务，有文档 | 学习曲线陡，工具链长 | 上手快，样式偏平台默认 |
| 成本 | 软件开源；API/算力按量 | 软件免费；人时最贵 | 订阅/免费档混合 |
| 最强场景 | 要双语导出 + 压制收口 | 要极致样式与逐帧打轴 | 国内短视频快出、少导出 ASS |
| 短板 | 质量绑死底层模型；AGPL 商用要读协议 | 工序碎、难周更 | 专名与双语工程感偏弱 |

选型句：要 **可控的双语字幕全流程**，优先认真试 MioSub；要 **逐帧样式与字幕组传统工艺**，继续 Aegisub；要 **短视频平台内快速出片**，剪映往往更省心——不必为清单硬切。

## 🧪 我实际跑下来的体验

说明：安装路径、功能点、FAQ 来自夹内笔记与官方公开资料；Stars 取撰写时 GitHub API（786）。**未编造测速**；「30 分钟约 8 分钟出片」仅作官方宣传口径标注。

### ✅ 好的方面

**1. 主链路叙事清楚，像给字幕组用的软件**

下载到压制写进同一产品故事，比「只给你一个 Whisper 按钮」更贴近真实交付。对我来说，少开三个窗口就是效率。

**2. 编辑器默认「人要改」**

预览、术语、搜索替换——说明作者不相信机翻终稿。这点和分发侧体感一致。

**3. Demo + 文档降低试错成本**

先在 https://demo.miosub.app 感受交互，再装桌面版配 API，比一上来编译环境友好。

**4. 纯音频路径扩大了使用面**

播客、电台、有声书不必硬造画面轨，译制选题可以更宽。

### ❌ 不好的方面

**1. 「开源」不等于「算力免费」**

转录/翻译走云端或本地模型，批量长视频账单要自己估算。把软件免费误当成内容免费，月底会哭。

**2. 专名与梗仍会翻车**

上下文感知再强，也扛不住圈内黑话与新梗。我的翻车点通常出在品牌中英文混写——编辑器必须过一眼。

**3. 仓库改名带来的下载摩擦**

产品叫 MioSub，Release 仍可能落在 Gemini-Subtitle-Pro 路径。给同事发链接时要指到具体资产，否则对方下错包。

**4. AGPL-3.0 对二次分发不温柔**

自用一般够；若要闭源嵌入或改完再分发，必须读 LICENSE，别只看「开源」两个字。

### 素材笔记里的常见问法

**Q：和传统 Aegisub + 机翻有什么区别？**  
MioSub 强调链接一键全流程 + AI 上下文翻译 + 内置对齐，减少工具来回切换；Aegisub 仍是样式与逐帧的天花板。

**Q：只有音频可以吗？**  
v3 支持播客/有声书等纯音频。

**Q：在线 Demo 和桌面版一样吗？**  
Demo 适合体验；大批量与压制建议桌面版 + 文档配置。

## 💡 怎么高效用它

### 用法 1：短样本打通再放大

先拿 3–5 分钟片段跑通「链接 → 编辑器 → 导出 SRT」。专名表先建好（品牌、人名），再丢长片。第一次就上两小时成片，等于主动找对齐事故和 API 账单。

> 📷 **配图待补**：短样本试跑界面（`images/miosub-usage-1.png`）

### 用法 2：半成品交给下一棒

字幕定稿后，若还要配音/译制口播，可交接给配音向工具（如 Violin 一类）；视觉封面与多平台尺寸可在 Lovart 侧定妆。MioSub 管字幕条，不管你的封面审美。

> 📷 **配图待补**：导出文件进入下一棒示意（`images/miosub-usage-2.png`）

### 用法 3：配置当资产

API Key、默认语言对、术语表写成内部一页说明；团队改掉共享口令，Key 不进群聊。配置不能交接，就不叫工序。

v2.x 升级看官方迁移指南（https://miosub.app/docs/guide/migration）；安装包从 GitHub Releases 或官网取。

## ⚠️ 安装和使用需要注意什么？

### 数据会离开本机吗？

桌面端本地编辑不等于转录不上云：一旦接云端 ASR/LLM，**音视频片段可能按供应商政策入云**。不要默认「开源 = 数据不出门」。敏感素材先确认所用服务的数据条款。

### 许可证允许商用吗？

协议为 **AGPL-3.0**。自用先看 SPDX；二次分发、闭源嵌入另读全文。

### 版权与平台规则

翻译/转载他人视频，工具能力解决不了著作权与平台规则。分发前仍要过「能不能转、要不要标注、会不会限流」三问。

> 📷 **配图待补**：API/权限设置页（`images/miosub-note-permission.png`）
