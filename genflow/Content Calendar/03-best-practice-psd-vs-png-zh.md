# 最佳实践：PSD 与 PNG 导出——何时使用每种格式

[图片 1 占位符 — 用户场景]

你刚刚在 Lovart 中完成了一个设计。它看起来非常精致。你将鼠标悬停在“导出”按钮上，出现了两个选项：PSD 和 PNG。如果你的第一反应是“有什么区别，我为什么要在意”，那你问的正是关键问题——答案将帮你避免导出后陷入困境。

一句话总结：**PNG 给你一张图片。PSD 给你一个项目文件。** 你需要哪一个，完全取决于下一步要做什么。

## 根本区别（通俗解释）

[图片 2 占位符 — 概念图]

PNG 是一个扁平化的图像——单层像素，就像一张照片。每个元素（文本、形状、背景、Logo）都被合并到一个静态帧中。你可以在任何图像查看器中打开它，上传到任何地方，与任何人分享。但编辑它？不行。除非从头开始。

PSD（Photoshop 文档）是一个分层文件。每个文本块、每个形状、每个图像都位于自己的图层上。在 Photoshop、Photopea（免费）或任何兼容编辑器中打开它，你可以移动标题、替换背景、调整单个颜色，并进行微调直到完美——无需从头重建任何内容。

可以把 PNG 想象成一张打印好的海报。PSD 则是打印机使用的那叠透明胶片。一个用于*查看*。另一个用于*编辑*。

## 3 种绝对需要 PSD 的场景

### 1. 设计将被再次编辑（由你或他人）

这是最常见的场景，也是先导出 PNG 会犯下真正错误的情况。如果你的设计需要内部审核——经理希望标题更大，客户希望移动 Logo，团队成员需要替换不同的产品照片——PSD 是必不可少的。

导出 PNG 然后要求某人“做一点小改动”，就像递给他们一张打印好的照片，然后要求他们用 Photoshop 处理。技术上可行，实际上很痛苦。PSD 保持每个元素独立且可编辑。收到你文件的人可以打开它，双击标题，然后输入新内容。搞定。

**经验法则：** 如果这个设计在现有版本之外还有未来，请导出 PSD。

### 2. 你向客户交付文件

客户交接时，格式选择从“锦上添花”变成了“合同义务”。大多数专业简报都指定分层源文件作为交付物。即使没有，发送 PSD 也能体现专业性。它传达的信息是：“这是你的设计，而且你可以在没有我的情况下对其进行修改。”

更实际的是，客户会要求修改。这不是“如果”，而是“何时”。第一轮就发送 PSD 意味着第二轮只需几分钟而不是几小时。你会打开文件，调整元素，然后重新导出。客户付更少的钱，你做更少的工作，每个人都赢。

### 3. 你正在打印实体物料

印刷生产有网页展示所没有的要求。出血边距、CMYK 色彩配置文件、特定的分辨率要求，而且通常——需要分层源文件供印刷厂的印前团队进行调整。

PNG 无法在不同软件之间可靠地携带色彩配置文件信息。PSD 可以。如果你的设计要用于广告牌、宣传册、展会横幅，甚至名片，请给印刷厂一个 PSD。他们会感谢你，因为不会在周五下午 4:55 打电话问你技术问题。

## 3 种选择 PNG 的正确场景

[图片 3 占位符 — 真实 UI 截图]

### 1. 社交媒体、网站和电子邮件

这些是“一次创建，永久发布”的用例。你的 Instagram 帖子不需要图层。你的邮件标题不需要出血边距。你��网站主图不应该是一个 200 MB 的 PSD 文件——它应该是一个压缩的、针对网络优化的 PNG，可以立即加载。

在 Lovart 中，当你为数字发布导出设计时，PNG 是默认选项，这是有充分理由的。它被普遍支持，压缩合理，并且支持透明度（与 JPEG 不同）。每个 CMS、每个邮件构建器、每个社交平台都能毫无问题地接受 PNG。

### 2. 最终预览或批准

在你向客户或利益相关者发送任何内容之前，请导出一个 PNG 样稿。它体积小，一键即可打开，并且能准确显示最终输出的样子。没有人会在尝试打开预览时意外更改图层。

在“这是它看起来的样子”阶段使用 PNG。在“这是工作文件”阶段使用 PSD。它们在审批流程的不同时刻发挥作用。

### 3. 嵌入演示文稿或文档中

当你将 PSD 放入 Google Slides 或 Notion 时，会发生糟糕的事情——应用程序要么直接拒绝它，要么渲染出一个无用的低分辨率预览。PNG 可以在每个平台上干净地嵌入。如果设计的最终目的地是演示文稿、文档或 Wiki 页面，PNG 是你唯一现实的选择。

## 决策树（请保存）

```
是否有人之后会编辑此文件？
  → 是 → 导出 PSD
  → 否 → 继续 ↓

是否要交给专业印刷厂？
  → 是 → 导出 PSD
  → 否 → 继续 ↓

  → 是 → 导出 PNG
```

## 选择错误的隐藏成本

当你需要 PSD 时导出 PNG，意味着当需要修改时，你必须从头重新创建设计。对于一个简单的社交图形，这很烦人。对于一个 40 层的活动视觉，这相当于浪费了半天的计费时间。

当 PNG 就足够时导出 PSD，意味着向只想查看设计的人发送一个 150 MB 的文件——现在他们打不开，现在他们给你发邮件，现在你无论如何都得重新导出。

你选择的格式是对接下来会发生什么的承诺。做出正确的承诺。
