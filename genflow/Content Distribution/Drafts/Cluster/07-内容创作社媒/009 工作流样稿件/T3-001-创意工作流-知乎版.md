## 每个环节具体怎么跑？

### Step ① 灵感采集：Liblib —— 从"不知道做什么"到"知道怎么做"

**痛点是什么？**

做内容最难的不是技术，是"今天发什么"。每次开电脑对着空白画布发呆半小时，刷了半天 Pinterest 也没方向。更痛苦的是，好不容易找到好灵感，下次想复现时完全忘了用了什么参数、什么 prompt。

**我怎么解决的？**

Liblib 不只是"看图"，它是你的灵感操作系统。核心打法三层：

**第一层：主动搜索，建立灵感库。**  
打开 [Liblib 灵感广场](https://www.liblib.art/inspiration)，按风格、用途、模型分类搜索。关键是**不要只看不存**——看到好作品立刻收藏到专属灵感库，打标签（如"科技风""产品图""情绪文案配图"）。积累 2 周，你的灵感库就是最宝贵的资产。

**第二层：复制工作流，而非复制图片。**  
Liblib 最强的能力是工作流复制。点进任意作品，能看到创作者的完整生成链路——用了什么模型、什么 LoRA、什么参数、什么 prompt 结构。一键复制到自己工作区，改几个参数就能产出风格一致但内容全新的作品。这比自己从零调参快 10 倍。

**第三层：反向工程，理解"为什么好看"。**  
不要只是复制，要看懂背后的设计逻辑。为什么这张图用了冷暖对比？为什么那个作品的构图是三分法？把这些"为什么"记下来，慢慢你就能从"抄作业"进化到"会出题"。

**关键细节：**
- **搜索技巧**：用"场景+风格+情绪"三元组搜索，比如"咖啡店 赛博朋克 温暖"，比单关键词精准得多
- **工作流模板**：收藏 5~10 个高频使用的生产工作流，建立你的"快捷菜单"
- **每周花 30 分钟刷一次灵感广场**，保持对新风格、新模型的敏感度——AI 生成领域审美迭代极快
- **成本**：完全免费，Liblib 的灵感广场和工作流复制不收费

### Step ② 品牌视觉：Lovart —— 从"素材"到"品牌感"

**痛点是什么？**

灵感有了，素材有了，但做出来的内容总是"散"的——今天蓝色明天绿色，字体换来换去，Logo 位置每次都不一样。观众看你的内容没有"品牌记忆点"，刷到也记不住是你。更惨的是，想统一风格但每次手动调色、调字体、调布局，比从零创作还累。

**我怎么解决的？**

Lovart 的 Brand Kit 功能，一次性解决品牌一致性问题。

操作路径：

**第一步：建立 Brand Kit（一次性，30 分钟）。**  
在 [Lovart](https://www.lovart.ai) 中创建品牌套件：上传 Logo、设定主色/辅色/强调色、选择 2~3 款品牌字体、定义图片风格关键词（如"扁平化、科技蓝、留白多"）。做完这一步，后面所有设计自动套用。

**第二步：用 Brand Kit 驱动批量出图。**  
需要产品图、封面图、社交媒体图时，只需输入内容描述，Lovart 会基于 Brand Kit 自动生成风格统一的视觉素材。一次生成 4~6 张变体，选最好的微调即可。

**第三步：多尺寸一键适配。**  
同一个设计，一键导出为小红书竖版（3:4）、公众号封面（2.35:1）、Twitter 横幅（16:9）等多种尺寸，Lovart 会智能调整布局，不用手动裁切。

**关键细节：**
- **Brand Kit 是核心资产**：花 30 分钟做好，后面省 30 小时。建议包含：Logo（深色/浅色两版）、配色方案、字体组合、图片风格 prompt
- **从 Liblib 迁移 prompt**：Step① 收藏的好 prompt，在 Lovart 里结合 Brand Kit 重新跑，出来的图既好看又有品牌感
- **善用"变体生成"**：同一个 prompt 生成多张图，从风格微调中找到最佳表达
- **成本**：Lovart Pro 约 ¥99/月，Brand Kit 含在内

### Step ③ 视频制作：LibTV —— 从"图片"到"会动的故事"

**痛点是什么？**

静态图再好看，在短视频时代也不够用。但传统视频制作门槛太高：学 Premiere 至少一周，AE 更是噩梦。找外包？一条 30 秒短视频报价 500~2000 元，一个月出 10 条就是一台 MacBook 的钱。而且外包周期长，跟不上热点节奏。

**我怎么解决的？**

LibTV 用节点式工作流，让"图片变视频"像搭积木一样简单。

操作路径：

**第一步：导入视觉素材。**  
把 Step② Lovart 生成的品牌视觉素材导入 LibTV，支持批量导入，自动识别素材类型。

**第二步：选择/搭建节点工作流。**  
LibTV 的核心是节点式视频工作流——每个节点是一个处理步骤（运镜、转场、特效、字幕、配音），连线就是完整的视频管线。

两个选择：
- **选模板**：LibTV 社区有大量现成的节点工作流模板，选风格匹配的替换素材即可
- **自己搭**：拖拽节点，连线，调参数。常用节点组合：`图片输入 → 运镜节点(Ken Burns) → 转场节点(溶解) → 字幕节点 → 背景音乐节点 → 输出`

**第三步：批量生成 + 微调。**  
同一套节点工作流，换不同素材就是不同视频。一次性生成 3~5 个版本，挑最好的微调——调整运镜速度、字幕位置、音乐节奏对齐。

**第四步：导出成片。**  
支持 1080p/4K 导出，自动适配各平台格式（竖版 9:16、横版 16:9、方形 1:1）。

**关键细节：**
- **节点工作流可复用**：搭好一套"产品展示"工作流，后面每次替换素材就行
- **运镜是灵魂**：静态图片做视频，Ken Burns 效果（缓慢放大/平移）是最万能的选择
- **字幕自动化**：LibTV 支持语音转字幕，做口播类视频能省大量时间
- **和 Lovart 的衔接**：Lovart 导出时保持统一画布尺寸和命名规范，导入 LibTV 就不会乱
- **成本**：基础功能免费，高级节点/大量导出按量计费，日常使用几乎零成本

### Step ④ 流程自动化：n8n —— 从"手动操作"到"自动跑"

**痛点是什么？**

前三步已经能高效产出内容了，但每次还是要手动：下载视频 → 打开发布平台 → 上传 → 填标题描述 → 加标签 → 发布 → 下一个平台……发 6 个平台光发布就要半小时，每个平台格式、标签、描述还不一样。更崩溃的是，哪天忘了发、发错版本，之前的努力全白费。

**我怎么解决的？**

n8n 是这条生产线的"中央调度室"——连接所有工具，自动化一切重复操作。

**第一步：部署 n8n（一次性，30 分钟）。**  
n8n 开源免费，[GitHub 192k stars](https://github.com/n8n-io/n8n)，Docker 一键部署。不想折腾服务器也可用云服务（有免费额度）。

**第二步：设计自动化流程。**  
核心工作流设计如下：

```
触发器（定时/手动/Webhook）
    │
    ▼
检查 LibTV 输出目录 ──▶ 发现新视频？
    │                      │ 否 → 等待
    │ 是
    ▼
获取视频文件 + 元数据
    │
    ▼
调用 Postiz API ──▶ 创建发布任务
    │
    ▼
填充各平台模板（标题/描述/标签/封面）
    │
    ▼
设置发布时间（可选：立即/定时/最优时段）
    │
    ▼
发送通知（飞书/微信/邮件）──▶ "内容已排期，预计 XX 时间发布"
    │
    ▼
监控发布状态 ──▶ 失败？自动重试 + 告警
```

**第三步：配置模板变量。**  
为每个发布平台设置独立模板——标题格式、描述长度、标签规则、封面尺寸各不相同。n8n 的 Set 节点和 IF 节点可以轻松处理这些差异。

**第四步：加上监控和通知。**  
n8n 的 Error Trigger 节点可以在任何环节失败时自动通知。你再也不用盯着屏幕等结果，该干嘛干嘛，出问题了手机提醒你。

**关键细节：**
- **Webhook 触发最灵活**：LibTV 导出完成后通过 Webhook 直接触发 n8n，完全无需人工干预
- **定时发布策略**：不同平台最优发布时间不同（小红书晚 8 点、公众号早 8 点、抖音中午 12 点），n8n 可为每个平台设置不同发布窗口
- **版本管理**：n8n 记录每次执行输入输出，方便回溯
- **渐进式自动化**：别一上来就全自动。先从"手动触发→自动发布"开始，稳定后再升级为"Webhook 触发→全自动"
- **成本**：自托管完全免费，云服务免费额度对个人创作者足够用

### Step ⑤ 多平台分发：Postiz —— 从"逐个发"到"一键发"

**痛点是什么？**

就算前面 4 步都自动化了，最后的发布环节仍是最大瓶颈。每个平台后台都不一样：公众号要传封面图、选分类、设原创标识；小红书要加话题标签；抖音要选音乐、加挑战赛标签；Twitter 要控制字数……一个内容发 6 个平台至少 20 分钟，还容易出错。

**我怎么解决的？**

Postiz 是开源的多平台社交媒体管理工具，[GitHub 27k stars](https://github.com/gitroomhq/postiz-app)，支持一次编辑多平台发布。

**第一步：连接社交媒体账号。**  
Postiz 支持微信公众号、小红书、抖音、B 站、Twitter/X、LinkedIn、Instagram 等主流平台。一次性授权连接，后续无需重复登录。

**第二步：创建发布任务。**  
上传视频 + 封面图，填写标题和描述。Postiz 编辑器支持为每个平台定制内容——同一个视频，小红书用种草文案，Twitter 用简短 hook，公众号用长文描述。

**第三步：智能排期。**  
Postiz 内置各平台最优发布时间建议，你也可以手动设置或交给 n8n 调度。

**第四步：一键发布 / 定时发布。**  
点击发布，Postiz 自动处理各平台格式转换、上传、发布。你只需要在"已发布"列表确认状态即可。

**关键细节：**
- **和 n8n 联动是关键**：Postiz 提供 API，n8n 可直接通过 API 创建发布任务，实现完全无人值守
- **内容模板系统**：为每个平台建立固定模板（标题格式、标签规则、描述框架），后续只替换核心内容
- **发布后监控**：Postiz 支持查看各平台发布状态和基础数据
- **自托管优势**：数据完全在自己手里，不受第三方平台限制，免费
- **成本**：自托管免费，Docker 部署 30 分钟搞定

## 适合谁？不适合谁？

### ✅ 非常适合

- **独立创作者 / 自媒体人**：一个人搞定全流程，不需要团队，预算友好
- **小型创业团队（1~3 人）**：用工具杠杆替代人力杠杆
- **品牌方的内容运营**：Brand Kit 保证品牌一致性，批量出图效率极高
- **知识付费 / 课程制作者**：大量标准化视觉内容需求，完美匹配自动化
- **跨境电商卖家**：多平台分发 + 多语言适配
- **技术背景的创作者**：n8n 自托管 + API 给你最大自由度

### ⚠️ 需要考虑

- **追求极致艺术性**：AI 视觉在"艺术表达"层面仍有上限
- **实时热点内容**：自动化更适合计划性内容，追热点仍需手动快速响应
- **深度长视频（>5 分钟）**：LibTV 更擅长短视频
- **完全不想碰技术**：n8n 自托管需要一定 Docker 知识（但可用云服务替代）

### ❌ 不太适合

- 纯文字类内容（小说/深度报道）
- 高度定制化的企业宣传片（需要专业拍摄和后期）
- 对版权有严格要求的场景（AI 内容版权仍有灰色地带）

## 进阶玩法：让生产线更聪明

跑通基础工作流后，可以进一步升级：

1. **数据驱动优化**：用 n8n 抓取各平台阅读/互动数据，回传 Liblib 灵感库——哪些风格表现好，就多生产类似的
2. **A/B 测试自动化**：同一主题生成 2~3 版封面/标题，通过 n8n 在不同时段发布，自动统计哪个版本更好
3. **内容日历联动**：在 Notion/飞书维护内容日历，n8n 定时读取，自动拉起当天生产流程
4. **品牌素材库热更新**：Lovart Brand Kit 更新后，n8n 自动通知 LibTV 更新节点工作流中的素材引用
