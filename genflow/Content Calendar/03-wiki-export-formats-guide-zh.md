# 导出格式完全指南

[图片 1 占位符 — 用户场景]

选择错误的导出格式会毁掉一个设计。一个漂亮的渐变以 GIF 格式导出后会出现条带。一个清晰的标志保存为 JPEG 后边缘会出现压缩伪影。一个以 RGB 格式提交的打印文件会带来意外的色彩偏移。理解导出格式并不光鲜——但它决定了设计看起来专业还是业余。

本指南涵盖了 Lovart 支持的**每种导出格式**，并为每种使用场景提供了清晰的决策标准。

## 导出格式决策树

[图片 2 占位符 — 概念图]

在深入了解每种格式之前，请使用这个快速参考：

```
需要透明度？
├── 是 → PNG 或 SVG（网页），TIFF 或 EPS（打印）
└── 否 → 继续

是照片还是复杂图像？
├── 是 → JPEG（网页/数字），TIFF（打印）
└── 否 → 继续

是标志、图标还是插图？
├── 是 → SVG（网页/数字），EPS（打印）
└── 否 → 继续

需要无限缩放？
├── 是 → SVG（网页），EPS 或 PDF（打印）
└── 否 → 继续

用于打印？
├── 是 → TIFF、EPS 或 PDF（CMYK，300+ PPI）
└── 否 → JPEG、PNG、WebP 或 SVG（RGB，72-144 PPI）
```

## 光栅格式（基于像素）

光栅格式将图像存储为像素网格。它们依赖于分辨率——过度放大会导致像素化。

### PNG（便携式网络图形）

**最佳用途：** 任何需要透明度的网页图形、截图、UI 元素、标志（当 SVG 不合适时）、包含文本的设计。

**技术规格：**
- **压缩：** 无损（DEFLATE 算法）
- **色彩深度：** 8 位（256 色，索引）或 24 位（1670 万色，真彩色），带 8 位 alpha 通道
- **透明度：** 完全 alpha 通道支持（0-100% 可变不透明度）
- **动画：** 支持 APNG ���体（动画 PNG）

**何时使用 PNG：**
- 带透明度的社交媒体图形
- 应用截图和 UI 原型
- 包含文本的设计（无损压缩保留清晰边缘）
- 数字用途的标志和图标（当 SVG 不可用时）
- 电子邮件图形（某些电子邮件客户端不支持 SVG）

**何时避免使用 PNG：**
- 大型照片（同等质量下文件大小是 JPEG 的 5-10 倍）
- 打印生产（不是打印格式——JPEG 有损但无损，仍是 RGB）
- 包含许多颜色的复杂渐变（24 位 PNG 文件变得很大）

**Lovart PNG 导出选项：**
- **PNG-8：** 最多 256 色。文件最小。适用于简单、纯色图形。
- **PNG-24：** 全彩色 + alpha。最佳质量。大多数导出的默认选项。
- **PNG-24（压缩）：** 使用 pngquant/zopfli 进行无损优化。比标准 PNG-24 小 20-40%。
- **PNG @2x / @3x：** 用于网页开发的 Retina 分辨率变体。

```bash
# 示例：将社交图形导出为优化后的 PNG，带 2x Retina
格式：PNG-24（压缩）
缩放比例：1x（1080x1080），2x（2160x2160）
```

### JPEG（联合图像专家组）

**最佳用途：** 照片、不含透明度的复杂图像、文件大小重要的网页图��。

**技术规格：**
- **压缩：** 有损（基于 DCT）。牺牲质量以减小文件大小。
- **色彩深度：** 24 位（1670 万色）
- **透明度：** 不支持
- **色彩空间：** RGB、CMYK（罕见，不推荐）

**何时使用 JPEG：**
- 照片和照片密集型设计
- 网站主图和博客文章特色图
- 电子邮件营销图像（小文件大小 = 加载更快）
- 文件大小影响上传速度的社交媒体帖子
- 数字广告（平台通常有文件大小限制）

**何时避免使用 JPEG：**
- 标志或包含文本的设计（压缩伪影产生模糊、浑浊的边缘）
- 纯色或锐利线条的图形（可见块状压缩伪影）
- 需要透明度的设计
- 将重新编辑的设计（每次保存都会降低质量——代际损失）
- 打印生产（不是打印格式）

**Lovart JPEG 导出选项：**
- **质量 100（最高）：** 接近无损。文件大。质量至关重要时使用。
- **质量 85（高，默认）：** 推荐用于大多数用途。良好平衡。
- **质量 60（中）：** 明显压缩。可接受用于缩略图和电子邮件。
- **质量 40（低）：** 严重压缩伪影。仅用于占位符或极小缩略图。
- **渐进式 JPEG：** 在网页上逐步加载。更好的感知性能。

---

### WebP

**最佳用途：** 现代网页性能。在网页交付中替代 PNG 和 JPEG。

**技术规格：**
- **压缩：** 有损和无损模式
- **色彩深度：** 24 位，带 8 位 alpha 通道
- **透明度：** 完全 alpha 支持（有损和无损）
- **动画：** 支持（替代动画 GIF）

**何时使用 WebP：**
- 网站图像（同等质量下比 JPEG 小 25-35%）
- 带透明度的图像（平均比 PNG 小 26%）
- 任何你控制技术栈的面向网页的图像

**何时避免使用 WebP：**
- 电子邮件营销（截至 2027 年客户端支持有限）
- 社交媒体上传（平台不接受 WebP 上传）
- 打印生产
- Apple 生态系统兼容性（Safari 在 2020 年添加了 WebP 支持，但较旧设备可能无法渲染）

**Lovart WebP 导出选项：**
- **有损 WebP（质量 85）：** 推荐用于照片。同等质量下比 JPEG 小约 30%。
- **无损 WebP：** 用于需要像素完美再现的图形。比 PNG 小约 26%。
- **WebP @2x：** Retina 变体。

```html
<!-- 始终为 WebP 提供后备 -->
<picture>
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="主图">
</picture>
```

### TIFF（标签图像文件格式）

**最佳用途：** 专业打印生产、存档级图像。

**技术规格：**
- **压缩：** 无损（LZW、ZIP）或未压缩
- **色彩深度：** 每通道最高 32 位
- **透明度：** alpha 通道支持
- **色彩空间：** RGB、CMYK、LAB、灰度

**何时使用 TIFF：**
- 打印生产（CMYK TIFF 是黄金标准）
- 专业摄影存档
- 高质量扫描
- 用于胶印或高端数字印刷机的设计

**何时避免使用 TIFF：**
- 网页使用（文件巨大——是 JPEG 的 10-100 倍）
- 电子邮件（会退回或被附件限制拒绝）
- 社交媒体
- 任何纯数字用途

**Lovart TIFF 导出选项：**
- **TIFF（RGB，LZW 压缩）：** 适用于 RGB 工作流程的较小文件。
- **TIFF（CMYK，未压缩）：** 打印就绪，最高质量，文件大。
- **TIFF（CMYK，LZW 压缩）：** 打印就绪，文件大小可控。
- **包含图层：** 保留图层结构以便编辑（显著增加文件大小）。

---

### GIF（图形交换格式）

**最佳用途：** 简单动画、反应图、旧版兼容性。

**技术规格：**
- **压缩：** 在 256 色限制内无损
- **色彩深度：** 8 位（最多 256 色）
- **透明度：** 1 位（完全透明或完全不透明——无半透明）
- **动画：** 是（2027 年的主要用途）

**何时使用 GIF：**
- 简短、简单的动画（5 秒以内）
- 旧版电子邮件客户端兼容性
- 社交媒体的反应 GIF

**何时避免使��� GIF：**
- 照片（256 色限制 = 质量差）
- 带渐变的设计（条带伪影）
- 任何专业网页用途（改用 WebP 或 MP4）
- 现代动画内容（APNG 或 WebP 严格优于它）

**Lovart GIF 导出选项：**
- **GIF（抖动）：** 通过抖动模式模拟更多颜色。更好的渐变。
- **GIF（无抖动）：** 仅纯色块。文件更小。
- **GIF（优化）：** 移除重复帧，减少调色板。文件最小。
- **循环次数：** 无限、一次或自定义（1-999 次循环）。

## 矢量格式（基于数学）

[图片 3 占位符 — 真实 UI 截图]

矢量格式将图形存储为数学路径、形状和曲线。它们与分辨率无关——可缩放到任意大小而质量无损。

### SVG（可缩放矢量图形）

**最佳用途：** 标志、图标、插图、UI 元素、数据可视化——任何受益于无限缩放的图形。

**技术规格：**
- **格式：** 基于 XML 的标记语言
- **可缩放性：** 无限（与分辨率无关）
- **动画：** 支持 CSS 动画和 SMIL
- **交互性：** 支持 JavaScript 事件处理
- **可访问性：** 支持 title、desc 和 ARIA 属性

**何时使用 SVG：**
- 标志（主要导出格式——始终如此）
- 网页和应用的图标和 UI 元素
- 纯色和定义形状的插图
- 数据可视化和图表
- 响应式网页设计（SVG 可缩放到任何视口）

**何时避免使用 SVG：**
- 照片（无法表示为矢量）
- 带渐变和纹理的复杂图像（文件大小可能超过光栅等效物）
- 打印生产（改为转换为 EPS 或 PDF）
- 电子邮件（电子邮件客户端对 SVG 支持有限）

**Lovart SVG 导出选项：**
- **SVG（标准）：** 带内联样式的默认导出。
- **SVG（优化）：** 最小化，去除编辑器元数据。小 40-60%。
- **SVG（响应式）：** 无固定宽度/高度。缩放到容器。
- **SVG（内联）：** 可直接粘贴到 HTML 中。无外部依赖。
- **SVG Sprite：** 多个 SVG 合并到一个文件中，使用 `<symbol>` 标签用于图标系统。

---

### EPS（封装的 PostScript）

**最佳用途：** 旧版打印工作流程、专业打印、与较旧设计软件的兼容性。

**技术规格：**
- **格式：** 基于 PostScript 的矢量格式
- **可缩放性：** 无限
- **色彩空间：** CMYK、RGB、专色（Pantone）
- **透明度：** 有限（PostScript Level 3 有所改进，但不完整）

**何时使用 EPS：**
- 打印供应商的标志文件（行业标准请求格式）
- 与较旧 RIP（光栅图像处理器）系统的兼容性
- 标牌和大幅面打印
- 刺绣和雕刻机器文件准备

**何时避免使用 EPS：**
- 网页使用（不是网页格式）
- 现代数字设计工作流程（PDF 已基本取代 EPS）
- 带复杂透明度的设计（EPS 透明度支持不一致）

**Lovart EPS 导出选项：**
- **EPS（CMYK）：** 打印就绪。将文本转换为轮廓。嵌入字体。
- **EPS（RGB）：** 以数字为先的矢量，使用 RGB 色彩空间。
- **EPS（旧版，EPS 8.0）：** 与较旧系统的最大兼容性。

---

### PDF（便携式文档格式）

**最佳用途：** 通用文档共享、打印就绪文件、演示文稿、多页面布局。

**技术规格：**
- **格式：** 页面描述语言
- **可缩放性：** 矢量元素无限缩放；光栅元素依赖于分辨率
- **色彩空间：** RGB、CMYK、专色、ICC 配置文件
- **页面：** 支持多页面
- **交互性：** 表单、超链接、书签、按钮

**何时使用 PDF：**
- 打印就绪文件（PDF/X-4 是现代打印标准）
- 客户演示文稿和提案
- 多页面文档（品牌指南、报告、提案）
- 可共享的设计校样和审阅包
- 存档目的（PDF/A 用于长期保存）

**何时避免使用 PDF：**
- 网页显示（浏览器可以渲染 PDF，但用户体验差）
- 社交媒体（平台不接受 PDF 上传）
- 单图像场景（改用 PNG 或 JPEG）

**Lovart PDF 导出选项：**
- **PDF（标准）：** 通用，RGB，中等压缩。
- **PDF（打印）：** CMYK，300 PPI，3mm 出血���裁切标记，符合 PDF/X-4。
- **PDF（印刷就绪）：** CMYK，300 PPI，出血，标记，嵌入字体，全分辨率图像。
- **PDF（网页优化）：** RGB，150 PPI，线性化以便快速网页查看。
- **PDF（交互式）：** 保留超链接、按钮和表单字段。

## 3D 与专用格式

### GLB / glTF

**最佳用途：** 用于网页和 AR 的 3D 产品可视化。

Lovart 支持产品可视化设计的 3D 导出。GLB（二进制 glTF）是基于网页的 3D 标准。

**何时使用：**
- 电子商务网站上的产品配置器
- AR 产品预览（Apple ARKit、Google ARCore）
- 交互式 3D 演示文稿
- 社交媒体 3D 帖子（受 Facebook 和兼容平台支持）

**导出选项：**
- **GLB（标准）：** 512px 纹理，Draco 网格压缩。
- **GLB（高质量）：** 2048px 纹理，未压缩网格。
- **USDZ：** 适用于 iOS Quick Look 的 Apple AR 兼容格式。

## 批量导出：多格式输出

Lovart 的批量导出功能允许您从单个设计在一次操作中生成多种格式。此功能在专业版及以上计划中可用。

```json
{
  "design_id": "design_xyz123",
  "exports": [
    {"format": "png", "scale": 1, "profile": "social_instagram_post"},
    {"format": "png", "scale": 2, "profile": "social_instagram_post"},
    {"format": "webp", "quality": 85, "scale": 1},
    {"format": "jpg", "quality": 85, "scale": 1},
    {"format": "pdf", "profile": "print"},
    {"format": "svg", "profile": "optimized"}
  ]
}
```
