## 四、操作纪律（每批通用）

| 项 | 要求 |
|---|---|
| 同批同会话 | 一个品类的所有行业瓦片必须同一会话连续生成 |
| 锁 seed | 同批共用同一 seed + 同一风格参考图 |
| 机位互异 | 自动分配：正视/侧角/微距/俯拍/低角度/侧轮廓… |
| 背景一致 | 同批背景为同一 flat 色 |
| 只换行业 | 只变行业配色/材质/气质，不变构图语言 |
| 排版品类 | 图内零可读字符；排版层级用抽象灰色条块表达 |
| 命名 | `hero-gallery-{cat}-{industry}-v1.png` |
