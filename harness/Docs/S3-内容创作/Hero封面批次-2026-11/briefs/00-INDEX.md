## 通用交付规范

| 项 | 要求 |
|---|---|
| 图内文字 | 零。含可读字符即废稿；含排版的模块用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB（视频 ≤8MB） |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips |

## 同批一致铁律

1. 同品类 / 同模块的多张图**同一会话连续生成**
2. **锁 seed + 同一风格参考图**
3. `05-gallery-tiles` → `07-b2b-industries` → `08-extra-industries` **同品类连着跑**
4. mosaic 每套 4 瓦、gallery 每套 6 瓦同理
