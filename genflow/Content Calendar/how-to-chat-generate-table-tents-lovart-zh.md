## 聊天生成桌牌的工作流程

### 第1步 — 指定物理格式

桌牌有标准尺寸。你的打印店需要知道是哪种：

- **4x6英寸（折叠后）**：最常见的尺寸。适合标准桌牌架。最适合单品促销。
- **5x7英寸（折叠后）**：稍大，菜单空间更多。常用于酒单和甜品菜单。
- **A5（148x210毫米，折叠后）**：欧洲标准。适合多项目展示。
- **定制形状**：模切桌牌（三角形顶部、圆角），用于高端呈现。

从物理规格开始提示：

```
桌牌设计，4x6英寸折叠，双面打印。
展开尺寸：8x6英寸（两个4x6面板并排），对折形成站立式A形支架。
```

### 第2步 — 编写双面设计提示

桌牌从两面观看（正面和背面，或左侧和右侧）。你的提示必须描述两面：

```

面A（面向进入的顾客/主要接近方向）：
全出血背景，暖陶土色渐变（底部较深，顶部较浅）。
顶部居中放置餐厅徽标（来自品牌套件）。
下方："NEW SEASONAL" 小号大写字母追踪，奶油色，居中。
粗体标题："Spring Tasting Menu" — Playfair Display 粗体，奶油色，居中，
视���上占据中间三分之一区域。
标题下方："$65 per person | 5 courses" — Lato 粗体，奶油色，居中。
底部：季节性食材风格化插图（芦笋、豌豆、可食用花卉）— 线条画，奶油色，精致。
右下角二维码：下方标注 "View Full Menu"，8pt，Lato，奶油色。

面B（面向就座后的顾客 — "等待时" 的一面）：
相同背景处理。不同内容：
"While You Wait" — Playfair Display 粗体，奶油色，居中，位于上部三分之一。

```

关键的桌牌专属细节：
- 折线规格（8x6平张的4英寸标记处）。
- 折叠区域安全边距（距折痕0.25英寸——此处无关键文字，因为折叠会使其模糊）。
- 双面内容区分——每一面有不同的作用。
- 出血、裁切、CMYK、DPI——可打印的规格。

| 原则 | 应用 |
|-----------|-------------|
| 30英寸外可读 | 正文最小10pt，标题最小18pt。如果需要更小的字体，说明信息太长——编辑文案，而非字号 |
| 一个桌牌一个主题 | "春季品鉴菜单"桌牌不应同时推广欢乐时光、私人活动和会员计划。一个桌牌一个信息，如果需要，每桌多个桌牌 |
| 二维码需要上下文 | 没有解释标签的裸二维码，扫描率不到带有"查看完整菜单"或"立即下单"标签二维码的一半 |
| 双面 = 两个任务 | 面A吸引注意。面B提供信息。绝不要在两面放相同内容——那是浪费表面 |
| 折叠区域是死区 | 将所有关键内容保持在距折痕至少0.25英寸的位置。跨折痕弯曲的文字难以辨认且不专业 |
| 纸张质量很重要 | 在打印说明中指定卡纸克重（推荐14pt或16pt）。薄纸桌牌会塌陷。优质纸张传达优质品牌 |

## 常见问题

**桌牌应该用什么纸张？**

14pt或16pt卡纸（封面重量）。任何更轻的纸张都会弯曲、塌陷或在桌面上显得单薄。对于高端场所，使用18pt或24pt并带有哑光或触感涂层。向打印店指定此要求，而非在设计文件中。

**代理能生成模切定制形状的桌牌吗？**

代理在带有出血标记的标准矩形画布上生成设计。对于定制模切形状（圆角、三角形顶部、独特轮廓），将生成的设计文件连同模切模板一起提供给打印店。视觉设计已完成；物理切割是打印店的步骤。

**如何让二维码看起来是设计好的而非随意贴上去的？**

提示："二维码，带有细的品牌色边框，圆角，下方居中放置 'Scan for Menu'，8pt Lato。"代理会将二维码渲染为设计元素，而非原始的黑白方块。对于功能性二维码，在后处理中将生成的占位符替换为真实可用的二维码。

**我能生成多种语言的桌牌吗？**

可以。提示："生成相同的桌牌，使用西班牙语文本。相同布局，相同设计，将所有英文文案替换为附带的西班牙语翻译。如果西班牙语文案较长，调整字号。"代理在本地化内容的同时保持设计。

**一家餐厅应该有多少种桌牌变体？**

三到五种是最佳数量。每桌两个桌牌——一个推广特定项目（品鉴菜单），一个推广更广泛的优惠（欢乐时光、会员计划）。每4-6周轮换设计，防止常客产生视觉疲劳。

**如果我的桌牌需要显示频繁变化的价格怎么办？**

设计一个带有指定"价格区域"的桌牌——一个特意留白用于插入价格的空间。导出不含价格的基础设计，然后在打印前以文本可编辑格式添加价格。对于频繁变化的菜单（每日特价），设计一个可重复使用的模板，带有黑板风格或剪贴画风格的价格区域，可手写填写。
