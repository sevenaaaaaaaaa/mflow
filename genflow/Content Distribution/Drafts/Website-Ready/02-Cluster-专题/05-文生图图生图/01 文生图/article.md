我是做市场营销出身的，2018 年开始接触跨境电商——从亚马逊、速卖通到 Shopee、TikTok Shop，帮卖家做过不下 2000 张 Listing 图。跨境卖家的视觉需求是最「变态」的：同一款产品，亚马逊要纯白底 2000×2000 主图，Shopee 要带场景的 800×800，TikTok Shop 要短视频封面，独立站又要 lifestyle 场景图……一个 SKU 下来少说 20 张图，10 个 SKU 就是 200 张。传统方案找设计师外包，一张产品图 100-500 元，一个店铺上线光图片成本就能吃掉几千块利润。

## 三、Step-by-Step：每个环节怎么跑通

### Step ① 素材预处理：Rembg + Real-ESRGAN —— 从「乱七八糟原片」到「高清白底图」

#### 😫 痛点

跨境卖家最头疼的问题：供应商给的图质量参差不齐。有的在仓库随手拍的，背景杂乱；有的分辨率只有 800×800，亚马逊要求 2000×2000 起步；有的拍歪了、曝光不对、颜色偏色。这些图直接上传 Listing，转化率直接拉胯——亚马逊 A9 算法对主图质量敏感，低像素图连曝光都拿不到。

#### 💡 我们的做法

**两步预处理，把任何原片变成可用的高清白底产品图：**

**第一步：Rembg 批量抠白底。**  
[Rembg](https://github.com/danielgatis/rembg) 是 GitHub 23.3K Stars 的开源 AI 抠图工具。用法极简：

```bash
# 单张处理
rembg i product_raw.jpg product_nobg.png

# 批量处理整个文件夹
rembg p ./raw_photos ./white_bg_photos
```

一条命令，整个文件夹 200 张产品图全部抠白底。对于电商场景的硬边缘产品（电子产品、家居、箱包），Rembg 的精度在 90% 以上，完全够用。软边缘产品（服装、毛绒玩具、珠宝）需要手动微调，但也省去了 80% 的手工抠图工作。

**第二步：Real-ESRGAN 超分放大。**  
[Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) 是腾讯 ARC 实验室开源的超分辨率工具，GitHub 35K+ Stars。把抠好的白底图放大到各平台要求的分辨率：

```bash
python inference_realesrgan.py -n RealESRGAN_x4plus -i white_bg_product.png -o product_4x.png
```

4 倍放大后，800px 的图变成 3200px，满足亚马逊 2000×2000 要求绰绰有余。而且 Real-ESRGAN 对 JPEG 压缩伪影的修复能力特别适合电商场景——供应商发的 WhatsApp 压缩图经过处理后，细节纹理还原得相当好。

#### 🔑 关键细节

- **顺序要对**：先抠图再放大，不要在带背景的图上直接放大，浪费算力
- **格式选 PNG**：抠图输出用 PNG 保留 alpha 通道，后续合成场景图时需要透明背景
- **批处理脚本**：写一个简单的 Shell 脚本把两步串联，丢进去一个文件夹，出来就是高清白底图
- **成本**：两个工具都是免费开源，本地跑，零费用

### Step ② 风格定调：Liblib —— 从「不知道做什么风格」到「风格方案已定」

#### 😫 痛点

白底图做好了，但如果只上白底图，Listing 太单调——特别是 Shopee 和 TikTok Shop，带场景的生活方式图转化率比纯白底图高 3-5 倍。问题来了：做什么风格？北欧极简还是美式复古？暖色调还是冷色调？咖啡桌还是海边？每次选风格都是选择困难症的噩梦。

#### 💡 我们的做法

**Liblib 是你的「风格参谋」。**

打开 [Liblib 灵感广场](https://www.liblib.art/inspiration)，按产品品类搜索：
- 家居类搜「北欧风 场景 家居」
- 电子类搜「科技感 桌面 产品展示」
- 服饰类搜「街拍 穿搭 lookbook」
- 美妆类搜「ins 风 护肤品 场景」

找到视觉效果好的作品，**不要只看，要收藏并打标签**。积累 10-20 张各品类的风格参考图，形成你的「风格模板库」。每次上新品时，从库里选 2-3 个匹配的风格方向。

更进阶的：**直接复制 Liblib 上的工作流**。很多创作者分享了完整的 ComfyUI/Stable Diffusion 工作流——用什么模型、LoRA、参数组合能稳定出某个风格。一键复制到你的 ComfyUI，改个产品就行。如果不想用 SD，把这些工作流的 prompt 结构提取出来，给 Lovart 用。

#### 🔑 关键细节

- **按品类建风格库**：一个品类 5-10 张参考图，每次直接用不用重新想
- **三元组搜索法**：用「产品+风格+场景」搜索，比如「蓝牙耳机 科技感 办公桌」
- **关注爆款风格**：在 Liblib 上按热度排序，高热度作品往往代表更大众化的审美偏好——这对电商是好事
- **成本**：完全免费

### Step ③ 品牌化出图：Lovart —— 从「散装素材」到「统一品牌视觉」

#### 😫 痛点

这是跨境卖家视觉工作的核心痛点——风格统一性。今天找设计师 A 做了一套场景图，明天设计师 A 没档期换了设计师 B，结果风格完全不一样。Listing 里 6 张图风格各异，买家刷到就觉得不专业。更头疼的是**多尺寸适配**：同一个主视觉，亚马逊要 1:1 正方形，Shopee 首图要 3:4，独立站 banner 要 16:9，Pinterest 要 2:3。手动裁切改版，一个 SKU 多平台适配能耗掉半天。

#### 💡 我们的做法

**Lovart 的 Brand Kit 功能，一次性解决品牌统一性和多尺寸适配。**

操作路径：

**第一步：建立品牌套件（一次性，30 分钟）。**  
在 [Lovart](https://www.lovart.ai) 创建你的品牌：
- 上传 Logo（白底和深底两版）
- 设定品牌色板（主色+辅色+强调色+中性色）
- 选择字体组合（标题体+正文字体）
- 定义视觉风格关键词（如「clean, professional, warm lighting, lifestyle」）

**第二步：用 Brand Kit 驱动批量出图。**  
把 Step① 的高清白底产品图 + Step② 确定的风格参考图喂给 Lovart：
- 「产品白底图 + 北欧风格场景 = 带生活场景的产品图」
- 「产品白底图 + Brand Kit = 带品牌水印和标准排版的主图」

Lovart 的 MCoT 推理引擎会根据你的 Brand Kit 自动调整出图风格，确保每张图都符合品牌规范。

**第三步：多尺寸一键适配。**  
同一个视觉方案，Lovart 一键导出：
- 亚马逊主图：2000×2000
- 亚马逊 A+ 内容：970×600 / 970×300
- Shopee 封面：800×800
- TikTok Shop：9:16 竖版
- 独立站 Banner：1920×600
- Pinterest：1000×1500

不需要手动裁切、重新构图，Lovart 会根据尺寸智能调整布局。

#### 🔑 关键细节

- **Brand Kit 是核心资产**，花半小时做好后面省 30 小时。每次做新 SKU 都自动套用
- **场景图 Prompt 优化**：在 Lovart 里描述场景时加上品类关键词——「该产品放置在阳光明媚的现代厨房大理石台面上，柔和自然光从窗户照入」比「放在厨房」准确得多
- **A/B 测试**：同一个产品出 3 种不同风格的场景图，做投放测试看哪种 CTR 更高
- **成本**：Lovart Pro ¥99/月，Brand Kit + 无限出图，一个月的钱可能就省下一个 SKU 的外包设计费

### Step ④ 视频制作：LibTV —— 从「静态图」到「会表达的产品视频」

#### 😫 痛点

2025 年的跨境电商，纯静态 Listing 已经不够了。TikTok Shop 和 Reels 的短视频带货是转化率最高的渠道，亚马逊 Listing 也支持主图视频。但做产品视频的门槛比做图片高太多——拍摄要布光置景、剪辑要学 Premiere、特效和字幕要单独做。一条 30 秒的产品展示视频外包价 500-2000 元，10 个 SKU 就是上万。

#### 💡 我们的做法

**LibTV 用节点工作流，把「静态产品图」变成「动态展示视频」——不需要拍摄、不需要剪辑技能。**

操作路径：

**第一步：导入品牌视觉素材。**  
把 Step③ Lovart 生成的场景图、白底图、细节特写图批量导入 [LibTV](https://www.liblib.tv/)。

**第二步：选择节点工作流模板。**  
LibTV 社区有大量针对电商场景的预设节点工作流：
- 「产品 360° 展示」：图片序列 + 旋转运镜
- 「功能特写」：局部放大 + 标注动画
- 「场景切换」：多个场景图溶解过渡
- 「开箱展示」：模拟开箱过程

选一个匹配品类的模板，把素材替换进去即可。

**第三步：加字幕和品牌元素。**  
LibTV 支持语音转字幕——把产品卖点文案转成 TTS 音频，自动生成时间轴字幕。再加上品牌 Logo 水印、片尾 CTA，一条 30 秒的产品视频就完成了。

#### 🔑 关键细节

- **运镜是灵魂**：静态产品图做视频，Ken Burns 效果（缓慢放大+平摇）是最安全的选择，自然而不做作
- **节奏要快**：跨境电商的产品视频，15-30 秒最佳，前 3 秒必须抓住注意力
- **批量生产**：搭好一个产品视频工作流模板，每个 SKU 只换素材，10 个 SKU 一天内全部出完
- **与 Lovart 无缝衔接**：Lovart 出图 → LibTV 做视频 → 形成完整生产管线
- **成本**：基础功能免费，高频使用按量计费但成本很低

### Step ⑤ 分发发布：Cap + Postiz —— 从「逐个上传」到「一键铺全渠道」

#### 😫 痛点

素材做好了，最痛苦的环节来了——上传。亚马逊 Seller Central 6 张图一张张传，Shopee 再传一遍，TikTok Shop 又传一遍，独立站 Shopify 再传……10 个 SKU × 4 个平台 = 40 次上传操作。加上每个平台对文件名、格式、顺序的要求不一样，错一张就可能导致 Listing 审核不过。

#### 💡 我们的做法

**日常沟通用 Cap，批量发布用 Postiz。**

**Cap**（[GitHub 17.2K Stars](https://github.com/CapSoftware/cap)）用于快速录制和分享：
- 给供应商录「这个产品拍的照片不行，要这样拍」的操作示范
- 给团队录 Listing 上传的操作 SOP
- 给客户录产品的使用演示视频

录完即生成分享链接，对方点开就能看，不用下载。

**Postiz**（[GitHub 27K Stars](https://github.com/gitroomhq/postiz-app)）用于社媒分发：
- 连接 TikTok、Instagram、Pinterest、YouTube 等社媒账号
- 一次上传，定时发布到多平台
- 跨平台内容微调（标题、描述、标签各平台不同）

#### 🔑 关键细节

- **通知供应商用 Cap 而非微信视频通话**：异步沟通效率高、可回看、有记录
- **社媒发产品视频用 Postiz 定时**：研究各平台的最优发布时间，批量排期
- **成本**：两个工具都免费开源

### 常见卡点 & 排障

| 卡点 | 原因 | 解法 |
|------|------|------|
| Rembg 抠图边缘粗糙 | 产品边缘有软毛/透明材质 | 用 `isnet-general-use` 模型代替默认 u2net |
| Real-ESRGAN 显存溢出 | 4K 大图直接放大 | 加 `--tile 400` 参数分块处理 |
| Lovart 场景图风格不统一 | 没用 Brand Kit | 先建 Brand Kit，所有出图都基于它 |
| LibTV 视频节奏拖沓 | 单张图停留太久 | 缩短每张图的运镜时间，总时长控制在 15-30s |
| 各平台图片要求不同 | 尺寸/格式/命名规则各异 | Lovart 多尺寸导出 + 建立平台命名规则 |

## 六、适合谁 / 不适合谁

### ✅ 非常适合

| 人群 | 为什么适合 |
|------|------------|
| **跨境卖家（SKU > 10）** | 批量出图的需求足够大，工作流回报极高 |
| **DTC 品牌方** | Brand Kit 保证品牌一致性，多平台素材统一输出 |
| **Shopee/Lazada/TikTok Shop 卖家** | 东南亚平台对场景图需求大，AI 出图成本优势明显 |
| **独立站运营** | 产品图、Banner、社媒素材一个工作流全搞定 |
| **一人公司/小团队** | 不需要雇设计师，一个人 + 一条工作流 = 视觉部门 |
| **FBA 铺货型卖家** | SKU 多、Listing 更替快，批量处理是刚需 |

### ⚠️ 需要考虑

| 情况 | 短板 |
|------|------|
| **超高端奢侈品/珠宝** | AI 生成的场景质感可能不够「奢华」，需要专业摄影 |
| **需要极端精确色准的产品** | AI 处理过程有细微信噪，色准要求高的需人工校色 |
| **特殊形状产品** | 形状特别不规则的产品，Rembg 抠图精度可能不够 |

### ❌ 不太适合

| 情况 | 原因 |
|------|------|
| 只做 1-2 个 SKU 的卖家 | 搭建工作流的成本高于直接找外包 |
| 需要法律版权保障的图片 | AI 生成图片的版权问题在部分平台仍有风险（但 Amazon 已接受 AI 生成图） |

## 七、进阶玩法：让生产线更聪明

1. **竞品视觉监控**：定时抓取竞品 Listing 主图，分析风格趋势变化，调整自己的风格库
2. **A/B 测试自动化**：同一产品出 3 套不同风格 Listing 图，投放测试 CTR 和转化率，数据驱动选最优风格
3. **季节/节日模板**：Lovart Brand Kit 建「圣诞版」「黑五版」「夏季版」等季节变体，一键切换
4. **多语言本地化**：Lovart 场景图里的文字元素，按目标市场替换为对应语言（Liblib 上找对应文化风格的 prompt）
