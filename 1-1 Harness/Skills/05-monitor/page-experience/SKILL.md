## 定位（体系第四层）

① 工程管理约束生成、② 品牌供资产、③ 执行产出——**本层管上线之后**：用户实际看到什么、页面活得好不好。发布不是终点，是体验层巡查的起点。

**启用条件**：有已发布页面且可公开访问（Lovart ✓ 生产运行；Moodio 站点未上线 → 未启用，上线后按本规程启动）。

## 四条巡查线（判据具体，频率固定）

### 线 1 · 渲染巡检（每周；新页面发布后 48h 内加扫一次）

| 查什么 | 判据 | 工具/方法 |
|---|---|---|
| 404 | 已发布 URL 零 404（sitemap 全量扫） | sitemap → 逐 URL 状态码扫描 |
| 表格显示 | Portable Text 校验 BLOCK=0；线上表格渲染抽查 | `validate_pt_body.py`（Lovart schema：`tableRow.cells: string[]`，非五层 tableCell——Pitfall #62） |
| 图片显示 | 图片 URL 存活率 100%；封面无撞车；CDN hash 完整（64 字符） | 图片 URL 批量 HEAD 扫描 + `image_pool` 规则复核 |
| 边距/版式 | 组件规格对照（33 组件库 preview-data）；移动端抽查 | 自动有限——每季人工抽查每类页面 3 页 |

**发现即工单**：渲染 bug 同步记入质量案例库（`1-3 GenFlow/Bugs/`，tableBlock/404/图片/翻译四类历史案例所在）——同类 bug 第二次出现必须升级为规则（进钩子或 preflight）。

### 线 2 · 性能与转化巡查（每月；投放白名单页每月必查）

| 查什么 | 判据 | 动作 |
|---|---|---|
| 长期无访问 | 落地页 30 天 UV < 阈值（默认 50） | 进优化队列：补内链/改标题/评估 301 |
| 长期无访问（90 天仍无） | 判死 | 301 合并 or 下架判决（走 pipeline） |
| 转化率低 | 低于页面类型基准（Tools ≥3% 起步值，按 cro-audit 修正） | 触发 cro-audit（landing-writer 内联版）三清单体检 → 改造队列 |
| 主推页停留 | 投放页停留 < 8min 基准 | 停投放（联动 paid-strategy kill criteria）+ 体检 |

### 线 3 · 多语言质量（每季抽查 + 事件触发）

- 语义等价：抽查每语种 3 页，数据点与结论跨语言必须一致（RULES-20 #12）
- 完整度：任一语言版本字数 < 主语言 60% → 视为未完成，补齐（RULES-20 #13）
- 线上残留：en 页汉字/中文标点扫描（lang-check 规则的线上版）；日文页简体字形
- hreflang：多语言页面 hreflang 标签完整性

### 线 4 · 内链健康（每周）

| 查什么 | 判据 | 动作 |
|---|---|---|
| 死链/断链 | 零容忍（含内链指向 404） | 24h 内修复或改指向 |
| hub 拓扑 | hub 出链 ≥8 · spoke 回链齐全 · 任意详情页 ≤3 跳达 hub | 破损 → 拓扑修补工单（hub-writer 规则为准） |
| 孤岛页 | 零内链入链的已发布页 | 补链（link-suggest.py 建议）或并入集群 |
| 重复/自链 | 同页重复链接到同一目标无差异注解 | 清理 |

## 工单分流（发现的问题去哪）

| 问题类型 | 去向 |
|---|---|
| 渲染 bug（表格/图片/版式） | 质量案例库（Bugs/）+ 修复工单进 pipeline S0 |
| 无访问/低转化 | cro-audit 体检 → 改造队列 / 301 / 下架 |
| 多语言缺陷 | i18n 重写（RULES-20 语义等价） |
| 内链/拓扑 | 拓扑修补工单（hub-writer 拓扑三律为准） |
| 流量类信号（高曝光低点击/排名下滑） | 同源 blog-writer 信号表（signals-and-phases 附表）——本层不重复处理，只转投 |
