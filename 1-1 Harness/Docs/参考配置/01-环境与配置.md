## 凭据位置

| 用途 | 位置 | 说明 |
|------|------|------|
| Sanity CLI | `~/.config/sanity/config.json` 或 studio `.env` | WRITE token 用于 import/patch |
| GSC / GA4 | Harness Skill `lovart-trident-data-engine` 配置 | 见 `lovart-gsc-api-setup-guide.md` |
| Sentinel | `1-4 Dev/scripts/sentinel/config.yaml` | 数据源开关 |
| Lovart API | `lovart-api-config.md`（Harness） | 内容生成 API |

**禁止**：将 token 提交到 git；`sanity deploy` 后检查 bundle 是否泄露 READ_TOKEN（AB-E07）。
