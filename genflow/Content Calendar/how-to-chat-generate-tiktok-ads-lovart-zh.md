# 如何通过聊天用Lovart生成TikTok广告——Spark Ads和信息流创意

[图片1占位符——人物场景]

你录制了一条TikTok广告。环形灯、像样的脚本、产品在画面中。你在TikTok广告管理后台发布它，日预算50美元。结果：点击率0.4%，单次转化成本12美元，并且你沮丧地意识到，TikTok用户从第一帧就能嗅出广告的味道。他们划过你精心打磨的品牌内容，速度比划过用iPhone 3拍摄的模糊猫咪视频还快。

TikTok的广告生态系统惩罚那些看起来像广告的广告。该平台自身的创意指南明确写道：“不要制作广告，要制作TikTok。”表现最好的TikTok广告与原生内容难以区分——相同的拍摄风格、相同的节奏、相同的感觉，就像有人在分享他们发现的东西。一个AI设计助手能帮你生成静态和缩略图素材，以这种原生美学来框定你的TikTok广告视频，避免那种会引发即时划过的设计工作室风格。

## 为什么TikTok广告需要不同的创意理念

[图片2占位符——概念图]

Facebook和Google Ads存在于指定的广告位中——用户知道他们正在看广告。TikTok广告则与原生内容出现在同一个信息流中。当你的广告出现时，用户正在刷舞蹈视频、烹饪技巧和喜剧小品。如果你的创意看起来像商业广告，那么划走是自动且无情的。

你TikTok广告的静态组件——缩略图（在个人资料和某些投放位置作为封面出现）以及任何文字叠加或结尾卡片——必须符合TikTok原生美学。这意味着：没有库存照片，没有企业配色方案，没有看起来像属于广告牌的工作室级完美产品照片。这种美学是手机优先、真实、略带粗糙的。

## 聊天生成TikTok广告的工作流程

### 第一步——采用TikTok原生视觉语言

在编写提示词之前，先内化TikTok原生图像的样子：

- **手机拍摄的真实感**：光线略有不完美，真实环境（卧室、厨房、车内），而非白色背景的工作室。
- **竖屏优先构图**：1080x1920（9:16）。所有内容都针对竖持手机进行构图——没有横屏转竖屏的裁剪。
- **文字叠加风格**：粗体、无衬线字体，通常带有彩色背景条或阴影。在快速浏览时可读。包含表情符号但不过度。
- **面部特写缩略图**：面部特写，表情夸张且易于解读。微妙的表情在TikTok信息流中无法存活。
- **紧跟潮流的色彩分级**：略微偏暖、略微降低饱和度，通常带有微妙的胶片颗粒纹理。那种“用iPhone拍摄，通过VSCO处理”的感觉。

### 第二步——编写TikTok广告封面/缩略图提示词

你的TikTok广告封面图像（用于个人资料展示和某些广告位）需要感觉像是一个引人入胜视频的定格画面——而不是一个设计好的图形。

```
TikTok广告封面，1080x1920竖屏。我——真诚惊讶的表情，
手机自拍风格，在��的客厅里，左侧有自然窗户光。
我右手拿着一个时尚的黑色小工具，向镜头展示。
休闲装束——连帽衫。房间看起来有人居住，不是刻意布置的。
顶部有粗体白色文字，TikTok原生风格，带有轻微彩色背景条：
'这个小工具每周为我节省了3小时'。
视觉效果应该看起来像视频截图，而不是设计好的图形。
轻微暖色调，微妙的胶片颗粒，手机相机画质——
不是工作室摄影。表情必须在1秒内可读。
```

与标准广告设计的关键区别：
- “视频截图”的框架——故意不完美，不精致。
- “手机相机画质”——不是“高分辨率产品摄影”。
- 真实环境、真实着装、真实光线——反工作室美学。
- 情感表达是钩子，而不是产品细节。

### 第三步——生成文字叠加素材

TikTok广告经常使用文字叠加，作为视频上的字幕出现。虽然Lovart助手可以生成静态叠加素材，但最有效的方法是生成一个与视频视觉语言匹配的风格化文字卡片：

```
TikTok文字叠加卡片，1080x1920。深色半透明渐变背景
（从底部黑色到顶部透明）。粗体白色无衬线文字居中
在上三分之一处：'我测试了47个桌面小工具'。
下方较小文字：'第3个让我惊讶'。
右下角有一个倒计时图形：'3... 2... 1...'
TikTok原生排版风格——粗体、高对比度、竖屏模式下可读。
设计用于叠加在产品视频上，作为前3秒的钩子。
```

生成3-5个这样的不同钩子，测试哪个开场文字叠加能带来最高的完播率。

### 第四步——创建结尾卡片和CTA素材

TikTok广告的结尾卡片——最后2-3秒——是转化发生的地方。如果你的视频在25秒内建立了好奇心和兴奋感，结尾卡片则将这种能量导向行动。

```
TikTok广告结尾卡片，1080x1920。品牌渐变背景（品牌颜色——
在品牌工具包中定义）。产品居中在下三分之一处——与视频中相同的黑色小工具，
略微放大。粗体白色文字居中：'在链接处获取你的'。
一个发光的CTA箭头指向下方产品。
微妙的粒子动画建议——背景应该感觉有活力，
而不是静态。TikTok原生能量，不是企业宣传册能量。
为TikTok原生CTA按钮在屏幕底部留出空间。
```

结尾卡片必须感觉像是视频的自然结尾，而不是突兀地切换到“广告模式”。视频美学与结尾卡片美学之间的一致性是不可妥协的。

### 第五步——构建创意多样性包

TikTok算法奖励测试多种创意角度的广告主。与Facebook结构化的A/B测试不同，TikTok的系统动态优化投放。给它多样性。

为每个广告系列生成一个五角度创意包：

| 角度 | 视觉风格 | 钩子风格 | 最适合 |
|-------|-------------|------------|----------|
| UGC评论 | 手机拍摄，真实环境 | “我简直不敢相信这真的有效” | 考虑阶段 |
| 问题演示 | 分屏——左侧问题，右侧解决方案 | “别再这样做了。试试这个。” | 教育 |
| 开箱/第一印象 | 仅手部，POV镜头 | “看看刚到的东西” | 产品发布 |
| 转变 | 前后对比视觉 | “第1周 vs 第4周” | 结果驱动型利基 |
| 蹭热点 | 当前TikTok meme格式，用产品重新创作 | 热点原生钩子 | 认知/覆盖 |

对于每个角度，从相同的视觉模板生成封面缩略图、文字叠加和结尾卡片，使广告从第一帧到最后一帧感觉连贯。

## 常见问题解答

**TikTok广告图片的尺寸应该是多少？**

1080x1920像素，9:16宽高比。所有TikTok广告位都是竖屏的。JPG或PNG格式，小于20MB。对于Spark Ads（推广原生帖子），封面图像继承原始帖子的缩略图。

**助手能生成Spark Ads缩略图吗？**

可以。Spark Ads使用原始TikTok原生帖子的缩略图。以TikTok原生风格生成一个缩略图，并在发布原生帖子时将其设置为封面图像——它会自动应用到Spark Ad。

**如何让我的TikTok广告看起来不像广告？**

最有效的单一技巧：像用手机拍摄场景一样描述它，而不是用软件设计它。“在我的厨房用手机拍摄，晨光，真实的杂乱，真实的生活”胜过“专业工作室拍摄，干净的白色背景，产品英雄构图”。提示词中的每个词都应该推动真实性。

**TikTok广告缩略图应该包含文字吗？**

是的——带有简短粗体文字叠加（3-6个词）的TikTok缩略图始终优于无文字缩略图。文字应该是一个好奇心钩子，而不是产品描述。

**我可以用Lovart生成广告视频本身吗？**

Lovart的视频生成能力可以从场景描述生成短视频内容，并可以动画化静态图像。对于TikTok广告，逐场景描述视频序列，指定时长（建议15-30秒），并包含上述原生美学提示。

**我应该测试多少个创意变体？**

TikTok建议每个广告组3-5个创意变体。每7-10天轮换表现不佳的变体。平台的动态创意优化会自动将预算转移到表现最佳的变体——你的工作是保持管道中有新鲜选项。

**TikTok的广告政策是否限制AI生成内容？**

TikTok要求广告主对“显示真实场景的合成或操纵媒体”进行披露——包括描绘真实人物、地点或事件的AI生成图像。在TikTok广告管理后台添加一个披露开关。这不会影响投放；这是一个透明度要求，而不是限制。
