あるコーヒーショップのブランド用にフォントを選んだ午後、丸一日潰したことがある。6ラウンドの組み合わせ、11種類のパターン。クライアントは全部ダメ出し。結局、1ラウンド目で自分が「地味すぎる」と却下した書体に戻った。

問題はフォントじゃなかった。問題は、見知らぬ2人をディナーパーティーで組み合わせようとするようにフォントを選んでいたこと。システムなし、雰囲気だけ。疲れたときは雰囲気に負ける。

あの案件の後、今の自分が実際に使っている4つのルールを書き出した。以来、約80のブランドシステムで通用している。クリエイティブでもなく、デザインの哲学でもない。動く組み合わせと動かない組み合わせを分ける、ただそれだけのことだ。

## ルール1: 一つの声がリードし、一つがサポートする

どの組み合わせにも階層がある。一つのフォントが見出しを担う — ページで一番大きな声。もう一つがサポートする — 本文、キャプション、補助情報。両方とも大きいと、ページが自分自身と喧嘩する。両方とも小さいと、何も目立たない。

テスト: 部屋の向こう側からレイアウトを細めて見る。一瞬で見出しのフォントがわかったら、階層は機能している。区別がつかないなら、コントラストの強いフォントを選ぶ。

コーヒーショップの案件では、ジオメトリックサンセリフを2つ組み合わせ続けていた — InterとDM Sans、次にInterとManrope、次にDM SansとPlus Jakarta Sans。全部同じに感じた。静かな声2つ、リーダーなし。クライアントは見出しがどれか判断できなかった。

解決は「もっと良いフォント」ではなく「異なるカテゴリー」だった。本文を **Lora**（ヒューマニストセリフ）に変更し、Interに見出しを任せた。突然、ページには自分自身と喧嘩する1つではなく、2つの声が生まれた。

**Lovartでのやり方**: プロンプトに役割を明示する。「見出し用の太いサンセリフ、本文用のセリフ — 見出しが告知し、本文が説明する。」AIは2つのフォントを同じ空間を争う2つのフォントではなく、システムとして扱う。

## ルール2: カテゴリーをまたいで組み合わせる

強い組み合わせは異なるカテゴリーのフォントから生まれる。セリフとサンセリフ。ジオメトリックとヒューマニスト。スラブとグロテスク。コントラストが面白さを生む。「モダン」ブランド向けの明白な選択であるジオメトリックサンセリフ2つの組み合わせは、ほぼ常に平坦に感じる。

繰り返し使う4つの信頼できるカテゴリー組み合わせ:

1. **セリフ見出し + サンセリフ本文** — 編集系的、信頼感。NYT、Vogue、多くのプレミアムブランド。
2. **サンセリフ見出し + セリフ本文** — モダンを加えた編集系。ブログやコンテンツ中心のサイト。
3. **スラブ見出し + サンセリフ本文** — 親しみやすく、自信に満ち、ややレトロ。消費者ブランド、食品、子供向け。
4. **ディスプレイ見出し + ニュートラルなサンセリフ本文** — 太いディスプレイ（スクリプト、コンデンス、装飾系）をワークホースサンセリフで支える。見出しがすべての視覚的仕事をする場合。

常に失敗する: セリフ2つ。ジオメトリックサンセリフ2つ。スクリプトと装飾系の組み合わせ。両方のフォントのx-heightが同じ組み合わせ。

**落とし穴**: 「Playfair Display + Lora」や「Inter + DM Sans」を選ぶデザイナーをよく見る。両方人気だから。同じカテゴリー、同じウェイト感、同じx-height。決定ではなく事故に見える。

**実際に使う組み合わせスタック**: Fontjoy（fontjoy.com）がニューラルネットから組み合わせを生成 — 行き詰まったときのインスピレーションに役立つ。その提案を **WhatFont**（Chrome拡張）に持ち込み、参考にしたい競合サイトで組み合わせを確認する。トップ3候補を **Lovart** に持ち込み、実際のヒーローセクションとして描画する。フルチェーン: Fontjoyが提案 → WhatFontが実サイトで検証 → Lovartがデザインとして描画 → 自分がデザインとして評価。3時間の推測の代わりに、5分で3つの検証済み組み合わせ。

## ルール3: 時代ではなくトーンを合わせる

どのフォントにもトーンがある。Futuraは精密、モダン、わずかに冷たい。Garamondは文学的、温暖的、伝統的。Bebas Neueは編集系的、緊急、新聞。Quicksandは親しみやすい、カジュアル、若い。Oswaldは直接、コンデンス、新聞スタンド。

組み合わせる2つのフォントは、同じ一般的な言語を話すべきだ。コントラストを作るのに十分違うが、1つのページに属する感じがするのに十分似ている。

かつてCormorant Garamond（ delicate文学的セリフ）をBebas Neue（産業的コンデンス）と組み合わせようとした。紙の上では: 編集系 + 直接、動くはず。実際には: ファッション誌と法的文書が交通事故を起こしたように見えた。

トーンテスト: 各フォントが「何を言っているか」を声に出して言う。両方の答えが同じブランドから来ているなら、組み合わせは機能する。1つが香水広告、もう1つが銀行明細書のように聞こえるなら、やめる。

**ショートカット**: トーンを確認するとき、**Google Fonts "Pairings" ギャラリー**（fonts.google.com/pairings）を開いて、欲しいムードでフィルターする。Googleはすでにトーンマッチテストを通過した事前検証済み組み合わせをキュレーションしている。フォントとしてではなく、デザインとして評価する。

## ルール4: ほぼ常に2フォント

最も強いシステムは2フォントを使う。期間。一つ特定の役割（3つ目のディスプレイフォントを大きな告知用）に予約するなら3つに伸ばせる。1つのレイアウトで4つは使うべきではない。

フォントを追加するたびに、読者の判断負荷が増える。3フォントだと目が何を見るか選んでいる。2つだと階層が明白。

例外: ブランドアイデンティティは全エコシステムで3-5フォントを使うことがある — プライマリブランドフォント、セカンダリ、本文フォント、アクセントディスプレイ、コード用モノスペース。ただし単一レイアウトでは2つがルール。

このルールを破ったことがある — 「制御された混沌」を求めたクリエイティブエージェンシー向けに意図的に一度。不注意で2回、後で修正した。不注意の方は、ブランドが決められないように見えた。

## どんなブリーフでも信頼できる8つの組み合わせ

これらはブランドブリーフの約80%をカバーする。唯一動く組み合わせではないが、ほぼすべての文脈で動く。

**編集系 / プレミアム**
1. Playfair Display + Source Sans Pro
2. Cormorant Garamond + Lato

**モダンテック / SaaS**
3. Inter + Inter Tight（1ファミリー、2ウェイト — 組み合わせミスのリスクなし）
4. Space Grotesk + IBM Plex Sans

**コンシューマー / ライフスタイル**
5. Fraunces + DM Sans
6. Recoleta + Work Sans

**ボールド / ステートメント**
7. Bebas Neue + Roboto
8. Archivo Black + Inter

迷ったら、このリストから始める。次にブランドが必要な方向に1ステップ調整する — 暖かく、冷たく、より真剣に、より遊び心強く。ゼロから始めない。

## 3時間の議論を置き換えたAIワークフロー

昔のやり方: Google Fontsを開き、30分ブラウズ、見出しを選び、本文を30分ブラウズ、一緒にスクリーンショットし、動かないと決定し、繰り返し。

今やっていること:
1. 上記の8つの組み合わせの1つを開始点として選ぶ。
2. Lovartを開き、その組み合わせで実際のヒーローセクションを描画する。
3. フォント名ではなく、デザインとして見る。「これはブランドが言いたいことを言っているか？」
4. 違うなら、1つのフォントを交換する — 通常は見出し、稀に本文。
5. 再描画。クリックするまで繰り返す。

ほとんどの時間はステップ3に使うようになった。ステップ1は1分。そこに品質がある — 結果の評価、入力の選択ではない。

動くプロンプト:
> 「[ブランドタイプ] のための3つのフォント組み合わせを提案。見出し用フォント1つ（太く、特徴的）、本文用フォント1つ（読みやすく、ニュートラル）。両方とも [トーン] の感じがすること。レイアウトサンプルとして横に並べて表示し、デザインとして比較できるようにして。」

AIは3つの組み合わせを実際のビジュアルサンプルとして返す。抽象的な決定ではなく、デザインとして比較する。比較の中で正しい組み合わせがだいたい明白になる。

## 何も動かないときの対処

10通り試しても何も感じが良くない場合、問題はフォントではなくレイアウト。

悪いレイアウトは良いフォントを悪く見せる。良いレイアウトは普通のフォントでも意図的に見せる。

組み合わせを変える前に、以下を試す:
- 見出しと本文のサイズ差を大きくする（3倍以上）
- 要素間の余白を増やす
- フォントウェイトを減らす（合計1つか2つ）
- 本文の行高を調整する

通常、これらの修正の1つで、組み合わせは最初から良かったことが判明する。

## 1分の判断フレームワーク

急いで決める必要があるとき — そしてよくある — 以下の順に確認:

1. 一方が明らかに見出し、一方が明らかに本文か？ 違うならコントラストを増やす。
2. 異なるカテゴリーか？ 違うなら1つを交換。
3. 同じ一般的なトーンを共有しているか？ 違うなら、より近い登録のフォントを見つける。
4. ちょうど2フォントを使っているか？ 違うなら2つに減らす。
5. レイアウトに十分な余白があるか？ 違うなら、まずレイアウトを修正する。

5つの質問、1分。3時間かけたデザイナーの大半より良い組み合わせ。

**繰り返し思い出す一文**: フォントが難しい部分ではない。難しいのは、ページに何を言ってほしいかを知ること。それが決まれば、組み合わせは言い方に過ぎない。

## FAQ

### ブランド新規立ち上げで、最も簡単なフォント組み合わせは？

Inter + Inter Tight（1ファミリー、2ウェイト）。組み合わせミスのリスクがなく、ヒーローから本文までクリーンにスケールし、古びた印象にならない。ブランドに強いトーン上の理由がない限り、ここから始める。

### セリフフォントを2つ組み合わせることはできる？

稀に、異なるカテゴリーの場合のみ — Bodoniのような高コントラストのダイドーンとGaramondのようなヒューマニストセリフの組み合わせは機能する。ヒューマニストセリフ2つはほぼ常に事故のように感じる。

### ブランドアイデンティティ全体で何フォント使うべき？

デフォルトは2つ。1つが非常に特定の役割（大きな告知用の3つ目のディスプレイフォント、コード用モノスペース）に予約されているなら3つ。3つを超えるとブランドが優柔不断に感じる。

### AIはフォント組み合わせをうまく扱える？

AIは組み合わせを適用するのは得意だが、発明するのは得意ではない。Lovartは指定した組み合わせを忠実に描画するが、Bebas Neue + Cormorant Garamondがひどいアイデアだとは教えてくれない。上記のルールを使って自分で組み合わせを選び、AIに30秒で10レイアウトでテストさせる。

### 最もよくあるフォント組み合わせミスは？

同じカテゴリーの2つのフォントを組み合わせること — ジオメトリックサンセリフ2つ、ヒューマニストセリフ2つ。片方の終わりと片方の始まりが目の区別がつかない。常にカテゴリーをまたいで組み合わせる。
