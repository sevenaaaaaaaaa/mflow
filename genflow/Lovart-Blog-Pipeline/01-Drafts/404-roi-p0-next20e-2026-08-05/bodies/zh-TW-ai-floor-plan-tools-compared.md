# AI 平面配置工具比較：2026 從 prompt 到可施工草案

这篇补 `/zh-TW/blog/ai-floor-plan-tools-compared` 404。搜索意图围绕「AI 平面配置工具比较」，读者要可执行步骤，不是灵感图库。

## 我的立场

AI 平面图 **不能当施工蓝图**，但可以 **快速给业主看方向**——比例尺、门窗符号、标注区必须用 Touch Edit 改，不能靠模型猜。

## Brief 合约（我实际在用的）

```
输出：示意平面 + 家具 icon，非施工
比例：写明 sqm 或 sqft，禁止瞎标
标注：房间名 Touch Edit，不烤进 AI
风格：2D clean 或 3D isometric 二选一
禁止：假结构承重墙改动
```

## 踩坑

**坑 1：比例尺乱。** 解法：brief 写面积+长宽。
**坑 2：门窗位置错。** 解法：人工 overlay 校正。
**坑 3：3D 像游戏不像平面。** 解法：2D clean 优先交付。
**坑 4：改房间名重跑。** 解法：Touch Edit 标注区。
**坑 5：当施工图交付。** 解法：免责声明+示意标头。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export

## 公式

\[ \text{可用示意} = \frac{\text{比例正确} \times \text{Touch Edit标注}}{\text{结构幻觉}} \]

## FAQ
