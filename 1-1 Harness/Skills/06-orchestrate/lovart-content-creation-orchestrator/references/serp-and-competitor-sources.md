## Page Type Decision

| Query Shape | Best Page Type | Notes |
|---|---|---|
| Concrete output (`ai logo generator`, `brand video maker`) | Tool landing | Must show input, output, edit, export, FAQ. |
| Broad category (`ai design generator`) | Hub or tested guide | Needs comparison and navigation. |
| Tool name / alternative | Comparison page | Fair verdict; do not blindly attack competitors. |
| Hard quality problem (`character consistency`) | Deep guide + feature page | Educate first, then sell. |
| Model name (`Sora`, `Kling`, `Veo`) | Model comparison / routing explainer | Show which model fits which job. |
| Utility feature (`background remover`) | Supporting page or section | Only standalone if Lovart has a strong wedge. |

## Competitor Framing

Use competitors as decision anchors:

- Canva: template/editor ecosystem.
- Looka: logo-only workflow and brand kit.
- AdCreative.ai: performance banner volume and conversion scoring.
- Creatify/Topview/OpenArt: video/ad/commercial workflow.
- Runway/Kling/Pika/Luma: standalone video/model capabilities.
- Neolemon/Ideogram: consistency/control education.
- Figma/Figr: product/design workflow.
- Manus/MindStudio/RelevanceAI: generic agent/workflow mindshare.

Lovart's strongest frame: brief-driven, editable, multi-asset campaign creation.
