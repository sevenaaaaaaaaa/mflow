# 中国内容平台链接政策速查（2026-06 调研）

## 🟢 放心放链接（技术社区）

### 51CTO
- GitHub 链接、官方文档链接：✅ 直接放
- 推荐标签：「技术选型」「开源项目推荐」
- 商业产品链接：偶尔可放，不宜过多
- 封号风险：低，但过度营销仍会被删文

### 开源中国 (OSChina)
- GitHub/Gitee 链接：✅ 标配
- 社区用户会主动点踩低质量内容
- 推荐写法：开源项目推荐、技术选型对比
- 商业产品需以「技术评测」角度写

### 掘金 (Juejin)
- 外链会弹「风险提示」中间页，GitHub 链接最安全
- 推荐标签：「实战教程」「工具盘点」
- 正文多放代码块建立技术可信度
- 禁止：二维码、微信群引流、竞品平台推广（CSDN/SegmentFault）
- 有信誉分系统，违规降分影响推荐

## 🟡 去链留名（保留产品名，去掉 URL）

### 知乎 (Zhihu)
- 外链全部被包裹在 `link.zhihu.com/?target=...` 并带风险警告
- **新号前 5 篇绝对不要放链接**，先养号
- 账号 4 级以上偶尔放链接相对安全
- 企业/认证号私信无限制
- 安全写法：「详见个人主页」「私信获取」
- 禁止：affiliate 链接、引流二维码、微信号
- 用户极度反感软文，会被主动举报
- **推荐策略**：回答已有问题（「有哪些好用的AI工具？」），个人简介放链接

### 简书 (Jianshu)
- 超链接可用但数量要少（1-2 个/篇）
- 禁止：博彩、色情、诈骗、过多 affiliate 链接
- 竞品写作平台链接可能触发审核
- 推荐写法：深度技术文 + 末尾「相关工具」板块
- 不要用短链接服务（看起来可疑）

### 搜狐号 (Sohu)
- **不能添加外部超链接**，只能放搜狐生态内链接
- 推荐写法：新闻报道风格（「近日，一款名为XX的AI工具引发关注」）
- SEO 优化关键词有搜索流量加成
- 用截图代替链接

## 🔴 纯文字（全去链接，只留产品名）

### 百家号 (Baijiahao / Baidu)
- **所有外部超链接被自动去除或变为纯文本**
- 二维码图片也会被标记
- 标题含关键词（AI工具、GitHub）有百度搜索加成
- 推荐写法：纯文字介绍 + 截图（无二维码无 URL）
- 信用分系统：违规扣分 → 降级 → 封号
- 流量闭环：只链百度生态（小程序等）

### 大鱼号 (Dayuhao / Alibaba)
- 类似百家号，外链基本被屏蔽
- 禁止竞品平台链接（尤其百度/腾讯生态）
- 分级创作者体系，违规降级
- 推荐写法：工具测评 + 纯文字产品名

### 豆瓣 (Douban)
- **最严格**：几乎任何外链都会被自动过滤/影子删除
- 群组管理员会主动删除软文
- 用户极度反商业
- 安全写法：个人日记体（「最近在用XX，感觉不错」）
- 绝对禁止：任何链接、二维码、微信号、注册链接
- 惩罚：内容删除 → 影子封禁 → 账号永封

## 🟠 好物分享（鼓励产品链接）

### 什么值得买 (SMZDM)
- 产品链接是核心功能，**平台鼓励放链接**
- 平台会自动将链接转换为自己的 affiliate/tracking link
- 推荐口吻：好物分享、经验分享、真实体验
- 写法：优缺点都说，诚实评测
- 可以用平台自带的「好价」链接系统
- 这是最适合直接推荐产品的平台

## 植入策略速查

| 场景 | 策略 |
|------|------|
| 技术社区（51CTO/OSChina/掘金） | 原文直发，链接全保留，GitHub 链接是标配 |
| 知乎/简书/搜狐号 | 去超链接，保留产品名，建议配截图 |
| 百家号/大鱼号/豆瓣 | 全去链接，纯文字 + 截图，「自行搜索」 |
| 什么值得买 | 好物分享口吻，链接用平台系统 |

## 通用避坑

- **内容比例**：至少 5:1（5 篇纯干货 : 1 篇含产品提及）
- **禁止触发词**：限时优惠、立即购买、点击链接、免费领取
- **禁止图片内**：二维码、微信号、联系方式水印
- **养号优先**：新号前 10-20 篇纯干货，建立信誉后再偶尔植入
- **截图代替链接**：在严格平台，产品界面截图是最安全的「隐性链接」
