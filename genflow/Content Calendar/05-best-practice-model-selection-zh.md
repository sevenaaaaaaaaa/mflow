# 最佳实践：为你的设计任务选择合适的AI模型

[图片1占位符 — 用户场景]

Lovart 为你提供了 9 个图像模型和 6 个视频模型。这既是强大的能力，也意味着需要做出决策。当你在 ChatCanvas 中输入提示词时，应该由哪个模型来处理？

答案取决于你正在创作的内容。不同的 AI 模型各有优势——有些擅长照片级真实感，有些擅长艺术风格化，有些擅长文本渲染，还有些擅长复杂场景构图。为任务选择合适的模型，决定了最终图像是看起来“AI生成的”，还是看起来完全符合你的预期。

本指南提供了一个模型选择的决策框架、一个快速参考表，以及关于何时在质量与速度或成本之间进行权衡的实用指导。

## 决策框架

[图片2占位符 — 概念图]

在为设计任务选择 AI 模型时，请按顺序评估三个因素：

### 1. 所需的视觉风格

这是主要的决定因素。能生成惊艳照片级真实感的模型，在插画方面会表现不佳。能渲染出干净标志的模型，在生活场景方面则会表现平庸。

**照片级真实感 → Nano Banana**
Nano Banana 是 Lovart 的照片级真实感专家。它能生成具有自然光照、准确材质渲染和真实纹理的图像。将其用于产品摄影、生活场景，以及任何以“这看起来像真实照片吗？”为质量标准的输出。

优势：肤色、织物纹理、自然光照、产品细节、环境真实感。
劣势：艺术风格化、抽象概念、大量文字叠加。

**艺术/风格化/插画 → FLUX**
FLUX 是创意引擎。它擅长处理艺术方向——特定的艺术风格、插画技巧、概念图像和非照片级真实感的视觉处理。如果你的提示词中包含“插画”、“水彩”、“概念艺术”或“风格化”等词语，FLUX 是正确的选择。

优势：风格遵循度、艺术范围、创意诠释、抽象概念。
劣势：严格的照片级真实感、技术准确性、跨代次的产品一致性表现。

**标志/品牌标识/矢量风格 → Recraft V3**
Recraft V3 专为标志设计、图标和矢量风格图形而构建。它能生成清晰的线条、几何精度以及可在多种尺寸下使用的构图。如果你正在设计标志、应用图标或品牌标识，请从这里开始。

优势：清晰的矢量美学、几何精度、可缩放构图、极简设计。
劣势：照片级真实感、复杂纹理、氛围光效、有机/自然主题。

**复杂场景/多元素/精确构图 → Seedream**
Seedream 处理多元素构图时，比单主体模型具有更好的空间连贯性。当你的图像需要前景主体、中景元素和详细背景——且三者处于正确的空间关系时——Seedream 能驾驭这种复杂性。

优势：场景构图、多个主体、空间关系、环境细节。
劣势：极端特写细节、非常简单的单主体拍摄（大材小用）。

**文字密集型设计/信息图/演示文稿 → Ideogram**
Ideogram 是文本渲染的领导者。它能生成带有准确、可读文字的图像——这对于信息图、演示幻灯片、社交媒体引语卡片，以及任何图像中文字与图像本身同等重要的设计来说至关重要。

优势：文字准确性、清晰布局、信息图构图、排版处理。
劣势：纯摄影（文字能力增加了开销）、高度抽象的艺术概念。

### 2. 输出用途

**商业产品图片** → Nano Banana 或 Seedream，取决于场景复杂度。
**社交媒体内容** → 品牌内容用 FLUX，产品展示用 Nano Banana。
**广告创意** → 产品层通常用 Nano Banana，可选择与 FLUX 背景合成。
**品牌资产（标志、标识、图标）** → Recraft V3。
**网站主视觉图** → 复杂场景用 Seedream，简单产品主图用 Nano Banana。
**印刷就绪设计** → 矢量风格用 Recraft V3，摄影风格用 Nano Banana——始终以 300 DPI 等效分辨率生成。

### 3. 成本与质量的权衡

更高质量的模型每次生成消耗更多积分。这种差异在大规模使用时意义重大——在 Nano Banana 上生成 1000 张图像可能花费约 12 美元积分，而同样数量在较轻量级模型上可能花费约 6 美元。

**在以下情况使用最高质量模型：**
- 图像面向客户（产品页面、广告、社交媒体）
- 图像将以全分辨率查看
- 品牌形象取决于视觉质量

**在以下情况使用成本优化模型：**
- 生成缩略图或预览图
- 制作内部模型和概念探索
- 进行高容量 A/B 测试，此时数量比单张图像质量更重要
- 在构思阶段快速迭代——使用更快/更便宜的模型进行概念设计，然后切换到高质量模型进行最终输出

## 视频模型选择

Lovart 的 6 个视频模型服务于不同目的：

**Seedance** — 产品展示视频。干净、稳定、以产品为重点。最适合电商产品演示、开箱风格视频和简单的动态产品展示。

**Kling** — 电影感和叙事性视频。创意上限高于 Seedance。最适合品牌故事讲述、包含人物主体的生活视频，以及氛围和叙事比产品细节更重要的内容。

**Runway Gen-3** — 快速迭代和风格迁移。最适合实验性视频概念和快速周转内容，此时速度比最终打磨更重要。

**Pika 2.0** — 简短、有力的社交媒体视频。针对在 TikTok 和 Reels 上表现良好的竖屏、快剪风格进行了优化。最适合紧跟潮流的内容。

**PixVerse** — 动画和动态图形。最适合动画解说、动态排版和以动作为导向的内容。

**Hailuo** — 通用视频，具有强大的文本到视频连贯性。当你需要可靠输出且无需特定模型调整时，它是一个不错的全能选手。

**视频决策规则：** 如果产品是主角 → Seedance。如果故事是主角 → Kling。如果速度最重要 → Runway Gen-3。如果平台�� TikTok → Pika 2.0。如果你需要动画 → PixVerse。如果你不确定 → Hailuo。

## 决策流程图

这是一个简化的决策路径：

1. **输出是摄影风格的吗？**
   - 是，简单场景 → Nano Banana
   - 是，复杂场景 → Seedream
   - 否（插画/艺术风格） → FLUX

2. **设计需要准确的文字吗？**
   - 是 → Ideogram
   - 否 → 继续沿着摄影或艺术路径

3. **是标志、图标或矢量风格图形吗？**
   - 是 → Recraft V3
   - 否 → 继续

4. **是视频吗？**
   - 产品展示 → Seedance
   - 品牌/电影感 → Kling
   - TikTok/Reels 风格 → Pika 2.0
   - 动画/动态 → PixVerse
   - 快速实验性 → Runway Gen-3
   - 通用 → Hailuo

## 实际案例：营销活动的模型选择

假设你正在推出一款新的蜡烛系列。以下是模型选择在整个活动素材中的体现：

**系列标志 → Recraft V3**
清晰、可扩展的品牌标识。以矢量兼容风格生成。

**白底产品照片（6 种蜡烛品种） → Nano Banana**
照片级真实感、光线一致、纯白背景。批量生成全部 6 种。

**生活场景：餐桌上的蜡烛 → Seedream**
包含多个元素的复杂场景——餐桌布置、食物、环境光、窗户背景。Seedream 处理空间复杂性。

**Instagram 轮播公告 → FLUX**
以一张风格化、艺术指导的公告幻灯片开始——FLUX 处理创意方向和独特美学。

**产品视频：蜡烛燃烧、蜡池形成 → Seedance**
干净、稳定的产品展示。产品是主角。

**品牌故事视频：蜡烛的制作过程 → Kling**
叙事驱动、温暖、有氛围。故事重于产品细节。

**信息图：香调与燃烧时间 → Ideogram**
文字准确的布局，清晰呈现产品信息。

**用于 A/B 测试的广告创意变体 → Nano Banana（产品）+ FLUX（生活背景）混合 → 合成**
在 Nano Banana 中生成产品照片，在 FLUX 中生成背景场景，通过 Lovart 的生成流程进行合成或交叉引用。

## 何时忽略本指南

这些建议是起点，而非规则。了解哪个模型最适合你的特定品牌、产品和受众的最佳方法是测试。

在 2-3 个模型上生成相同的提示词。比较输出结果。你可能会发现，尽管“最佳实践”推荐 Nano Banana，但 Recraft V3 却能生成与你的品牌完美匹配的产品图像美学。你品牌的视觉形象才是最终的决策者——这些指南能帮助你更快地找到正确答案，而不是规定它。
