## 一级标题（章级）

### 文章总览
- 页面顶部：6-8个核心KPI卡片（数值+趋势+含义）
- 三引擎交叉摘要：
  - **SERP Agent**：搜索引擎端的品牌安全、搜索声量、竞品截流
  - **Social Agent**：社媒粉丝动向、互动率变化、新内容/新平台
  - **Insight Agent**：跨渠道综合分析、深层趋势判断、战略建议

- 总览本周期品牌声誉变化历程

### 二、品牌声量与影响力分析
- 2.1.1 整体声量趋势：搜索声量 + 社媒声量合并趋势
- 2.1.2 渠道声量分布：各平台声量特征 + 情感倾向 + 角色定位表
- 2.1.3 区域声量分布：地域流量占比 + CTR + 趋势评估

### 三、本周期关键事件回顾
- 3.1 关键营销活动时间线：功能发布/内容产出/营销活动
- 3.2 重大舆情事件时间线（阶段式叙事）：
  - 3.2.1 第一阶段：产品发布与初始声量积累
  - 3.2.2 第二阶段：增长爆发期（新功能上线 + 用户涌入）
  - 3.2.3 第三阶段：增长平台期与结构性裂缝
  - 3.2.4 第四阶段：当前状态（声量维持但健康度分化）

### 四、情感态度分析
- 4.1 品牌联想词云：正面/负面词簇对比表
- 4.2 核心议题分析：文化失控/技术不可靠/定价争议 + 交叉污染
- 三重压力的协同效应分析

### 五、用户画像分析
- 5.1 人群属性：分层画像表（身份+诉求+忠诚度+风险）
- 5.2 兴趣标签：四象限分析 + 交叉污染检测
- 5.3 核心触媒习惯：平台/内容形态/舆情特征 + 私域暗网标注

### 六、主要负面议题追踪
