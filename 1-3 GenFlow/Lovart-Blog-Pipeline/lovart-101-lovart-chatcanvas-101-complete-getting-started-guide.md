## FAQ

**Q: Is ChatCanvas the same as Lovart?**

A: ChatCanvas is the workspace surface; Lovart is the platform including the Design Agent, models, Brand Kit, and exports. You always create on ChatCanvas when producing inside Lovart.

**Q: Do I need design software experience?**

A: No—briefs in plain language work. Design literacy helps for typography and hierarchy, but Touch Edit and Text Edit reduce traditional tool learning curves.

**Q: Thinking Mode vs Fast Mode—which default?**

A: Use Thinking Mode for new products, categories, or legal-sensitive layouts. Use Fast Mode when repeating proven formats with new copy or SKUs.

**Q: Can teams share one canvas?**

A: Yes on plans with collaboration. Agencies typically separate canvases per client to keep Brand Kit and assets isolated.

**Q: What file types export from ChatCanvas?**

A: PNG, JPG, SVG, PSD, PDF, and MP4 depending on asset type; Upscale supports high-resolution stills for print.

**Q: Where do credits go?**

A: Complex video, upscale, and multi-step Thinking Mode runs consume more credits than a single Fast Mode still. Monitor usage on [Lovart pricing](https://lovart.ai/pricing).
