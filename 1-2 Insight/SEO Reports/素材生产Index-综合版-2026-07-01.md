## 零、一句话背景

Lovart 在 13 家竞品大盘中非品牌词曝光 Share 仅 0.03%（竞品中位 ~8%），**12 个品类词簇合计 17.3M/月竞品曝光我们近乎零覆盖**。本轮素材生产的目标是：为 110 个存量改造页面 + 约 40 个新建页面提供视觉素材，将这些缺口词的搜索流量从 0 承接至预期月点击 +5,000~20,000。

你生产的每张 hero 图 / feature 图 / capability tab 图，会直接影响对应页面在 Google 搜索中的 CTR（点击率）和用户停留时长。当前非品牌词页面 CTR 仅 0.5-1.4%，竞品同类页面 CTR 在 2-5%——**优质素材能直接把这个数字翻 2-3 倍**。

## 三、补充：之前漏掉的分类

对比竞品大盘和 GSC 数据，以下内容品类在 Sanity 中**零覆盖或极弱覆盖**，需要补建：

1. **Pricing / Comparison 页面**：`/pricing` URL 本身非 compositePage 但有 536K 曝光 1,476 点击。需要 `Lovart vs Canva`、`Lovart vs Freepik`、`Lovart vs Fotor` 等竞品对比 landing
2. **行业垂类 landing**：Education / Healthcare / Real Estate / E-commerce / Restaurant 等行业专属页。竞品 Venngage 用 `solutions/*` 承载，我们在 scenario 分类下有 70 个但均零 GSC（未被 Google 认可为品类页）
3. **Video 品类 Hub 页**：video-generator / ai-video-generator / text-to-video / image-to-video 散落在 tool/feature 下，缺一个 `topic/ai-video-generator` 品类聚合页
4. **Free Tools Hub**：nano-banana-free（193K 曝光）说明 "free" 是高流量后缀，但其他工具的 free 版本（如 free-ai-video-generator）未建
5. **Integration / API 页**：WordPress plugin / Shopify app / Figma plugin 集成页——竞品 Canva/Fotor 都有
6. **Tutorial / Resource Hub**：教程列表页——CapCut 用教程式 landing 承接了大批搜索流量
7. **Enterprise / Team 页**：大客户方案页——Venngage 有 enterprise 独立落地
8. **Before/After Gallery**：展示 AI 处理前后的效果对比，Seedance/Fotor 都有
