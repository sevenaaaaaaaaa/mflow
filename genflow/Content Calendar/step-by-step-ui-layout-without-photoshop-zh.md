## 场景引入

[图片 1 占位符 — 用户场景]

你的创业公司路演演示文稿截止时间还剩 48 小时。你有一个经过验证的问题陈述、12 页的叙事框架，但 UI 模型为零。你的 Figma 文件是一个名为“未命名”的空白画板，并且你看了 17 分钟的 YouTube Figma 教程，这些教程让你相信仅自动布局就需要一个学期来学习。你需要五个界面——引导页、主页��产品详情、结账和确认——它们看起来足够有说服力，能够支撑你的路演叙事，但你是一位创始人，而不是产品设计师。投资者不会为 PowerPoint 中绘制的线框图提供资金。

## 第一步：描述你的应用界面，让 Lovart 构建骨架

[图片 2 占位符 — 概念图]

打开 Lovart 的 ChatCanvas，选择 **UI 布局** 预设（位于 模板 → 数字 → UI 界面 下）。输入：**"一款植物护理追踪应用的移动端主页，iOS 风格，390x844。底部标签导航包含：首页、我的植物、浇水计划和个人资料。英雄区域有一个'今日任务'卡片，显示 3 株需要浇水的植物。下方是一个水平滚动的植物健康卡片区域，带有圆形进度指示器。"** Lovart 生成结构化的布局：一个状态栏、一个包含指定卡片的内容区域，以及一个带有四个图标的标签栏。所有间距自动遵循 8pt 网格系统。

## 第二步：通过自然语言迭代进行优化

生成的布局为你提供了一个 80% 准确的骨架。现在，使用精确指令进行迭代：**"将'今日任务'卡片改为圆角 16px，柔和的鼠尾草绿色背景，不透明度 15%，植物名称左对齐，字体 18pt SF Pro Display。"** 或者：**"将标签栏图标替换为 Phosphor 图标风格的线条图标，活动标签颜色改为 #2E7D32，并为标签栏添加一个 0.5px 高度的微妙顶部边框。"** Lovart 将这些自然语言指令转化为像素级别的调整，无需你操作单个属性面板。每条指令在 3 秒内处理完成。

## 第三步：生成真实的内容和数据

像“Lorem ipsum”这样的占位文本会立即向投资者发出“假模型”的信号。Lovart 的 **内容生成器**（点击任何文本元素上的闪光图标）将占位文本替换为上下文真实的内容：植物名称（"龟背竹"、"琴叶榕"）、用户名、时间戳以及与应用领域匹配的错误消息。对于图表或进度条等数据驱动元素，Lovart 会生成真实的示例数据。输入：**"将浇水计划替换为每周柱状图，显示星期二是最繁忙的一天"**，Lovart 会渲染出一个包含 7 列和合理数值的简单柱状图。

## 第四步：在所有界面中应用一致的样式

一旦你完善了一个界面，无需从头开始创建其余界面。Lovart 的 **界面同步** 功能（$49 Pro 计划可用）将设计令牌——颜色、字体、圆角半径、阴影预设和间距值——链接到项目中所有界面。将你的主页设计完成，然后输入：**"创建一个 390x844 的引导页，使用与主页相同��设计令牌，包含一个 3 页可滑动轮播，介绍植物追踪功能，'开始使用'和'登录'按钮，以及微妙的植物插画装饰。"** Lovart 生成的新界面会继承所有令牌。无需手动复制样式。无需担心十六进制颜色代码不一致。

## 第五步：导出为可用于演示的模型

[图片 3 占位符 — 真实 UI 截图]

Lovart 的 **UI 导出** 模式以三种格式输出界面：**单个 PNG**（2x 和 3x 分辨率，适用于视网膜显示屏）、**Figma 导入文件**（基于 SVG，以便设计师可以继续你的工作）和 **模型演示文稿**——一个显示所有界面顺序排列并带有设备边框的 PDF 或 PNG 长图。设备边框生成器会添加逼真的 iPhone 16 Pro 或 Pixel 9 边框，包括状态栏和刘海/挖孔，使你的模型看起来像拍摄的屏幕截图，而不是裸露的画板。对于路演演示文稿，以 1920×1080 导出模型演示文稿，无需进一步格式化即可直接放入你的幻灯片中。

## 常见问题

**问：Lovart 的 UI 设计能否移交给真正的开发人员？**
答：Lovart 生成的是视觉模型，而非生产代码。Figma 导入文件将界面导出为可编辑的 Figma 图层，开发人员可以检查间距、颜色值和排版规格。如需用于生产环境的移交，请导出到 Figma 并使用 Figma 的开发者模式。

**问：Lovart 是否支持 Android Material Design 3 规范？**
答：支持。在你的提示中指定 **"Material Design 3"**，Lovart 会应用 M3 设计令牌：动态颜色、更新的排版比例（展示、标题、正文、标签）和形状系列。8pt 网格在 iOS 和 Material 指南中保持一致。

**问：我可以在 Lovart 中设计平板和桌面 UI 布局吗？**
答：可以。指定画布尺寸：iPad 11 英寸（820×1180）、桌面 SaaS 仪表盘（1440×900）或任何自定义分辨率。Lovart 的布局引擎会根据目标视口调整间距和组件大小。

**问：Lovart 的 UI 模式与使用 Figma 的 AI 功能有何不同？**
答：Figma AI（2025 年推出）可以根据提示生成布局，但仍在 Figma 的画布范式内工作。Lovart 的 UI 布局模式生成结构化的、对齐网格的布局，并隔离和同步设计令牌。Lovart 在初始模型生成方面更快；Figma 在详细优化和开发移交方面更强。

**问：我可以在 Lovart 中将我的 UI 组件库保存为可重用模板吗？**
答：在 $49 Pro 计划中，你可以将任何界面或组件保存为 **可重用块**，并在项目之间访问。构建一个按钮、卡片、导航栏和表单元素的库，插入时会自动应用你的设计令牌。

**问：Lovart 是否支持深色模式 UI 生成？**
答：支持。在你的提示后添加 **"深色模式"**。Lovart 会生成带有深色背景（Material 深色为 #121212，iOS 深色为 #000000）、适当对比度文本和调整后的投影阴影的界面。使用界面同步功能可以生成同一布局的浅色和深色两种变体。
