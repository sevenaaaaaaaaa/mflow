# 2026 文生视频与图生视频 AI 完全指南

这篇补 `/zh/blog/complete-guide-text-to-video-image-to-video-ai` 404。搜索意图围绕「文生视频与图生视频 AI」，读者要可执行步骤，不是灵感图库。

## 我的立场

视频 AI 成败在 **accepted seconds（可交付秒数）、I2V 锁帧、0.5x 慢放质检** — 不是生成秒数越多越好。

## Brief 合约（我实际在用的）

```
时长：4–8s 生产片段 + 16:9/9:16 双比例
任务：一个主体、一种镜头运动、一个 logo 安全区
主体：Brand Kit 锁定的 still → I2V
禁止：20s 一镜到底、人脸大特写、logo 变形
```

## 踩坑

**坑 1：T2V 产品 logo 每帧变形。** 解法：I2V 从 locked still 出发。
**坑 2：12s 长镜头末尾融化。** 解法：4–8s 分段 + extend 从干净尾帧。
**坑 3：0.5x 慢放才看到纹理沸腾。** 解法：交付前必跑慢放质检。
**坑 4：提示词写小说不写镜头。** 解法：CRAFT（Context/Reference/Action/Framing/Timing）。
**坑 5：accepted rate 低于 35%。** 解法：Lovart still 系统 + I2V 默认路由。

## Lovart 五步

1. ChatCanvas 生成或确认 Brand Kit still
2. Touch Edit 修 still 上的 logo/标签
3. MCoT 写 CRAFT 运动 brief
4. I2V 4–8s，两 seed 选稳定者
5. 0.5x 慢放质检 → export 或 extend

## 公式

\[ \text{cost\_per\_accepted\_second} = \frac{\text{credits} + \text{剪辑小时} \times \text{时薪}}{\text{可交付秒数}} \]

## FAQ

### 文生视频和图生视频怎么选？

有 locked still / SKU 真相 → I2V 优先；探索 mood → T2V 短片段。

### 2026 哪个模型最好？

没有万能冠军。按 job 路由：产品 orbit 用 I2V，lifestyle b-roll 用 T2V 4–8s。

### 为什么视频会「融化」？

时间一致性问题。每帧独立生成但物理/身份记忆不完整。

### Lovart 在哪一步介入？

still 系统 + ChatCanvas brief + Touch Edit 修帧 + I2V 完整流程。

### 多少 direction 够？

两 seed 选一；系列工作用 still sheet 强制 I2V。
