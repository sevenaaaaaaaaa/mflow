## Text

Master text placement on Lovart's infinite canvas. Create headlines, labels, and body copy with hierarchy. Seamlessly integrate text with AI-powered editing workflows.

### Overview

Text anchors your visuals with language — headlines, body copy, labels, and more. Lovart’s Text tool is optimized for quick placement, hierarchy, and collaboration with AI-powered editing.

### How to use

- Select Text from the toolbar and click on the Canvas to create a text layer.
- Choose a text style (headline, subhead, body) aligned with your design system.
- Type or paste your content; adjust font, size, weight, and alignment.
- Combine text with shapes, images, and grids to build clear, readable layouts.

### Advanced Text Features

**AI Typography Enhancement:**

Lovart's AI understands typography beyond just font selection. When you create text, the AI can:
- Suggest optimal font pairings based on your design style
- Recommend spacing and leading adjustments for better readability
- Auto-adjust text size based on container dimensions
- Apply text effects that complement the overall design

**Text Editing with AI:**

Instead of manually adjusting every parameter, use natural language commands:
- "Make the headline 30% larger"
- "Center the text and add a subtle shadow"
- "Change the font to a modern sans-serif style"
- "Add a gradient text effect in brand colors"

**Common Text Workflows:**

1. **Marketing Materials**: Create headlines that pop, subheads that guide, and body text that converts
2. **Social Media**: Design scroll-stopping text overlays with dynamic typography
3. **Presentations**: Build professional slide decks with consistent text hierarchy
4. **Brand Assets**: Generate text-based logos, wordmarks, and typographic designs

### Keyboard Shortcuts

- **T**: Quick-select Text tool
- **Cmd/Ctrl + B**: Bold selected text
- **Cmd/Ctrl + I**: Italic selected text
- **Cmd/Ctrl + Shift + >**: Increase font size
- **Cmd/Ctrl + Shift + <**: Decrease font size

### FAQ

**Q: Can I use custom fonts in Lovart?**
A: Lovart provides a curated library of fonts optimized for design. For specific brand fonts, you can upload font files for custom typography.

**Q: How does AI help with text alignment?**
A: The AI analyzes surrounding elements and suggests optimal positioning for visual balance. You can accept suggestions or override manually.

**Q: Can I edit text after placing it?**
A: Yes—double-click any text element to edit content, or use the Text Edit feature in the top toolbar for AI-powered modifications that preserve styling.
