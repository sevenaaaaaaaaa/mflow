# capability-tabs · Tab 切换大内容区

> **section type**：`capability-tabs`  
> **图片来源字段**：`tabs[].content.media.src`  
> **尺寸 / 比例**：1760 × 1100 · 16:10  
> **每实例图片数**：4  
> **站内覆盖页面**：约 6592 个文档

## 模块形态

左 4 列 tab list（label + icon），右 8 列内容区（图 + 标题 + 描述 + bullets + CTA），可自动轮播。

**用途**：用于「同一能力的多个维度」或「多个工具切换演示」。

## 本模块专属纪律

1. **4 张必须同一视觉世界**：同材质、同打光、同背景色 —— 因为它们是同一个内容区轮播
2. 切换时只换「对象」，不换「风格」；否则轮播会闪
3. 图片右侧留 8 列文字位，主体重心偏左

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
