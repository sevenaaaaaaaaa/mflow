# AI 生成动物与宠物肖像：2026 从参考照到可打印成品

这篇补 `/zh/blog/how-to-generate-animals-pets-ai` 404。搜索意图围绕「AI 动物宠物生成」，读者要可执行步骤，不是灵感图库。

## 我的立场

宠物 AI 图不是「越可爱越好」，而是 **参考照选对了、品种特征锁住了、背景能分区改不重跑整张**。

## Brief 合约（我实际在用的）

```
参考：1 张正面清晰照，无滤镜，无第二只动物
任务：1 个风格方向 + 1 个打印尺寸（A4 或 8×10）
主体：品种名写进 brief（金毛、英短、柯基）
背景：可替换，禁止假 award 框
禁止：六根手指式错爪、双 CTA、版权角色
```

## 踩坑

**坑 1：参考照角度太偏。** 解法：Touch Edit 换参考或重选正面照。
**坑 2：品种特征 drift。** 解法：Brand Kit 锁毛色+耳型关键词。
**坑 3：背景喧宾夺主。** 解法：MCoT 分区：主体+背景分 artboard。
**坑 4：打印 DPI 不够。** 解法：Export 300 DPI，禁止 72 只用于屏。
**坑 5：仿迪士尼/IP 角色。** 解法：法务 BLOCK。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export

## 公式
