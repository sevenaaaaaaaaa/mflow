# 1-2 Insight — 情报资产（本地数据）

本目录存放情报侧的**本地运行时数据**：搜索控制台报告、舆情日报、关键词研究、
页面分析、知识库（Knowledge Base）等。**数据不入公开仓库**（含业务事实），
目录结构约定保留供管线与工作台读写。

## 约定结构（管线自动创建）

```
1-2 Insight/
├── Knowledge Base/      产品知识库（生成时检索的真实来源；.md 逐篇）
├── Trident Insights/    搜索/收录/引用报告（reports/{monthly,weekly,...}）
├── SEO Reports/         SEO 周报月报
├── Keywords Research/   关键词研究
└── ...                  其他情报产出
```

## 上手

1. 「数据管线 Trident」页配好凭证后执行采集，产出自动落盘；
2. 知识库直接放入 `.md` 文件（H2 分节），「知识中台」页即可检索；
3. 报告中心/报告仪表会自动索引本目录下的 `.md` 报告。
