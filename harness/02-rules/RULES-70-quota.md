# RULES 70 — 数量限制与防注水（硬性）

> 目的：**禁止 agent 灌水**。所有生成/改稿任务必须有明确数量预算；超出即 BLOCK。
> 执行：gateway 钩子 `quota-check.sh`（生成链自动跑）+ 提示词注入 CONTENT_BUDGET。违反数字 = 废稿。

## 一、每篇预算（硬上限，超一即废）

1. **字数（Blog 已并轨长文，2026-11-03 短格式/改稿轨废止）**：Blog 一律按**长文生产铁律**——正文 ≥7,500 词（EN）/ ≥12,000 汉字（ZH）/ ≥21,600 字（JA，= 中文基准 ×1.8），上限 = 下限 ×1.2（EN ≤9,000 词 / ZH ≤14,400 汉字 / JA ≤25,920 字），只计正文；长文用 RULES-20 Multi-Turn / Column-Writer Lane 分节生成，单次调用 ≤3,000 词。**落地页文案 600–1000 字**（不变）；摘要/分发稿 ≤600（不变）。**不得超过上限 20%**
2. **H2 章节**：4–7 个；**禁止**为凑结构拆出 <120 字的空章节
3. **FAQ**：3–5 条；**禁止**超过 5 条或把正文段落改写成问答充数
4. **数据点**：每千字 1–3 个；**禁止**同一数据在文中重复出现超过 1 次
5. **外部来源**：2–5 条；**禁止**堆砌无正文引用的链接
6. **列表块**：全文 ≤ 4 处；**禁止**连续 2 个列表块（禁止把段落改成 bullet 清单充字数）
7. **段落**：单段 ≤ 300 字符；**禁止**连续 3 段以同一句式开头

## 二、禁止的注水手法（出现即 BLOCK）

8. **禁止**同义反复：同一观点用不同措辞写两遍（重复句检测：连续 2 句语义重合度 >70%）
9. **禁止**总结段落复述前文（"综上所述/由此可见"式复述）
10. **禁止**模板化过渡词堆砌（首先/其次/然后/最后 ≥4 次，或用"值得注意的是"≥2 次）
11. **禁止**无信息量的形容词堆叠（"强大而灵活、高效且智能"）
12. **禁止**为凑字数扩写数字（"大约 100 到 200 之间可能是 150 左右"）
13. **禁止**同段落重复主语引出（"品牌方 可以… 品牌方 还能… 品牌方 也支持…" 连续 3 次）

## 三、批量任务预算（防批量灌水）

14. 单批次 ≤ **5 项**（`batch_size` 默认 5）；超 5 项必须拆多批次并传递上下文摘要
15. 单任务 items 上限：物料/字段 ≤200；生成/改稿 ≤20
16. **禁止**同一 `item_id`/`doc_id` 在一个任务内出现两次
17. 每项 token ≤ 4000（**单次调用**）；长文按 Lane 分节生成，每节 ≤3,000 词，禁止单次调用灌长文

## 四、自检（生成后必查）

18. 生成完成后必须回答四问：**谁读 / 为何现在读 / 读完改变什么 / 下一步做什么**——任一答不出即删段而非扩写
19. 删减优先于扩写：字数不足时**优先删冗余**而不是加段落；确需补内容则补数据/案例，不补形容词
20. 预算与门禁冲突时：**门禁优先**（宁短不水）

## 五、长文标准（Blog 唯一轨，2026-11-03 起短格式/改稿轨废止）

21. **Blog 一律长文**（原"豁免通道"升级为唯一标准）：
    - 生产流默认 `budget_profile=longform`（blog-writer SKILL 生产流内置，无需额外声明）
    - 地板/上限：EN 7,500→9,000 词 / ZH 12,000→14,400 汉字 / JA 21,600→25,920 字（只计正文，不含 frontmatter 与 HTML 注释）；H2 ≤14、FAQ ≤8、连续列表项 ≤14（其余规则不变）
    - 分节生成：RULES-20 Multi-Turn / Column-Writer Lane（`OUTLINE → DRAFT_PART* → INTEGRATE_QA`），单次输出 ≤3,000 词
22. **落地页/摘要/分发稿不受此条约束**：落地页维持 600–1,000 字；摘要/分发稿 ≤600 字——它们不是 Blog
23. 仍需过 `quota-check.sh`（Blog 自动按长文档判定）与全部其它门禁（Anti-Slop / GEO / 语言规范）
24. **翻新/改稿任务**：目标为 Blog 时同样交付长文级更新（整篇或按节）；仅修字形/字段/素材的任务不受字数约束
