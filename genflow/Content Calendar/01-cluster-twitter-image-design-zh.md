## 你需要的每一个 Twitter 图片尺寸（2026 版）

[图片 2 占位符 — 概念图]

Twitter 并不羞于更改其规格。以下是截至 2026 年中期的当前情况，简单直接。

### 个人资料照片：400 x 400 像素

你的个人资料照片在大多数屏幕上显示为 200 x 200 像素，但请上传 400 x 400 像素以在视网膜屏幕上保持清晰。Twitter 会将其裁剪为圆形，因此请将你的焦点保持在正中心。在这里，Logo 比宽横幅效果更好——人们会在缩略图尺寸下认出它。

**专业提示：** 在 48 x 48 像素下测试你的个人资料照片。这是它在回复线程中显示的尺寸。如果在这个比例下难以辨认，请重新考虑设计。

### 页眉/封面照片：1500 x 500 像素

页眉是你的广告牌。它横跨你个人资料的顶部，在桌面端是访客首先看到的东西。Twitter 推荐 1500 x 500 像素，最大文件大小为 5 MB。但这里有个陷阱：你的个人资料照片会重叠在左下角，而在移动端，两侧会被裁剪。安全区域大约是居中位置的 1200 x 400 像素。

这是品牌个性所在。用它来传达你的业务、展示社会认同或推广当前活动。只是不要塞满会被裁���掉的文字。

### 信息流/时间线照片：1600 x 900 像素

这是关键镜头。当你将图片附加到推文时，Twitter 在信息流中以 600 x 335 像素（裁剪为 16:9）显示，但当有人点击时，会扩展到 1200 x 675 像素。上传 1600 x 900 像素可为每种显示场景提供余量。

**宽高比很重要：** Twitter 支持从 1:1 到 3:1 的宽高比。参与度的最佳点是 16:9——它填满了信息流，而不会导致尴尬的裁剪。方形图片（1:1）效果不错，但会浪费空间。

### 卡片图片/链接预览：1200 x 628 像素

当你分享链接时，Twitter 会拉取 Open Graph 图片。标准是 1200 x 628 像素，比例为 1.91:1。这是你在信息流中的缩略图，它通常是决定有人点击还是划过的关键。让它发挥作用。

### Twitter 广告图片尺寸（快速参考）

| 广告类型 | 推荐尺寸 | 宽高比 |
|---|---|---|
| 单图广告 | 1200 x 1200 像素 | 1:1 或 1.91:1 |
| 轮播广告 | 800 x 418 像素（每张卡片） | 1.91:1 或 1:1 |
| 视频广告 | 1280 x 720 像素 | 16:9 或 1:1 |
| 网站卡片 | 800 x 418 像素 | 1.91:1 |

## 真正能推动进展的设计原则

了解尺寸只是入门。将吸引眼球的��品与背景噪音区分开来的，是设计师们通过艰难方式学到的一些原则。

### 1. 每张图片一个想法

Twitter 上最大的错误？试图表达太多。你的图片大约有一秒钟的时间来传达其要点，否则拇指就会继续滑动。选择一个信息。一个焦点。一个要点。如果你需要三个要点，你就需要三张图片。

### 2. 对比度是你的作弊码

Twitter 信息流很拥挤。你的图片正在与表情包、新闻截图和朋友的度假照片竞争。高对比度——无论是在颜色还是概念上——都能在噪音中脱颖而出。深色背景配亮色文字。大胆的排版。用负空间来框定你的信息，而不是埋没它。

### 3. 品牌一致性，无需头疼

每个人都知道你应该保持品牌一致性。但很少有人谈论当你在 Twitter、LinkedIn、Instagram、电子邮件和博客上创建图片时，这有多么令人筋疲力尽。这就是模板系统发挥作用的地方。定义你的调色板、字体搭配和 Logo 位置一次——然后在每种格式中重复使用。

### 4. 正确叠加文字

Twitter 图片文字需要在信息流尺寸下可读（桌面端大约 600 像素宽，移动端更小）。这意味着正文至少 24 pt，标题至少 36+ pt。无衬线字体在小尺寸下表现更好。还有——除非你在发布信息图，否则单张图片上不要超过两行文字。

### 5. 在上下文中测试

你的设计软件会在干净的画布上以全分辨率显示图片。而你的受众看到的是被压缩、裁剪，并夹在一条热评和一个猫咪视频之间的图片。在发布之前，将你的图片放入一个模拟信息流布局中。它仍然有效吗？仍然可读吗？如果不是，就简化。

## 比图片尺寸更重要的事

这里有一个令人不安的事实：你的受众并不关心你是以 1200 像素还是 1600 像素上传的。他们关心的是你的图片是否阻止了他们的滑动，并说出了值得阅读的内容。

最好的 Twitter 图片共享三个特征：
- **清晰度：** 信息是即时的。无需解码。
- **相关性：** 视觉内容与推文文字匹配。没有标题党。
- **个性：** 它听起来像是由人制作的，而不是品牌机器人。

做到这三点，精确的像素尺寸就变得次要了。
