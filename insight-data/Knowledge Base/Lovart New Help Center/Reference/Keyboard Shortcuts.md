Use these shortcuts to move faster on the Canvas.

|Shortcut|Tool / Action|
|---|---|
|V|Select tool|
|H|Hand tool (pan/zoom)|
|Spacebar (hold)|Temporary Hand tool|
|Shift+Click|Multi-select elements|
|A|Image Generator|
|S|Video Generator|
|@|Open Mention panel|
|F|Frame|
|T|Text|
|P|Pencil|
|M or Cmd/Ctrl+Click|Mark / Touch Edit|
|Tab|Quick Edit (with element selected)|
|Cmd+Z / Ctrl+Z|Undo|
|Esc|Exit current mode / Cancel|
