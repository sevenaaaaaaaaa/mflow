## 三、职业内容格式标准

### 3.1 工作流文章结构

```
1. 引言：这个职业为什么需要 AI 设计（痛点共鸣）
2. 传统工作流 vs AI 工作流（对比图/表格）
3. 完整工作流分步指南（5-8步，每步带截图）
4. 实际案例：用 Lovart 完成一个真实项目
5. 时间/成本对比数据
6. Pro Tips（3-5个该职业专属技巧）
7. 推荐的 Lovart 功能/模板
8. CTA：下载工作流模板/Checklist
```

### 3.2 职业 Landing Page 结构

```
1. Hero："[职业]专属设计助手" + 职业场景视觉
2. 该职业的3个设计痛点
3. Lovart 如何解决（3个场景×截图）
4. 同行案例/评价
5. 推荐套餐
6. CTA：免费试用 + 职业专属模板包
```
