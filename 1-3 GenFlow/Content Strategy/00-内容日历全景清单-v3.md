## 〇、框架说明

### 页面类型体系（Silo Structure）

| 页面类型 | 定义 | 实现方式 | TDK视角 |
|----------|------|----------|---------|
| **Core Page** | Homepage / Product / Solution / Pricing / About | Manual，逐页 | 品牌词 + 核心产品词 + Top带量词 |
| **Pillar Page** | 101合集 / Workflow合集 / 年度精选 / For细分 | Manual，逐页 | 核心场景词，具备内部路由能力 |
| **Cluster Page** | Topic Cluster，按行业/人群/场景聚合 | Manual or 策略生成 | 核心场景词的长尾词 |
| **Glossary** | 术语库，有多少放多少 | 快速量大管饱 | 专业词汇 |
| **Marketplace** | 模板市场/示例库 | 策略生成匹配 | 行业词、场景词、人群词 |
| **Community** | UGC驱动的社区内容 | UGC | 不断根据用户需求挖掘细分词 |
| **Auto Tag** | 聚合详情页，量小的长尾词 | 按策略生成匹配 | 量小长尾词 |
| **Detail Page (Blog)** | How-to / Alternative 等 | 按策略生成匹配 | 长尾词 |
| **Template / Example** | 产品详情/模板/案例 | 按策略生成匹配 | 行业词、场景词（Category聚合） |
| **Resource** | 资源页 | Manual，逐页 | 行业词、场景词、人群词 |
| **Wiki / Documental** | 帮助文档/知识库 | 按策略生成匹配 | 合理合法合规做大量 How-to 长尾词 |
| **Podcast / Webinar** | 播客/网络研讨会存档 | Manual，逐页 | 占特定搜索入口 |
| **Event Calendar** | 活动日历 | Manual，逐页 | 占按时间搜索的用户需求 |
| **Event Detail** | 活动详情 | Manual，逐页 | 占按时间、地点搜索的用户入口 |
| **Thought Leader** | 认知、概念、方法论、行业洞察 | Manual，逐页 | 与认知、概念、方法论相关词汇 |

### 博客分类体系（Blog Taxonomy）

| 分类 | 定位 | 受众 |
|------|------|------|
| **Topics** | 精选/置顶，根据UV和注册/付费贡献筛选，不单独创作 | 全体用户 |
| **Lovart 101** | 科普入门，超长扫盲文，后期可做 Pillar Page 聚合 | 小白、客户旅程早期 |
| **How-To** | 干货教程，兼顾阅读体验和 SEO | 需要更好使用 Lovart 的用户 |
| **Segment** | 细分行业/人群，含入门/进阶/案例/故事 | 细分人群 |
| **Best Practice** | 快速讲透某个产品使用技巧，篇幅短，口语化，SEO友好 | 卡在某个功能上的用户 |
| **Better Design** | 不一定与 Lovart 直接相关，辅助好设计的知识/案例/技巧 | 对设计知识有需求的用户 |
| **Insight & Trend** | 行业洞察、设计趋势，树立专家人设 | 全体用户 |
| **Lovart Digest** | 站内版 Newsletter，精选一周好文章 | 老用户 |

### 内链路由逻辑（Silo Structure）

```
首页 (Core)
  ├─ 产品页 (Core) → 产品集合页 → 功能详情
  ├─ 解决方案页 (Core) → 行业/场景 Cluster
  ├─ 定价页 (Core)
  ├─ 博客首页 → Topics 精选
  │   ├─ Pillar Page (101/合集) → Cluster Pages → Detail Pages (Blog)
  │   ├─ Segment 首页 → 行业/人群子页
  │   ├─ Insight & Trend
  │   └─ Lovart Digest
  ├─ Glossary → 术语详情
  ├─ Marketplace → 模板详情
  ├─ Community → 用户案例/模板/挑战
  ├─ Resource → 资源详情
  ├─ Wiki → 帮助文档
  └─ Event → 活动日历 → 活动详情
```

### 1.3 核心矛盾（数据信号）

- **品牌词95%+流量**：非品牌词覆盖率仅30.8%，必须转型「品牌+品类双轮驱动」
- **桌面端CTR暴跌**：从10.6%锐减至6.7%，AI Overview/竞品截流严重
- **Pillar Page完全缺失**：没有任何合集/101页面做内部路由，长尾内容无法形成合力
- **Best Practice几乎空白**：用户卡在功能时无快速解决方案
- **视频模型赛道爆发**：Seedance页面增长66-193%，video-generator增长166.8%
- **多语言两极分化**：俄语/日语CTR 10-20%，法语/葡语展示被浪费
- **用户从浅层流失→高价值留存**：回访用户占55.6%，互动时长+72.5%

### 维度一：内容营销专业度缺陷

#### 9.1 未按漏斗阶段（Funnel Stage）组织内容

v2 按「页面类型 × 时间」组织，但**没有映射到用户购买旅程**。内容营销的核心不是「写了什么」，而是「在用户决策的哪个节点出现」。

| 漏斗阶段 | 用户心理 | 对应博客分类 | v2 覆盖度 | 缺口 |
|----------|---------|------------|----------|------|
| **TOFU（认知）** | "我有个设计问题" | Better Design, Insight & Trend, Lovart 101 | ★★★★ | 可用 |
| **MOFU（考虑）** | "我在评估不同方案" | How-To, Segment, 对比系列 | ★★★★ | 可用 |
| **BOFU（决策）** | "我准备选一个工具" | Best Practice, Case Study, ROI 证明 | ★★ | **严重不足** |
| **Post-Purchase（留存/扩展）** | "我已经是用户，想用得更好" | Best Practice, Wiki, Digest, Community | ★ | **几乎空白** |

### 维度三：用户旅程（User Journey）缺陷

#### 9.7 没有区分「发现路径」和「激活路径」

v2 假设用户通过 Google 搜索进入博客 → 读完 → 注册。但实际用户旅程是**非线性的**：

```
用户实际旅程（非线性）：

发现 ←─── Google 搜索（SEO）
  │         ├── 品牌词（已有用户回访）
  │         ├── 非品牌词（新用户发现）← v2 重点优化的
  │         └── 长尾问题词（Better Design / How-To）
  │
  │  ←─── 社媒发现（Twitter/LinkedIn/TikTok/YouTube）
  │         ├── Thought Leader 文章被分享
  │         ├── 短视频教程被推荐
  │         └── 用户作品被转发
  │
  │  ←─── 口碑/推荐
  │         ├── ChatGPT/Perplexity 引荐（已有15%互动率）
  │         ├── civitai.com 社区推荐（17.1%互动率）
  │         └── huggingface.co 技术社区（24.2%互动率）
  │
  ▼
试用 ←─── 博客 CTA → 免费试用
  │         ├── Core Page（功能词落地页）→ Try Free
  │         ├── Best Practice → 解决具体问题 → Try This Feature
  │         └── 对比文章 → Lovart 优势 → Try Free
  │
  ▼
激活 ←─── 首次使用体验
  │         ├── Lovart 101（新手引导）
  │         ├── Best Practice（功能快速上手）
  │         └── Template Marketplace（直接用模板）
  │
  ▼
留存 ←─── 持续使用
  │         ├── Best Practice（进阶技巧）
  │         ├── How-To（新场景探索）
```

| 满意 → 推荐 | 用户案例征集 + 推荐激励 | 错过口碑增长 |
