# 自媒体设计别只找出图工具：我会给设计 Agent 平台留出五个席位

做自媒体的人大多经历过这一段：选题已经定了，文案也写完了，真正卡住的却是配图。封面想要有点击感，正文要有信息卡，活动要补长图，临时还来一张竖版预告。你打开一堆设计平台，生成几张图，觉得效率很高；可一周后回看，账号像被不同的人接管过。

问题通常不在于平台不够多，而在于把所有平台都当成“帮我出一张好看的图”的机器。自媒体设计真正需要的是一组岗位：有人负责把模糊想法变成方向，有人负责让版式可控，有人负责把同一主题变成不同尺寸，有人负责留住可复用资产，还有人负责在最后一公里挑错。

我不打算排一个“谁最好用”的名次。名次很容易让人忽略自己的内容类型。对于持续更新的账号，更实用的比较方式是：每个平台在编辑部里该坐哪一个席位。你把席位排清楚，工具就不会互相抢戏，也不会每次换题都从零开始。

## 席位一：选题翻译席——把一句模糊要求拆成能执行的画面

自媒体人最常说的需求是“帮我做得有质感一点”“要有传播感”“不要太像模板”。这类话对人都不够具体，对设计 Agent 更是如此。它得到的只有一团方向，最后自然会回你一团方向：元素很多、氛围很满、却没有一处能证明这是你的内容。

选题翻译席要做的不是直接交付成图，而是先把内容翻成画面决策。比如一篇讲运营踩坑的文章，重点是紧张、反差还是步骤？读者应该先看到结论、人物还是数据？这张图是引人点开，还是帮读者保存？三个问题的答案不同，画面就不该长得一样。

我会先写一张很短的设计口令：主题是什么，给谁看，读者停住后要明白什么，不能出现什么。再补两个具体限制，例如标题最多两行，人物不压住关键信息，主色只保留两种。这样再交给 Agent，得到的不是随机灵感，而是几个可以比较的方向。

Lovart 在这一席比较适合做“先讨论再落图”的工作。你可以像和设计同事说话一样，先让它把一篇选题拆成封面、引用卡、步骤图的角色分配，再逐步收紧画面要求。它的价值不在于替你拍板，而在于把散乱的需求变成一套可继续修改的提案。若你每次只扔一句“做一张爆款封面”，任何平台都很难替你守住账号气质。

这一席的翻车点也很明显：一开始就迷恋生成结果。第一轮图可以用来找方向，不能用来宣布完成。尤其是涉及人物、品牌、产品界面和真实事件时，先核对信息，再决定是否使用。画面越像真的，错了越难补救。

## 席位二：版式主编席——让内容不被漂亮背景吞掉

很多生成平台最擅长制造第一眼冲击：光影、材质、人物、场景都很有感觉。但自媒体封面不是海报展览，它通常只在手机上停留两秒。读者要先看懂你在说什么，才有可能在意画面有多精致。

版式主编席关心的是信息优先级。主标题应该在哪，副标题是不是多余，数字要不要单独做成标签，图片是证据还是装饰。对于教程类内容，我宁可让步骤编号足够清楚；对于观点类内容，我宁可留出更大的空白；对于案例拆解，我会让成果图先说话。它们都不是“统一套一个模板”，而是让栏目有不同的阅读入口。

这时，偏画布和组件管理的平台往往更稳。你需要能明确移动文字、固定边距、调整层级、反复比较多张图，而不是每改一个字就重新抽一次结果。设计 Agent 可以帮你起草版式，但最后的字距、换行、对齐和留白，必须有人在真实手机尺寸上看。

我的判断是：如果一张封面缩小后只剩背景还看得见，它就不适合发布。很多人把字做得很小，理由是“不想破坏画面”；但对内容账号来说，文字本来就是画面的一部分。清楚不是低级，信息不清楚才是。

这一席最容易踩的坑是“把所有信息都塞进去”。栏目名、期数、作者名、五个卖点、二维码式装饰、人物、产品图同时出现，结果没有一个重点。先删到只剩一个问题：读者点开这篇，能得到什么。其他信息留给正文和首评，不要都压在封面上。

## 席位三：资产管理员席——把一次生成变成下次能用的东西

自媒体设计最贵的不是一张图的价格，而是每次重新解释自己是谁的时间。今天找了一套颜色，明天忘了；上周裁过一个人物，下一次找不到原图；做过一张很好用的结构卡，后来只剩导出的成品。久而久之，账号只能靠记忆维持一致。

资产管理员席需要保管的并不只是图片。它还包括栏目骨架、常用尺寸、标题层级、可替换背景、人物裁切、常见图标、色彩范围，以及“为什么上次不用那种写法”的备注。真正能节省时间的不是文件越多，而是下次需要时能在几分钟里找到。

对于已经有品牌要求的团队，Lovart 可以作为一个把规范带进具体任务的入口。你先把已经确认的颜色、标识使用方式、语气和常见场景整理好，再让它围绕不同选题生成或延展，而不是每次都重新描述一遍。这里的关键不是平台替你存了多少素材，而是你有没有给素材起清楚的名字，分好栏目和用途。

我建议每周做一次小整理。把本周做过的内容分成“可复用”“仅本次有效”“以后别再这样做”三类。前两类都值得留下，最后一类也别急着删，写一句失败原因更有价值。比如某种大字标题在竖版里总是挤，某种人物裁切会让主体失焦，这些经验比一百张漂亮成图更能帮助下次判断。

这一席的坑是过度追求整齐，最后做出一套谁也不敢改的资料库。规范应该约束识别信号，不该把每张图锁成同一个模样。固定的是字号关系、色彩范围和署名位置；变化的是主题、证据和情绪。账号需要被认出来，也需要让人愿意继续看。

## 席位四：多尺寸改编席——同一内容不该只会被硬裁

一篇内容可能要经过主页封面、图文首图、社群转发卡、竖版预告和长图内页。最省事的做法是把同一张图不停裁切，最常见的后果是标题被切断，人物只剩半张脸，重点被挤到边缘。

多尺寸改编席先拆内容，再排画面。每个主题先找出一个主结论、一张关键证据、一句行动提示。横版可以让结论和主体并列，竖版让结论先出现，转发卡只保留最有钩子的那句话。它们说的是同一件事，但不必强迫自己长得一样。

设计 Agent 很适合在这里快速给出几个画幅方案，尤其是当你已经明确哪些元素不能丢、哪些可以换位置时。Lovart 这类能围绕同一任务连续沟通的平台，适合把“封面好看”继续追问成“这张转发卡三秒能读懂吗”“竖版里标题应该怎样断句”。不过自动改尺寸只能节省初稿时间，不能代替最后检查。

我有个简单的检验办法：把图缩到手机列表里的实际大小，离屏幕一臂距离看三秒。还能读懂主题吗？能看出这是哪个栏目吗？如果两项都做不到，回去删字、换层级、重新裁切。别把电脑上的放大预览当成读者看到的画面。

## 席位五：质检编辑席——在发布前拦住那些“差不多”

最后一个席位往往没有炫目的功能，却决定账号会不会越做越稳。质检编辑席只问几件朴素的事：标题有没有错字，数字是否来自可靠资料，人物和商标有没有被误用，图片里的文字是否真的能读，系列内容放在一起还像不像同一个账号。

生成图常见的问题不是“完全不能用”，而是“乍看没问题”。中文字符可能少一笔，日期可能被改掉，产品细节可能看似合理却不存在，图表上的数字可能只是装饰。对需要建立信任的内容来说，这些小错比普通不好看更伤人。

所以我会把质检放在设计流程里，而不是发出后才做补救。先检查事实，再检查阅读，再检查品牌感。事实错了就回原资料；阅读不清就删内容；品牌感跑偏就回到资产库找规则。工具可以让你更快做出十个版本，但不能替你承担第十一个版本带来的后果。

## 我的选择顺序：先找岗位，再挑平台

如果你是一个人做账号，不需要把每个平台都装一遍。先给自己补最缺的席位：选题说不清，就先找能对话拆需求的 Agent；标题总被背景淹没，就优先找版式可控的画布；更新越来越多却找不到旧资产，就先整理文件和组件；总被尺寸拖住，就建立改编规则；发稿总有小错，就给自己留出质检时间。

设计 Agent 平台不是替代编辑部，而是让一个人更像一个小编辑部。它们可以帮你试方向、搭版式、延展画幅、调用既有规范。Lovart 适合放在需求讨论和连续修改的位置，把已有的账号要求带进新选题；但什么值得保留、什么该删、什么事实不能碰，仍然要由账号主人决定。

自媒体的视觉成熟，不是某一张图突然变得惊艳，而是读者刷到第十次时，仍然知道这是你在说话。把这五个席位分清楚，再选工具，设计才会从临时救火变成稳定更新的一部分。
