# tool-grid / blog-grid · 工具卡与文章网格

> **section type**：`tool-grid / blog-grid`  
> **图片来源字段**：`tools[].media.src` / `posts[].cover.src`  
> **尺寸 / 比例**：1600 × 1000 · 16:10  
> **每实例图片数**：6  
> **站内覆盖页面**：约 226 个文档

## 模块形态

tool-grid：3 列网格，每卡 icon + 名称 + 分类 + 描述 + tag + 评分；blog-grid：3 列卡片，封面图 + 标题 + 摘要 + 日期。

**用途**：tool-grid 用于「工具矩阵入口」；blog-grid 用于「内容聚合」。

## 本模块专属纪律

1. tool-grid 图是「该工具产出的样张」，必须有辨识度（一眼能看出是 logo / 海报 / 包装）
2. blog-grid 图是「文章配图」，可更泛化（场景/氛围），不要求具体品类
3. 两者都是小卡，主体须占 70% 以上，缩略后仍可辨

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
