- **wp-admin**: 需要用户提供的凭据

## 筛选方法

1. 用 browser_console 从 sitemap 提取全部 URL
2. 按关键词筛选：ai, open-source, tool, free, github, video, image, audio, design, mac, windows, browser, plugin, extension, automation, workflow, code, editor, developer, saas, product, seo, content, translate, subtitle, screen, recorder, pdf, ocr, database, backup, sync, email, music, tts, speech, font, drawing, rss, bookmark, clipboard, file, converter, search, note, knowledge, ebook, reader, player, 3d, render, animation, logo, poster, template, ui
3. 排除：slg, rpg, game, adult, career, sales-theory 等非工具类
4. 与现有 Tags 交叉对比，找出全新素材
