# Medium

| 项 | 值 |
|----|-----|
| 自动化 | **爱贝壳**（主轨）— 扩展同步草稿箱 |
| 轨道 | A 摘要为主；B 原生可选 |
| canonical | **必须** `canonicalUrl` → lovart.ai |
| API | ❌ 新账号已无 Integration Token |

## 内容规格

- 标题：不同于主站，偏叙事/观点
- 长度：600–1200 词（摘要）
- Tags：3–5 个站外长尾词（非主站核心词）
- 首图：换图或裁剪，勿用主站同图 alt 文案

## 适配要点

1. 开篇 2 段全新
2. 列表化 3–5 要点
3. 文末 CTA + UTM
4. 不设全文 import from URL

## 发布（爱贝壳）

1. Arc/Chrome 登录 medium.com
2. 爱贝壳扩展侧栏 → 粘贴 `drafts/medium-{slug}.md`
3. 勾选 Medium → 同步到草稿箱
4. Medium 后台确认发布
5. Story settings → Advanced → **Canonical URL** = `lovart.ai` 原文

`dispatch-publish.js` 会在爱贝壳轨打印上述步骤。

## 防抢权重

- 必须 canonical
- 禁止 RSS 全文同步主站 blog
