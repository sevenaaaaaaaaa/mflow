# Hero 封面单张 Brief（93 张 · Lovart 批量生成版）

> 用法：每张 brief 复制「Prompt」一行到 Lovart 生成；尺寸按标注设置；生成后按 README §4 验收。
> 全局禁用项（如 Lovart 支持负面词则附加）：`text, letters, words, watermark, signature, logo text, gibberish UI labels, distorted faces, extra fingers, low resolution, jpeg artifacts, clutter, frame border, oversaturated colors`
> 所有 Prompt 已内置统一风格后缀与 no-text 约束，可整行直接投喂。
