## 一、核心洞察

> 赶时间：**只读下方 1–3 段结论**；（一）（二）为展开；OKR 与大盘表见 **§二 / §三**。

1. **全链路表现**：流量收缩（+0.0%），转化走弱（注册 **+16.4pp**），GEO 值得关注；GEO DAU **0%**，须分开看 SEO/GEO 转化（见 **§六**）。

2. **关键词层面**：收录数暴增（有曝光 URL **2,787→4,715**，收录率 **13.94%→23.57%**），但点击仍依赖品牌词（**98.5%**（-0.9pp））；增长突破口在非品牌曝光 **↑+43,288 / +4.1%**，以及 **10** 个竞品核心非品牌词（ai ad generator、ai commercial、brand video、character consistency、dall-e…）与内容池 **50** 个 Blog、**26** 个 Features、**26** 个 Tools。详见 **§四 / §七 / §八 / §九**。

3. **执行层面**：**建 landing**（非品牌词页）｜**首页导流**（首页改造）｜**优化目录**（Footer）｜**扩收录**（404 页面）｜**保付费**（SEO+GEO 高付费意向词）｜**提注册**（Tools 页面改造）｜**补流量**（新增 Tools 页）；双引擎分工见 **§4.16 / §9.5 / §11.10**。


### （一）自然搜索整体表现

1. **规模全面收缩** —— 访问/新增注册/新增付费三项齐跌，增长引擎降速；访问 UV ↑+1,237,667 / +0.0%、新增付费 ↑+2,440 / +0.0%（详见 **§三 卡 B**、**§二 OKR**）。
2. **转化效率走弱** —— 注册转化与付费率双降，漏斗在漏水；注册转化率 0.0%→16.43%（+16.4pp）、新增注册→付费 0%→1.2%。
3. **渠道结构** —— SEO 是绝对主力（**Google、Microsoft、百度** 为 SEO 前三入口）；**Google 与 Microsoft** 同时承载搜索与部分 AI 发现流量，**GEO**（豆包/ChatGPT 等）DAU 虽小但付费转化更高。SEO 占 DAU **0%**、GEO **0%**（**§三 卡 A**）；入口对照 Google 点击 ↓-1,922,791 / -58.8%、Bing 站点 →+0 / +0.0%（**§三 C/C-Bing**）。

### （二）收录、关键词排名与页面表现

1. **收录绝对值和收录率都大幅提升** —— **23.57%** 有曝光（+9.6pp）、缺口 **15,285** URL；不扩收录则长尾/非品牌词无从放量（**§三 卡 F**）。
2. **点击高度依赖头部品牌词** —— 集中度 **98.5%**（-0.9pp），抗风险弱；非品牌曝光 **↑+43,288 / +4.1%** 是积极信号。最大缺口 **10** 个竞品核心词零排名；解法→修跌幅词（**§4.7**）+ 补非品牌高曝光低 CTR 标题（**§4.5**）+ 双引擎 landing（**§4.16**）。
3. **流量过度集中首页、内页 discovery 弱** —— 首页占 GSC 点击 **90.5%**；tools/features/blog 合计 **95,334**（↓-49,920 / -34.4%）。解法→首页 hub 内链 + tools/features 目录 SEO（**§九**）；Bing 首页系 **99.4%**（**§9.4–9.6**）。

- **表现最好**：大中华（↑+17,883 / +34.1%, 品牌占比99.0%）；日本（↑+8,226 / +28.4%, 品牌占比97.7%）；南亚（↑+18,024 / +6.7%, 品牌占比99.5%）
- **基本持平**：无显著变化
- **表现最差**：中东非洲（↓-571,901 / -74.9%, 品牌占比99.8%）；拉美（↓-996,612 / -73.3%, 品牌占比99.9%）；其他（↓-340,886 / -54.9%, 品牌占比99.4%）

> 💡 **大区策略** — 优先在「表现最差」大区复制「表现最好」区的非品牌词 landing 模板；GA4 与 GSC 缺口大的区（如大中华）单独排查渠道与品牌词污染。
