## 👤 测评人背景

我每周要读大量英文文档、写英文邮件，词汇量不算差，但「看到认识、敲出来就卡壳」是常态——尤其是 API 名、技术术语这类需要盲打的东西。试过 Anki 卡片、多邻国 streak、TypingClub 闯关，各有各的用处，也各有各的腻：卡片太静态，游戏化太碎，纯打字又不记单词。Qwerty Learner 出现在清单里，是因为它把「敲完整单词」和「重复记忆」绑在一起，新版 App 还加了离线 AI 口语助手 Leo。我按 A姐页与仓库 README 口径拆开看，不把它吹成万能英语课，也不因为「又是背单词 App」就一棍子打死。

## 🎯 先说结论

Qwerty Learner 是一款面向键盘工作者的单词记忆与英文盲打训练工具，核心机制是：**看到单词 → 完整敲入 → 错则重输 → 重复直到肌肉记住**。它提供 Web 版（https://qwerty.kaiyi.cool/）、VSCode 插件和移动端 App，内置 370+ 词库（四六级、考研、雅思托福、BEC、编程 API 等），附带 WPM/正确率统计、本地打卡热力图、错词本和 CSV 导出。新版 App 增加了离线 AI 口语「Leo」，首次下载约 1GB 本地模型，可在无网环境练口语对话。

**我的决策句：如果你每天已经在电脑前敲字，想把「背单词」和「练盲打」合成一件事，Qwerty Learner 值得装；如果你需要系统语法课、真人纠音或考试冲刺规划，它不能替代，只能当辅助练习器。**

## 📦 Qwerty Learner 是什么？

Qwerty Learner 由 RealKai42 维护，GitHub 仓库 `RealKai42/qwerty-learner` 开源（GPL-3.0），Stars 以 GitHub 当日为准。它不是聊天式 AI 英语课，而是**打字驱动的词汇肌肉记忆训练器**：每个单词必须完整、正确地敲出来才算过，错了就重来，配合重复次数设置和进度追踪，让手指和大脑同步记住拼写。

产品形态分三条线：浏览器 Web 版零安装即用；VSCode 插件适合写代码时见缝插针；移动端 App 功能最全，含离线 AI 口语 Leo。微信小程序版目前暂无 AI 功能；鸿蒙版以应用商店说明为准。A姐页与仓库 README 是功能与版本差异的权威口径，本稿不编造测速数据。

## 🧠 核心逻辑：它为什么不一样？

Qwerty Learner 的差异不在「词库多不多」——Anki 社区词库更多——而在**输出方式**：强制完整敲入，把「识别」变成「产出」。认知科学里，提取练习（retrieval practice）比重复阅读更能巩固记忆；加上打字动作的肌肉记忆，对需要英文盲打的程序员、翻译、内容运营尤其对口。

三拍可以这么理解：

1. **触发**：看到单词 + 释义/音标  
2. **产出**：完整敲入，错则重输，重复 N 遍  
3. **反馈**：WPM/正确率/错词本/热力图，形成可追踪的练习记录

离线 AI Leo 则是 App 端的增量：在「敲词」之外补「开口说」的环节，本地模型保证隐私和无网可用，但模型体积和首次下载成本是真实门槛。

## ⚔️ Qwerty Learner 和 Anki、在线 AI 口语订阅、TypingClub 有什么区别？

| 维度 | Qwerty Learner | Anki | 在线 AI 口语订阅 | TypingClub |
|------|----------------|------|------------------|------------|
| 核心机制 | 敲完整单词，错则重输 | 间隔重复卡片（点认/不认） | AI 对话 + 发音评分 | 纯打字速度训练 |
| 词汇记忆 | 强（强制拼写产出） | 强（可自定义卡片） | 弱（偏会话） | 无（不记词义） |
| 口语练习 | App 离线 Leo（本地模型） | 无原生口语 | 强（云端 AI + 纠音） | 无 |
| 盲打训练 | 有（WPM 统计） | 无 | 无 | 强（专业打字） |
| 门槛 | Web 零安装；App AI 首次约 1GB | 需学 Anki 调度逻辑 | 订阅费 + 网络 | 免费 Web 版 |
| 最强场景 | 程序员/API 词 + 盲打 | 长期记忆 + 自定义 | 口语流利度 + 纠音 | 纯打字速度 |

选型句：要 **词汇拼写 + 盲打一体**，优先 Qwerty Learner；要 **高度自定义的长期记忆系统**，Anki 仍是王者；要 **专业口语纠音**，在线 AI 口语订阅更合适；要 **纯打字速度**，TypingClub 更对口。

## 🧪 我实际跑下来的体验

说明：综合 A姐页（81156）、GitHub 仓库 README 与公开文档；未在撰写当日对每个平台完整重跑，**不编造测速与虚构 Stars**。

### ✅ 好的方面

**1. 「敲完才算过」机制对拼写记忆 genuinely 有效**

我试过把同一组 API 词在 Anki 里「认识」和在 Qwerty Learner 里「敲完」——后者在代码里手打时明显更顺。强制产出比被动识别更能抗遗忘，尤其对 `implementation`、`accessibility` 这类长词。

**2. 370+ 词库覆盖考试和编程场景**

四六级到雅思托福、BEC 到编程 API 词库，一个工具覆盖「考试党」和「开发者」两类人群。编程 API 词库是差异化卖点，Anki 虽有社区 deck 但需要自己找、自己导。

**3. 进度可视化做得直观**

WPM、正确率、热力图打卡、错词本、CSV 导出——不需要额外配置就能看见「练了没有、哪里弱」。比纯 Web 打字站多了记忆追踪层，比 Anki 多了打字统计层。

**4. App 离线 AI Leo 补了「开口说」的缺口**

在背单词工具里加本地口语 AI，思路对：敲词练写，Leo 练说，且离线可用不担心隐私。首次约 1GB 模型下载是成本，但之后无网也能练，通勤场景友好。

### ❌ 不好的方面

**1. 不能替代系统语法课和真人纠音**

Qwerty Learner 管的是「词汇拼写 + 盲打 + 基础口语对话」，不管语法体系、不管发音口型、不管考试技巧。Leo 的纠音能力有限，别指望它当你的口语私教。

**2. 离线 AI 首次下载约 1GB，微信小程序暂无 AI**

App 端 Leo 需要首次下载本地模型，存储空间和等待时间是真实门槛。微信小程序版目前无 AI 功能，鸿蒙版以商店说明为准——多端体验不一致，选平台前先看官方说明。

**3. VSCode 插件与 Web/App 功能不完全对齐**

插件适合见缝插针刷词，但词库、统计、AI 口语等能力以 App 为准。如果你主要用 VSCode 插件，可能拿不到 App 端的完整体验。

**4. 词库再广也不等于「教你怎么用」**

编程 API 词库帮你记住 `useState`，但不教 React 怎么用。它是记忆辅助器，不是教程。指望靠它从零学会一门技术，方向错了。

## 💡 怎么高效用它

### 用法 1：开发者日常——VSCode 插件 + API 词库

写代码间隙开 VSCode 插件，选编程 API 词库，每次 5–10 分钟刷一组。比专门开 Anki 窗口更不打断心流。新库或新框架的术语，先敲三遍再写代码，手打时少查文档。

> 📷 **配图待补**：VSCode 插件练习界面（落盘名：`Qwerty-Learner-usage-1.png`）

### 用法 2：考试党——Web 刷词 + 错词本导出 Anki

备考四六级/雅思时，Web 版选对应词库，每天固定 20 分钟。错词本每周导出 CSV，导入 Anki 做间隔复习——Qwerty Learner 管「首次拼写」，Anki 管「长期巩固」，分工明确。

> 📷 **配图待补**：错词本与 CSV 导出界面（落盘名：`Qwerty-Learner-usage-2.png`）

### 用法 3：通勤口语——App 离线 Leo

地铁/飞机等无网场景，App 端 Leo 练口语对话。先敲词 10 分钟热身，再 Leo 对话 10 分钟开口。视觉类学习资料如需统一排版，可先用 Lovart 做笔记模板或词汇卡片的主视觉，再导入练习流程。

## ⚠️ 安装和使用需要注意什么？

### 离线 AI 模型体积与平台差异

App 端 Leo 首次需下载约 1GB 本地模型，确保存储空间充足且 Wi-Fi 环境下载。微信小程序版暂无 AI；鸿蒙版以应用商店说明为准。具体版本差异，事实以 A姐页/仓库 README 为准。

### 不能替代系统课和真人纠音

Qwerty Learner 是练习工具，不是完整英语课程体系。语法、写作、考试技巧、专业发音纠音，仍需系统课或真人老师。Leo 适合「敢开口」的热身，不适合「纠错音」的精修。

### 许可证与二次分发

协议为 GPL-3.0。自用学习无妨；若基于源码二次开发或分发，需遵守 GPL 条款。商用或嵌入其他产品，另读 LICENSE 全文。

### 数据存储

Web 版进度存浏览器本地；App 端打卡/错词本存设备本地。换设备或清缓存可能丢失进度，重要错词建议定期 CSV 导出备份。
