# feature-detail · 图文左右交错

> **section type**：`feature-detail`  
> **图片来源字段**：`items[].media.src`  
> **尺寸 / 比例**：1600 × 1200 · 4:3  
> **每实例图片数**：4  
> **站内覆盖页面**：约 7303 个文档

## 模块形态

N 个图文块左右交错：第 0 条图在右，`reverse: true` 让图在左。站内覆盖面最大的模块。

**用途**：用于「逐条展开能力」，每条一个图 + 标题 + 描述 + bullets + CTA。

## 本模块专属纪律

1. **构图必须为文字留位**：图在右时主体偏左，图在左时主体偏右（交错排版的呼吸感）
2. 同页 4 条要形成节奏：机位高度、主体大小交替变化，不能 4 张一模一样
3. 每条配 3 个 bullet，图片需能承载「具体可指认」的对象（可被 bullet 描述）

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
