Getting Started
Design Your First Project
Try a Quickstart Project
Run a ready-made preset and see Lovart in action without writing a prompt.
The fastest way to see what Lovart can do is to run one of the ready-made quickstart projects on your homepage. Click one, hit generate, and watch a finished asset land on the Canvas. No prompt writing required.
Go to Lovart homepage.
The quickstart projects sit right under the input box, grouped by category (Design, Branding, E-Commerce, Video, and more).
Pick a project.
Lovart loads the preset with prompt, model, and reference files.
Click Generate.
Lovart will automatically open a new project and run the prompt.
Collect the product.
Wait for the product to appear on the Canvas. From there, download your asset or keep chatting with the Agent to iterate.
Quickstart projects need available credits to run. Top up or switch the model if a run fails.
Generate Your First Image
Prompt our Agent to create on-brand assets for you on the infinite canvas.
Open a new project.
From the Lovart homepage, click New Project to open a blank Canvas.
Type your prompt in the input box.
Describe what you want in plain language. Here is an example:
a fluffy orange tabby cat wearing a tiny business suit, sitting at a desk in front of a laptop, looking extremely concerned, office lighting, shallow depth of field, shot on iPhone
Send the prompt.
Press enter or click send. Lovart processes your intent and starts generating.
Review the result on the Canvas.
Edit Your First Image
Use Lovart&#x27;s editing tools to refine the image you just generated.
Select the original image.
Click the image you just generated on the Canvas.
Ask the Agent to edit using natural language.
The selected image appears in the input box. Click inside the input box to confirm.
Then type what you&#x27;d like to edit. For example, you can ask the Agent to
swap the background to pure white
change the cat into a dog
The Agent returns a new image with the edits applied.
Use our one-click editing presets.
Select an image on the Canvas to reveal the editing tools in the top bar.
Click Upscale to boost resolution. No prompt needed.

Make a precise tweak.
Click Mark in the Canvas toolbar, press M, or hold Cmd/Ctrl and click the spot you want to change.
The marked region appears in the input box. Click inside the input box to confirm.
Then type what you&#x27;d like to edit.
The Agent returns a new image with the edits applied.

Transform the content.
Change object angles: Select an image on the Canvas, then click Multi-Angles in the top bar to open the control panel.
Drag the Subject or Camera controls, then click Run to generate an image of the same object from a new angle.

Turn Your Image Into a Video
Animate your still image into a short video.
Select the original image.
Click the image you just generated on the Canvas.
Ask the Agent to animate it.
The selected image appears in the input box. Click inside the input box to confirm.
Add any video description you want. For example, you can ask the Agent to
turn this image into a 5-second video.
The Agent will animate the image with sound.
Play it with sound on!
Export and Publish
Download your finished work or share it with the Lovart community.
Export a single asset.
Click any item on the Canvas, then click the export button.
Export multiple assets at once.
Drag to select multiple items on the Canvas, then click the export button. PSD is supported for batch export.
Publish to the community feed.
Click the publish button on the Canvas to post your work to the Lovart community feed.
