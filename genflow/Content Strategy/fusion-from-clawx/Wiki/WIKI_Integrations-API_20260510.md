Integrations & API

**OpenClaw Integration:** Lovart provides OpenClaw-based integration for team communication platforms. Users can generate designs directly from Slack, Discord, Feishu, and other supported platforms without switching contexts.

**API access:** Custom API integration is available for enterprise plans. Generate designs programmatically, automate batch production, integrate into existing workflows.

**Supported platforms:**
- Slack: Generate designs directly from Slack channels
- Discord: AI design commands in your server
- Feishu/Lark: Integration for Chinese market teams
- Custom: API-based integration for any platform

See the [OpenClaw documentation](https://applink.feishu.cn/client/thread/open) for setup instructions and API reference.
