# 最佳实践：最大化生产力的 ChatCanvas 布局策略

[图片 1 占位符 — 用户场景]

大多数设计工具都给你一个固定的画板——一个矩形、一个画布、一次一个想法。ChatCanvas 则恰恰相反：一个无限的工作区，每一次生成、每一个变体、每一份参考资料都并排放置，可以向任何方向滚动，永无止境。这很解放。但如果你没有一个系统，它也容易变成一个数字杂物抽屉。

本指南就是关于这个系统的。三种布局策略、一些拖放模式，以及那些能区分“我在探索想法”和“我什么都找不到”的键盘快捷键。

## ChatCanvas 到底是什么

[图片 2 占位符 — 概念图]

在我们进入战术层面之前，先来统一认识。ChatCanvas 是 Lovart 的无限空间画布——可以把它想象成 Figma 的画布加上聊天界面，但专为 AI 生成的设计而构建。你用 Nano Banana 生成的每一张图像都会作为可移动、可调整大小、具有图层意识的对象落在画布上。你可以直接拖拽它们、分组、固定参考图像，并在不离开工作区的情况下重新混合元素。

与传统工具的关键区别：你的画布是*持久化*的。关闭浏览器，第二天回来，一切都在你离开时的位置。这种持久性使得布局策略变得有价值——你投入在整理画布上的时间会在多个会话中累积。

## 策略 1：水平布局用于 A/B 对比

**最适合：** 在变体之间做选择、客户演示、调色板探索。

将你的生成物按从左到右的顺序排列在单行水平线上。每个变体位于相同的垂直位置、相同的缩放级别、相同的视觉权重。没有哪个生成物“高于”或“低于”另一个——它们是平等的，并排排列以便于对比判断。

为什么这样做有效：当图像在同一水平线上对齐时，人眼更容易检测到差异。垂直比较会引入一种微妙的“顶部更重要”的偏见，而水平布局可以避免这一点。

**如何在 ChatCanvas 中设置：**
1. 生成同一提示词的 3-5 个变体。
2. 将最佳候选拖到最左边作为你的“锚点”。
3. 将剩余的变体以等间距对齐到右侧。
4. 缩放以同时将所有变体显示在屏幕上。
5. 将最弱的选项拖到画布底部的丢弃区（或直接删除）来淘汰它。

最终，你应该在水平行中拥有 2-3 个强有力的候选，准备好分享或做决定。

## 策略 2：垂直布局用于线性工作流

**最适合：** 迭代优化、逐步推进、设计冲刺。

将你的生成物从上到下垂直堆叠。最顶部的图像是你的起点——原始的第一次生成、参考图像或之前的版本。下面的每一张图像代表一次迭代：“相同设计，但标题更大”、“相同设计，但深色模式版本”、“相同设计，但用产品图 B 代替 A”。

这会创建一个即时的视觉变更日志。任何查看你画布的人都可以在几秒钟内从上到下追踪设计的演变过程。

**如何在 ChatCanvas 中设置：**
1. 将你的起始图像放在工作区的顶部。
2. 每次重新生成或使用 Touch Edit 操作后，将新版本直接拖到前一个版本的下方。
3. 使用**固定**功能（右键单击 → 固定到画布）将你喜欢的版本锁定到位，这样它们在滚动时就不会移动。
4. 当垂直堆栈变高时，使用 **Cmd/Ctrl + 滚动** 缩小以查看完整的进展。

## 策略 3：分区布局用于多资产项目

[图片 3 占位符 — 真实 UI 截图]

**最适合：** 品牌活动、多格式交付物、团队协作。

将你的画布划分为命名的区域——每个区域对应活动中的一个资产。例如：左上角区域用于 Instagram 故事，右上角区域用于邮件标题，左下角区域用于着陆页主图，右下角区域用于参考资料和情绪板。

每个区域独立运作，但在视觉上共存。你可以一眼看到整个活动，并立即发现不一致之处：“邮件标题感觉比 Instagram 帖子更暖——让我调整一下。”

**如何在 ChatCanvas 中设置：**
1. 缩小以查看大面积区域（使用 `Cmd/Ctrl + -` 或在触控板上捏合缩放）。
2. 将你的第一个资产类型放在其指定区域。
3. 使用空白文本框或便签风格元素（通过直接在画布上输入来创建）来标记每个部分：“IG 帖子”、“邮件标题”、“主图”。
4. 当你生成新资产时，将它们拖到相应的部分。

专业提示：如果你正在处理一个每周或每月重复的活动，将此布局保存为模板。一次性生成基础内容，复制画布（`文件 → 复制画布`），然后在每个周期中替换新内容。

## 拖放式重新混合：被低估的超能力

ChatCanvas 不仅仅是一个展示表面——它还是一个编辑表面。以下是大多数用户忽略的三种拖放操作：

**从一个生成物中拾取元素并放到另一个生成物上。** 看到变体 A 中你喜欢的背景纹理，但更喜欢变体 B 中的标题布局？按住 `Shift`，点击这两个元素，将它们拖到一个新的画布区域，让 Lovart 将它们合并成一个新的生成物，结合两者的优点。

**直接将参考图像拖到画布上。** 无需上传对话框，无需文件选择器。从你的桌面、浏览器或 Finder 窗口中抓取一张图像，然后放到 ChatCanvas 上。它会成为一个固定的参考，Nano Banana 会在后续生成中考虑它。

**通过自由放置创建情绪板。** 将十几张灵感图像倾倒到画布上，按颜色、风格或概念将它们分组排列，然后指向你想要模仿的集群。模型会读取视觉模式，并将其应用到你的下一次生成中。

## 值得记住的键盘快捷键

你不需要全部学会。从前三个开始，然后随着习惯的形成再添加其余的。

| 快捷键 | 功能 |
|----------|------|
| **空格 + 拖拽** | 平移画布（保证是你最常用的快捷键） |
| **Cmd/Ctrl + 滚动** | 放大/缩小 |
| **Cmd/Ctrl + 0** | 适应屏幕显示所有内容 |
| **Cmd/Ctrl + G** | 组合选中的元素 |
| **Shift + 拖拽** | 将移动限制在水平或垂直轴 |
| **Delete** | 删除选中的元素 |
| **Cmd/Ctrl + Z** | 撤销上一个操作 |

## 今天就开始的一个布局习惯

如果你从本指南中只学到一件事，那就是：**在进一步迭代之前，始终固定你最好的生成物。** 右键单击你最喜欢的变体，然后点击“固定到画布”。这一个操作就能防止最常见的 ChatCanvas 挫败感——在一堆实验中意外丢失那个好的版本。

无限画布既是一个设计工具，也是一个思考工具。以整理实体办公桌时同样的用心来对待它，它就会以清晰、速度和更少的“等等，那个版本去哪儿了？”的时刻来回报你。
