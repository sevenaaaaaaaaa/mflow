# canvas-wall · 10 卡画布墙

> **section type**：`canvas-wall`  
> **图片来源字段**：`items[].media.src`  
> **尺寸 / 比例**：1600 × 1000（大卡）/ 1000 × 1000（小卡） · 16:10 (大卡) / 1:1 (9 小卡)  
> **每实例图片数**：10  
> **站内覆盖页面**：约 1374 个文档

## 模块形态

左上 1 大卡 + 右上 5 小卡 + 底排 4 卡，每卡可显示作者 / likes / caption。

**用途**：用于「作品集展示」与「创作多样性」证明。

## 本模块专属纪律

1. **10 张必须是 10 个不同品类**（海报/包装/名片/画册…），这是「能力广度」的唯一证明
2. 统一背景色与光向，视觉上像「同一面展示墙」
3. 每卡右下角有 caption 遮罩，主体避开右下 25%

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
