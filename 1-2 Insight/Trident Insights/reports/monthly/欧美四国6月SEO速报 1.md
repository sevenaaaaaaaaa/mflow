# Lovart 欧美四国 6月 SEO 速报

**范围**：美国 / 英国 / 澳大利亚 / 加拿大
**窗口**：2026.5.1-5.31 vs 6.1-6.30（全月）· 环比日均值（May 31天 / Jun 30天）
**数据源**：GSC API + Bing Webmaster API（7.2 实时拉取，6月全量）
**品牌词分类**：`lovart_brand_match.is_brand()` 五层规则

## 重点1：四国整体流量 — 曝光、点击、CTR

| Bing CTR | 35.65% | 30.48% | -5.2pp |
| **合计点击** | **650,435** | **526,533** | **20,982→17,551/日 -16.4%** |

GSC 和 Bing 双降，GSC 曝光跌幅更大（-15.8%）。Bing 曝光微增（+4.7%）但 CTR 大跌 5.2pp。
