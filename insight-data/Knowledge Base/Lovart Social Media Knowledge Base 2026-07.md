# Lovart 社交媒体知识库

本文件是 Lovart 官方社交媒体的第一版整理稿，目标不是做一次性截图式汇总，而是建立一个以后可以继续增补的基础盘。[lovart-social-001]  
整理范围覆盖官方 X、YouTube、LinkedIn、Instagram、TikTok 五个渠道，并尽量把每个平台的账号画像、代表内容、内容类型、对外叙事和可操作洞察拆开保存。[lovart-social-007]

## 一、这份整理的使用边界

本次以公开可抓取页面为主，辅以仓库里已有的 `Lovart ORM/raw` 监测骨架和外部镜像源交叉验证。

- 高可信源：`fxtwitter` 的 X 账号 API、YouTube 视频页与频道抓取、LinkedIn 公司页公开摘要。
- 中可信源：DuckDuckGo 对 Instagram / TikTok / YouTube / LinkedIn 的索引摘要。
- 辅助源：X-Sou 对 X 时间线的镜像，可用于补帖文样本，但 follower 数与官方 API 有口径差。

因此，这份 KB 里有两种信息：

- 可以当成相对稳定事实的账号级信息，比如 follower 量级、账号定位、更新主题。
- 只能作为样本与趋势参考的信息，比如某条帖子的点赞量、某个平台的某个摘要快照。

## 四、跨平台内容分类

把 5 个渠道放在一起看，Lovart 的内容已经形成相对稳定的 6 个大类：

### 1. Feature Drop

最常见。  
例如：Move Object、Vectorize、Voice Mode、Slides、Multi-Angles、GPT Image 2、Seedance 2.0、Kling 3.0。

承载渠道：

- X
- LinkedIn
- TikTok
- Instagram
- YouTube Shorts / 短 demo

### 2. Workflow Tutorial

把单个能力放进完整任务流里，例如做品牌、做广告 campaign、做 YouTube thumbnail。

承载渠道：

- YouTube 为主
- LinkedIn 次之

### 3. Visual Showcase

强调最终效果图、视觉冲击和“这看起来就很贵”的结果。

承载渠道：

- Instagram
- TikTok
- YouTube 某些 showcase 视频

### 4. Promo / Offer

折扣、升级、成员权益、限时福利。

承载渠道：

- Instagram
- LinkedIn
- TikTok

### 5. Community / Participation

例如评论送 prompt、follow + repost 抽奖、tag us 展示作品。

承载渠道：

- Instagram
- X
- YouTube 描述区 CTA

### 6. Positioning Narrative

一句话把 Lovart 定义为 `The design agent`，并不断把单功能外推到“从想法到交付的完整工作流”。

承载渠道：

- 全平台一致

## 五、有效的对外发声洞察

### 洞察 1：Lovart 的外宣核心不是“AI 能做图”，而是“AI 能接管设计工作流”

这点在所有平台都高度一致。[lovart-social-007]

不是简单说：

- 生成更快
- 画得更好

而是持续说：

- 从 brief 到 deliver
- 从 one prompt 到 full campaign
- 从 brand idea 到 brand system
- 从 image 到 video 到 multi-format rollout

这意味着 Lovart 的真正品牌资产不是某一个模型，而是“工作流整合能力”。

### 洞察 2：最强内容并不是抽象定位，而是可以直接看到差异的 demo

YouTube 播放更高的内容，多数是 Seedance、GPT Image 2、Pencil、Move Object 这类强结果差异的功能样片。  
Instagram 与 TikTok 也明显偏向 before/after 与强视觉结果。

因此，Lovart 最有效的发声素材不是空泛理念，而是：

- 一条 15-60 秒的结果演示
- 一个完整 brand build 的过程
- 一个单能力把旧工作流替换掉的瞬间

### 洞察 3：YouTube 是教育主阵地，Instagram/TikTok 是结果传播主阵地，LinkedIn 是商业买家主阵地

如果把矩阵角色拆开：

- YouTube：讲明白
- Instagram：让人想试
- TikTok：让人立刻停住
- LinkedIn：让团队和营销负责人看到 ROI
- X：做轻量新品公告

这说明 Lovart 的矩阵已经有雏形，但还没有被显式文档化。

### 洞察 4：Lovart 对外发声高度“产品驱动”，但相对缺少人物与客户故事沉淀

目前能看到的主内容几乎都围绕产品能力本身。  
优点是统一、清楚、容易复用。  
缺点是品牌记忆点更偏工具，不够偏人物、客户、行业案例。

缺口包括：

- 创始人 / 设计负责人视角
- 客户案例复盘
- 真实团队 workflow 改造前后
- 用户分层故事，比如 agency、电商、creator、SMB

如果后续要把社媒变成“品牌资产”，这会是最值得补的一块。

### 洞察 5：账号命名与跨平台口径存在轻度不一致，可能稀释品牌识别

目前可见的不一致包括：[lovart-social-008]

- Instagram 主账号是 `@lovart.ai`
- 其他大多数主账号是 `@lovart_ai`
- YouTube 描述里曾出现指向 `@lovart_ai` 的 Instagram 写法
- TikTok 监测说明里也出现 `@lovart.ai` 与 `@lovart_ai` 双口径

这件事短期看不严重，但长期会影响：

- 搜索一致性
- 用户跨平台迁移
- 社媒知识库自动采集规则
- 品牌资产统一

- 把 handle 不一致问题做成单独的品牌治理检查项。

## 八、当前结论

截至 2026-07-05，Lovart 的社媒矩阵已经具备三个清晰特点：

- 已经不是“有没有发声”的问题，而是“发声很产品化，但还没被系统整理”。
- 最强的公开资产是视频和可视化 demo，不是长文和观点。
- 真正的品牌母题已经出现，而且非常稳定：`The design agent` 与 `从想法到交付的一体化创作工作流`。[lovart-social-007]

这意味着 Lovart 现在最缺的不是素材，而是把现有素材编目、分类、复用、提炼成长期内容资产的机制。
