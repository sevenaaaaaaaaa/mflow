## 二、地区报告生成方法

### 2.1 地区报告类型

| 报告类型 | 数据源 | 主要内容 |
|----------|--------|----------|
| **GSC 地区报告** | Google Search Console | 关键词排名、点击、曝光、CTR |
| **GA4 地区报告** | Google Analytics 4 | 用户行为、会话、转化 |
| **品牌/非品牌报告** | GSC + 竞品词库 | 品牌词和非品牌词表现 |
| **地区 mini 月报** | 综合 | 完整的地区月度报告 |

### 2.2 地区报告生成命令

```bash
# 生成日本地区月报
python3 "1-4 Dev/scripts/seo_monthly_v2.py" --month 2026-05 --region japan

# 生成日本地区周报
python3 "1-4 Dev/scripts/weekly_review_v3.py" --region japan

# 生成日本地区日报
python3 "1-4 Dev/scripts/sentinel/collect.py" --source gsc --region japan
```

### 2.3 地区报告结构

**月报 §11.2–11.8 分区月报（双月）：**

| 表 | 双月列 | 环比列 |
|----|--------|--------|
| GSC 汇总 | 点击、曝光、CTR、点击占比、曝光占比 | 五项均有 |
| 品牌/非品牌 | 点击、曝光、CTR（双月） | 点击、曝光环比 |
| Top15 词 | {上月}/{报告月} 点击+曝光 | 点击环比 |
| Top10 页面 | 双月点击 | 点击环比 |

## 四、竞品词覆盖分析

### 4.1 竞品词匹配引擎

```
GSC N 关键词 × 竞品 265 全量词（子串匹配）
  ├── Full Match: 宽口径，所有竞品词变体
  ├── Core Match: 严口径，36 个高优先级核心词
  ├── SEO 报告: 覆盖率+分层表现+缺失分析
  └── Sentinel: 行业词变化检测+竞品种子词对比
```

### 4.2 日本市场竞品词分析

**主要竞品：**
- Canva（キャンバ）
- Adobe Firefly（アドビ ファイアフライ）
- Midjourney（ミッドジャーニー）
- DALL-E（ダルイー）
- Stable Diffusion（ステーブルディフュージョン）

**竞品词覆盖分析指标：**
- 覆盖率：命中竞品词数量 / 总竞品词数量
- 分层表现：Top 10/50/100 的竞品词表现
- 缺失分析：完全无排名的核心词

## 六、日本市场特殊注意事项

### 6.1 语言特殊性

**日语 SEO 特殊性：**
- **假名使用**：平假名、片假名、汉字的混合使用
- **关键词变体**：同一关键词的多种变体（如：AI デザイン、AIデザイン、AI設計）
- **搜索习惯**：日语搜索习惯与英语不同，需注意长尾关键词

**日语内容优化建议：**
1. **关键词研究**：深入研究日语关键词变体
2. **内容本地化**：内容需完全本地化，避免机翻
3. **用户体验**：优化日语用户体验
4. **移动优先**：日本移动搜索占比高，需优化移动端

### 6.2 文化特殊性

**日本市场文化特点：**
- **注重细节**：日本用户注重细节和品质
- **品牌信任**：日本用户注重品牌信任和口碑
- **用户体验**：日本用户注重用户体验
- **隐私保护**：日本用户注重隐私保护

**文化优化建议：**
1. **品牌建设**：加强品牌建设和口碑营销
2. **用户体验**：优化用户体验，提高满意度
3. **隐私保护**：加强隐私保护，提高用户信任
4. **本地化**：内容完全本地化，符合日本文化

### 6.3 竞争特殊性

**日本市场竞争特点：**
- **高度竞争**：日本市场竞争激烈
- **本地竞品**：本地竞品实力强
- **国际竞品**：国际竞品也在日本市场布局
- **技术竞争**：技术竞争激烈

**竞争优化建议：**
1. **竞品分析**：深入分析竞品策略
2. **差异化**：寻找差异化竞争优势
3. **技术创新**：加强技术创新
4. **本地化**：加强本地化策略
