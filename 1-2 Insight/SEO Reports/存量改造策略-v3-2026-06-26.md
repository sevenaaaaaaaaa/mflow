## 四、改造 vs 新建决策

### 4.1 什么时候该改造？

| 场景 | 决策 |
|------|------|
| 现有 Blog 排名 4-10 但 0 点击 | **改造** |
| 现有 Blog 主题沾边但关键词密度低 | **改造** |
| 现有 Tools 页面 CTR < 1% | **改造** |
| 现有页面 1000+ 曝光 | **改造** |
| 现有页面 slug 含核心词 | **改造** |

### 4.2 什么时候该新建？

| 场景 | 决策 |
|------|------|
| 现有 Blog 主题完全不沾边 | **新建** |
| 现有 Blog 内容陈旧（>1年） | **新建** |
| 关键词是新词（如 Sora 2） | **新建** |
| 现有 Tools 完全没有 | **新建** |

### 4.3 避免雷同策略

| 风险 | 解决 |
|------|------|
| 标题雷同 | 差异化公式：核心词 + 限定词 + 价值主张 |
| 内容雷同 | 每个页面加 1-2 个独有元素 |
| 关键词堆砌 | H1/H2 密度 < 3% |
| 重复 FAQ | 复用框架但问题不同 |

### 4.4 差异化公式

```
Page Title = 核心关键词 + 限定词 + 价值主张

例:
- "AI Video Generator for E-commerce Ads"
- "AI Video Generator for YouTube Shorts"
- "AI Video Generator from Text — Free"
- "AI Video Generator vs Runway: 2026"
```
