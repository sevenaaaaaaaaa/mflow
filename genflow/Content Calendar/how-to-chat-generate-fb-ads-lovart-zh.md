## 聊天生成Facebook广告的工作流程

### 第一步——确定你的素材格式

Facebook支持多种广告格式。你的提示必须指定是哪种：

- **单图广告**：1080x1080（正方形）或1200x628（横版链接广告）。一张主视觉，一个信息。
- **轮播广告**：每张卡片1080x1080，2-10张卡片。每张卡片讲述故事的一部分，或展示系列中的一款产品。
- **精品栏广告**：封面图（1200x628或1080x1080）加产品图块。封面设定品牌基调；图块从你的目录中提取。
- **视频缩略图**：代表视频广告播放前的静态帧。1080x1080或1200x628。

每个提示都以格式开头："Facebook单图广告，1080x1080..."

### 第二步——编写带有社交证明的产品主图提示

有效的Facebook广告素材共享相同的DNA：产品为主角，利益为信息，社交证明为信任信号。你的提示应嵌入所有三个元素。

```
Facebook单图广告，1080x1080。一个光滑的白色护肤品瓶子放在纹理石面上，
周围环绕着新鲜芦荟叶，瓶盖上有一滴露珠。
左上方的柔和自然光，投下轻柔的阴影。
右上角有一个小金徽章：'4.9 ★ 12,000+ 条评论'。
底部留出空间，用于白色文字叠加标题。
干净、高端、编辑风格的美妆摄影。
贴近生活方式——令人向往但可信。
```

关键组成部分：
- 产品为主角（白色护肤品瓶子，位置突出）。
- 通过生活方式背景暗示利益（新鲜芦荟、露珠——新鲜感、纯净感）。
- 社交证明徽章（星级评分、评论数量）。
- 为文字叠加预留布局（底部标题空间）。
- 风格护栏（"令人向往但可信"——避免恐怖谷般的AI完美感）。

### 第三步——生成格式变体

从你的主图提示出发，生成平台特定的变体：

**横版链接广告（1200x628）**：
```
相同的产品场景，但重新格式化为1200x628横版。
产品在左侧三分之一，文字叠加空间在右侧三分之二。
Facebook链接广告格式——更宽的构图，垂直密度更低。
```

**轮播卡片组（每张1080x1080）**：
```
卡片1：产品主图，相同风格。卡片2：成分特写——芦荟纹理，微距细节。
卡片3：前后对比分割——左侧暗淡皮肤，右侧光彩皮肤（无面部，仅颈部以下）。
卡片4：生活场景——产品在浴室架子上，晨光，令人向往。
卡片5：评论引用卡片——'我试过所有产品。就这个最好。'——优雅字体，
品牌颜色，角落可见产品。
```

**深色模式变体**：
```
相同的产品场景，但背景为深炭色而非石头。
更暗的氛围，更戏剧化的光线。适用于出现在深色模式信息流中的展示位置。
```

### 第四步——应用Facebook的素材指南

在导出之前，根据Facebook的广告政策验证你的素材：

- **图片中的文字**：Facebook不再严格执行20%文字规则，但文字覆盖率低于20%的广告仍然表现更好。如果你的图片文字过多，覆盖人数会减少。
- **前后对比声明**：避免"神奇"的转变图像。保持对比有依据且可信。
- **无误导性CTA**：图片上的"立即购买"按钮不应暗示平台原生按钮已提供的功能。
- **安全区域**：Facebook在不同展示位置（信息流、快拍、Marketplace、Audience Network）对广告进行不同裁剪。将关键元素保持在画布中心80%区域内。

政策安全输出的提示："无误导性的前后对比声明，图片上文字最少，保持中心区域远离边缘关键元素。"

### 第五步——构建素材测试矩阵

AI生成的广告素材的真正力量不在于速度——而在于测试数量。通过手动设计，测试五个素材角度意味着五次委托或五个小时。通过AI助手，这意味着五个提示。

为每个广告活动生成一个测试矩阵：

| 角度 | 视觉类型 | 钩子 | 测试变量 |
|-------|-------------|------|---------------|
| 产品主图 | 棚拍，干净背景 | "12,000人转用的精华" | 图片清晰度 vs 生活方式 |
| 生活场景 | 产品使用中，真实环境 | "你的晨间流程，升级版" | 真实性 vs 精致度 |
| 社交证明 | 评论引用卡片 + 产品 | "4.9星。12,000条评论。" | 文字为主 vs 图片为主 |
| 问题/解决方案 | 分割构图——左侧问题，右侧解决方案 | "使用Lovart前。使用Lovart后。" | 情感对比 |
| 创始人故事 | 创始人照片或头像 + 产品 | "我为自己的皮肤制作了它" | 个人化 vs 企业化 |

在同一个广告组中运行所有五个。让Facebook的算法优化投放至获胜素材。淘汰表现不佳者。将获胜者作为下一轮变体的基础。

## 常见问题解答

**正确的Facebook广告图片尺寸是多少？**

信息流广告：1080x1080（正方形）或1200x628（横版）。快拍广告：1080x1920（竖版）。轮播广告：每���卡���1080x1080。精品栏封面：1200x628或1080x1080。所有图片应为JPG或PNG格式，小于30MB。

**助手能否为Facebook的Advantage+展示位置生成广告？**

可以。指定"Facebook Advantage+素材，需要多种宽高比"，助手将从同一基础场景生成针对信息流、快拍和Reels展示位置优化的版本。

**每个广告活动我应该生成多少个广告变体？**

至少三个——一个产品主图、一个生活场景、一个社交证明。对于高预算广告活动（每天$500以上），生成五到七个变体，为算法提供更多信号进行优化。

**Facebook会惩罚AI生成的广告素材吗？**

不会。Facebook在广告审核或投放系统中不区分AI生成和人工设计的素材。算法根据互动信号评估素材效果，而非来源。

**如何避免广告素材中的"库存照片"感？**

避免过于通用的提示（"微笑的商务人士，白色背景"）。使用具体的场景描述、品牌特定的道具和纹理提示（"胶片颗粒"、"自然光"、"略微欠曝"）。你的场景描述越具体，输出就越不像库存照片。

**我可以用助手生成视频广告吗？**

Lovart助手生成静态图片，并可以从图像序列和场景描述中制作视频内容。对于视频广告，逐帧描述场景进展，并指定视频广告格式。

**如何在多个广告活动中保持品牌一致性？**

在Lovart中保存你的品牌工具包，包括你的Logo、调色板、字体搭配和批准的图片风格参考。每个生成的广告都将遵循相同的视觉规则手册，即使跨越不同的广告活动和格式。
