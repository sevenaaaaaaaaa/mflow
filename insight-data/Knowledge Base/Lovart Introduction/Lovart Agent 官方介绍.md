# 主推能力

## 1 **Multi-Angles（多角度）**

这个功能可以让你**直接改变一张图片的视角和镜头感**。不用重新生成图片，只需要拖动或调整参数，就能把同一张图变成完全不同的构图和镜头效果。

**1、如果你是普通用户，推荐使用 Image 模式。** 画面里的主体就像一个可以旋转的小雕塑，你拖动它就能看到不同角度的效果，所见即所得，非常直观。做海报、电商图、社媒配图时，可以很快找到最舒服的视角。

**2、如果你是设计师、摄影爱好者或视频创作者，可以使用 Camera 模式。** 在这个模式下，你调整的是虚拟摄像机的位置和角度，就像在真实摄影里移动机位一样，可以获得更专业的构图和镜头语言。

**3、除了拖拽操作，两个模式还支持 参数化调整，可以精准控制画面的视角。** 用户可以组合三个参数进行调整：

Rotate：控制水平旋转角度：0° / 45° / 90° / 135° / 180° / 225° / 270° / 315°

Tilt：控制俯仰角度：-30° / 0° / 30° / 60°

Scale：控制镜头远近：Close-up / Medium / Wide

三组参数可以自由组合，一共可以产生 **96 种不同的视角变化**。你可以一步到位选择一个组合，也可以只微调其中一个参数，快速找到最理想的构图。

**4. 模式特色玩法**

**Image 模式：一键广角** 一键把普通画面扩展成广角镜头，空间瞬间被拉开，主体更有张力，场景更有冲击力。很多原本普通的图，用广角后会立刻变得更有电影感。

**Camera 模式：一键 12 个最佳角度** 系统预设 12 个常用机位，一键切换不同视角，比如平视、俯拍、侧面、特写等。快速浏览一圈，很容易找到最有表现力的构图。

很多用户第一次用会发现一个很有意思的地方：**同一张图，其实可以“拍”出很多张不同的图。**

你可以把它理解为一个 **AI摄影棚**。图已经生成好了，而你现在只是在选择最好的机位和镜头。

## 2 文字编辑-Text Edit

Text Edit 就是 **让图片里的所有字，都重新变成“可编辑的字”**。无论这张图来自海报、PPT、KV、电商图，还是艺术字、手写字、变形字，只要有字——你都能直接改。像改文档一样改图里的字。

**1、多段、多层级的文字一键提取**

图片上有一堆字？标题、副标题、小字、标注？直接全部提取出来，排好顺序放在右边，让你一个一个改。不改版式、不改排版、不乱套。

**2、艺术字也能改，改完还是原来的样子**

笔刷字、立体字、手写字、变形字、做过特效的字……以前改不了，现在都能改。而且改完后 **风格、粗细、阴影、质感都和原来一样**。 **3、遮挡的字也能自动恢复并替换**

有的人挡住字、有物体压着字？Text Edit 会自动“理解”被挡的部分是什么样子。改完之后，前后关系不破坏，画面依旧自然。

**4、中文换英文、英文换中文，都能保持原风格**

跨语言替换不会导致排版崩溃。即使长短不一样，也能自动适配。

**5、大量减少重复工作**

不用抠图、不用找字体、不用重新排版、不用重做特效，几秒钟就能完成过去几十分钟的 PS 活。

## 3 精准编辑-Touch Edit

Touch Edit 做的就是：把强模型变成强控制，对用户来说：从「一次次押 prompt 赌运气」，变成「在画布上，一边指一边说，模型帮你把事做完」，也解决了用户“需要用脑子去想怎么描述画面某部分”的难题，一点就行，这也是**最符合直觉和用户习惯的交互方式**。

**能做什么？**

- 融合很多图的素材：全部拖进画布，然后分别点选你想要的部分，融合图
    
- 精准局部改动：点击画面局部，进行精准修改、替换，可控延展：加物体、换场景、补环境、补光线
    
- 改字：做海报、PPT，直接mark文字部分就可以进行修改
    

**两种使用方式：**

1. 在任意图片上 cmd+click（Mac）/ ctrl+click（Windows）
    
2. 左侧 sidebar 最上方图标下拉，选择 Mark 模式
    

- 直接Mark，可以点选+理解识别非常复杂的图片，可以直接和画布对话（“这只猫换成白色”“把右边做成海报风”）
    
- 自动识别画面结构、物体关系、布局，可以精准定位（自动选择是“女人的头发”还是“女人头部”或者“女人”）
    
- 做复杂、多步骤的图像改动特别好用
    

## 4 样机-mock up

Mockup 就是 **把你的设计，一键贴到任何物体、场景里，自动变成真实效果图**。不管是杯子、手机、包装盒、海报框、公交站牌、T 恤、车身……只要你点一下，它就能自动贴上去，而且看起来非常“真”。

**1、自动透视匹配**

不用调角度、拉扯、变形。 Lovart 会自动识别物体的角度，把你的图贴得刚刚好。就像你真的拍了一张成品照一样。

**2、自动贴合材质与弧度、自动融合光影与环境**

玻璃的反光、纸张的质感、布料的褶皱、车身的弧面……Lovart 会自动让图贴上去后“长”得像真的在那个物体表面一样。Lovart 会让你的设计自然地融入场景。

**3、任何场景都能瞬间变样机**

你随手找的一张照片，也能当样机用。不是只能用模板，任何图都可以拿来贴。

**4、做电商、品牌视觉、包装设计的救星**

一张平面 KV → 10 个场景效果图，5 分钟搞定一整套上新素材。超级省时。

## 5 分层编辑-Edit Elements

AI、非AI图片的痛点都是在于不能编辑，如果希望编辑，必须有原始文件，所以设计师的取材受到很大的影响，现在Lovart独家研发了元素拆分的功能，重新赋予设计更大的自由度。

**Lovart帮你一键“炸开”所有图片，分离元素、背景、文字，让一切变得可以编辑！**

1️⃣ **自动识别图层**：AI 一键拆解图片中的前景、背景、文字。 2️⃣ **可编辑的每一层**：移动、替换、旋转、重绘、修改文字，全都直接在 Lovart 里完成。 3️⃣ **从产物到模板**：上传/生成任意图 → 一键拆分 → 立刻变成可编辑素材。 4️⃣ **重建设计自由**：再也不用重做整个图，只改一层。

## 6 PPT

**Lovart 现在已经可以完整地完成一份可直接使用的 PPT**。从资料整理、内容结构搭建，到页面设计和最终导出，都可以在 Lovart 里一次完成。你可以同时提供多个 PDF，或让它联网搜索资料和图片，Lovart 独家的 Deep Research 会自动完成信息收集与梳理，生成结构清晰、逻辑顺畅、适合分享、汇报和 pitch 的演示内容。只需用自然语言说明你想要的风格、色系、页数和排版偏好，整体视觉就能自动统一好；生成后也有很大的修改空间，无论是直接改文字，还是针对单页替换图片和布局，整体风格依然保持一致，编辑过程非常顺滑。在整体审美和可编辑性上，Lovart 已经更接近一份“生成后就能直接用”的成熟 PPT，相比 NotebookLM 等工具，在视觉呈现和后续调整体验上更完整。
