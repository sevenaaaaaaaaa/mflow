Macro still-life photograph, museum vitrine light, tight and clinical, one abstract mark repeated across four material grounds of identical size — cold-pressed paper, raw linen, brushed bronze, translucent vellum — each catching the light differently, arranged in a precise row, material truth with visible surface texture, one focal point only, muted base with at most one accent, 4:3, edges safe for rounded-corner crop, no text, no letters, no watermark, no screens, no UI windows

## Alt 文案

`Lovart brand agent applying one mark across four material grounds`

## 风格锚定

**三层锚定**：材质真实（可触摸的表面肌理）· 单一焦点（只有 1 个视觉重心）· 克制配色（低饱和底 + 至多 1 个点睛色）

## 本模块纪律

- 视觉重心落在中右 60%（左侧是页面文案栏）
- 四边 ≥5% 裁切余量（圆角卡片渲染）
- 主视觉 ×1 + 支撑元素 ≤2 + 背景 ×1；禁止画界面
