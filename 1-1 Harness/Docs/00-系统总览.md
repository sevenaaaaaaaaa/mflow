## 端到端管道

```
数据采集 (Trident GSC/GA4/Bing + Sentinel 舆情)
    ↓
分析决策 (pipeline-orchestrator：报告触发、内容缺口、竞品覆盖)
    ↓
内容生成 (Blog / Features / Tools / Landing — 1-3 Content Gen)
    ↓
质量门禁 (preflight L1 → convert → NDJSON → import --missing → verify L2)
    ↓
发布上线 (Sanity production · Sitemap · 多平台分发)
    ↓
效果回测 (SEO 周报/月报 · Sentinel · quality-audits)
```

## 铁律（全局）

- production 增量：`--missing` + patch；禁止无授权 `--replace`
- 禁止 `sanity deploy`、禁止改 `schemaTypes/` 除非用户明确要求
- 发布前：`check-sanity-auth` + preflight BLOCK=0
- 详见 [AGENTS.md Part B7](../AGENTS.md#b7-内容-anti-bugs强制)
