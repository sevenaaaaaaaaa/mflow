Tools

## Select / Hand / Mark

Master Lovart's infinite canvas. Use Touch Edit for AI object recognition (no masking needed), leverage Smart Select for layout, and streamline workflows with Quick Edit.

### Select (Shortcut V)

![Lovart Canvas Tools: Master Touch Edit, Smart Select & Hand Tool](https://cdn.sanity.io/images/o11tm2qe/production/59fa46e97b813e364ec130431226a683e3e4f6c8-2160x1350.png)

Lovart Canvas Tools: Master Touch Edit, Smart Select & Hand Tool

The Select tool, active by default, lets users pick single or multiple design elements like text, shapes, or images, with drag handles for adjusting position, size, rotation, and skew.

Click an element to show a blue bounding box; use Shift for multi-select or drag to lasso groups; right-click for layer options like lock, hide, or duplicate. Ideal for precise layout alignment, such as poster rearrangements or UI component tweaks.

1. Select an Asset (Left Click)
	- **Left-click** an image/video on the canvas to select it (you’ll see a **blue bounding box** with handles).
	- Once selected, the **Top Bar** appears for quick actions on the current asset, such as **Upscale, Remove bg, Mockup, Remover, Edit Elements, Edit Text, Expand, and Crop**
2. Manage the Asset (Right Click Menu)
	- **Right-click** the selected asset to open the context menu.
	- **Copy / Paste**: duplicate the selected asset on the canvas.
	- **Move up / Move down**: adjust the asset’s layer position.
	- **Bring to front / Send to back**: move the asset to the top or bottom layer.
	- **Add to chat**: send the asset into the chat as a reference for further edits or generation.
	- **Group**: group multiple selected assets for easier movement and management.
	- **Show/Hide**: toggle asset visibility without deleting it.
	- **Lock/Unlock**: prevent accidental moves or edits.
	- **Export**: export the asset as **PNG / JPG / SVG**.
	- **Delete**: remove the asset from the canvas.
3. Quick Edit Shortcut
	- With an asset selected, press **Tab** to open **Quick Edit** for faster edits.

### Hand (Shortcut H)

Lovart's Hand tool switches the cursor to a hand icon, dedicated to canvas panning and zoom navigation, enabling designers to efficiently control the workspace.

Click the left toolbar icon or press shortcut H for persistent mode, or hold Spacebar for temporary activation to avoid interrupting the editing flow.

## Mark - Touch edit

![](https://cdn.sanity.io/images/o11tm2qe/production/3ab48ed5edaae86e403c147dc27ff6932af860b9-2160x1350.png)

### Overview

**Touch edit** is the core tool of Lovart's Mark mode, enabling you to intuitively mark and edit design elements as naturally as touching a screen. Simply click any area on an image—text, graphics, objects—and Lovart's AI automatically recognizes the content and transforms it into an editable object, eliminating complex layer operations or selection drawing.

### Getting Started

1. **Activate Mark Mode**
	- Select Mark mode from the left toolbar on the canvas
	- Use keyboard shortcuts: Cmd+Click (Mac) or Ctrl+Click (Windows) or shortcut M
2. **Mark & Recognition**
	- Click on the element you want to edit on the canvas, and the system will:
		- Automatically detect the content type at the marked location
		- Marked content displays in real-time in the right panel as blue numbered tags
		- Supports up to **10 mark marks** for multi-element batch editing
3. **Editing Methods**
	- **Agent panel**: Describe your modification needs in natural language
	- **Click marks on canvas or press Tab**: Trigger the Quick Edit panel for instant element property adjustments
### Advanced Touch Edit Workflows

**Scene-Based Editing Example:**
You're editing a coffee shop promotional poster with multiple elements. The AI has already separated the background, main image, text, and decorative elements into distinct editable layers.

**Workflow 1: Targeted Element Replacement**
1. Mark the coffee cup in the main image
2. "Replace with a latte cup showing latte art"
3. AI intelligently replaces while maintaining composition
4. Shadow and lighting automatically adjust to match scene

**Workflow 2: Style Transfer**
1. Mark the background element
2. "Apply warm autumn color palette"
3. AI transforms colors while preserving texture and depth
4. Other elements remain untouched for contrast

**Workflow 3: Proportional Adjustment**
1. Mark the logo
2. "Make 15% smaller and move to top-right corner"
3. AI recalculates position based on new size
4. All connected elements (tagline, brand elements) adjust proportionally

### Multi-Element Batch Editing

**Selecting Multiple Marks:**
- Up to 10 mark points can be active simultaneously
- Useful for batch operations: "Make all these elements 20% more vibrant"
- AI understands relationships between marked elements
- Apply consistent changes across multiple design components

**Batch Style Changes:**
1. Mark key elements (logo, product image, background pattern)
2. "Apply retro color grading to all marked elements"
3. Each element transforms while maintaining its unique characteristics
4. Overall visual consistency achieved efficiently

### FAQ

**Q: Can Touch Edit handle complex backgrounds?**
A: Yes, the AI analyzes complex scenes and intelligently separates elements, even in busy backgrounds.

**Q: What if Touch Edit marks the wrong element?**
A: Click the marked element to deselect, then mark the correct area. AI learns from corrections.

**Q: Does marking affect the original image?**
A: No, marking is non-destructive. The original remains intact; edits create new layers.

**Q: Can I undo Touch Edit operations?**
A: Yes, use Cmd/Ctrl + Z to undo. Each mark operation is separate and reversible.
