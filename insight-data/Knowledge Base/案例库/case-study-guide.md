# 案例库建设指南

> 目标：收集真实用户故事（Sentinel 舆情 / 用户反馈 / 社区讨论），用于增加内容可信度。

## 来源

1. **Sentinel 舆情日报** — 用户在 Reddit/X/ProductHunt 的讨论
2. **GSC 查询** — 用户实际搜索的问题（真实需求信号）
3. **客服/反馈** — 用户实际使用场景与痛点
4. **DataWorks** — 注册用户的行业/来源分布

## 案例模板

```markdown
---
type: case-study
persona: 中小电商团队
industry: ecommerce
use_case: 海报批量生成
result: "节省 70% 设计时间"
date: 2026-09
source: Sentinel daily 2026-09-15
---

## 场景
[用户的真实情况]

## 痛点
[他们为什么需要 AI 设计工具]

## 解决方案
[他们如何使用 Lovart 解决]

## 结果
[可量化的结果 + 用户原话引用]
```

## 使用规则

- **禁止**编造案例（铁律）
- 有真实数据才能写"结果"字段；没有就写"用户反馈积极"
- 每个案例至少关联一个 persona（画像 1/2/3）
- 案例用于 Blog 的 "Real World Example" 段和落地页的 testimonial
