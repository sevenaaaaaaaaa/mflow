# showcase · 前后堆叠 / 横向滚动展示

> **section type**：`showcase-stacked / showcase-horizontal`  
> **图片来源字段**：`items[].media.src`  
> **尺寸 / 比例**：1760 × 1100 · 16:10  
> **每实例图片数**：3  
> **站内覆盖页面**：约 149 个文档

## 模块形态

stacked：垂直堆叠 N 个图文块；horizontal：横向 carousel，每卡 16:10 大图 + 标题 + 描述 + CTA。

**用途**：用于「产品流程」深度叙事，视觉权重仅次于 hero。

## 本模块专属纪律

1. **大图叙事，每张要有独立可读的完整场景**（不是缩略图放大）
2. N 张之间是「流程先后」，需有递进关系
3. 横向 carousel 会左右裁切，主体避开左右各 8%

## 通用规范

| 项 | 要求 |
|---|---|
| 图内文字 | **零**。含可读字符即废稿；如模块自带排版，用抽象灰色条块表达层级 |
| 多语言 | 同页面 10–11 语言版本共用同一套图，按模块做、不按语言做 |
| 安全区 | 四边 ≥5% 裁切余量，主体不触边 |
| 体积 | JPG q85 或优化 PNG ≤1.5MB |
| 禁用元素 | 紫蓝渐变 / 玻璃拟态 / 悬浮 3D 球 / 等距插画 / 光轨 / floating chips / 多点拼贴 |
