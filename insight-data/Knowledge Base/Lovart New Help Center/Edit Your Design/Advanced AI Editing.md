# Advanced AI Editing

### Quick Edit

**Shortcut:** `Tab`

> Fast AI adjustments on a selected image.

![](https://cdn.sanity.io/images/o11tm2qe/production/a1bec3984ff83d96290cc94412c1d41cab2fae09-2160x1350.png?w=800&q=75&auto=format)

**What It Does**

Quick Edit provides fast access to common editing tasks. Pick a frequently used adjustment from the panel, or prompt for a custom edit.

**How to Use**

1. **Access Quick Edit.**
    - Select an image on the Canvas.
    - Click Quick Edit in the image toolbar, or press `Tab`.
2. **Make adjustments.**
    - Click Swap to see more adjustment presets.
    - Select an adjustment, or write a prompt.
3. **Generate.**
    - Click Run.

**Quick Tips**

- Quick Edit is handy for A/B testing. Compare side by side on the Canvas.
- Combine Touch Edit with Quick Edit to fine-tune the image with more precision.

**Related Features**

- [Select](https://www.lovart.ai/docs/edit-your-design/customize-your-canvas#cdcd787e2a83): Select an element first, then press Tab for Quick Edit.
- [Mark / Touch Edit](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing#6ae82b6e027d): Click a specific spot in an image, then open Quick Edit to refine just that region.

### Mark / Touch Edit

**Shortcut:** `M` or `Cmd/Ctrl+Click`

> Click anywhere on an image and Lovart identifies the exact objects you want to edit.

![](https://cdn.sanity.io/images/o11tm2qe/production/3ab48ed5edaae86e403c147dc27ff6932af860b9-2160x1350.png?w=800&q=75&auto=format)

**What It Does**

Touch Edit lets you mark an element in an image and describe a precise edit in natural language. Lovart identifies the element and applies the edit.

**How to Use**

1. **Activate Mark Mode.**
    - Click Mark in the toolbar, press `M`, or hold down `Cmd/Ctrl` and click the element you want to edit.
    - Lovart automatically recognizes and labels the marked object. The mark appears in the input box.
2. **Describe the change.**
    - Type your prompt in the input box, or press `Tab` to use Quick Edit.

**Quick Tips**

- Use multiple marks to batch-edit several elements in a single pass.

**Limitations**

- Mark Mode supports up to 10 marks per prompt.

**Related Features**

- [Quick Edit](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing#1a22fc7995d3): Rapid AI adjustments via Tab on a marked element.
- [Edit Elements](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing#a325d3865db9): Split images into editable layers for manual repositioning instead.

### Edit Elements

> Separate an image into layers with AI and edit each layer freely.

![](https://cdn.sanity.io/images/o11tm2qe/production/11990086076078e21c2cf45e1e7677248da4aa5c-1280x800.png?w=800&q=75&auto=format)

**What It Does**

Edit Elements breaks your image into individual layers, so you can reposition, resize, and adjust subjects, backgrounds, and text independently. Use it when you want to manually rearrange the composition.

**How to Use**

1. **Access the tool.**
    - Select the element on the Canvas you want to edit.
    - Click Edit Elements in the top bar.
2. **Rearrange the elements.**
    - Your image is now separated into movable parts. Resize, rotate, or rearrange them as needed.
3. **Edit text elements.**
    - You can change the font, size, and content of text elements.
4. **Flatten and export.**
    - Once you're happy with the new composition, export multiple layers as PSD, or select multiple layers and flatten them before exporting as an image.

**Quick Tips**

- Edit Elements works best on images with clear subjects, text, and backgrounds.

**Related Features**

- [Edit Text](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing#b26a423b73fd): Change the text content inside an image while preserving its style.
- [Mark / Touch Edit](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing#6ae82b6e027d): Edit specific elements without layer separation.
- [Remove Background](https://www.lovart.ai/docs/edit-your-design/basic-ai-editing#31d1b4d59068): Remove the background entirely instead of separating into layers.

### Edit Text

> Change the text content inside an image while preserving its style.

![](https://cdn.sanity.io/images/o11tm2qe/production/160ea33cd32895577d0070ad4e9227f02e781576-1280x800.png?w=800&q=75&auto=format)

**What It Does**

Edit Text lets you modify text within an image while preserving the original font and visual style. Use it when you only need to change the words, for example swapping a headline on an AI-generated poster or correcting a typo on a product label.

**How to Use**

1. **Access the tool.**
    - Select the element on the Canvas you want to edit.
    - Click Edit Text in the top bar.
2. **Edit your text.**
    - The Edit Text panel opens on the right side.
    - Type or paste your new text content.
3. **Apply or cancel.**
    - Click Run to generate, or Cancel to discard.
    - Press `Esc` to exit text editing.

**Quick Tips**

- Review spelling and formatting before applying.

**Related Features**

- [Edit Elements](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing#a325d3865db9): Split an image into layers when you need to reposition text or change font and style, not just rewrite the text.
- [Text](https://www.lovart.ai/docs/edit-your-design/canvas-objects#da4ec3b9cfcb): Add new text layers to the Canvas.
