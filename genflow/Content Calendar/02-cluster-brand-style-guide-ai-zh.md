# 如何利用AI创建品牌风格指南：分步指南

[图片1占位符 — 人物场景]

品牌风格指南是你为品牌创建的最不华丽、却最重要的文档。它不是情绪板，也不是创意探索。它是一本规则手册——是那些执行一致的品牌与那些逐渐陷入视觉混乱的品牌之间的分水岭。

好消息是：AI可以在几分钟内生成一份专业的品牌风格指南。更好的消息是：它比大多数初创公司手动拼凑的指南更精确、更全面。

以下是使用Lovart的品牌工具包（Brand Kit）和生成功能的完整分步流程。

## 品牌风格指南必须包含的内容

[图片2占位符 — 概念图]

在生成之前，我们先定义什么是“完整”。一份专业的品牌风格指南涵盖七个部分：

### 1. 品牌概述
- 品牌使命和价值观（各1-2句话）
- 品牌个性（3-5个形容词）
- 目标受众摘要
- 品牌语气和语调原则

### 2. 标志系统
- 主标志及留白空间要求
- 次要/替代标志变体
- 图标/标记使用规则
- 标志禁忌（不得拉伸、重新着色、旋转、添加效果）
- 印刷和数字用途的最小尺寸要求
- 文件格式规范（SVG、PNG等）

### 3. 色彩调色板
- 主色及十六进制、RGB、CMYK和Pantone值
- 辅色及规格
- 中性调色板（文本、背景、边框）
- 强调色/行动号召色
- 使用比例（应用60-30-10规则）
- 验证过的可访问性对比度比率

### 4. 字体排印
- 主字体及所有字重和用例
- 副字体及所有字重和用例
- 字体层级（H1到正文到说明文字，含字号/字重/行高）
- 网页字体后备栈
- 特殊情况（数据、代码、说明文字）

### 5. 图像与摄影
- 摄影风格描述及视觉示例
- 插画风格（如适用）
- 图标风格和库
- 图案和纹理指南
- 图像处理规则（无滤镜、特定裁剪、色彩分级）

### 6. 布局与构图
- 网格系统
- 间距和边距
- 跨格式的标志放置规则
- 留白理念

### 7. 应用示例
- 社交媒体模板（帖子、故事、横幅）
- 文具（名片、信头、电子邮件签名）
- 演示文稿（标题幻灯片、内容幻灯片）
- 网站（首屏、导航、页脚）
- 商品或包装（如适用）

这就是标准。大多数初创公司的“品牌指南”只是一个标志文件和三个十六进制色码。而AI让你能以专业质量覆盖所有七个部分。

## 第一步：收集你的品牌资产

在生成之前，整理你已有的内容：

- 标志文件（SVG、PNG变体）
- 任何现有的品牌颜色
- 你正在使用的字体
- 你喜欢的设计示例（你自己的或灵感来源）
- 品牌策略笔记（个性、受众、定位）

如果你是从零开始，直接跳到第二步——AI会生成所有内容。

如果你有现有资产，先将其上传到Lovart的品牌工具包（Brand Kit）。AI会分析你现有的品牌，并围绕真实资产（而非假设性资产）构建指南。

## 第二步：生成完整的品牌风格指南

在Lovart的ChatCanvas中，使用`@brandguide`命令：

```
@brandguide 为[品牌名称]生成一份完整的品牌风格指南。
行业：[简要描述]。
品牌个性：[3-5个形容词]。
目标受众：[简要描述]。
包含：带留白空间图的标志系统规则、完整的色彩调色板及十六进制/RGB/CMYK值、带字号和字重的字体层级、带做与不做示例的摄影风格指南、社交媒体模板规格、印刷规格。导出为PDF就绪文档。
```

**会��生什么**：Lovart的MCoT（多链思维）引擎会跨多个维度处理此请求——它生成品牌架构逻辑（系统如何运作）、视觉处理（看起来如何）以及文档结构（如何组织）。你得到的是一个结构化的文档，而不是带有注释的情绪板。

**生成时间**：15-20页的指南需要2-3分钟。

**你会看到什么**：生成的指南包含实际设计的页面，而不仅仅是文本描述。色板已渲染。字体层级通过示例文本展示。做与不做的示例使用实际的品牌元素。

## 第三步：优化每个部分

AI能搞定结构。现在你来优化细节：

### 标志部分优化

将AI生成的占位标志替换为你实际的标志（拖放到画布中）。指南会自动更新所有标志使用示例。

指定留白空间规则。在Lovart中，使用触摸编辑（Touch Edit）点击标志区域并定义：
```
留白空间 = 各边1倍标志高度
```

指南会自动生成带尺寸的留白空间图。

### 色彩部分优化

验证每个颜色值。Lovart从你的品牌工具包（Brand Kit）中提取真实的十六进制色码——它们应与你实际使用的颜色匹配。

添加使用比例。编辑色彩部分以包含：
```
主色使用比例：品牌材料的60%
辅色：25%
强调色：10%
中性色：5%（或根据需要用于背景/文本）
```

开启可访问性验证。Lovart会自动测试每种颜色组合是否符合WCAG AA标准（普通文本4.5:1，大文本3:1）。任何失败组合都会被标记，并附上建议的替代方案。

### 字体排印部分优化

Lovart会根据你选择的字体自动生成字体层级。检查并调整：

```
H1：36px / 44px行高 / 粗体
H2：28px / 36px / 粗体
H3：22px / 30px / 半粗体
正文：16px / 24px / 常规
小号：14px / 20px / 常规
说明文字：12px / 16px / 中粗体
```

点击任何值进行调整。该层级是响应式的——更改正文字号，层级会按比例重新计算。

添加网页字体后备栈：
```
主字体：'Your Font', -apple-system, BlinkMacSystemFont, sans-serif
副字体：'Your Body Font', Georgia, 'Times New Roman', serif
```

### 图像部分优化

这部分最受益于示例。生成3-4张“做”的图像和2-3张“不做的”图像：

```
@dogen 品牌摄影示例：[品牌名称]风格，温暖自然光，生活场景上下文，浅景深，真实抓拍感
```

```
@dont 品牌摄影反例：过度滤镜、高动态范围过重、无菌影棚灯光、刻意摆拍、不自然姿势
```

并排的做与不做格式是传达图像指南最有效的方式。

## 制作更好指南的专业技巧

### 要具体，不要空泛
糟糕：“我们使用干净、现代的设计。”
优秀：“标题使用Satoshi粗体，字号36px，白色背景上字母间距-1%。永远不要在字体排印上使用投影。永远不要在标志上使用渐变。”

AI有助于具体化——它生成精确的规格。不要用模糊的语言弱化它们。

### 包含“为什么”
每条规则都应有一个简短的理由。“标志留白空间为1倍标志高度”告诉人们做什么。“标志留白空间为1倍标志高度，以保持视觉呼吸空间，防止相邻元素拥挤”告诉他们为什么。当人们理解理由时，他们能更好地遵守规则。

### 为指南设置版本
在指南封面页添加版本号和日期：
```
品牌风格指南 v2.1 — 最后更新于2026年6月
```
品牌会演变。版本控制可防止对当前指南的混淆。

### 创建快速参考单页
完整指南有20页。大多数人不会读20页。生成一张速查表：
```
@brandguide 生成一页快速参考速查表，总结关键品牌规则：标志留白空间、颜色十六进制色码、字体名称和主要字号、前5条做与不做规则
```

完整指南是真相来源。速查表是人们日常实际参考的内容。

## 品牌风格指南 vs 品牌工具包：有什么区别？

这让人困惑，所以让我们澄清一下：

**品牌工具包**（Lovart功能）= 自动执行品牌规则的*引擎*。设置一次。你创建的每个设计都会自动遵循你的品牌规则，无需你思考。

**品牌风格指南**（我们刚刚创建的PDF）= 向人类传达品牌规则的*文档*。这是你发送给自由职业者、代理机构和新团队成员的内容。

它们是互补的。品牌工具包用于Lovart内部的AI驱动创作。风格指南用于Lovart外部的人类协作者。两者对于大规模品牌一致性都是必要的。

## 糟糕的风格指南长什么样

作为参考，以下是薄弱品牌风格指南的标志：

- 没有标志留白空间规格
- 颜色列出时没有十六进制色码（“有点蓝绿色”）
- 字体提到时没有字号、字重或层级
- 完全没有图像指南
- 没有应用示例——期望你自行摸索如何运作
- 规则陈述时没有理由
- 没有可访问性信息
- 过时（引用旧标志、旧颜色、旧字体）
