## The Chat-Generate Table Tents Workflow

### Step 1 — Specify the Physical Format

Table tents come in standard sizes. Your printer needs to know which one:

- **4x6 inches** (folded): The most common size. Fits standard tent holders. Best for single-item promotions.
- **5x7 inches** (folded): Slightly larger, more space for menus. Common for wine lists and dessert menus.
- **A5** (148x210mm folded): European standard. Good for multi-item displays.
- **Custom shapes**: Die-cut table tents (triangle-topped, rounded corners) for premium presentation.

Start the prompt with the physical specs:

```
Table tent design, 4x6 inches folded, double-sided printing. 
Flat size: 8x6 inches (two 4x6 panels side by side), folded in half to create a standing A-frame.
```

### Step 2 — Write the Double-Sided Design Prompt

Table tents are viewed from two sides (front and back, or left-facing and right-facing). Your prompt must describe both:

```
Table tent design, 4x6 inches folded, double-sided.

BRAND KIT: [Restaurant Brand Kit] — warm terracotta (#C67B5C), cream (#FFF8F0), 
dark charcoal (#2D2D2D), font pairing Playfair Display (headings) + Lato (body).

SIDE A (faces the customer entering / the main approach side):
Full-bleed background in warm terracotta gradient (darker at bottom, lighter at top). 
At the top, the restaurant logo centered (from brand kit). 
Below: "NEW SEASONAL" in small uppercase tracking, cream color, centered. 
Bold heading: "Spring Tasting Menu" — Playfair Display Bold, cream, centered, 
occupying the middle third visually. 
Below heading: "$65 per person | 5 courses" — Lato Bold, cream, centered. 
At the bottom: a stylized illustration of seasonal ingredients (asparagus, peas, 
edible flowers) — line art, cream color, delicate. 
QR code in the bottom right corner: "View Full Menu" label below it, 8pt, Lato, cream.

SIDE B (faces the customer once seated — the "while you wait" side):
Same background treatment. Different content:
"While You Wait" — Playfair Display Bold, cream, centered upper third.
Below: Three recommended cocktails with brief descriptions — 
"Rhubarb Spritz — Prosecco, rhubarb syrup, fresh mint" etc.
Lato Regular, cream, 10pt, left-aligned with 0.3-inch margins.
At the bottom: "Ask your server about wine pairings" — italic, centered, 9pt.

PRINT SPECS: 0.125-inch bleed on all edges. Fold line at the 4-inch mark. 
CMYK color profile. 300 DPI. Crop marks included. All text 0.25 inches from fold zone.
```

Critical table-tent-specific details:
- The fold line specification (4-inch mark for an 8x6 flat sheet).
- The fold zone safety margin (0.25 inches from the fold — no critical text there because the fold obscures it).
- Double-sided content distinction — each side has a different job.
- Bleed, crop, CMYK, DPI — print-ready specifications.

### Step 5 — Prepare for Print Production

Table tents are printed objects. The export step matters:

```
Export all table tent variations as a single print-ready PDF:
- US Letter sheets (8.5x11 inches), two tents per sheet to minimize paper waste.
- 0.125-inch bleed on all edges.
- Crop marks on every tent.
- Fold line indicators as non-printing guide marks.
- CMYK color profile (US Web Coated SWOP v2).
- 300 DPI.
- All fonts embedded.
- Filename: AcmeRestaurant_Spring2026_TableTents.pdf
```

Most local print shops accept this specification without adjustment. For online print services, check their specific file requirements and adjust the export prompt accordingly.

## Table Tent Design Principles

[IMAGE 3 PLACEHOLDER — Real UI Screenshot]

| Principle | Application |
|-----------|-------------|
| Readable at 30 inches | Body text minimum 10pt, headings minimum 18pt. If you need a smaller font, the message is too long — edit the copy, not the font size |
| One idea per tent | A "Spring Tasting Menu" tent should not also promote happy hour, private events, and the loyalty program. One message per tent, multiple tents per table if needed |
| QR codes need context | A naked QR code without an explanation label gets scanned at less than half the rate of a QR code with "View Full Menu" or "Order Now" beside it |
| Double-sided = two jobs | Side A attracts. Side B informs. Never put the same thing on both sides — that is a wasted surface |
| Fold zone is dead zone | Keep all critical content at least 0.25 inches from the fold. Text that bends across a fold crease is illegible and unprofessional |
| Paper quality matters | Specify card stock weight in your printer instructions (14pt or 16pt recommended). Flimsy paper tents collapse. Premium stock communicates premium brand |

## Frequently Asked Questions

**What paper stock should I use for table tents?**

14pt or 16pt card stock (cover weight). Anything lighter will bend, collapse, or look flimsy on the table. For premium venues, 18pt or 24pt with a matte or soft-touch coating. Specify this to your printer, not in the design file.

**Can the agent generate die-cut custom shapes for table tents?**

The agent generates the design on a standard rectangular canvas with bleed marks. For custom die-cut shapes (rounded corners, triangular tops, unique silhouettes), provide the generated design file to your printer along with the die-cut template. The visual design is complete; the physical cutting is a printer step.

**How do I make a QR code look designed instead of slapped on?**

Prompt: "QR code with a thin brand-color border, rounded corners, with 'Scan for Menu' in 8pt Lato centered below it." The agent will render the QR code as a design element, not a raw black-and-white square. For functional QR codes, replace the generated placeholder with a real working QR code in post-processing.

**Can I generate table tents in multiple languages?**

Yes. Prompt: "Generate the same table tent with Spanish text. Same layout, same design, swap all English copy for the attached Spanish translation. Adjust font sizes if Spanish copy runs longer." The agent maintains the design while localizing the content.

**How many table tent variations should a restaurant have?**

Three to five is the sweet spot. Two table tents per table — one promoting a specific item (tasting menu), one promoting a broader offer (happy hour, loyalty program). Rotate designs every 4-6 weeks to prevent visual fatigue among regular customers.

**What if my table tent needs to display prices that change frequently?**

Design a table tent with a designated "price zone" — a space intentionally left clean for price insertion. Export the base design without prices, then add prices in a text-editable format before printing. For frequently changing menus (daily specials), design a reusable template with a chalkboard-style or clip-art price area that can be written in by hand.
