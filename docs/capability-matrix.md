```
  ↓
真实放量三选一：QA 84 项修复（U7）· 物料替换（U4）· 低 CTR 改稿（U6）
  ↓

```

## 原则（对齐用）

1. 任何能力先问「能不能验证」，再问「能不能批量」
2. 生产写入默认 dry-run；人工授权不可绕过
3. 换站点只换档案，不改代码
4. 地基层也要可见（在矩阵里标注，而不是让用户感觉"没做正事"）
5. **无数据就是 0，不造假分**——空状态如实呈现，好过一屏漂亮的假数字
