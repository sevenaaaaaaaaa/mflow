# 美工每天都在改图抠图延展，到底该给哪些设计工具留席位

做美工的人大概都懂一种荒谬：客户上午说主图里的杯子要换成浅色，下午说背景要干净一点，傍晚又要把横图补成竖图，临下班还问能不能把人物抠出来做三张活动卡。听上去全是小改动，真正做起来却像在一张图里拆房子。最磨人的不是创作，而是反复处理边缘、比例、阴影、文字和尺寸。

我不建议美工去找一个号称什么都会做的工具。日常改图有不同席位：有的专门救脏素材，有的负责把一张图补全，有的守住商品真实感，有的负责批量落版。把它们混成一次随机生成，返工只会更多。下面这份清单按席位说，适合经常处理电商图、活动图、社媒图和临时物料的人。

## 席位一：抠图清边席

这是一切改图的起点。真正难抠的从来不是白底杯子，而是发丝、半透明塑料、婚纱纱边、毛绒玩具和带反光的玻璃瓶。自动抠图工具值得放在这一席，因为它能先把八成轮廓分出来，让人不用从零描路径。

我实际用下来，抠图最该看的不是第一次结果有多干净，而是能不能继续修。边缘有一圈白边时，能否擦掉；头发被削薄时，能否补回来；原来的阴影没了时，能否只保留地面接触感。没有这些细修入口，自动结果越快，后面越容易卡死。

常见坑是把抠图当成完工。人物离开原背景后，光线方向、脚底阴影和边缘色温都还留着旧场景。把这样的素材直接贴到新海报上，读者不一定能说出哪里不对，却会觉得整张图像拼的。我的做法是先抠主体，再用低透明度的软阴影把它重新压回新背景；人物边缘偏蓝或偏绿时，只在边缘做一点颜色回收，不要整个人一起调色。

高效用法是把常用商品、人像、标识都保存成带命名的透明底素材。不要每次客户来一句“还是用上次那个”才翻聊天记录。素材库分成产品、人物、装饰、标识四类，后面改尺寸和换背景会轻松很多。

## 席位二：局部换物席

客户说“这张能不能别重拍，换一下颜色和道具”，考验的是局部换物能力。它适合改掉桌上一件不合时宜的物品、把礼盒色系换成节日色、补一块空出来的画面，也适合把已经拍好的商品图做成几个轻微不同的陈列版本。

这一席不是让工具替你重新画一张商品图。越接近商品主体，越要克制。颜色可以改，背景道具可以换，缺掉的边角可以补；但标签文字、产品结构、瓶身比例和关键卖点，最好回到真实素材确认。尤其是食品、护肤、数码和服饰，画面里的细节一旦和实物对不上，后面的客服会替你承受问题。

我踩过的坑是提示写得太宽。只说“换成高级一点的背景”，经常会把原图光线、台面透视和产品边缘一起改坏。更实用的写法是先圈定区域，再说清楚只能换什么：保留主体位置和镜头角度，把右侧空白处换成哑光石材台面，光线仍从左上方来，背景不要出现文字。限制越清楚，结果越能接着用。

如果你经常接活动图，我会把这类工具和一份色彩备忘放在一起。每个品牌写清主色、禁用色、金属质感、留白范围和可用道具，改图时少凭感觉。Lovart 适合在这里承担整理和延展的角色：先把已有主视觉中的色彩、字级和图形关系读出来，再按同一套要求出不同画面，而不是每次都凭一段模糊描述重新猜。

## 席位三：画幅延展席

横图改竖图，方图改横幅，九宫格又要拆成单张，这是美工最容易被低估的劳动。只拉伸画布当然快，但主体一下偏到角落，文字没有呼吸，背景纹理也会在接缝处露馅。能理解画面空间关系的延展工具，能把原图之外的区域补得像同一次拍摄。

它特别适合救已经通过审核的主视觉。原图不必重做，只要确定哪个元素必须固定：人物的脸、产品的正面、标题区、标识区。接下来再决定新加出来的空间给背景还是给文字。横版通常需要左右的呼吸位，竖版更需要上下的叙事空间；这两个方向不能用同一种补法。

坑在于让延展区承担关键信息。补出来的花束、建筑、桌面和布景可以做氛围，别把最重要的产品卖点、复杂标识或人物手部交给它。画面边缘出一点小问题，缩小后没人会追究；核心对象出问题，客户一眼就看见。

我会先做一张无字底图，再分别做横版、竖版和方版，然后最后才排文案。这样文字永远有可用的安全区，不必为了凑字把产品压得喘不过气。延展不是把照片变大，而是给同一个主题腾出新的阅读距离。

## 席位四：批量落版席

美工真正耗时的部分，经常出现在“再来十张同款”之后。十个商品、三种尺寸、两套文案、一个节日角标，看起来只是复制粘贴，实际每张都有标题长短不同、产品高矮不同、重点不同的问题。批量落版席的价值，是让固定部分不必重复摸一遍。

这里需要的不是一张好看的模板，而是一套能伸缩的版式。比如标题最多两行，价格区永远在右下，产品永远留在中间偏左，活动角标只占一个固定角落。图片过高时怎么缩，标题过长时怎么换行，卖点只有一个时怎么留白，都先定好。

最常见的翻车是模板做得太漂亮，却只适合第一个商品。第二个瓶子更高，第三个包装更宽，第四个标题多八个字，画面马上开始挤。真正耐用的版式要先拿最难处理的素材测试，而不是拿最整齐的样品庆祝。

Lovart 这类能根据任务生成不同画幅的设计助手，可以减少手动搭底稿的次数，但最终仍要有人检查。尤其是中文标题，字数一变，重心就会变。工具可以帮你排队，美工要决定哪句话值得站在最前面。

## 席位五：发布前收口席

这一席没有炫目的效果，却最值得保留。它负责检查抠图边缘有没有脏色，商品文字有没有改错，延展背景有没有出现怪异纹理，价格和日期是否仍然正确，竖图缩小后标题能不能读。很多返工都不是创意问题，而是最后三十秒没人收口。

我自己会把检查拆成两遍。第一遍在大屏看细节：边缘、阴影、错别字、标识比例。第二遍把图缩到手机大小看阅读顺序：先看见什么，产品还在不在，文字有没有挤成一团。两遍都通过，才导出。

这个席位还有一个容易被忽略的作用：拦住不该改的东西。客户临时提一句“能不能把产品也修得更饱满”，如果已经碰到真实商品特征，就该先问清楚而不是马上动手。美工不是所有要求都照做的人，守住真实与可交付，才是专业的一部分。

## 美工工具怎么坐，不用追总分

每天被抠图折磨，先补抠图清边席；客户总想旧图翻新，补局部换物席；尺寸改到崩溃，补画幅延展席；活动物料越做越多，先把批量落版席建起来；团队图总在最后一步出错，就把发布前收口席写进交付习惯。

我最想说的一句是：改图不该被当成低价值的机械活。它考验的是你是否知道一张图里哪些部分能动，哪些部分不能动，哪些问题可以交给工具，哪些判断必须由人承担。把重复劳动交出去，把眼睛留给比例、真实感和阅读顺序，美工才有余力把“能改”做成“改得对”。
