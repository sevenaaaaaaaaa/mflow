# 0 门槛上手（3 步开工）

> 目标：不懂 items JSON、不懂 prompt，也能通过对话加内容、做 QA、搭工作流。

## 第一步：登录并看健康

`https://nownexts.com/mflow/` → 用管理员分配的账号登录 → **总览页顶部「系统健康」**：
- 绿色=一切正常；黄色=有噪音/积压（去「设置 → 维护」清理）；红色=LLM 或 Sanity 异常

## 第二步：选一个预设工作流（不用写任何配置）

**批量任务页 → 预设工作流**，点一下就能跑（数据自动取），7 个预设覆盖最高频场景：

| 预设 | 做什么 | 需要的唯一输入 |
|------|--------|---------------|
| 🎯 GEO 缺口改稿 | AI 引用缺口 → 改稿任务 | 条数（默认 5） |
| 📉 高曝光低 CTR 刷新 | 有曝光但点击率低的页面重写 | 最小曝光（默认 1 万） |
| 🍂 衰减页刷新 | 30 天无表现页面重写 | 条数 |
| 🔧 QA 字段修复 | seoTitle/description 问题自动修 | 页面类型 + 条数 |
| 🏷️ 封面 alt 补齐 | 缺 alt 的封面批量补 | 条数 |
| 🔍 例行 QA 扫描 | 按类型/语言体检，出问题清单 | 页面类型 + 条数 |
| 🌏 多语言批量产出 | 一个主题 × N 语言 | 主题 + 语言列表 |

**默认 dry-run**：先看结果不写库；确认后把 `dry-run` 去掉再跑一次即为真实执行（admin）。

## 第三步：用对话下达（Agent 任务台）

不想点选？直接说人话：
- "帮我把 5 篇高曝光低 CTR 的英文页按 GEO 标准改稿，先给方案"
- "扫一遍 tools 里英文页的 SEO 字段问题并修复"
- "把封面缺 alt 的都补上"

Agent 会：①带入 harness 规则（限 1200 字符，只取相关）②检索相关 skills ③查内容库与 GEO 缺口
→ 产出**可执行任务规格**（受门禁校验）→ 你批准 → 执行器跑。

## 权限与边界（谁都能用，但不会闯祸）

| 角色 | 能做 | 不能做 |
|------|------|--------|
| viewer | 看全部（只读） | 任何写操作 |
| editor（marketing/sales/operator） | 生成/质检/建任务 | LLM 配置、账号、审批、真实发布 |
| admin | 全部 | —（发布仍需人工授权） |

三条硬边界：**生产写入默认 dry-run** · **发布永远人工授权** · **每次真实写入记审计**。

## 新站点接入（给站点负责人）

1. 写 `run/sites/{site}.json`（domain / default_lang / source / sections[{dir,route,docType,pageType}]）
2. 内容库页选该站点 → 「同步 Sanity」→ 台账与目录结构自动适配
3. 无需改代码（换站点只换档案）
