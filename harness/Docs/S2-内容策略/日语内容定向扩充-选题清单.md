### 词簇 1｜SNS 场景（树状结构）

```
SNS（统称）
├── 任务词：SNS運用 / SNSマーケティング / SNS投稿作成 / コンテンツ制作
└── 平台词：X運用 / Instagram運用 / TikTok運用 / LINE公式アカウント運用
           └── Facebook：日本仍有使用，优先级低于上述平台 → 主要放 B2B 场景
```

| 类别 | 覆盖 |
|------|------|
| 独立站 | 自社EC、Shopify |
| 综合平台 | Amazon、楽天市場、Yahoo!ショッピング、メルカリ、TikTok Shop |
| 任务词长尾 | 商品画像／商品ページ／出品画像／広告素材 |

### 词簇 3｜创业品牌（表达映射规则）

| 中文概念 | ❌ 不用 | ✅ 用 |
|----------|---------|-------|
| 超级个体 / OPC | 超級個体、OPC（非主流搜索表达） | 個人事業主／一人会社・ひとり法人 |
| 国货新品牌 | 直译（无对应词） | 新興ブランド／新規ブランド／D2Cブランド |
| （补充） | — | スタートアップ／スモールビジネス |

### 词簇 4｜设计工作流

`デザイン制作フロー／クリエイティブ制作／制作工程／デザイン業務効率化／広告クリエイティブ制作／ブランドデザイン／コンテンツ制作`

## 四、生产管线映射

| 内容线 | 入口 Skill | 质量门禁 | 发布 |
|--------|-----------|----------|------|
| Blog（Track A + Track B） | `blog-writer`（先输出 blog-routing 路由声明；场景线按 Field Guide/Encyclopedia 框架） | L1 预检 → L1b Anti-Slop → L5 i18n（`preflight-content.js --type blog-i18n`） | `sanity-publish` |
| Tools（T1~T10） | Tools v2 JSON + `landing-writer` 参考 | `preflight-content.js --type tools --lang ja` + `i18n:verify` | `i18n:publish` |
| Features（F1~F3） | `i18n-workflow.js` apply | `i18n:verify:crosslang` | `i18n:publish` |

**每篇/页写作前必须**：
1. 输出 Route Statement（blog-routing.md §Required Route Statement）
2. 建 per-language i18n Ledger
3. 负面样本校准：`content-quality-gates/samples/i18n-ja-bad-001.md`（Rubric 38/100）逐条规避
4. 场景线文章遵守词簇 3 表达映射：**禁止**「超級個体/OPC」直译；用 個人事業主／一人会社・ひとり法人／D2Cブランド
5. 平台例子：SNS 线默认 X/Instagram/TikTok/LINE公式アカウント；Facebook 仅限 B2B 语境
