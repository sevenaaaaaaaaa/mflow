# 一、执行摘要

6月份自然搜索有两件事值得关注，3件好，一件需要警惕。

**好的方面**：

- **付费转化效率在改善。**注册→付费率从 5月 1.10% **提升至 1.28%（+0.18pp**）， ARPPU 持平在 $93，但同等注册量下能产出更多付费用户。
    
- **Bing 渠道尤为突出——仅占 25% 的注册 UV 却贡献了 54% 的付费金额（$80,095）**，付费率（2.40%）是 Google（0.72%）的 3.3 倍。**ChatGPT 渠道付费率 6.98% 为全场最高，**说明 AI 搜索来的用户购买意向极强，只是量还太小。
    
- **6月后 10 天（6/21-6/30）数据显示注册量在回升：6/21 的 3,505 逐步回升至 6/26 的 5,919（全月最高），月尾稳定在 4,500 左右。DAU 也从 6/21 的 89,770 恢复到 14-15 万区间。**
    

**需要警惕的**：

- 日均新增注册从 5月 4,970 降至 4,095（-17.6%），GSC 日均点击从 13,444 降至 10,448（-22.3%）**。品牌词是主要拖累**——品牌词点击从约 11,800/日降至约 9,300/日（-21%），非品牌词点击基本持平。**这不是排名问题，而是 lovart / loveart 品牌词本身的搜索量在在回落意味着我们的品牌影响力本身在下降，而不是负责收口的付费或自然搜索的问题。**

## 二、核心指标

### 搜索流量

- 流量
    
    - 6月 GSC 总点击 282,095（日均 10,448），总曝光 164.8 万（日均 61,045），整体 CTR 17.1%。**环比 5 月（日均点击 13,444），日均点击下降 22.3%**。
        
- 品牌与非品牌
    
    - 品牌词日均点击从 12,087 降至 9,274（-23.3%），非品牌词从 1,357 降至 1,174（-13.5%）。**品牌词和非品牌词齐降，但品牌词是主要拖累——说明 6 月品牌影响力依旧在降低，整体搜索需求在收缩，而非仅品牌词的问题。**
        
    - 同时，6月 GSC 曝光中品牌词占比 45.4%（747,707 / 1,648,217），非品牌词占比 54.6%（900,510）。**非品牌词曝光量反而多于品牌词，但点击只有品牌词的 1/8**——这说明非品牌词的仅完成了曝光任务、匹配度仍需提高。
        
- 优质渠道
    
    - Bing 6月关键词点击 150,652（日均 5,022），总曝光 357,374，CTR 42.2%。全量 traffic 维度 174,185 点击。
        
    - Bing 的 CTR 远高于 GSC（42.2% vs 17.1%），因为 Bing 上 Lovart 的关键词以高意向品牌词和品牌变体为主。"l o v a r t"（空格拼写变体）一个词就贡献了 26,273 点击。本月 Bing 收录约 27,492 页，其中 48 篇博客在 Bing 有流量。

## 三、关键词结构

### 品牌词 vs 非品牌词

|   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|
|分类|词数|点击|点击占比|曝光|曝光占比|CTR|
|品牌词|1,926|250,388|88.80%|747,707|45.40%|33.50%|
|非品牌词|23,074|31,707|11.20%|900,510|54.60%|3.50%|

非品牌词数量是品牌词的 12 倍（23,074 vs 1,926），但点击只有品牌词的 1/8。根源不是词不够多，而是排名和 CTR 双低：

- 品牌词 Top 3 CTR 约 40-70%，而非品牌词 Top 3 CTR 约 5-15%
    
- 非品牌词中排名 4-10 的词 CTR 趋近于 0%
    

### 排名区间

25,000 词的排名分布显示明显的「头部集中」：

- Top 1：3,057 词（12.2%），几乎全是品牌词
    
- Top 3：6,340 词（25.4%），贡献了 94.8% 的点击
    
- Top 10：18,321 词（73.3%），贡献了超过 99% 的点击
    

排名第 4-10 的约 12,000 个词几乎没什么点击——这些词已经在首页，只需要更好的 title/desc 就能产生点击。

### Bing 关键词结构

Bing 178 词中品牌词占 91.7% 的点击（138,118/150,652），非品牌词仅 8.3%（12,534）。与 GSC 的品牌占比 88.8% 接近，略高。Bing 上的 Lovart 搜索几乎全是品牌认知驱动。

Bing 非品牌词 Top 5：

- seedance 2.0 free：clicks 99，CTR 22.0%
    
- ai background remover free：clicks 73，CTR 12.3%
    
- freepik ai image generator：clicks 54，CTR 19.6%
    
- ai upscaler free：clicks 46，CTR 20.3%
    
- ai video background remover：clicks 33，CTR 36.3%
    

> **洞察**：Bing 上非品牌词的 CTR（平均约 20%）远高于 GSC 非品牌词（3.5%），说明 Bing 用户对非品牌结果的点击意愿更强。Bing 上「free」类关键词表现好，与我们 Tools 页面的定位一致——但当前 Tools 页面在 Bing 的收录和排名都不足。

## 五、地区表现

按 GSC 搜索点击排序的大区分布：

南亚和拉美合计贡献了 48.4% 的 GSC 点击——这是 Lovart 自然搜索的核心市场。北美虽然曝光量最大（91.6 万，占总曝光 56%），但 CTR 仅 2.3%——说明美国用户搜索 Lovart 时大量曝光未转化为点击，可能是因为 meta description 没有差异化，或搜索结果中竞品广告位抢占了点击。

GA4 数据揭示了不同的视角：US 以 1,429,469 sessions 位居第一（21.4%），远超 GSC 占比（7.3%）。说明美国用户主要通过 Direct / Referral / Paid 渠道访问，而非自然搜索。大中华区（China + HK + Taiwan）GA4 sessions 合计 218.6 万（32.7%），是最大的用户来源区。

> **洞察**：北美是「搜索点击效率最低」但「整体流量最大」的市场。提升北美 GSC CTR 从 2.3% 到 5% 就能增加约 25,000 月点击——这个目标不需要提升排名，只需要优化 meta description。南亚和拉美是「自然搜索占比最高」的市场，应优先保证这些地区的多语言版本（印地语、葡萄牙语、西班牙语）的 SEO 质量。

## 六、页面品类

EN 页面按品类拆分 GSC 数据：

首页（/）贡献了 95.4% 的 GSC 点击（269,128 / 282,095）——几乎所有品牌词搜索都落在首页。CTR 30.5% 是合理的品牌词首页表现。

Blog（1,284 页）：总点击 4,461，CTR 0.39%。平均每篇博客每月仅 3.5 个搜索点击。但 Blog 有 115.6 万曝光——问题不是没人看到，而是看到了不点。428 篇博客排名 4-10（首页 2-3 页），CTR 趋近于零。

Tools（425 页）：总点击 8,315，CTR 0.78%。其中 3 个核心页面（text-to-image-generator、video-generator、nano-banana-free）占据了大部分流量。长尾工具页面的搜索流量几乎为零。

Features（230 页）：总点击 6,103，CTR 1.30%——是 CTR 最高的内容品类。部分页面如 diploma-design（CTR 6.2%）、instagram-feed-planner（CTR 6.7%）表现优秀。

> **洞察**：Blog 是流量效率最低的品类（1,284 页 → 4,461 点击），但也是 Meta 优化空间最大的品类。本周对 46 篇博客的 title/desc 优化预计是边际提升最大的单项动作。Tools 3 个核心页面合计 94 万曝光但 CTR 仅 0.3-1.4%，通过加入「免费」「无需登录」差异化关键词，预期 CTR 可提升 2-4 倍。
