# ja-copywriter — 日语创作叠加规范

> **定位：不是独立入口。** `lang=ja` 的 Blog 走 `blog-writer`、页面走 `landing-writer`，本 skill 只做日语层的**叠加加载**（与主 skill 同时生效）。
> **冲突裁决顺序**：RULES 硬条款（RULES-00/20/70/80）> 四门禁脚本 > 主 skill > 本 skill。
> 来源：japanese-copywriting.md（日语文案规范）+ RULES-20 §16 + 门禁实测反馈。

## 0. 加载时机

- 任何 `lang=ja` 的 Blog / Tools / Features / Landing / Topic 的生成与改稿
- 日语存量稿翻新、日语 CTA/按钮文案、日语标题评审
- Loop 引擎（auto_loop）无需手动加载：核心条款已内联 `LANG_RULES["ja"]`（console.py），本 skill 是完整版与评审依据

## 1. Voice（声线）

- 以日语产品营销的口吻**直接用日语写作**，不是从英文/中文"翻译"过来
- 说明性文案默认 **です・ます体**；标题/按钮允许体言止め（简洁名词短语收尾）
- 全文敬体/常体一致（与 RULES-80 §9 对齐）
- 句读用「、」，日式汉字写法，禁简体中文字形（「体」为日语新字体，合法）

## 2. 消息顺序（每个屏/每个块固定）

1. **Headline**：用户能一眼认出的"任务或结果"
2. **Support**：用户给什么 → 产品做什么 → 产出什么
3. **Proof**：产品行为 / 例子 / 客户证据 / 明确的限制
4. **CTA**：一个具体动作

## 3. 标题规则

- 写**具体任务**，不写抽象品类宣言；一条标题只承载一个主意
- 在语义边界断行；禁止为压成一行而缩字号或删词
- 避免**片假名 + 名词的长串堆叠**；加助词或动词能提升可读性时必须加
- 英文 slogan **禁止直译**；译文脱离任务感就重写
- 示例（句式模式，非固定品牌文案）：
  - ✗ `革新的なAI技術で、あなたのクリエイティビティを無限に解放します。`
  - ✓ `ひとつのアイデアから、広告もSNS投稿も。`
  - 支持文案：`伝えたい内容を入力するだけで、キャンペーンに必要なクリエイティブをまとめて制作できます。`

## 4. 正文与 UI 文案

- 一段一个意思；信息密的地方拆段（单段 ≤300 字符，与 GEO 门禁一致）
- **先讲价值再讲技术原理**（除非机制本身就是搜索意图）
- 同一动作在页面 / UI / 帮助文档用**同一个词**
- 英文/AI 术语首次出现必须一句话解释
- 用**具体产出名词**：`広告バナー`、`商品画像`、`SNS投稿`、`LPビジュアル`
- 自助型页面不用过度商务敬语（营销腔の敬語連呼は避ける）

## 5. CTA 模式（按钮 = 下一屏的准确描述）

| 文案 | 何时可用 |
|---|---|
| `無料で始める` | 仅当确实存在免费开始路径 |
| `今すぐ試す` | 产品入口 |
| `制作例を見る` | 作品展示 |
| `料金プランを見る` | 定价页 |
| `詳しく見る` | 仅当下文让目标显而易见 |

- **禁止**用口号式文案当按钮；按钮必须描述下一屏发生的动作

## 6. 禁用表述（无现行证据即违规，与 anti-slop 对齐）

- 禁：`業界No.1`、`必ず`、`完全`、`無制限`，以及无条件的收益/省时保证
- 慎（在替代具体利益时禁）：`圧倒的`、`革新的`、`究極`、`次世代`
- 区分**能力与结果**：「作れる」≠「売上が伸びる」
- 不可验证数字标 `[待考证]`（RULES-20 §15），禁止编造

## 7. 数据点（与 RULES-20 §16 / geo-check 对齐）

- 每篇 **≥5 个数据点**：百分比 / 价格 / 年份 / 倍数 / 带单位统计数；数字用半角
- 日语示例：`導入率 42%`、`年間 120万円`、`制作時間 1/3`、`3倍`
- 同一数据不重复使用

## 8. 门禁速查（ja 特有）

| 项 | 基准 |
|---|---|
| 字数 | ja 上限 = 中文基准 ×1.8（Blog 3888 / 落地页 2160），quota-check 已内置 |
| 字形 | 禁简体中文字形；「体」合法（lang-check 已豁免） |
| 句读 | 「、」；禁半角逗号句号接 CJK |
| 结构 | H2 4–7 · FAQ 3–5 · 外部来源 ≥2 条完整 URL |
| 数据点 | 每千字 ≥1（geo-check statistics density） |

## 9. 本地化 QA（交稿前自检 6 问）

1. 读起来是"用日语写的"，而不是"翻译过来的"？
2. 目标用户在第一屏能认出自己的任务？
3. 主语 / 宾语 / 指代清晰？
4. 术语与标点全文一致？
5. 每个断言有依据可支撑？
6. CTA 准确描述下一个屏幕 / 动作？
