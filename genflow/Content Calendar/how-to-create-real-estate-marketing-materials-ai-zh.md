## 房产传单：可重复使用的模板

房产传单是数量最大的素材，也是最容易系统化的。经纪人们常犯的错误是每次都从头设计。相反，应该构建一个主模板，然后替换内容。

**AI传单提示词公式：**

```
房地产房产传单，豪华/现代/温馨风格，[卧室/浴室/平方英尺]，[房产类型]主图，[关键特性以项目符号列表形式]，经纪人姓名和联系方式，[品牌色]，简洁排版，适合打印，专业
```

**第1步：** 生成你的主传单布局。使用一个示例房源。确保结构正确——照片位置、文字层级、经纪人品牌区域、二维码空间。

**第2步：** 将其保存为Lovart中的一个项目。现在它就成了你的模板。

**第3步：** 对于每个新房源，打开模板，用新房产照片替换主图，并更新文字。Lovart的ChatCanvas允许你重新生成特定区域——因此你可以刷新“特性”部分或“社区亮点”框，而无需重建整个传单。

**第4步：** 以打印分辨率导出（300 DPI，标准8.5×11英寸至少2550×3300像素）。另存一个屏幕分辨率版本用于邮件。

对于豪华房源，在提示���中添加：“高端房地产，杂志品质，金色点缀，衬线字体。”对于入门级住宅：“温馨诱人，现代农舍美学，干净的无衬线字体，明亮的自然感。”

## 房源照片：AI增强而不造假

MLS对照片处理有严格规定。你不能添加不存在的游泳池，也不能移除后院的电线杆。但你可以：

**天空替换。** 灰色阴沉的天空会破坏外观吸引力。替换为逼真的蓝天。提示词：“将天空替换为明亮、部分多云的蓝天，自然光线，照片级真实。”这是房地产摄影中的标准做法，不会歪曲房产。

**草坪增强。** 冬天的枯黄斑块。提示词：“将草坪增强为健康的绿色，自然草地质感，相同光照条件，照片级真实，无结构变化。”季节性外观改善——草坪在五月看起来就是这样。

**黄昏转换。** 白天照片 → 黄昏照片，带有温暖的室内灯光。黄昏照片的房源浏览量是白天的3倍。提示词：“转换为黄昏外观照片，透过窗户可见温暖的金色室内灯光，黄昏天空，豪华房地产摄影风格。”

**虚拟整理。** 选择客厅照片中杂乱的角落。提示词：“清除此区域的杂物，替换为干净开阔的空间，保持相同的家具布局和光线。”这是移除卖家的一堆邮件，而不是移除墙壁。

你绝对不能做的是：添加或移除结构元素、改变房间尺寸、或更改永久性固定装置。这越过了增强的界限，进入了虚假陈述。

## 虚拟布置：投资回报率之王

[图片3占位符——真实UI截图]

空房间比布置好的房间卖得慢。实体布置每套房产花费2000-4000美元。AI虚拟布置只需几分钟，而且看起来与真实家具越来越难以区分。

**虚拟布置提示词：**

```
虚拟家居布置，[房间类型]，[室内设计风格]，[家具件]，[配色方案]，照片级真实，自然光线，高端房地产摄影，保持原始房间结构和尺寸
```

示例：“虚拟家居布置，客厅，现代有机室内设计，米色组合沙发，天然边几，落地植物，中性温暖色调，照片级真实，自然窗户光线。”

**最佳实践：**
- 每个房间布置一个焦点角度（通常从角落拍摄，捕捉两面墙）
- 将布置风格与房屋建筑相匹配（不要将超现代家具放在维多利亚式房屋中）
- 保持可信——900平方英尺的公寓不应该有三角钢琴
- 始终在房源描述中注明“虚拟布置”
- 只布置完全空置的房间；部分布置的房间加上AI添加物会显得不协调

Lovart的触控编辑功能在这里特别有用。先用全房间提示词布置主要家具，然后触控编辑特定区域以修复比例问题或替换看起来不对的物品。

## 社交媒体内容引擎

房地产社交媒体遵循固定模式。AI帮助你更快地执行这些模式：

**新上市帖子：** 房产主图 + “新上市”叠加文字 + 关键数据（卧室/浴室/价格）。提示词：“Instagram帖子，‘新上市’叠加文字使用优雅衬线字体，[房产照片]作为背景，[经纪人品牌]，豪华房地产美学，1080×1080。”

**降价提醒：** 制造紧迫感。粗体排版。提示词：“Instagram帖子，‘价格下调’粗体公告，[房产照片]，[新价格]突出显示，简洁现代设计，红色强调紧迫感。”

**开放日邀请：** 以活动为重点。提示词：“开放日邀请设计，[日期/时间/地址]，[房产照片]，温馨欢迎美学，显示关键特性，方向二维码占位符。”

**市场更新：** 数据可视化。提示词：“信息图社交媒体帖子，[市场数据]突出显示，[社区名称]，现代数据设计，[品牌色]，简洁排版，专业。”

**已售出公告：** 庆祝胜利。提示词：“Instagram帖子，‘已售出’横幅叠加文字，[房产照片]，‘在[X]天内’副文本，庆祝但优雅，经纪人品牌，���色���缀。”

批量处理这些。在一次会话中，为某套房源生成所有五种帖子类型。将它们排入你的日程安排器。25分钟的AI工作取代了3小时的Canva调整。

## 常见问题

**问：MLS允许AI虚拟布置吗？**
答：允许，但需要披露。大多数MLS平台要求你标记虚拟布置的照片。添加“虚拟布置”水印或在照片描述中注明。请查看你当地的MLS规则——有些有特定的标签要求。

**问：AI能取代我的专业房地产摄影师吗？**
答：不能。AI增强照片，但不拍摄照片。你仍然需要高质量的基础照片供AI处理。AI在拍摄后增加价值——天空替换、虚拟布置、社交媒体裁剪——但不能取代摄影师。

**问：如何确保我每年50多套房源的传单看起来一致？**
答：在Lovart中构建一个主模板并重复使用。该模板锁定你的经纪人品牌（颜色、字体、徽标位置）。每套新房源只需替换房产照片和文字。一致性建立认知度。认知度建立信任。

**问：房地产印刷材料的最佳分辨率是多少？**
答：传单：2550×3300像素（8.5×11英寸，300 DPI）。明信片：1800×1200像素（6×4英寸，300 DPI）。开放日指示牌：5400×3600像素（18×24英寸，300 DPI）。按你需要的打印分辨率生成。Lovart标准计划支持高达4K输出。

**问：我可以将同一设计同时用于数字和印刷吗？**
答：你可以使用相同的布局，但需要不同分辨率的导出。数字版本可以是较低分辨率和RGB色彩空间。印刷版本需要300 DPI和CMYK——但如果你通过在线服务打印，他们通常会处理RGB到CMYK的转换。

**问：如何在视觉上处理豪华房源与标准房源？**
答：构建两个模板变体。豪华：衬线字体，金色/黑色/白色调色板，更多留白，杂志风格布局。标准：无衬线字体，更暖色调，更高信息密度，平易近人的感觉。切换模板只需一次点击——不要按层级从头重新设计。

**问：Lovart与我的MLS或CRM集成吗？**
答：Lovart导出标准图像格式（PNG、JPEG），可上传到任何MLS或CRM平台。目前没有直接的API集成，但导出到上传的工作流程每份素材不到一分钟。
