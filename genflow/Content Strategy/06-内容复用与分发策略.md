# 内容复用与分发策略

> v2 假设每篇内容独立存在，且全部是文字博客
> 本文档规划「一鱼多吃」的复用策略和多渠道分发体系

---

## 一、内容复用（Repurposing）体系

### 1.1 核心理念

**一篇 Pillar Page = 一个内容资产，可以被拆解为 10+ 个独立内容触点。**

```
内容资产金字塔：

                    Pillar Page
                   /     |      \
            Thread   Carousel   Video
           /    \       |         \
      Tweet  LinkedIn  IG Post   YouTube
                                /    \
                          TikTok    Shorts
```

### 2.2 各渠道内容策略

#### Twitter/X（P0）

**定位**：Thought Leadership + 社区互动 + 实时讨论

| 内容类型 | 频率 | 格式 |
|----------|------|------|
| Thread（长线程） | 2-3/周 | 5-8 条推文，拆解一篇博客 |
| Quick Tip | 每日 | 1 条设计技巧 |
| Product Update | 按需 | 新功能发布 |
| User Spotlight | 1/周 | 展示用户作品 |
| Poll / Question | 1/周 | 互动话题 |
| Curated Share | 2-3/周 | 转发行业内容 + 评论 |

**发帖节奏**：
```
周一：Thread（本周主题文章拆解）
周二：Quick Tip + 行业评论
周三：User Spotlight + Quick Tip
周四：Thread（另一篇内容拆解）
周五：Poll / Question + 周末轻松内容
周六/日：Curated Share / 轻量互动
```

#### LinkedIn（P0）

**定位**：B2B 决策者触达 + 专业讨论 + 品牌建设

| 内容类型 | 频率 | 格式 |
|----------|------|------|
| 长文（改编自博客） | 2/周 | LinkedIn Article |
| 短帖（观点/数据） | 3-4/周 | 文本 + 图片 |
| Case Study 分享 | 1/周 | 文本 + Before/After |
| Carousel（教程精华） | 1-2/周 | PDF Carousel |
| Company Update | 按需 | 产品/团队动态 |

#### YouTube（P1）

**定位**：深度教程 + 产品演示 + SEO 视频

| 内容类型 | 频率 | 时长 |
|----------|------|------|
| 深度教程 | 1-2/周 | 8-15 分钟 |
| 功能演示 | 2/月 | 3-5 分钟 |
| 客户案例视频 | 1/月 | 5-8 分钟 |
| Shorts（精华片段） | 3-5/周 | 30-60 秒 |

**YouTube SEO 策略**：
```
标题：包含目标关键词（与博客共享关键词库）
描述：前200字包含关键词 + 博客链接
标签：10-15 个相关标签
字幕：自动生成 + 手动校对
卡片：链接到相关博客文章
结束画面：订阅 + 相关视频
```

#### Email / Newsletter（P0）

**定位**：用户培育 + 留存 + 转化

| 邮件类型 | 频率 | 目标 |
|----------|------|------|
| **Lovart Digest** | 双周 | 精选文章 + 产品更新 |
| **Onboarding 序列** | 注册后 21 天 | 激活新用户 |
| **Content Upgrade** | 按需 | 捕获 Lead |
| **Product Update** | 月度 | 产品新功能 |
| **Re-engagement** | 按需 | 唤醒沉睡用户 |

**邮件列表分段**：
```
- 未注册读者（TOFU）：发送 Digest + 内容升级
- 免费试用用户（MOFU）：发送 Onboarding + Best Practice
- 付费用户（BOFU/留存）：发送高级功能 + 社区邀请
- Team Plan 用户：发送团队管理 + 企业功能
- 沉睡用户（>30天未活跃）：发送 Re-engagement
```

#### Instagram（P1）

**定位**：视觉展示 + 品牌美学 + 年轻用户触达

| 内容类型 | 频率 | 格式 |
|----------|------|------|
| Feed Post（作品展示） | 3-4/周 | 1080×1080 |
| Carousel（教程/步骤） | 2-3/周 | 1080×1080（8-12 张） |
| Reels（短视频教程） | 3-5/周 | 1080×1920（30-90秒） |
| Stories（日常 Tips） | 每日 | 1080×1920 |
| Highlights（分类存档） | 按需 | 圆形图标 |

#### TikTok（P1）

**定位**：品牌曝光 + 年轻用户 + 病毒传播

| 内容类型 | 频率 | 格式 |
|----------|------|------|
| 60秒教程 | 3-5/周 | 屏幕录制 + 旁白 |
| Before/After | 2-3/周 | 分屏对比 |
| Design Hack | 2-3/周 | 快速 Tips |
| Trending Audio + Design | 1-2/周 | 蹭热点 |
| Behind the Scenes | 1/周 | 团队/产品幕后 |

## 三、内容更新（Refresh）策略

### 3.1 内容衰减模型

| 内容类型 | 衰减速度 | 半衰期 | 更新触发条件 |
|----------|---------|--------|------------|
| 工具评测 | 快 | 6-9 个月 | 竞品重大更新 / 新竞品出现 |
| 对比文章 | 中 | 6-12 个月 | 竞品功能更新 / 价格变化 |
| How-To 教程 | 慢 | 12-18 个月 | 产品界面变更 / 新功能 |
| Best Practice | 慢 | 12-24 个月 | 产品功能变更 |
| Insight & Trend | 中 | 6-12 个月 | 行业重大变化 |
| Segment 案例 | 中 | 12 个月 | 新案例补充 |
| Pillar Page | 慢 | 6 个月 | 新 Cluster Pages 需链接 |
| Glossary | 极慢 | 24 个月 | 新术语出现 |

### 3.2 年度更新日历

| 月份 | 更新任务 | 涉及内容 |
|------|---------|---------|
| **1月** | 年度回顾 + 新年预测 | Insight & Trend 全部 |
| **每季度** | 更新"Best AI Tools [Year]" | 工具评测 Pillar + Cluster |
| **每季度** | 更新竞品对比（竞品有重大更新后1周） | 对比文章 |
| **每半年** | Review Glossary，补充新词条 | Glossary |
| **每半年** | 更新 Pillar Page，补充新 Cluster | 所有 Pillar Pages |
| **6月** | 年中盘点，更新数据和排名 | 工具评测 + 对比 |
| **竞品更新后1周** | 更新对应的 vs 文章 | 对比文章 |
| **产品更新后** | 同步更新相关教程 | How-To + Best Practice |

### 3.3 内容审计流程

```
每季度执行一次内容审计：

1. 导出所有博客文章列表
2. 标注每篇文章的：
   - 最后更新日期
   - 过去30天流量
   - 排名变化
   - 内容类型
3. 识别：
   - 流量下降 >20% 的文章 → 优先更新
   - 排名在 6-10 位的文章 → 优化后可进入 Top 3
   - 发布 >6 个月未更新的评测文章 → 需要刷新
4. 制定下季度更新计划
```
