# 如何通过聊天生成 Lovart 价目表 — 能促进销售的服务菜单

[图片 1 占位符 — 人物场景]

你的沙龙有 27 项服务，分布在 5 个类别中。你需要一份价目表，让顾客不用眯着眼就能看清，让你的高端服务看起来物有所值，而且不能看起来像从 Excel 2003 打印出来的电子表格。你打开文字处理器，创建一个表格，输入服务名称和价格。结果……准确无误。但视觉上令人不适，并且会主动拉低你的平均客单价。

价目表是世界上最常见的商业文档之一，也是最常被设计得糟糕的文档之一。一份设计良好的价目表所做的远不止显示数字——它引导视线转向高价值服务，传达品牌品质，让定价显得公平而非随意。AI 设计代理将价目表制作从格式噩梦转变为几分钟内即可完成的专业设计输出。

## 为什么价目表设计直接影响收入

[图片 2 占位符 — 概念图]

顾客并非中立地阅读价目表。他们会扫描锚点——最高价设定上限，最低价设定下限。设计糟糕的价目表会埋没你的高端产品，让每个价格看起来都像随机数字。设计良好的价目表则利用视觉层次将服务分层呈现，让中间层看起来明显是最佳价值，而高端层则令人向往。

这不是心理操纵。这是信息设计。就像组织良好的餐厅菜单引导顾客选择利润最高的菜品一样，设计良好的价目表引导顾客选择能带来最佳价值的服务——对他们和你的业务都是如此。

## 聊天生成价目表的工作流程

### 第 1 步 — 定义价目表格式

价目表有多种格式，针对不同的展示场景进行了优化：

- **墙面展示**：11x17 英寸或 A3 尺寸，大版面，5 英尺外可读。常见于沙龙、理发店、水疗中心。
- **柜台卡片**：5x7 英寸或 A5 尺寸，立于柜台或支架上。用于销售点的快速参考。
- **宣传册插页**：三折面板，是更大营销物料的一部分。常见于全套服务菜单。
- **数字显示屏**：针对屏幕优化，1920x1080 或方形 1080x1080。用于网站、平板电脑、社交媒体。
- **带走卡片**：名片大小，3.5x2 英寸。供顾客带回家。

从格式和展示场景开始你的提示：

```
沙龙价目表 — 墙面展示，11x17 英寸，纵向。
设计为 5 英尺外可读。裱在接待台后面。
```

### 第 2 步 — 在提示前组织好内容

代理设计布局。你提供结构。在提示之前，组织好你的服务：

```
类别 1：剪发
- 女士剪发与造型 | 65 美元
- 男士剪发 | 40 美元
- 儿童剪发（12 岁以下）| 30 美元
- 刘海修剪 | 15 美元

类别 2：染发服务
- 全染 | 120 美元
- 局部挑染 | 95 美元
- 全头挑染 | 150 美元
- 渐变染 | 180 美元
- 颜色修正 | 200 美元以上

类别 3：护理服务
- 深层护理 | 45 美元
- 角蛋白护理 | 250 美元
- 头皮护理 | 55 美元
```

代理需要结构（类别分组）和数据（服务 + 价格对）来布局一份连贯的价目表。

### 第 3 步 — 编写价目表设计提示

```
沙龙价目表 — 墙面展示，11x17 英寸，纵向。

品牌工具包：[沙龙品牌工具包] — 暖玫瑰色 (#D4A0A0)、深炭灰色 (#2D2D2D)、
奶油色 (#FFF8F0)、金色点缀 (#C8A84E)。字体搭配：Cormorant Garamond（标题）+
Montserrat（正文/价格）。

布局：
- 顶部：沙龙标志居中，下方用优雅衬线字体写有“服务菜单”，金色。
- 下方：三个等宽列，每列代表一个服务类别。

第 1 列（左侧）：“剪发” — 标题使用 Cormorant Garamond Bold，24pt，炭灰色，
下方有一条细金色分隔线。服务垂直列出，每行一项：
服务名称（Montserrat Light，14pt，炭灰色）位于每行左侧，
价格（Montserrat SemiBold，16pt，炭灰色）位于右侧。
名称和价格之间用微妙的虚线引导线连接。项目间距 0.3 英寸。

第 2 列（中间）：“染发服务” — 相同的标题和布局处理。
高端服务（渐变染、颜色修正）在价格旁边有一个微妙的金色星形图标。

第 3 列（右侧）：“护理服务” — 相同的标题和布局处理。

底部区域：一个微妙的页脚 — “价格可能变动。不含小费。”
— 9pt，Montserrat Light，50% 透明度炭灰色，居中。
底部中央有小型沙龙标志标记。

背景：柔和奶油色 (#FFF8F0)，带有微妙的水印图案（暖玫瑰色细几何线条，
5% 透明度）。干净、优雅、编辑风格的美容行业美学。

排版规则：
- 服务名称：左对齐，14pt，Montserrat Light。
- 价格：右对齐，16pt，Montserrat SemiBold。
- 类别标题：24pt，Cormorant Garamond Bold，带有金色分隔线（1pt，列宽的 80%）。
- 最小文本大小：12pt — 确保墙面展示的可读性。
```

此提示中嵌入的关键价目表设计原则：
- **清晰的类别分隔**（三列）—— 避免文本墙问题。
- **服务与价格之间的虚线引导线** —— 引导视线跨越间隙，防止价格错位。
- **高端指示符**（金色星星）—— 在不显得强推的情况下，吸引注意力到高价值服务。
- **根据场景设置可读的最小尺寸** —— 墙面展示最小 12pt，顾客距离 3-5 英尺。
- **带有免责声明的页脚** —— 法律上谨慎且符合行业标准。

下个季度，当价格变动时：打开模板，更新内容，在一次会话中重新生成所有四种格式。价目表维护从“我几个月都不想碰的事情”变成了“我 15 分钟就能搞定的事情”。

## 价目表设计心理学

[图片 3 占位符 — 真实 UI 截图]

| 原则 | 应用 |
|-----------|-------------|
| 价格锚定 | 将最高价服务放在类别顶部附近——这会让它下面的所有东西相比之下显得合理 |
| 诱饵定价 | 如果你想多卖 95 美元的服务 B，列出 65 美元的服务 A 和 150 美元的服务 C。B 就成了“最佳价值”的中间选项 |
| 移除货币符号 | “65 美元”会触发价格敏感度。“65”更中性。在奢侈品语境中，完全去掉美元符号可以提升感知价值 |
| 层级命名 | 不要用“便宜 / 中等 / 昂贵”。试试“基础 / 标志 / 高端”或“经典 / 豪华 / 大师”。名称框定了购买决策 |
| 价格周围的留白 | 被文字挤在一起的价格显得昂贵且有压力。被呼吸空间包围的价格显得公平且经过深思熟虑 |

## 常见问题解答

**如何处理可变定价的服务（“起价”或“从 X 美元起”）？**

列出基础价格并附上说明。在你的提示中：“渐变染 — 从 180 美元起（价格因长度而异）。”代理会清晰地格式化价格范围，而不会使布局杂乱。对可变条款使用较小的斜体注释。

**我可以生成包含每项服务图片的价目表吗？**

可以。提示：“每个类别列在类别标题旁边包含一个小的 1x1 英寸圆形图片——代表该服务类型（剪发、染发、护理）的照片。”代理会将图片合成到布局中。对于真实的沙龙照片，计划在后处理中替换为实际照片。

**如何让我的价目表看起来高端而非折扣导向？**

四种技巧：(1) 移除货币符号。(2) 使用优雅的衬线字体。(3) 在类别和项目之间增加大量留白——拥挤的布局表示“预算”，宽敞的布局表示“高端”。(4) 使用克制的配色方案——最多 2-3 种颜色，没有亮红色的促销标签。

**我可以对我的价目表布局进行 A/B 测试吗？**

虽然你不能像测试网页那样测试印刷的墙面展示，但你可以生成两个布局选项，各打印一份，并向员工或几位值得信赖的客户展示以获取反馈。代理使这种探索成本为零。

**如果我的价目表需要符合行业法规怎么办？**

在你的提示中指定法规要求：“在页脚包含许可证号 #MM12345，8pt。包含‘价格含 GST’的标注。不得有‘最低价’或‘最优价’声明——符合[行业]法规。”代理会将合规元素整合到设计中。

**我可以生成多语言价目表吗？**

可以。提示：“用法语内容生成相同的价目表。相同的设计，相同的布局，法语文案。调整排版以适应法语重音字符。包含两种语言？创建一个双列布局，左侧为英语，右侧为法语。”

**Lovart 的价格计划如何适应价目表制作？**

免费计划生成单张价目表图片。19 美元的入门计划支持基本的价目表布局。对于多格式制作（从一个内容集生成墙面 + 数字 + 社交媒体 + 带走卡片），49 美元的专业计划提供了专业服务业务所需的生成量和导出选项。99 美元的团队计划增加了共享品牌工具包，以实现多地点的一致性。
