Ground your designs in real-time web search insights.
What It Does
Web Search integrates real-time web data into your design context, allowing the Agent to reference up-to-date information, current trends, visual inspiration, and design workflows. You can trigger it by clicking the icon, typing a search prompt, or pasting a public URL.
Method 1: Turn on Web Search
Click More (the + button) on the bottom-left corner of the input box.
Toggle Web Search on.
Method 2: Prompt for Semantic Search
Type your search request directly in the input box, e.g.,  search for latest minimal logo design trends  or  find examples of brutalist web design.
Method 3: Drop a Public Web Link
Share a public URL in your prompt.
Lovart will analyze the page content and extract relevant design insights.
Use Web Search to discover current visual trends, campaigns, and design movements.
Extract composition, color palette, typography, and layout principles from reference websites.
Ground infographics and design directions in factual data and cultural signals.
Combine web research with reference files for synthesized inspiration.
Limitations
URLs requiring login or authentication or behind paywalls are not supported.

Control whether the Agent reasons deeply or explores quickly.
What It Does
Lovart offers two modes that control how the Agent approaches a request. In Thinking Mode, the Agent reasons longer and returns comprehensive, structured solutions. In Fast Mode, the Agent generates multiple creative options quickly for rapid exploration.
Toggle your mode.
Click Thinking (the lightbulb icon) on the bottom-right corner of the input box to toggle it on and off.
Use Thinking Mode for complex brand systems, multi-step campaigns, strategic decisions that need justified reasoning, and long-term content series with consistent voice and visual language.
Use Fast Mode for initial brainstorming, quick side-by-side comparisons of different directions, incremental refinements to existing concepts, and visual reference gathering.
Related Features
Select AI Models
: Set model preferences that apply in either mode.
: Combine with Web Search for informed outputs.

What It Does
Voice Mode lets you communicate with the Agent by speaking — generate, edit, and ask questions with your voice.
Enter Voice Mode.
Click the Voice Mode icon on the bottom-right corner of the input box.
Speak into the microphone.
Your speech is transcribed live into the input box.
Confirm and send.
Click the Check icon to confirm your message and hit Send.
Make sure your device&#x27;s microphone is enabled.
