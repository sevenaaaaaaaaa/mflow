# 社媒经理每日 AI 设计工作流：2026 从日历到限动导出

这篇补 `/zh/blog/ai-design-for-social-media-managers-daily-workflow` 404。搜索意图围绕「社媒经理 AI 设计工作流」，读者要可执行步骤，不是灵感图库。

## 我的立场

社媒设计不是「每天做一张好看的」，而是 **日历驱动 + 一套 brief 出齐尺寸 + 改文案 Touch Edit 不全图重跑**。

## Brief 合约（我实际在用的）

```
日历：本周 7 帖主题 + 1 campaign CTA
尺寸：1080×1080 + 1080×1920 + 1200×628 一次出
任务：每帖 1 hook + 1 CTA + 发布日期
Brand Kit：锁色字，禁止 daily drift
禁止：双 CTA、假 trending 徽标
```

## 踩坑

**坑 1：每天风格 drift。** 解法：Brand Kit + 周模板。
**坑 2：改 hashtag 重跑。** 解法：Touch Edit 文案区。
**坑 3：尺寸漏平台。** 解法：MCoT artboard 清单。
**坑 4：campaign 和日常混在一起。** 解法：日历分栏 brief。
**坑 5：假 viral 元素。** 解法：法务 BLOCK。

## Lovart 五步

1. ChatCanvas 重述 brief 合约
2. Brand Kit 锁色与字体系
3. MCoT 出多 artboard（按渠道分尺寸）
4. 3 direction 选信息最清楚的一张
5. Touch Edit 改日期/价格/联系区 → export

## 公式

\[ \text{日产} = \frac{\text{日历brief} \times \text{MCoT多尺寸}}{\text{晚班重跑}} \]

## FAQ

### 能直接交付客户吗？

Export 前跑一遍 checklist：假徽标、双 CTA、联系信息可读。

### 改期/改价怎么办？

Touch Edit 改对应区域，不全图重跑。

### 需要会 PS 吗？

不必；极端修图仍可用 PS 补。

### 多语言 brief？

品牌术语 Lovart、MCoT、ChatCanvas、Touch Edit 不翻译。

### 多少 direction 够？

3–4 个，选一个进 Brand Kit 流程。
