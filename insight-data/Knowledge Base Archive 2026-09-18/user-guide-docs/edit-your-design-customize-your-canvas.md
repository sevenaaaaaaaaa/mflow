What It Does
You can define a custom background color for your workspace.
Open Canvas Background.
Click the Canvas Background button on the Canvas.
Choose a color.
Pick a preset or enter a custom color value to apply it to the Canvas.

Browse every object in the project and review its history.
What It Does
The Layer panel lists every object in your project along with its history. Use it to locate elements across a busy Canvas and revisit earlier states.
Open the Layer panel.
Click the Layer button on the Canvas to open the popup panel.
Browse objects and history.
Scroll through the list to find any object in the project.
Toggle visibility.
Click on the eye icon next to any object to show or hide it on the Canvas.

Generated Files
Browse and download every file generated in the project.
What It Does
The Generated Files panel lists every file the Agent has produced in the project, each with a download button.
Open Generated Files.
Click the Generated Files button on the Canvas to open the popup panel.
Browse the list.
Scroll through the generated outputs to find the file you want.
Download a file.
Click the download button next to any file to save it locally.
