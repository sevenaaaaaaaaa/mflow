# 2026-08-07 Tools 正文挂掉诊断

## 结论

Tools「正文挂掉」不是单一空 bodyJson，而是两层叠加：

1. **存量壳文案**：约 **475** 篇 Tools（EN 336）`bodyJson` 仍是 `Professional Creative Tool` / `Generate professional … in seconds with AI` 模板灌词，页面能开但正文像坏掉。
2. **同 slug 双文档 SSR 漂移**：Tools↔Features 共约 **1163** 对同 `language+slug`。前端 `/tools/{slug}` 有时吃到 Features 旧壳，有时吃到 Tools；今日重写后 Sanity 已好、线上仍闪回旧壳。历史 bug 见 `1-3 GenFlow/Bugs/重复文档删改.md`（同 slug SSR 随机返回）。

另有一批 Tools `_id` 不是 `tools-*`（`tool-*` 或 UUID），更容易被路由/查询漏接，表现为 **空 H1**（如 `ai-model-generator`、`ai-storefront-designer`）。

- Tools 总量：`pageType=="tool"` = **1872**（`sourceType` 全为 null）
- Tools 含壳短语：`Professional Creative Tool` = **475**；双标记 ≈ **448**
- Features 含壳短语：**578**

- 今日 EN 重写且 Features 仍为壳、需 Tools→Features 同步：**11** 篇（清单见 Local Dev QA-Memo）

## 根因排序

1. **P0 路由/去重**：同 slug Tools+Features 并存 → SSR 不稳定；UUID/`tool-*` id 加剧漏查。
2. **P0 内容债**：475 Tools + 578 Features 仍是壳模板，用户感知即「正文挂了」。
3. **P1 今日重写质量**：部分 CJK 用「品牌一致設計工作流」统一尾巴；JA 混繁中（`windows-ai-design`）。

## 缓解（按 ROI）

1. **立即**：对今日 11 篇 EN，把已重写 Tools 的 `bodyJson`（+TDK）同步到同 slug Features 壳文档，消除 SSR 闪回旧壳。
2. **立即**：给 UUID/`tool-*` 的 EN Tools 补规范 `tools-{slug}-en` 文档或修正前端查询（优先 pageType+slug，勿只 match `tools-*`）。
3. **本周**：按 `preflight_tools_page_rewrite.py` 整页重写剩余 475 Tools 壳；Features 壳另队。
4. **工程**：`/tools/*` 查询强制 `pageType=="tool"`；禁止 Features 同 slug 抢答。
