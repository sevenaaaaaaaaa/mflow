## 一句话

发布不是终点。**每周/每月/每季各跑一张检查清单**，发现问题按分流表转成工单——没有别的机制。

## 每周清单（机器全自动）

- [ ] 已发布 URL 全量扫 **404** → 零容忍，24h 修复或改指向
- [ ] 内链**死链/断链** → 同上
- [ ] **图片** URL 存活 100%、封面不撞车、CDN hash 完整（64 字符）
- [ ] **表格** portable-text 校验 BLOCK=0（Lovart schema：tableRow.cells 为字符串数组）
- [ ] **内链拓扑**：hub 出链 ≥8 · spoke 回链齐全 · 孤岛页（零入链）→ 补链
- [ ] 新发布页面 48h 内加扫一次以上全部

## 每月清单（GSC 月度数据后）

- [ ] 落地页 **30 天 UV < 50** → 进优化队列（补内链/改标题/评估 301）；**90 天仍无** → 判死（301 或下架）
- [ ] **转化率**低于页面类型基准（Tools ≥3% 起步）→ 触发 cro-audit 三清单体检（landing-writer 内联版）→ 改造队列
- [ ] 投放主推页**停留 < 8min** → 停投放（联动 paid-strategy 终止判据）+ 体检

## 每季清单（人工 + 机器）

- [ ] **多语言**：每语种抽 3 页——语义等价（数据点结论一致）/ 字数 ≥ 主语言 60% / 线上语言残留（en 页汉字、中文标点）/ hreflang 完整
- [ ] **移动端边距版式**：每类页面人工抽 3 页（对照 33 组件库规格）
- [ ] **零流量零转化资产**总审 → 301 合并 / 深度重写 / 下架建议

## 工单分流（发现的问题去哪）

| 问题 | 去向 |
|---|---|
| 渲染 bug（表格/图片/版式） | 记质量案例库（Bugs/）+ 修复工单进 pipeline；**同类第二次出现升级为规则**（进钩子/preflight） |
| 无访问 / 低转化 | cro-audit 体检 → 改造队列 / 301 / 下架 |
| 多语言缺陷 | i18n 重写（RULES-20 语义等价） |
| 内链 / 拓扑 | 拓扑修补工单（hub-writer 三律为准） |
| 流量类信号（高曝低点/排名下滑） | 同源 blog-writer 信号表（signals-and-phases 附表），只转投不重复处理 |
