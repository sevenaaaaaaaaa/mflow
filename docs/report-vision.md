# 报告可视化 v2 规划（Report Vision）

> 背景：报告中心现有 400+ 份报告全部为 Markdown 纯文本渲染，不利于展示与决策。
> 2026-09-15 已落地 V1 增强（见下），本文件规划 V2 方向，按 ROI 排序。

## 已落地（V1，2026-09-15）

1. **阅读器目录（TOC）**：自动提取 H2/H3 锚点，阅读窗顶部生成可跳转目录（月报可产出 60+ 条）。
2. **表格数值条**：渲染时后处理 HTML 表格——每列数值按列内最大值归一化，单元格内嵌比例条形图，负值用警示色。
   纯 CSS 实现、零依赖，月报级表格（3,700+ 数值格）即刻获得可视化对比。
3. 明暗双主题适配（oklch 变量）。

## V2 规划（按 ROI 排序）

### R1 报告类型模板化 Dashboard（高）
把三类高频报告从"读文档"升级为"看仪表"：
- **SEO 月报页**：指标卡（点击/曝光/CTR/排名/收录率，环比箭头）+ 品牌 vs 非品牌趋势线 + Top10 页面表 + 国家/地区分布条形。
- **舆情日报页**： sentiment 走势 + 平台声量份额 + 高热提及列表。
- **404/收录页**：修复进度燃尽（已修 vs 存量）+ 语言分布。
数据源：报告 md 内的结构化表格（已有解析器）+ Trident JSON 快照（gsc-full/ga4-full）。

### R2 Chart.js 趋势图（中）
阅读器内自动识别"日期 + 数值"双列表格，追加折线/柱状图表（CDN 引 Chart.js，报告 HTML 不落库）。
表格转图表一键切换，保留原文。

### R3 报告对比模式（中）
选两期同型报告（如 2026-07 vs 2026-08 月报）并排或叠加，差异单元格高亮（RULES-10 环比铁律的可视化）。

### R4 PDF / 图片导出（低）
阅读器一键导出 PDF（headless Chrome print）或 16:9 摘要图（给飞书/管理层推送）。

### R5 报告订阅摘要卡（低）
每周一管线后自动生成"本周报告速览"卡片（3-5 个关键数字 + 链接），推送到工作台总览与飞书。

## 约束

- 铁律：报告必须有环比（RULES-10）；可视化不得绕过"问题/根源/缓解"三段洞察要求。
- 所有渲染在后端 console 进程内完成，不引入持久化 schema 变更。
- 数据口径以 Trident 快照为 SSOT（GSC 正式口径 = www.lovart.ai URL 前缀；GA4 需 hostName 过滤 + LA 时区）。
