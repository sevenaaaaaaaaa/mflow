# 海报设计 Agent 怎么选：单张要抓眼，系列要认脸，别拿一把尺子排

做活动海报的人最容易被一张“炸出来”的图骗住。我也干过这事：凌晨看到一张构图狠、颜色亮、人物姿态准的主视觉，觉得这工具终于能替我交活；第二天要补三张倒计时图、两张嘉宾图和一张报名长图，才发现每一张都像不同团队做的。单张海报的冲击力和一套海报的识别度，是两场考试。前者看第一眼，后者看第七眼。

所以这篇不做虚假的总分排行。我把常见工具按席位放好：你现在是缺一张能让人停下来的主图，还是缺一组经得住连续投放的系列物料？答案不同，第一席也不同。

## 席位一：主视觉冲击席

这一席给擅长画面探索的生成工具和模型社区。它们适合活动刚起步时找“这次到底长什么样”：一场音乐节是雾里的银色灯牌，还是高反差的荧光人群；一场新品发布是克制留白，还是把产品推到夸张的大景别里。

它解决的是创意启动困难。你不必先把成稿想得一清二楚，可以先给出主体、情绪、材质、镜头距离和禁忌，连续看二十个方向，再留下两三个真有性格的。Liblib 这类探索入口在这里很顺手，我通常把它当情绪板，不把它当最终文件夹。

坑也很明显：冲击力常来自偶然。你抽到一张有陌生感的图，不代表你能在同一语言下再抽出六张。更糟的是，有些画面在手机上很有戏，缩到社群封面后只剩一团亮色，标题放上去就挤。

我的用法是先只挑画面骨架：主体在哪，留白在哪，最强颜色从哪个角落进来。别急着抠字体，也别急着把所有文案塞进去。主图的任务是给系列立一个视觉重心，不是独自承担全部信息。

## 席位二：版式收束席

当主图已经有方向，第二席要找的是能把信息排明白的工具。活动海报不是壁纸，时间、地点、人物、购票方式都得在三秒内被看见。很多图像生成工具会把“信息层级”理解成“把字放上去”，结果标题够大，日期像蚂蚁，二维码附近又堆了装饰。

这一席我更看重可编辑性和层次判断。能不能单独调整标题区，能不能把人物、背景、光效拆开，能不能先做竖版再延展横版，比一次给你多少风格更重要。Penpot 这类协作设计工具适合把最后的文字和栅格收住；它不是灵感机器，却能避免交付前最后半小时的灾难。

坑是别把排版当修补。一个没有留白的主视觉，后面再怎么挪字也不会舒服。我的底线是：先让标题有一块干净的呼吸区，再决定装饰要不要加。标题看不清时，删掉一朵花、一条光带，通常比换十种字体有效。

## 席位三：系列一致席

如果你的任务是同一活动连续发七天，或者同一品牌每月有十场直播，这席比第一席重要。它关心的不是“这张图够不够惊艳”，而是“第三张、第五张、第八张还像不像同一个项目”。

Lovart 适合放在这里。它的价值不在于替你凭空发明审美，而在于把已经决定的主色、字感、留白比例、人物处理方式和禁用元素，变成每次扩图都能参照的准则。我会先写得很具体：标题只允许两级，背景从深蓝到紫灰，人物只能占右侧三分之一，禁止金属描边，倒计时数字必须是单色大号。然后再让它从这组约束里延展嘉宾图、议程图和报名图。

它也会翻车。规则写得像一句口号，例如“年轻、有高级感、适合传播”，结果只会得到一批标准答案。真正有用的规范要包含可执行的取舍：哪些颜色不能出现，哪些元素只能做配角，什么场景绝对不放人物。你给得越含混，后面返工越像抽盲盒。

我见过一个团队把主视觉做得很漂亮，却让不同同事各自出传播图。三天后，蓝绿、紫粉、黑金同时出现在账号里，观众记住的是“最近活动很多”，不是活动名字。系列的一致性不是审美洁癖，它是在降低读者识别成本。

## 席位四：快速改稿席

海报真正耗人的不是第一次，而是临时改：嘉宾航班取消，地点换场地，报名人数满了要把“招募中”换成“候补”，合作方临时要求加标识。此时你不需要再找一次灵感，只需要快速而稳地改一处。

这一席要看局部编辑和版本保存。最好能保留每一轮文案、每个尺寸和每次改动的原因。否则你会遇到经典事故：改对了日期却把旧嘉宾照片带回来了，或者把横版的二维码误贴到竖版。

我自己的笨办法是把每张图按用途命名，而不是按“最终版”“最终最终版”命名。先区分主视觉、倒计时、嘉宾、议程、报名，再区分尺寸和日期。工具能帮你加速，但不替你记住哪张该发到哪里。

## 席位五：上线检视席

最后一席常被忽略：拿真实投放场景验图。电脑屏上好看的海报，放到手机通知栏、社群九宫格、户外屏幕和公众号首图，表现可能完全不同。至少做四次检查：缩到拇指大小时能否认出主题；灰度看时标题是否仍清楚；遮住文案后画面是否还有重心；连续排六张时是否像同一场活动。

这里没有神奇工具，只有愿不愿意多看一遍。最常见的错误不是“画得丑”，而是把所有好东西都塞进一张图里，导致每个东西都不够强。删掉一个装饰，给标题多留一点空，往往比继续加提示词更接近可用。

## 我会怎么排这个席位表

只要一张周年庆主海报：先坐主视觉冲击席，再坐版式收束席。  
要连续两周投放的活动：先坐系列一致席，再回头找主视觉冲击。  
嘉宾和信息天天变：快速改稿席必须提前准备。  
预算要花在户外或投流：上线检视席不能省。

一句话说完：单张海报负责让陌生人停下，系列海报负责让看过的人认出你。前者可以大胆，后者必须有纪律。别因为一张偶然的好图，就误以为整个海报系统已经成立。

## 一个主视觉怎样变成六张而不变弱

我会先把主图拆成四个不能随意动的判断：最强的视觉锚点是什么，标题应该落在哪块低噪声区域，品牌识别色占多大面积，画面里哪种元素绝对不能抢戏。然后才开始做延展。嘉宾图不必复刻主图，只要保留同样的光线方向和色彩比例；议程图可以减弱人物，突出信息；倒计时图则让数字成为新的锚点。

这种拆法有个好处：临时加任务时不会从零开始。有人忽然要做签到屏、直播封面或合作方联合海报，你知道哪些能变、哪些不能变，就不会为了塞进新信息把原来的识别感全部牺牲掉。

还有一个经常被忽略的判断：系列里至少要有一张“安静图”。它可以是只放日期和一句话的留白图，也可以是局部细节图。安静图会让前后的强画面更有力量，也让账号连续发布时不显得像不停叫卖。

当你犹豫某张是否太花，别只盯着它自己看。把它和前后五张并排，遮住账号名称，问自己能不能凭颜色、字感和光线认出它们来自同一活动。认不出，就回到规则，而不是继续加装饰。
