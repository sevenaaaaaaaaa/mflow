# Lovart 101 Playbook

## Writing goal

Help a beginner understand the concept quickly, use it safely, and know what to learn next.

## Core structure

1. Quick Overview
2. What this concept is
3. Key terms explained simply
4. The basic workflow or mental model
5. Starter templates or examples
6. Common beginner mistakes
7. Next-step guide routing
8. FAQ

## Must-have moves

- define the concept in plain language
- include a mini glossary or terminology table
- show one simple Lovart use case
- include copyable starter patterns
- route to deeper guides near the end

## Five topic templates

1. AI design 101
2. Prompting 101
3. Brand kit 101
4. AI image editing 101
5. AI video 101

## Anti-patterns

- too advanced too early
- no examples
- no bridge to deeper content
- generic intro with no reader orientation
