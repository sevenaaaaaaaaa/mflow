### 三、修复手段

1. **KB 权威源重写**：用 `Output/Knowledge Base/Features/*.json` 真实产品规格，13-block 模板（hero→bento→tabs→feature→prompt→workflow→comparison→cluster→testimonial→pricing→faq→cta）替换 slug 填充模板
2. **最小可用补建**：SEO 长尾页用 3-block（hero+faq+cta）保证无空页
3. **精准 _id 分发**：发现每个 slug 有 4 种 _id 版本（无前缀 / `features-` / `drafts.` / UUID），必须 patch **无前缀版**前端才读取
4. **标题清洗**：正则 `[\u4e00-\u9fff]` 扫描 + slug→Title Case 映射
5. **备份优先**：draft 删除前备份至 `Output/QA-Memo/deleted-draft-pages-2026-07-31.json`
