# AI 室內設計實戰：2026 從拍照到可落地改造

這篇補 `/zh-TW/blog/how-to-design-interior-rooms-ai` 404。搜尋意圖圍繞「AI 室內設計」，讀者要可執行步驟，不是靈感圖庫。

## 我的立場

室內 AI 成敗在 **原圖採光、家具比例、材質可 Touch Edit 不重跑** — 不是多生幾張漂亮圖。

## Brief 合約（我實際在用的）

```
尺寸：1080×1350 案場 IG + 1920×1080 簡報 + A3 mood board
任務：一個空間、一個風格方向、一個可採購家具清單
主體：原圖結構保留 + 家具/牆面/燈光可改
禁止：假窗戶、比例失真沙發、未標註虛擬 staging
```

## 踩坑

**坑 1：北向暗房 AI 變成黃光。** 解法：brief 寫色溫 5000K + 原圖補光。
**坑 2：小坪數塞 3 人座。** 解法：MCoT 先算走道寬度。
**坑 3：虛擬 staging 未標註。** 解法：輸出加「電腦合成」字樣。
**坑 4：材質改一次整圖重跑。** 解法：Touch Edit 牆面/地板區。
**坑 5：Pinterest 拼貼風格。** 解法：Brand Kit 鎖一個主風格。

## Lovart 五步

1. ChatCanvas 上傳原圖 + 重述 brief 合約
2. Brand Kit 鎖色與材質參考
3. MCoT 出 3 個風格方向（保留結構）
4. 選比例最可信的一張
5. Touch Edit 改牆色/家具/燈具 → export

## 公式

\[ \text{可落地} = \frac{\text{比例可信} \times \text{Touch Edit}}{\text{整圖重跑}} \]

## FAQ

### 能直接給客戶看嗎？

Export 前跑 checklist：比例、採光方向、虛擬 staging 標註。

### 改牆色/沙發色怎麼辦？

Touch Edit 改對應區域，不全圖重跑。

### 需要會 3D 嗎？

不必；極端結構改造仍建議找設計師確認。

### 多語言 brief？

品牌術語 Lovart、MCoT、ChatCanvas、Touch Edit 不翻譯。

### 多少 direction 夠？

3–4 個，選一個進 Brand Kit 流程。
