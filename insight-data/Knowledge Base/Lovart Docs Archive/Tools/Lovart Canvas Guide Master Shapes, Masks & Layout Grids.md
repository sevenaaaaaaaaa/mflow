## Shapes

Master the Shapes tool on Lovart's infinite canvas. Learn to build grids, use shapes as containers or masks, and create professional layouts with custom strokes.

### Overview

Shapes provide clean, flexible building blocks for layouts, emphasis, and structure. Use them as frames, containers, guides, or graphic elements in your compositions.

### How to use

- Select Shapes from the toolbar.
- Choose a base shape (rectangle, circle, line, etc.) and draw it on the Canvas.
- Adjust size, corner radius, stroke, and fill to match your design.
- Use shapes as masks, backgrounds, or containers for images and text.
- Duplicate and align shapes to build grids, cards, or repeated structures.

### Shape Types and Applications

**Basic Shapes:**
- **Rectangle**: Perfect for cards, containers, backgrounds, and UI elements
- **Circle/Ellipse**: Great for avatars, badges, highlights, and decorative elements
- **Line**: Use for dividers, arrows, connecting elements, or decorative accents
- **Polygon**: Create custom shapes with multiple sides for unique visual effects

**Advanced Shape Operations:**
- **Corner Radius**: Soften sharp edges by adjusting corner radius from 0 to any value
- **Stroke Options**: Customize stroke width, color, and dash patterns
- **Fill Options**: Solid colors, gradients, or transparent fills
- **Shadow Effects**: Add depth with configurable drop shadows

### Shape as Container System

**Image Masking:**
1. Draw a shape (circle, rectangle, etc.)
2. Place your image inside or behind the shape
3. Right-click the shape and select "Set as Mask"
4. The image is automatically clipped to the shape boundaries

This is perfect for:
- Profile picture frames with circular masks
- Photo galleries with consistent shape containers
- Product showcases with clean edges

**Layout Building with Shapes:**

1. **Grid Systems**: Create alignment guides by drawing multiple evenly-spaced shapes
2. **Card Components**: Build reusable card designs with shape-based containers
3. **Background Patterns**: Duplicate shapes and arrange them for repeating backgrounds
4. **UI Elements**: Construct buttons, navigation bars, and interactive components

### Professional Workflows

**Creating Consistent Card Layouts:**

1. Draw a rectangle with desired corner radius (e.g., 12px for soft cards)
2. Add subtle drop shadow for depth
3. Duplicate the card shape for each item
4. Use the Align tool to distribute cards evenly
5. Add content inside each card with consistent spacing

**Building Complex Shapes:**

1. Start with basic shapes
2. Use the Pen tool to add custom points
3. Combine shapes with path operations
4. Apply gradients and effects for polished results

### Shape Shortcuts

- **R**: Rectangle tool
- **O**: Ellipse/Circle tool
- **L**: Line tool
- **Shift + Drag**: Constrain shapes to perfect squares or circles
- **Alt + Drag**: Draw shapes from center
- **Cmd/Ctrl + D**: Duplicate selected shape

### FAQ

**Q: Can shapes be used with AI generation?**
A: Yes! Shapes can serve as containers or guides for AI-generated content. Use shapes as reference boundaries or mask containers for AI outputs.

**Q: How do I create rounded button shapes?**
A: Draw a rectangle, increase the corner radius (try 20-30px for buttons), add a subtle shadow, and use solid or gradient fills. This creates professional button designs instantly.

**Q: Can I convert text to shapes?**
A: Select text and use the "Convert to Shape" option. This allows full path editing of letterforms for custom typography designs.
