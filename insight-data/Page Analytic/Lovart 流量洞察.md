- **Paid Social** 和 **Display** 时长仅12-14秒，用户快速流失，建议审慎扩量；

## 各渠道主要负责团队和常见数据错误原因

用户数约等于 UV ，互动率是用户访问过程中触发总事件数≠转化率

|   |   |   |   |
|---|---|---|---|
|渠道|核心识别|主要负责团队|常见错误统计来源|
|Direct|(direct)/(none)|品牌/产品|app 跳转、隐私模式、UTM缺失|
|Organic Search|organic|SEO|一般不会被错误统计成其他<br><br>付费漏标、国内引擎异常|
|Paid Search|cpc/GCLID|SEM|标记错误、自动标记关闭|
|Referral|referral|外链/PR|社交误判、短链接丢来源|
|Paid Social|social/cpc|社媒广告|UTM乱、自然/付费混淆|
|Cross-network|Pmax/智能购物|全渠道广告|与Paid Search混淆，尤其是漏标 utm 或 utm 错标为 cpc|
|Organic Social|social|社媒运营|社媒特别喜欢用短链，短链跳转会丢referrer、归Referral|
|Unassigned|无匹配规则|全团队（规范）|UTM配置错误无法识别，比如投放中 utmsource 填写成 gg|
|Organic Video|video(organic)|视频内容|付费 视频漏标、丢来源|
|Paid Other|paid/其他付费|商务/小众投放|标记模糊，无法识别|
|Display|display/cpm|展示广告|误归Paid Search，本来utm 是 cpm 但编辑成了 cpc|
|Paid Video|video(cpc)|视频广告|归Organic Video|
|Email|email|邮件营销|无UTM→Direct|
|Organic Shopping|shopping(organic)|产品/SEO|付费误判自然|
|Affiliates|affiliate|联盟/商务|归Referral|
|Mobile Push|push|用户增长|无UTM→Direct|

不包含 Pmax 或 demandgen
