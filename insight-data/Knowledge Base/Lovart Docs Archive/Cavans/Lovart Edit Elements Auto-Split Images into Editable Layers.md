## Edit Element

Transform flat images into editable layers with Lovart's Edit Elements. Automatically extract subjects and backgrounds to adjust position, size, and layout instantly.

![Lovart Edit Elements: Auto-Split Images into Editable Layers](https://cdn.sanity.io/images/o11tm2qe/production/11990086076078e21c2cf45e1e7677248da4aa5c-1280x800.png)

Lovart Edit Elements: Auto-Split Images into Editable Layers

### What It Does

Edit Elements extracts your image into individual layers, allowing you to modify, adjust, and fine-tune each element. You can easily edit positioning, size, and other design properties.

### How To Use

1. **Access the Tool**
	- Select the element on the canvas you want to edit
	- Click **"Edit Elements"** in the top toolbar
2. **Move things around**
	- Your image is now separated into parts that you can move around.
	- Edit them to your liking and export.

### Quick Tips

- Combine multiple adjustments for refined results
- Undo (Ctrl+Z or Cmd+Z) if you need to revert changes
### Element Extraction Workflows

**Product Image Editing:**
1. Upload product photo
2. Click "Edit Elements"
3. AI splits into: product, background, shadows, reflections
4. Reposition product in scene
5. Adjust size and rotation
6. Reassemble for new composition

**Portrait Manipulation:**
1. Upload portrait photo
2. Apply Edit Elements
3. Extract: person, clothing, background
4. Change background to new scene

6. Create composite portrait

**Scene Reconstruction:**
1. Select scene with multiple objects
2. Extract individual elements
3. Rearrange composition

### Advanced Element Management

**Layer Organization:**
After extraction, elements are organized as separate layers. You can:
- Reorder layers for proper z-index
- Group related elements
- Lock elements to prevent accidental changes
- Hide/show elements for comparison

**Transform Operations:**
- Move: Drag elements to new positions
- Scale: Resize while maintaining aspect ratio
- Rotate: Rotate for different orientations
- Flip: Mirror elements horizontally or vertically

**Combining Elements:**
- Drag elements from different images
- Mix extracted elements with new designs
- Create unique compositions
- Build complex scenes from multiple sources

### Best Practices

**For Clean Extractions:**

**Quality Tips:**

### Troubleshooting

**Extraction Incomplete:**
- Try with different image
- Use Remove BG first for cleaner subjects
- Apply Remover to clean up edges
- Consider manual layer creation

**Elements Don't Separate Cleanly:**
- Some images have complex blending
- Use edge refinement tools
- Combine with other extraction tools
- May need manual masking

### FAQ

**Q: How many elements can be extracted?**
A: AI determines natural separations. Simple images may have 2-3 layers, complex scenes may have more.

**Q: Can I re-extract after initial split?**
A: Yes, you can reapply "Edit Elements" to any layer or the entire composition.

**Q: What's the difference between Edit Elements and Remove BG?**
A: Edit Elements splits image into multiple layers. Remove BG creates one transparent layer with background removed.

**Q: Can I undo element extraction?**
A: Yes, Cmd/Ctrl+Z reverts changes. Layers remain until you close the file.

**Q: Do extracted elements maintain quality?**
A: Yes, extracted elements maintain original resolution for maximum flexibility.
