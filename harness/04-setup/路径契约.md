# 三层目录架构 — 路径契约 v2

> 日期：2026-06-24
> 目的：将运行输出、线上只读拉取缓存、备份与 Git 重对象从 Obsidian vault 中分离，降低 Obsidian 与 iCloud 同步负担。
> 状态：目录骨架已建立；Obsidian exclude 已配置；默认不移动旧文件、不删除旧路径。

---

## 一、三层架构

| 层 | 目录 | 定位 | 内容 |
|---|------|------|------|
| **1-Project** | `MindRe/1-Project/` | 轻量源码层 | 文档、脚本、SOP、Skills、工作流定义、轻量报告 |
| **3-Resource** | `MindRe/3-Resource/` | 可复用资源层 | 大型数据集、Git object store、worktree、Knowledge Base |
| **运行层** | `~/MFlow Local Dev/`（兼容软链：`~/Documents/MFlow Local Dev`） | 运行产物层 | 输出、缓存、拉取结果、备份、日志、临时文件 |

### 核心原则

1. **1-Project 只放轻量源码**：文档、脚本、SOP、Skills、工作流定义
2. **3-Resource 放可复用但体量可能大的资源**：Git object store、worktree、Knowledge Base、大型数据集
3. **运行层放运行产物**：输出、缓存、拉取结果、备份、日志、临时文件
