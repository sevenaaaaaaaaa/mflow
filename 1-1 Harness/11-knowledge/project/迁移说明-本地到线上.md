## 四、Docker 配置

### 4.1 Dockerfile

```dockerfile
FROM python:3.11-slim

# 系统依赖
RUN apt-get update && apt-get install -y \
    nodejs npm curl jq git \
    && rm -rf /var/lib/apt/lists/*

# Sanity CLI
RUN npm install -g @sanity/cli

# Python 依赖
COPY requirements.txt .
RUN pip install -r requirements.txt

# 应用代码
COPY . /app
WORKDIR /app

# 环境变量
ENV LOVART_RESOURCE_ROOT=/app/vault
ENV LOVART_LOCAL_DEV_ROOT=/app/local-dev

# 数据目录
RUN mkdir -p /app/vault/1-3\ GenFlow/.pipeline \
    /app/vault/1-2\ Insight \
    /app/vault/1-4\ Dev

CMD ["python3", "-m", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

