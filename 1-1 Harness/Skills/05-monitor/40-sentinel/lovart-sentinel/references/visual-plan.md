# Lovart Sentinel 报告可视化方案

## 设计原则
- 每页一个核心信息，先看图表再看文字
- 图表类型按数据类型自动选择（趋势→折线、对比→并列柱、分布→饼图/雷达、层级→漏斗）
- 标注数据来源和时间，保证可追溯

## 图表工具推荐

| 图表 | 推荐工具 | 难度 |
|------|---------|------|
| KPI卡片 | HTML/CSS 或 Keynote/PowerPoint | 低 |
| 折线图 | Matplotlib / Chart.js / Mermaid | 低 |
| 柱状图 | Matplotlib / Google Sheets | 低 |
| 漏斗图 | Mermaid flowchart / HTML Canvas | 中 |
| 金字塔图 | HTML/CSS 或 ProcessOn | 低 |
| 世界地图 | Datawrapper / Flourish | 中 |
| 时间线 | Mermaid gantt / Timeline.js | 低 |
| 词云 | WordCloud (Python) / WordArt.com | 低 |
| 流程框 | Mermaid / Draw.io | 低 |

**建议优先级**：先用 Mermaid（代码生成，可直接嵌入 Markdown，易维护），再用 Matplotlib 补充数据图表，最后用 HTML/CSS 做定制排版。
