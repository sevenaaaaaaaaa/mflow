## The Chat-Generate Illustration Workflow

### Step 1 — Define the Illustration's Job

Illustrations serve different functions in different contexts. Identify yours before prompting:

- **Conceptual metaphor**: Represents an abstract idea visually — "data overload" as a person drowning in floating numbers, "growth" as a seedling breaking through pavement.
- **Spot illustration**: A small, focused visual that breaks up text — an icon-like scene, a character in a specific action, a single object rendered with personality.
- **Narrative scene**: A full illustration that tells a story — a moment in time, a before-and-after, a character journey.
- **Diagrammatic illustration**: Explains a process or relationship — simplified, color-coded, labeled.

The job determines the composition. A conceptual metaphor needs a strong central image with negative space around it. A narrative scene needs depth, environment, and human presence.

### Step 2 — Specify Style Before Subject

The most common illustration prompt mistake: describing the subject in detail but leaving the style vague. "Draw a person working at a computer" — the agent defaults to a generic semi-realistic style that lacks personality. Style determines whether the output feels like a New Yorker cartoon, a tech-company blog header, or a children's book.

```
Editorial illustration for a blog post about remote work burnout. 
Style: flat vector illustration with limited color palette — 5 colors maximum. 
Think "The Atlantic" or "Wired" magazine editorial style. 
Clean lines, geometric simplification, no gradients, no photorealism. 
Color palette: deep navy (#1B2A4A), coral (#FF6B6B), warm cream (#FFF3E0), muted teal (#4ECDC4), charcoal (#2D3436).

Subject: A person sitting at a home desk, but their body is made of melting clock faces 
(Salvador Dali reference). The desk is floating in an abstract void. 
Around them, notification icons (bell, envelope, chat bubble) orbit like planets — 
some close, some distant. The person's posture is hunched, hands on temples. 
The visual metaphor: time is melting while notifications pull attention in every direction.
```

This prompt specifies style first, then subject. The agent now has a visual language to work within — flat vector, geometric, 5-color palette — before it starts composing the scene. The result will look coherent and intentional, not like a default AI art output.

### Step 3 — Iterate on Composition

Your first prompt establishes the concept and style. Your second prompt refines composition:

```
Great concept. Three composition adjustments:
1. Make the figure larger — it should occupy roughly 40% of the frame, not 20%.
2. Move the orbiting notification icons into a more chaotic, overlapping arrangement — 
   they should feel oppressive, not orderly.
3. Add more negative space on the left side of the frame for headline text placement.
```

Treat the agent like an illustrator you are art-directing. You approved the concept sketch. Now you are giving notes on the final comp. Specific, directional, one aspect at a time.

### Step 4 — Generate Multi-Platform Versions

An illustration commissioned for a blog post might also work as a social media graphic, a newsletter header, and a presentation slide. Generate the versions:

```
Create three format variants from this illustration:
1. HORIZONTAL BANNER: 1200x628, landscape crop. Focus on the figure and the closest orbiting notifications. 
   Leave the right third clean for text overlay.
2. SQUARE SOCIAL: 1080x1080, centered composition. Tighten on the figure and the clock-face metaphor. 
   Fewer notification icons — keep the most impactful three.
3. VERTICAL STORY: 1080x1920, portrait composition. Stack the figure at the bottom with the 
   notification orbits spreading upward. Leave the top third for headline text.
Same style rules — same 5-color palette, same flat vector treatment.
```

This is where AI illustration goes from "nice image" to "asset system." You are not just producing one illustration. You are producing a visual identity for an entire content piece, across every platform where it will appear.

## Frequently Asked Questions

**Can the agent replicate a specific illustrator's style?**

The agent can interpret style references descriptively ("in the style of flat vector editorial illustration, like The Atlantic"). It cannot replicate a specific living artist's work identically — nor should it, for ethical and copyright reasons. Use style descriptors to communicate the aesthetic direction, not to clone someone's portfolio.

**How detailed should my illustration prompt be?**

A productive illustration prompt has four components: style (visual language), subject (what is depicted), composition (how it is arranged), and context (where it will be used). All four matter. The style is the most commonly neglected — and the most impactful when specified.

**Can I use the same illustration style across multiple articles?**

Absolutely. This is the purpose of the illustration style library. Define your style once, save it, and reuse the style rules with new subjects for each piece of content. This creates visual brand consistency without requiring you to restate the entire style brief every time.

**What if my illustration needs text incorporated into the design?**

Specify text placement in your prompt: "Include the headline 'The Future of Remote Work' in bold sans-serif, navy, centered in the upper third, with adequate contrast against the background." The agent will compose the illustration around the text, not paste text on top as an afterthought.

**Can the agent create illustrated characters that remain consistent across images?**

Yes. If you need a recurring character (a mascot, a brand avatar), generate the character once with a very specific description, then reference that description in subsequent prompts: "Same character as before — the woman with round glasses, wavy brown hair, yellow sweater. Now show her gardening." The agent maintains character continuity across generations when given specific descriptions.

**What export formats are supported?**

PNG (with transparency for illustrations that need to float over backgrounds), JPG (for web use), SVG (scalable vector — request specifically if needed for print), and PDF (for print-ready output). Specify the desired format in your export prompt.
