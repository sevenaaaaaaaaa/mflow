# 目录架构 — 路径契约 v3

> 日期：2026-10-14（v3：项目与任何外部笔记库彻底解耦，所有路径相对仓库根 `$MFLOW_ROOT`）
> 定义：`dev/automation/local-dev-env.sh`（环境变量的唯一来源）

---

## 一、两层架构

| 层 | 目录 | 定位 | 内容 |
|---|------|------|------|
| **仓库** | `$MFLOW_ROOT`（本 git 仓库） | 源码 + 项目数据 | 代码、Skills、规则、SOP；gitignored 的项目数据（`insight-data/`、`genflow/`、`harness/11-knowledge/`、`ops/`） |
| **运行层** | `$MFLOW_LOCAL_DEV_ROOT`（默认 `~/Documents/MFlow Local Dev`） | 运行产物 | 输出、缓存、线上只读拉取、备份、日志、临时文件、Git 重对象 |

### 核心原则

1. **代码与可复用资产进仓库**：公开部分进 GitHub；项目/品牌数据放 gitignored 目录，由 `deploy/sync.sh` 同步到服务器。
2. **运行产物进运行层**：输出、缓存、拉取结果、备份、日志不进仓库。
3. **禁止硬编码绝对路径**：一律用下面的环境变量或仓库相对路径。

---

## 二、环境变量

```bash
export MFLOW_ROOT="<本仓库>"                                   # 默认由脚本自身位置推导
export MFLOW_LOCAL_DEV_ROOT="$HOME/Documents/MFlow Local Dev"
export MFLOW_RESOURCE_ROOT="$MFLOW_LOCAL_DEV_ROOT"             # 大型可复用资源（数据集、Git object store）
export MFLOW_LOCAL_GIT_DIR="$MFLOW_LOCAL_DEV_ROOT/Git"
```

## 三、目录结构

```text
$MFLOW_ROOT/
├── harness/          ← Skills、规则、SOP（11-knowledge/ 为 gitignored 知识库）
├── insight-data/     ← 情报/知识数据（gitignored）
├── genflow/          ← 内容生产数据（gitignored）
├── ops/              ← 使用工具时的脚本/批次/品牌资料（gitignored，ops/brands/<brand>/）
├── run/              ← 运行时状态（大部分 gitignored）
└── dev/              ← 代码、自动化

$MFLOW_LOCAL_DEV_ROOT/
├── Output/
│   ├── Page Gen/_pull/
│   ├── automation-reports/
│   ├── composite-v2-audit/
│   ├── quality-audits/
│   └── Data Ingestion/
├── Backup/
├── Sanity/production-pulls/
├── WordPress/readonly-pulls/
├── Git/{object-stores,worktrees}/
├── Logs/
└── Temp/
```

## 四、职责边界

| 内容 | 位置 | 说明 |
|------|------|------|
| 自动化运行报告 | `$MFLOW_LOCAL_DEV_ROOT/Output/automation-reports/` | Notion 同步只读摘要 |
| Sanity production export | `$MFLOW_LOCAL_DEV_ROOT/Output/composite-v2-audit/` | 线上只读缓存 |
| Content health audit | `$MFLOW_LOCAL_DEV_ROOT/Output/quality-audits/` | 摘要可回写 `insight-data/` |
| Trident 原始 JSON | `$MFLOW_LOCAL_DEV_ROOT/Output/Data Ingestion/` | 大型快照外置 |
| Knowledge Base | `insight-data/Knowledge Base/` | 知识资产 |
| SEO 报告 | `insight-data/Trident Insights/` | 知识资产 |
| WordPress 只读缓存 | `$MFLOW_LOCAL_DEV_ROOT/WordPress/readonly-pulls/` | 不发布、不写线上 |
| 品牌专属资料 | `ops/brands/<brand>/` | 不进 GitHub，随 `deploy/sync.sh` 到服务器 |
