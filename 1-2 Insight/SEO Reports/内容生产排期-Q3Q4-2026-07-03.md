## 五、协同规则

1. **数据共享**：所有 Agent 读同一份 GSC 数据 + Sanity schema + AGENTS.md
2. **风格统一**：每个 Agent 必须先阅读 `lovart-complete-guide` Skill（Cursor 已部署 SSOT）
3. **质量门禁**：字数 ≥2,000 / 第一人称 ≥10 处 / 反向推荐 ≥1 / 工具对比 ≥3 / 真实数据 / 无 AI-slop
4. **评审**：Agent A 终审其他 Agent 周交付内容
5. **合并发布**：每周末 Agent A 批量 patch 到 Sanity + IndexNow
6. **冲突解决**：分类归属 → Agent A 决定；事实冲突 → GSC/Sanity 原始数据为准
