## 五、新建 vs 改造决策矩阵

### 5.1 什么时候该新建？

| 场景 | 决策 | 理由 |
|------|------|------|
| 现有 Blog 主题完全不沾边 | **新建** | 改造反而稀释 |
| 现有 Blog 内容陈旧（>1年） | **新建** | 改造价值低 |
| 中文版严重缺失 | **新建** | 78篇中文已发，但多语言版本不足 |
| 关键词是新词（如 Sora 2） | **新建** | 历史页面无相关性 |
| 用户搜索词是新组合 | **新建** | 必须新建独立页面 |

### 5.2 什么时候该改造？

| 场景 | 决策 | 理由 |
|------|------|------|
| 现有 Blog 排名 4-10 但 0 点击 | **改造** | 已有关键词权重 |
| 现有 Blog 主题沾边但关键词密度低 | **改造** | Meta 改写立竿见影 |
| 现有 Tools 页面 CTR < 1% | **改造** | Title 优化即可 |
| 现有页面 1000+ 曝光 | **改造** | 流量基础已建立 |

### 5.3 避免雷同的策略

| 风险 | 解决 |
|------|------|
| **标题雷同** | 差异化公式：核心词 + 痛点 + 解决方案 |
| **内容雷同** | 每个页面加 1-2 个独有元素（特定行业/特定案例/特定对比） |
| **关键词堆砌** | 控制 H1/H2 关键词密度 < 3% |
| **重复 FAQ** | 复用框架但每个页面的 FAQ 问题不同 |

### 5.4 差异化公式

```
Page Title = 核心关键词 + 限定词 + 价值主张

例:
- "AI Video Generator for E-commerce Ads"
- "AI Video Generator for YouTube Shorts"
- "AI Video Generator from Text — Free"
- "AI Video Generator vs Runway: 2026"
```

## 六、改造执行 SOP（标准化）

### 6.1 单页改造流程（30分钟/页）

```bash
# 1. 拉取该页 GSC 数据
python3 fetch_gsc.py --page /blog/{slug}

# 2. 读取源文件
cat "/Users/seveno/Documents/Lovart Local Dev/Output/Lovart-Blog-Pipeline/Lovart-Blogs/01-Drafts/{slug}.md"

# 3. 应用 patch 改写
- Title: 加入主关键词
- H1: 优化结构
- Meta Description: 加入 CTA + 关键词
- 添加 1-2 段长尾段落
- 添加 2-3 个 FAQ
- 添加 Internal Links

# 4. 提交 GSC 重新索引
python3 indexnow_submit.py --url https://www.lovart.ai/blog/{slug}
```

### 6.2 批量改造（按主题）

```bash
# 1. 提取该主题所有零点击页面
python3 extract_zero_click.py --theme video --output video_pages.json

# 2. 批量改写 Title（仅 Title）
python3 batch_rewrite_titles.py --input video_pages.json \
  --template "AI Video Generator: {original_topic} | Lovart"

# 3. 验证
python3 verify_titles.py --min-len 50 --max-len 70

# 4. 提交
python3 indexnow_batch.py --urls video_pages.json
```
