# 批量生成最佳实践

[图片 1 占位符 — 用户场景]

一次只创建一个设计无法规模化。无论你是为包含 500 个 SKU 的目录生成产品图片，为 12 个市场制作本地化广告变体，还是为某个营销活动创建 A/B 测试创意，Lovart 的**批量生成引擎**都能将数小时的重复设计工作转化为几分钟的结构化自动化流程。

本指南涵盖了从数据准备到质量控制的完整批量生成工作流，并融入了 Lovart 高级用户（每月生成 10,000+ 个设计）经过实战检验的实践。

## 何时使用批量生成

[图片 2 占位符 — 概念图]

当你需要以下内容时，批量生成是理想之选：

- **一个设计的多个变体** — 相同的布局，不同的文本/图片（例如，本地化的社交媒体帖子、特定产品的广告）
- **大规模应用模板** — 将一个模板应用于数百行数据（例如，整个目录的产品列表图片）
- **多格式输出** — 一个设计概念同时导出为 15 种特定于平台的尺寸
- **A/B 测试创意** — 为广告平台测试生成 50 多个设计变体
- **季节性更新** — 使用新颜色、图像或文案更新整个营销活动的素材

批量生成**不**适用于：
- 一次性、高度定制的设计（请使用标准生成器）
- 每个输出都需要复杂、独特布局的设计（批量处理最适合结构一致性）
- 每个输出在批准前都需要大量人工审查的项目（批量处理的 ROI 会降低）

## 第 1 步：数据准备

批量输出的质量几乎完全取决于你的输入数据。垃圾进，垃圾出，这一点在 AI 生成中加倍适用。

### CSV 结构

Lovart 的批量引擎接受具有以下结构的 CSV 文件：

```csv
sku,product_name,headline,description,image_url,category,brand_color
SKU001,Ergonomic Desk Chair,"Work in Comfort","Premium ergonomic chair with lumbar support",https://cdn.example.com/chair1.jpg,Office,blue
SKU002,Standing Desk Pro,"Stand Tall","Electric standing desk with memory presets",https://cdn.example.com/desk1.jpg,Office,green
SKU003,Monitor Arm,"Free Your Desk","Articulating monitor arm for 17-32 screens",https://cdn.example.com/arm1.jpg,Accessories,black
```

### 列映射

在**批量生成器 > 列映射**中将 CSV 列映射到模板变量：

| CSV 列 | 模板变量 | 类型 |
|-----------|-------------------|------|
| `product_name` | `{{product_name}}` | 文本 |
| `headline` | `{{headline}}` | 文本（标题） |
| `description` | `{{description}}` | 文本（正文） |
| `image_url` | `{{product_image}}` | 图片 URL |
| `category` | `{{category}}` | 类别选择器 |
| `brand_color` | `{{accent_color}}` | 颜色覆盖 |

### 数据质量检查清单

在运行任何批量作业之前，请验证你的数据：

- [ ] **所有必需变量均已填充** — 空单元格会在设计中变成空白区域
- [ ] **文本在字符限制内** — Lovart 会截断文本，但不会智能地重新排版。检查每个平台的标题最大长度。
- [ ] **图片 URL 可访问** ��� Lovart 必须能够获取图片。受保护的 CDN 需要将 IP 范围加入白名单（请联系支持）。
- [ ] **文件名中无特殊字符** — 避免在输出文件名中使用表情符号、非拉丁字符或特殊符号
- [ ] **格式一致** — 所有价格使用相同的小数位数，所有日期使用相同的格式，所有 URL 使用相同的协议（HTTPS）

**专业提示：** 为每个 CSV 行添加一个 `batch_id` 列。这样可以轻松追踪每个输出是由哪个批次生成的——这对于调试和迭代非常宝贵。

## 第 2 步：模板准备

### 命名模板变量

在任何模板文本层中使用 Lovart 的变量语法：

```
{{variable_name}}
```

变量回退提供了安全网——如果 CSV 单元格为空，则会显示回退文本：

```
{{headline:默认标题文本}}
{{description:无可用描述}}
```

### 条件可见性

你可以根据变量是否被填充来有条件地显示或隐藏模板层：

```
图层："促销徽章"
条件：{{discount_percentage}} != ""
行为：如果 discount_percentage 为空，则完全隐藏促销徽章。
```

这可以防止在没有折扣数据时显示“促销：%”的设计。

### 动态颜色映射

将 CSV 值映射到模板中的特定颜色：

```csv
category,accent_color
Office,#2563EB
Gaming,#DC2626
Wellness,#059669
```

在模板编辑器中，将类别变量链接到颜色查找表。当批量处理遇到“Gaming”类别时，强调色会自动变为红色，无需任何手动干预。

## 第 3 步：批量配置

### 生成模式

**顺序模式（默认）：**
逐行处理。速度较慢但更稳定。推荐用于：
- 小批量（少于 100 项）
- 包含 AI 生成图像的复杂模板
- 首次批量运行（在扩展之前先用顺序模式测试）

**并行模式：**
同时处理多行。速度最高可提升 10 倍，但每秒消耗更多 API 积分。推荐用于：
- 大批量（100 项以上）
- 简单模板（仅文本替换，无 AI 图像生成）
- 时间敏感的生产运行

在**批量生成器 > 设置 > 处理模式**中设置模式。

### 批量大小

Lovart 分批处理：

- **免费计划：** 每批最多 10 项
- **入门版（$19/月）：** 每批最多 50 项
- **专业版（$49/月）：** 每批最多 250 项
- **商业版（$99/月）：** 每批最多 1,000 项
- **企业版（$149/月）：** 每批最多 10,000 项

对于超出计划限制的批次，请将 CSV 拆分为多个文件并顺序运行。或者使用 API 进行编程式批处理：

```python
import lovart
import pandas as pd

# 将大型 CSV 拆分为符合计划限制的块
df = pd.read_csv("catalog_5000_items.csv")
chunk_size = 250  # 专业版计划��制

for i, chunk in enumerate(range(0, len(df), chunk_size)):
    batch = df[chunk:chunk + chunk_size]
    batch.to_csv(f"batch_{i}.csv", index=False)
    lovart.generate_batch(
        template_id="tmpl_xyz",
        csv_file=f"batch_{i}.csv",
        brand_kit_id="bk_abc",
        output_format="png"
    )
```

### 输出配置

**命名约定：**
使用模板变量定义输出文件名：

```
{{sku}}_{{category}}_{{product_name_slug}}.png
→ SKU001_Office_Ergonomic_Desk_Chair.png
```

**格式选项：**
- **图像：** PNG（无损）、JPEG（质量 60-100）、WebP（针对网络优化）、SVG（矢量，支持有限）
- **多格式导出：** 同时生成 PNG + WebP 用于网络使用
- **尺寸预设：** 应用命名的尺寸预设（例如，“Instagram 帖子”= 1080x1080）
- **多尺寸导出：** 从单个批次行生成 5 种以上尺寸

**输出组织：**
选择：
- **扁平输出：** 所有文件在一个文件夹中
- **分类输出：** 按 CSV 列划分子文件夹（例如，`/Office/`、`/Gaming/`、`/Wellness/`）
- **基于行的输出：** 每个 CSV 行都有自己的文件夹（当每行生成多个尺寸时很有用）

## 第 4 步：质量控制工作流

[图片 3 占位符 — 真实 UI 截图]

### 自动化 QC

Lovart 的批量引擎包含自动化质量检查：

**生成前检查：**
- 缺少必需变量
- 将溢出模板容器的文本
- 返回 4xx/5xx 错误的图片 URL
- 违反品牌无障碍配置文件的颜色对比度

**生成后检查：**
- 图像渲染错误（空白输出、损坏文件）
- 文本渲染问题（字体回退伪影、文本被裁剪）
- Logo 放置违规（清晰空间被侵占）
- 品牌合规性偏差（检测到未批准的颜色）

在**批量生成器 > 设置 > 质量控制**中配置 QC 严格程度：
- **宽松：** 对问题发出警告，仍继续生成
- **标准（推荐）：** 跳过有问题的行，继续批量处理
- **严格：** 在第一次违规时停止批量处理

### 人工审查抽样

对于审查每个输出不切实际的大批量，设置审查抽样策略：

- **随机抽样：** 随机选择 10% 的输出进行审查
- **分层抽样：** 从每个类别中审查 2 个（确保覆盖各个细分市场）
- **边缘案例审查：** 审查 5 个最短标题 + 5 个最长标题（文本溢出风险）
- **基于置信度的审查：** 审查 Lovart 内部置信度分数低于阈值的输出

Lovart 的批量报告会标记高风险输出（低置信度、检测到异常）以供优先审查。

### 迭代优化

批量生成很少在第一次运行时就能完美完成。标准工作流：

1. **试点运行** — 处理 10-20 行，100% 审查输出，识别问题模式
2. **优化** — 修复模板问题（溢出、对比度、布局），更新 CSV 数据，调整 QC 设置
3. **全面运行** — 使用优化后的设置处理整个批次
4. **抽样审查** — 应用你的审查抽样策略
5. **补救运行** — 使用更正后的数据或模板修复重新处理失败/跳过的行

**专业提示：** 为你的批量生成工作流添加书签。常见模式（例如，“产品目录刷新”或“月度社交媒体批量处理”）应保存为可重复使用的批量预设，其中包含预配置的模板、列映射和 QC 规则。

## 高级：嵌套批量生成

对于复杂的生产流水线，Lovart 支持嵌套批次——其中一个批次的输出成为另一个批次的输入。

**示例：电子商务产品发布**

```
批次 1：生成产品列表图片（247 个 SKU，主模板）
   ↓
批次 2：生成社交媒体变体（247 × 4 个平台 = 988 个输出，使用批次 1 的图片作为输入）
   ↓
批次 3：生成广告创意变体（前 20 个 SKU × 5 种广告格式 = 100 个输出，使用批次 2 的选择）
   ↓
批次 4：生成电子邮件活动素材（精选 10 个产品，新闻通讯模板）
```

嵌套批次可以手动链接，也可以通过 Lovart API 使用 Webhook 触发器自动执行。

## 常见陷阱与解决方案

| 问题 | 原因 | 解决方案 |
|---------|-------|----------|
| 输出质量不一致 | AI 在图像生成中的随机性 | 锁定种子值以获得可重复的结果；在生成设置中增加 `quality` 参数 |
| 大批量时的速率限制 | 在并行模式下超过 API 速率限制 | 减少并行工作线程数；在 API 脚本中实现指数退避 |
| 小模板中的文本溢出 | 变量内容比模板预期的要长 | 使��文本自动调整大小；为标题设置 `truncate: true` 并添加省略号 |
| 品牌颜色意外偏移 | CSV 颜色值覆盖了品牌调色板 | 在模板设置中锁定品牌调色板；从 CSV 映射中移除 `accent_color` |
| 输出中缺少图片 | 图片 URL 损坏或受保护 | 使用简单脚本预先验证所有 URL；将图片上传到 Lovart 的 CDN 用于批量运行 |
| 积分在批次中途耗尽 | 积分估算不佳 | 在运行前使用批量估算工具；设置积分限制警报 |
