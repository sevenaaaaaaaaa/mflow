## 环比总则（所有频次、所有维度）

**任何 SEO 报告、任何维度都必须有环比。** 用户说「5 月月报」→ 默认 **5 月 vs 4 月**；「5 月周报」→ 该周 vs **紧邻上一同等长度周期**（可跨月落在 4 月末）。

| 频次 | 当前周期 | 环比基准 |
|------|----------|----------|
| 日报 | 昨日 | 前日 |
| 自然周报 | 上周一～周日 | 上上周同期 |
| 复盘周报 | 上周三～本周二 | 上上周三～上周二 |
| 月报 | 报告月全月 | 上一自然月 |
| 季报 | 报告季 | 上一自然季 |
| 年报 | 报告年 | 上一自然年 |

## 通用质量标准（所有频次）

| 标准 | 要求 |
|------|------|
| 板块完整 | 所有报告含 7 大板块：核心洞察 + 关键词 + GA4 + 竞品词 + 页面 + 地区 + TODO |
| 环比全覆盖 | **所有维度、所有频次**必须有环比（见上表）；不允许仅当期数据 |
| 数据完整 | GSC 关键词：**点击+曝光+CTR** 三维度齐全 |
| 关键词环比 | 关键词相关表格须 **点击环比+曝光环比+CTR 环比**（绝对值+百分比） |
| 细分占比 | Top N / 地区 / 目录 / 品牌拆分：**点击占比+曝光占比** |
| 全维度双期 | 对比表须含 **当期+环比期** 两列完整点击/曝光/CTR，不可只有点击 |
| 品牌词过筛 | 使用扩展版 regex（25+ pattern），lova/love/art 所有拼写变体+多语言均视为品牌词 |
| 洞察深度 | 每节末尾 **💡**（**问题** + **根源/积极信号** + **缓解**），不可只罗列表格 |
| 正面视角 | 核心洞察每条配建设性/积极视角；月报须 **首页+品牌词** vs **其他页面+非品牌词** 分流 |
| 月报 OKR | OKR 月达成看板为 **§二**（紧跟 §一 核心洞察之后） |
| 月报 movers | §4.4–4.7：点击增/跌、曝光增、CTR 变化 Top15（不可只看点击分层） |
| 月报地区 | 每大区 **mini 月报** + Top**15** 词（不可仅 Top5 两张表） |
| 年均备注 | 月报各节末 **📊 年均对比**（2026 YTD 月均 vs 2025 月均） |
| 竞品词 | 用真实 265 词库匹配，不用硬编码假词库 |
| 页面分类 | 首页独立列出，不可混入 "other"；canvas/login 功能页独立 |
| 地区完整 | 周报：每区 Top5 品牌/非品牌 + GA4 + Top5 页面；**月报：每区 mini 月报 + Top15 词 + Top10 页面** |
| 截断检查 | 写入后验证末尾包含最终章节 |
| OKR | 报告置顶 OKR 看板；**跑前须向用户确认是否更新目标**（默认 2026-05 版） |
| 地区定义 | 北美=US+CA+UK+AU+NZ，大中华=CN+HK+TW+MO，日本=JP |

```

- GSC 单日拉取（rowLimit=200）
```

## 常见问题

**Q: 各频次报告的差异是什么？**
A: 结构统一（全部 7 板块），差异在时间维度和专属特性：日报有 7 日趋势、周报有 4 周趋势、月报有年均对比+多语言+收录、季报有 3 月逐月对比、年报有 12 月逐月曲线。

**Q: Bing 能按月拆分吗？**
A: 能（2026-06 修正）。`GetQueryStats`/`GetPageStats` 返回的 `QueryStats` 记录含 `Date`（每周 top~100 词/页）+ `AvgImpressionPosition`，按 (月,词/页) 聚合即得月度关键词/页面（clicks/impr 求和、曝光加权词位、自算 CTR、可环比）；`GetRankAndTrafficStats` 提供站点级日序列。`bing_fetch.py` 输出 `keywords_monthly`/`pages_monthly`/`traffic_monthly`，已并入月报 §四/§九/§十。限制：每周仅 top~100 词、`AvgClickPosition` 不可用、**无 country 维度**（分地区仅 Google）。

**Q: 竞品词为什么用子串匹配？**
A: GSC 关键词是用户真实搜索词（如 `free ai logo generator online`），子串匹配才能捕获真实覆盖面。

**Q: 收录数据为什么是 ~9K/20K？**
A: 主口径是「全月有搜索曝光的 URL 数」÷ 语料库 20k。禁止用 page API 前 1000 条 ÷ sitemap submitted（会得到固定 1.43%）。

**Q: OKR 注册/付费数据可靠吗？**
A: 不可靠，仅作为趋势参考。标注为「估算值（UV × 目标转化率）」。
