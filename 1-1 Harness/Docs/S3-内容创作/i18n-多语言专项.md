# i18n 多语言专项 — 入口

> **定位**：全链路多语言内容策略专项，涵盖 SEO 多语言、内容重写规则、翻译工作流、语言质量门禁，覆盖 Sanity Studio 全部 10 个语言。

---

## 目标

确保 Lovart 的所有内容（Pages、Blog、Features、Tools）在 10 个语言市场达到本地化质量标准。核心原则：**多语言是重写不是翻译**——SEO 关键词本地化，用户痛点本地化，语气本土化。

---

## 体系架构

```
EN SSOT（英文原创）
    ↓
Sentinel i18n 情报（GSC 多语言查询数据）
    ↓
翻译管线 A: Python（MiMo API → Markdown Blog 翻译）
翻译管线 B: Node.js（Glossary → Sanity Studio JSON 页面）
    ↓
质量门禁: L1 结构预检 → L1b Anti-Slop → L5 i18n 检查
    ↓
发布 → 跨语言一致性验证
```
