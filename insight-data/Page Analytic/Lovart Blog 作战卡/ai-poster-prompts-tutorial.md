# 作战卡：ai-poster-prompts-tutorial

## SERP 证据卡

**主 query：** ai poster prompts tutorial
**次级 query：** best ai poster prompts / ai poster design prompts / how to write ai poster prompts

**当前 GSC 信号（最近 28d）：** 曝光 6,106 / 点击 213 / 排名 5.7

**SERP 前排 3-5 结果：**
1. designwiz.com/blog/120-best-ai-poster-prompts — 120 条 prompt 清单。强：量大。弱：只有 prompt 示例，没有方法论
2. a1.art/prompts/poster — 平台自己的 prompt 集合页。强：工具集成。弱：导购性质
3. pixexact.com/blog/how-to-create-a-poster-with-ai — 完整教程（prompt→生成→导出）。强：流程完整。弱：绑自家工具
4. letsenhance.io/blog/article/ai-text-prompt-guide — 通用 prompt 工程指南。强：底层原理。弱：不专于 poster
5. lettercrafted.com/ai-art-prompts-for-posters — 50 条 prompt + 公式 + 排版建议。强：有设计理念。弱：偏艺术

**共同套路：**
- 绝大多数是 prompt 清单贴，贴完 50-120 条 prompt 就结束
- 教程类绑自家工具，独立性不够
- 没有人区分「海报的用途决定 prompt 结构」—— 活动海报、产品海报、品牌海报、社交媒体海报的 prompt 写法完全不同

**缺口：**
- SERP 上没有任何文章从「海报类型 × prompt 结构 × 工具匹配」三维交叉的角度写
- 「如何在 Lovart 里用 MCoT/Canvas 做海报设计」是唯一空缺

**Lovart 切入角度：**
**"写好 AI 海报 prompt 的秘密不是更好的形容词，而是理解海报的 job-to-be-done。"** 按四个核心用途（活动/产品/品牌/社交）各给一套 prompt 框架 + Lovart 工作流示范。
