## 二、分流规则（所有 40 行 + 30 词统一按此路由）

```
有排名没点击 → 改标题/改开头（跑题要紧类优先）        → TDK 批修车道
有页面无排名 → 改页+内链（对比表/步骤/FAQ 结构补齐）  → 改页车道
未布局       → 建页（先查 content-inventory 防重复）  → 建页车道
刚 10        → 推前 3（内链 hub + 外链 + 内容刷新）   → 推前车道
被竞品超越   → 整页改写 + 竞品外链来源 3-5 个         → 改页车道（重量级）
```

多语言词路由：ja → 对接《日语SEO流量倍增-冲刺计划》矩阵；ru/pt/fr/zh → 对应语言页增量（先确认已有承接页再决定改/建）。
