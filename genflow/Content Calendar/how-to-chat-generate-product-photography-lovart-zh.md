# 如何通过聊天生成产品摄影 — Lovart Agent 工作流程

[图片 1 占位符 — 人物场景]

你的产品很好。你的照片不行。你知道这一点，因为你的转化率告诉了你——访客进入你的产品页面，浏览三张图片，然后跳出。他们没有加入购物车。他们没有开始结账。他们看着你那在皱巴巴床单上拍摄、光线昏暗的咖啡杯，再看看价格，心里一算，觉得不值。

你不需要一个摄影棚。你需要的是一个能将手机快照转化为能促进销售的产品图片的工作流程。下面就是具体操作方法，只需与一个 AI agent 聊天即可。

## 简化版产品摄影技术栈

[图片 2 占位符 — 概念图]

传统产品摄影需要：

- 适合近摄的相机机身和镜头（800-2000 美元）
- 持续光源或闪光灯（200-1000 美元）
- 背景系统和表面材料（100-500 美元）
- 用于保持稳定性的三脚架（100-300 美元）
- 用于后期处理的 Lightroom 或 Capture One（120-240 美元/年）
- 掌握光圈、快门速度、ISO、白平衡和色彩管理知识

总投入：设备 1300-4000 美元，外加数月的学习时间——而这一切都是为了拍摄可能随季节变化的产品。

AI 辅助替代方案需要：

- 你的智能手机相机
- 一面白墙或一张干净的桌子
- Lovart agent
- 用文字描述场景的能力

总投入：你已经拥有的设备，加上一个价格与流媒体服务相当的订阅。

## 完整的产品摄影工作流程

### 第一阶段 — 拍摄源图像

这一步很重要。Agent 可以增强，但不能起死回生。一张光线差、失焦的源图像，只会产生一张光线差、失焦但背景更漂亮的结果。

源照片的拍摄指南：

- **自然窗光**：将产品放在窗户附近。用薄纱窗帘柔化直射阳光。阴���是理想选择——光线柔和均匀。
- **纯色背景**：一面白墙、一张海报板、一个干净的桌面。背景越简单，agent 就越容易分离你的产品。
- **填满画面**：你的产品应占据图像的约 60-80%。在边缘留出一些空间供 agent 处理。
- **在视线水平或略高处拍摄**：这是最自然的产品观看角度。除非你想要戏剧性的、英雄式的角度，否则避免从下往上拍摄。
- **拍摄多个角度**：正面、四分之三侧面、侧面、细节特写、包装图。你需要所有这些来构建一个完整的产品图库。

### 第二阶段 — 导入并描述

将你的源图像上传给 agent。然后描述你想要的最终图像，而不是你拍摄的照片。Agent 需要知道目的地，而不是起点。

**蜡烛产品的示例提示词**：

> "将我上传照片中的这支蜡烛放在一个现代木制床头柜上。夜晚氛围——画外暖色台灯光线，旁边放着一本读了一半的书，柔和的阴影。舒适、高端、生活方式产品摄影。蜡烛应该是构图中明确的主角。周围留一点空间以便裁剪。"

Agent 会分析你的源图像，识别你的产品，并将其放入所描述的场景中，同时尽��能匹配光线方向、比例和透视。

### 第三阶段 — 优化输出

第一次结果通常能达到 70-85% 的效果。常见的优化要求：

- **光线不匹配**："蜡烛上的光线感觉比温暖的夜晚场景要冷——调暖一些，匹配黄金时刻的色调。"
- **比例问题**："蜡烛相对于床头柜看起来太小了——将其尺寸增大 30% 左右。"
- **构图调整**："在左侧展示更多书本，并添加一副阅读眼镜。"
- **背景细节**："将床头柜后面的白墙替换为有纹理的壁纸——柔和的米色，亚麻质感。"
- **产品准确性**："蜡烛上的标签缺少金箔细节——确保标签可见且清晰可读。"

反复迭代，直到输出符合你的标准。通常需要两到三轮优化才能得到可投入生产的图像。不要满足于初稿，但也不要为了追求完美而进行 15 轮迭代——在某个点上，图像已经足够好到可以销售产品，额外的调整收益会递减。

### 第四阶段 — 为图库生成变体

一个完整的产品页面需要不止一张图片。从你的一张源照片中，生成：

- **白色背景主图**："同一支蜡烛，干净的白色背景，影棚灯光，仅产品，无道具。"
- **生活场景图**："同一支蜡烛，早晨厨房场景，早餐桌上有咖啡和糕点，柔和的自然光。"
- **细节特写**："蜡烛标签和蜡质纹理的极端特写，浅景深，暖色光线。"
- **比例参考图**："同一支蜡烛，握在手中以显示大小——自然、不做作、日光。"
- **包装图**：如果你销售礼品套装，"同一支蜡烛，放在礼品盒里，衬有薄纸，开箱时刻，俯拍平铺图。"

一张源照片，五个提示词，五张图片。十分钟的提示词输入取代了半天的拍摄工作。

### 第五阶段 — 为你的平台导出

Shopify 建议产品图片使用 2048x2048 像素（支持缩放）。Amazon 要求最长边至少 1000 像素，纯白色背景（RGB 255,255,255），产品至少占据画面的 85%。Etsy 偏好列表图片的最短边为 2000 像素。

导出时指定你的目标平台。当你指明目的地时，agent 会处理分辨率、宽高比和背景要求（例如 Amazon 的纯白规定）。

## 常见问题解答

**AI 会改变我产品的实际外观吗？**

Agent 会将你上传的产品图像放入生成的场景中。它应该保留你产品的实际外观——颜色、形状、标签细节。如果输出歪曲了你的产品，请使用"保持产品与我原始照片中的外观完全一致——不要改变其颜色或形状"进行优化。准确性对于减少退货至关重要。

**我可以在不上传源图像的情况下生成产品照片吗？**

可以，你可以提示 agent 仅根据描述生成产品。然而，这对电商来说风险更大——生成的产品可能看起来"接近但不完全一致"，导致客户失望。强烈建议对你实际销售的商品使用基于源图像的生成。

**反光或透明产品（玻璃、珠宝、光泽包装）怎么办？**

无论你使用 AI 还是相机，这些产品都是最难拍好的。为了获得最佳效果，请在受控光线下拍摄源照片，以最大程度减少刺眼的反射。Agent 可以在场景中增强反射和透明效果，但当源图像本身已经干净时效果最佳。

**一次订阅可以生成多少张图片？**

使用限制因套餐层级而异。大多数套餐每月支持数百次生成——足以满足活跃的多 SKU 店铺。请查看平台的定价页面了解当前限制。

**我可以用 AI 完全取代我的整个产品摄影流程吗？**

对于次要图像——生活场景、社交媒体变体、电子邮件营销素材——可以。对于在具有严格要求的市场（如 Amazon）上使用的白色背景主图，混合方法更安全：使用真实照片作为合规的主图，使用 AI 生成上下文补充图像。

**Agent 是否支持多个产品的批量处理？**

是的。你可以上传一个产品照片文件夹，并对所有照片应用一个共享的场景提示词。Agent 会依次处理它们，将相同的背景、光线和构图应用于批次中的每个产品。

**如何匹配在不同日期拍摄的产品之间的光线？**

使用一致的场景提示词模板和一致的源照片条件。如果你在晴朗的星期二拍摄产品 A，在阴天的星期五拍摄产品 B，它们的源光线会不同。为了最大程度的一致性，在相同的窗光条件下拍摄同一系列的所有产品，并使用相同的 agent 提示词进行处理。
